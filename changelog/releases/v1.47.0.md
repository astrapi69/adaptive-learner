# Adaptive Learner v1.47.0

**Released**: 2026-06-01

Minor release. **Phase 63 — Lesson Flow Control.** Lessons can now be
paused, abandoned and resumed instead of being all-or-nothing, progress
auto-saves as you go, and oversized imported lessons are split into
digestible chunks. Also folds in touch-capable drag-to-reorder for Word
Tiles, a batch of mobile horizontal-scroll fixes with regression
coverage, content-sharing improvements, and a backend security-header
pass.

## Added

- **Lesson flow control (pause / abandon / resume).** A lesson is no
  longer all-or-nothing. `LessonProgress` gains `paused` / `abandoned`
  states plus `paused_at` / `abandoned_at` timestamps (Phase 63A;
  backend Alembic + Dexie schema, both modes). Leaving an in-progress
  lesson opens an exit dialog offering **Pause**, **Abandon** (with a
  sub-confirmation for the destructive path) or **Continue**; returning
  to a paused lesson offers **Resume** or **Start over** (63B/63C).
- **30-second autosave + auto-resume.** In-progress lessons autosave
  every 30 seconds and on tab-hide (`visibilitychange` / `beforeunload`),
  and auto-resume where you left off when you return to the tab (63E).
- **Dashboard paused-lessons widget.** A `PausedLessonsCard` surfaces
  in-flight paused lessons on the Dashboard with a one-tap resume (63D).
- **Lesson splitter for oversized imports.** Imported lessons that
  exceed a configurable exercise budget (5–20, default tunable in
  Settings) are split into multiple sequential lessons, with a
  cross-language parity test pinning the TS and Python splitters to
  shared golden fixtures (63G–63J). New i18n in all 8 languages.
- **Paused-lesson retention cleanup.** A configurable retention sweep
  clears stale paused lessons, with a Settings control to tune it (63F).
- **Word Tiles: touch-capable drag-to-reorder.** The placed-tile
  reorder UX moved from native HTML5 drag (which never fired on touch
  devices) to `@dnd-kit`, so reordering now works with a finger on
  mobile — the primary use case. A 5px activation distance keeps
  tap-to-remove intact; arrow buttons and keyboard reorder remain as
  accessible fallbacks; `prefers-reduced-motion` is honored.
- **Two-phase exercise step.** Exercise steps now use an explicit
  Check → Continue ("Prüfen" → "Weiter") flow, and answers persist with
  completed steps locked when a lesson is revisited (BUG P1).

## Changed

- **Community sharing is lower-friction.** Sharing a lesson now opens
  the GitHub web new-file PR editor directly (zero-auth), the
  rule-based share validator is informational rather than blocking, and
  a same-language pair is no longer a hard block on Save-as-Lesson.
- **Matching exercise UX.** Clearer selected state, instructions and
  column behavior.

## Fixed

- **Mobile horizontal scroll (P0).** Three real overflow sources fixed
  (Dashboard / Settings / Session) plus a flex-wrap fix for the
  My-Lessons action buttons, behind `overflow-x` guard rails. Backed by
  a no-horizontal-scroll regression spec measuring real authenticated
  pages at 320 / 375 / 414 px across routes, Settings tabs, the badge
  gallery and real lesson content (Dexie release gate).

## Security

- **CSP + security headers on the backend (Phase 61 audit P3).** A new
  middleware attaches `Content-Security-Policy`, `X-Content-Type-Options`,
  `X-Frame-Options` and `Referrer-Policy` to every response. The backend
  is API-only, so the default CSP is a strict `default-src 'none'`; the
  DEBUG-only Swagger / ReDoc / OpenAPI paths get a CDN-aware policy so
  the docs UI still renders.

## Tests / tooling

- The no-horizontal-scroll layout spec now waits for web fonts +
  post-paint (`document.fonts.ready` + double rAF) instead of fixed
  sleeps, removing a class of width-measurement flakiness.

## Related content (separate `adaptive-learner-content` repo)

- Both pilot A1 courses are now full 15-lesson courses in **both source
  languages**: **Spanish A1** and **French A1**, for English speakers
  (`sets/en`) and German speakers (`sets/de`). French A1 for German
  speakers grew from 3 lessons to the full 15 in this cycle.
