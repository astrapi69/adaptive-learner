# Adaptive Learner v1.72.2

Patch release — three P3 code-hygiene items: an inline-style → Tailwind
migration, a proper Anki empty state, and the removal of all frontend
import cycles. Frontend only; no schema, API, or data-model change.

## Changed

- **Import-Detail + Import list migrated to Tailwind + design tokens
  (#275).** The two import pages styled everything with ~52 inline
  `style={{…}}` attributes instead of Tailwind utilities + design tokens,
  against the design-token rule. Replaced with token-backed utilities
  (`px-6`/`max-w-*`/`flex`/`gap-*`, `font-semibold`, `text-fg-muted`,
  `bg-card`, `border-border`, `text-accent`, `border-success/-destructive/
  -warning`, `text-accent-foreground`). The quick-paste textarea now
  inherits the shared global input chrome. No functional change; the only
  remaining inline style is the dynamic analysis progress-fill width.

## Added

- **Anki page empty state (#276).** `/anki` showed only a one-line muted
  paragraph when no cards existed — a near-dead view. It now renders a
  proper empty state: a Layers icon, a title + body explaining how to
  create cards (import a conversation, then "Extract Anki cards"), an
  "Import a conversation" CTA, and — when the active provider has no key —
  the shared API-key-required notice pointing at Settings > Integrations.
  New `anki.empty_title/_body/_cta` strings in all 8 languages.

## Fixed

- **All 3 frontend import cycles resolved (#252).** madge had reported
  three cycles, all type-only back-edges from `storage/types.ts` (the
  IStorageService contract) into implementation modules. The shared TYPE
  shapes were extracted into pure modules so the contract — and
  `api/client.ts` — can name them without importing the code:
  `AiValidationResult` (+ the Ai\*Issue shapes) →
  `lib/content/content-validation-types.ts`; the export-report shapes →
  `storage/export-types.ts`; the 19 request-body DTOs →
  `api/request-types.ts`. Each origin module re-exports its moved types so
  existing imports are unchanged. madge now reports **0** cycles and the
  `check-circular` baseline drops 3 → 0 (ratchet-down only), so any new
  cycle is a hard CI error.
