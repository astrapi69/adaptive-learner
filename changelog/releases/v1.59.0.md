# Adaptive Learner v1.59.0

Minor release — **Learning Path Redesign: a personal path with zoom
levels**. The old `/learning-path` rendered all ~225 lessons as one
graph (unusable); it now answers the learner's real question — *"Wo bin
ich? Was kommt als Nächstes?"* — with a compact, two-level personal
view. No schema or storage changes; both storage modes (API + Dexie /
GitHub-Pages) carry it.

## UX

### Learning Path Redesign — personal path with zoom levels

- **Level 1 — set overview (default):** one compact row per
  *downloaded* set, sorted by last activity (most recent first). Each
  row shows a domain icon + title, a mini progress track
  (● done / ◐ in progress / ○ not started), the percentage, a relative
  last-activity hint ("gestern", "vor 3 Tagen"), the current/next
  lesson, and one context-aware action button —
  **Fortsetzen / Starten / Nächstes Level verfügbar / Abgeschlossen**.
- **Level 2 — lesson detail:** click a set row to expand it inline
  (accordion, no page change). Each lesson shows its number + title,
  stars (0–3, or — if never attempted), per-direction mastery
  (rezeptiv / produktiv, EXP-018), the last-attempt date, and a ▶
  marker on the current lesson. Bottom actions: **Adaptive Lektion
  starten** and **Fehler wiederholen (N)** (the set-wide review queue,
  shown only when errors exist).
- **"Nur meine" / "Alle Sets" filter** toggle plus a collapsible
  **"Nicht heruntergeladen"** section with per-set download buttons.
  Both the view and the filter persist in `localStorage`.
- A completed course offers its **next CEFR level** (e.g. A1 → A2) when
  one exists, downloaded or not.
- **xyflow graph kept as an alternative view**, reachable via a
  **Persönlich / Graph** switch and lazy-loaded only when selected.

### Navigation

- The mobile **hamburger menu moved to the left** side (Tailwind).

## Performance

- **xyflow (~177 KB chunk) removed from the default bundle** — it now
  loads only when the Graph view is selected. The default Learning Path
  chunk is **~21 KB** (was the full xyflow graph).

## Internals

- New pure data layer: `buildPersonalPath` (grouping, last-activity
  sort, action resolution, stars, per-direction mastery, next-level
  detection) + `relativeTime` (`Intl.RelativeTimeFormat`, all 8
  languages, no new dependency), consumed via the `usePersonalPath`
  hook through `getStorage()` so it works in both storage modes.
- The original graph page is renamed `LearningPathGraph`;
  `LearningPathPersonal` is the new default route.
- New `learning_path.*` strings added to all 8 i18n catalogs.
- All Tailwind (no new CSS), 6 themes, 44 px touch targets,
  `prefers-reduced-motion`-safe, reflows cleanly at 375 px.

## Tests

Backend + plugins + Vitest all green via `make test`
(**311 frontend test files / 3365 tests**); the Dexie-mode release gate
green; production build clean (xyflow isolated in the lazy graph
chunk). New coverage: the `buildPersonalPath` + `relativeTime` helpers,
the `SetRow` / `LessonRow` / `SetDetail` / `NotDownloadedSection`
components, the page, and a rewritten Dexie E2E (empty state, set-row
expand → open a lesson, no horizontal overflow at 375 px, and the
Personal → Graph lazy switch).

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads AdaptiveLearner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```
