# Adaptive Learner v1.75.0

Minor release: the TipTap rich-text editor stack is migrated from v2 to v3.
The whole `@tiptap/*` dependency tree moves together in one atomic change,
the Dependabot major-hold is lifted, and two pre-existing/incidental hygiene
issues surfaced during the migration are cleaned up. Frontend + dependencies;
no schema, API, or data-model change.

## Changed

- **TipTap editor stack migrated v2 -> v3 (#311 / #314).** All 23
  `@tiptap/*` packages move from `2.27.2` to `3.26.1` in a single commit
  set. A mixed v2/v3 tree does not compile (v3 extensions require v3 core),
  which is exactly why the prior piecemeal Dependabot bumps failed and the
  major-hold (#305) was put in place. The breaking changes were resolved
  against the *actually installed* 3.26.1 packages (export maps + `.d.ts`),
  not from memory:
  - `TextStyle` and `Table` lost their default export -> named imports.
  - StarterKit v3 now bundles `Link` and `Underline`; both are disabled in
    the editor config so the custom-configured standalone extensions added
    below them do not collide (a duplicate extension name throws at
    construction).
  - `setContent`'s second argument is now an options object:
    `setContent(doc, { emitUpdate: false })`.
  - `NodeViewContent` is generic with a `NoInfer`'d `as` prop:
    `<NodeViewContent<"code"> as="code" />`.
  - `Editor` / `JSONContent` / `NodeViewProps` type imports are unchanged
    (`@tiptap/react` still re-exports them from `@tiptap/core`).

  `tsc --noEmit`, `npm run build` (no `MISSING_EXPORT` - the v1.67/v1.73
  failure mode), **3953 Vitest tests with zero test changes**, and the
  **88-spec `make test-dexie-smoke`** gate are all green.

- **Dependabot `@tiptap/*` major-hold removed (#305 / #306).** With the
  stack on v3, future `@tiptap` minor/patch updates flow via the
  `frontend-minor-patch` group again; a later v4 major arrives as its own
  deliberate PR instead of being silently held.

## Fixed

- **5 `no-useless-assignment` ESLint errors on `main` (#312 / #313).** The
  `@eslint/js` 9 -> 10 bump (#310) added `no-useless-assignment` to
  `eslint:recommended`, which flagged five dead variable initializers
  (`RatingDialog`, `useLesson`, `draft-to-lesson`, `github-api`,
  `content-loader-dexie`) - every reachable path overwrites them before the
  value is read. Dropping the initializers restores the frontend
  `eslint --max-warnings 0` gate to green. Discovered while verifying the
  migration; fixed in its own scoped PR.

- **Editor files restored to the repo's 4-space style (#315).** The
  migration inadvertently committed a whole-file 2-space reformat of
  `RichTextEditor.tsx` and `CodeBlockView.tsx` (the `frontend/` tree has no
  prettier config, so the `prettier-frontend` pre-commit hook runs prettier
  *defaults* and rewrites entire files; CI already skips it). Both files are
  restored to 4-space with only the ~20-line v3 change applied, so they
  match the rest of `frontend/src`.

## Notes
