# Adaptive Learner v1.48.0

**Released**: 2026-06-01

Minor release. **Phase 64 — Community Sharing UX + Smart Lesson
Organization**, landed alongside **Smart Next-Step Suggestions** after
lesson completion. Sharing a lesson you made should feel rewarding, not
bureaucratic: the app now figures out where the lesson belongs, warns
about duplicates, lets you contribute a variation, credits you by name
(if you want), remembers your contributions, and points you at gaps you
could help fill. And when you finish a lesson, it suggests a sensible
next step instead of a dead end.

## Added

- **Smart placement engine.** When you share, the app computes exactly
  where the lesson lands in the content tree
  (`sets/{source}/{target}-{level}/`) and an auto-numbered filename
  (`{nn}-{slug}.json`, the next number after the existing lessons),
  detects a brand-new pair + level ("New set! You're the first."), and
  can auto-detect the target language / level / topic from the cards
  when metadata is incomplete.
- **Duplicate, variation and supplement detection.** Before sharing,
  the lesson is compared (advisory, never blocking) against the lessons
  already in that tree path by card overlap + exercise overlap. A
  similar lesson can be shared **as a variation** (`variation_of` +
  an optional note); a near-duplicate offers **"suggest only the new
  exercises"**, which extracts just the exercises the original lacks.
- **Four-step Share Wizard.** Replaces the one-shot share modal with
  Preview + placement → Duplicate scan → Quality summary → Share, with a
  celebration (confetti + thank-you + a link to the GitHub submission)
  on the final step.
- **Optional author credit.** A "Your name (optional)" field, remembered
  locally for next time, stamps `contributed_by` / `contributed_at` onto
  the shared lesson, shows a muted "Contributed by {name}" line under the
  lesson title in the viewer, and lists the author in the GitHub issue.
- **Contribution history + recognition.** Shared lessons are remembered
  locally (no account) under "My Contributions" with a counter and a
  "Community Contributor" recognition at five shares.
- **Missing-Lessons gap suggestions.** The Set Browser surfaces
  encouraging suggestions ("Can you help?") for the next CEFR level of an
  existing pair, or a target taught for one source language but missing
  for another.
- **Smart Next-Step Suggestions after lesson completion.** The lesson
  summary now proposes a sensible next step — start an adaptive lesson
  from your errors, jump into the review queue, continue to the next
  lesson in the set (or celebrate set completion), and resume awareness
  for paused lessons — via a new `useNextStepSuggestions` hook and a
  themed suggestions card.
- **EXP-021 Lesson Creator exploration.** Documents a future
  `/create-lesson` route to author lessons from scratch (metadata → card
  editor → auto-generated exercises → save/share), reusing the Phase 64
  share wizard. Planning only; implementation deferred.
- New i18n in all 8 languages for every new surface
  (`content.wizard.*`, `content.contributions.*`, `content.gaps.*`,
  `content.credit.*`, `lesson.contributed_by`, `lesson.next_step.*`).

## Changed

- **Content lesson schema 1.2 → 1.3 (additive, backward compatible).**
  `ContentLesson` gains optional `variation_of`, `variation_note`,
  `contributed_by` and `contributed_at`; lessons without them behave
  exactly as before, and the content loader reads older lessons
  unchanged.

## Internal

- New pure, fully-tested modules: `placement-engine.ts`,
  lesson-level detection in `duplicate-detection.ts`,
  `contribution-history.ts` (localStorage), `gap-detector.ts`, and the
  `ShareWizard` component — each covered by Vitest, with the Content page
  share flow rewritten around the wizard. Community-sharing history and
  recognition are deliberately localStorage-only (no Dexie schema bump).
