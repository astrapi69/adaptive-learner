# Adaptive Learner v1.42.0

**Released**: 2026-05-29

Phase 59 — Analysis-to-Lesson Converter + Community Content Sharing.
The chat-import analysis already produced structured insights
(vocabulary, error patterns, summary, suggested curriculum). v1.42.0
turns that data into a complete, replayable **offline lesson** — and
lets learners share the lessons they create with each other and with
the official content repo, entirely without a cloud backend.

## What's new

### Analysis to offline lesson

- A new **"Save as Offline Lesson"** action on a finished chat
  analysis (`/import/{id}`) generates a full lesson from the analysis
  and saves it for offline play.
- The generator (`lib/content/analysis-to-lesson.ts`, with a Python
  mirror for API mode) is deterministic and offline — no AI calls.
  Theory steps come from topic / summary / subtopics / strengths /
  weaknesses / error patterns / suggested curriculum; exercises come
  from the extracted vocabulary (matching + free-text from
  word/translation, cloze + word-tiles from example sentences).
- Lesson quality scales with the analysis: rich vocabulary yields all
  four exercise types; a thin analysis yields a theory-only study
  guide with a note suggesting a longer chat.
- Generated lessons validate against the existing lesson schema (v1.1)
  and play in the unmodified viewer with full scoring.

### My Lessons

- The Content Browser (`/content`) gains a **"My Lessons"** section
  listing your user-generated lessons separately from downloaded sets,
  each labelled by origin (from analysis / from adaptive lesson /
  imported), with **Play**, **Edit**, **Delete**, **Export** and
  **Share** actions, plus an empty state.
- Stored as a local content set (`source: "user-generated"`) in the
  same cache as downloaded sets — IndexedDB in Dexie mode, the
  filesystem cache in API mode. Local only; never synced.

### Sharing + community contribution

- **Export** a lesson as a standalone JSON file, or **Export as set**
  as a content-set ZIP (manifest + lessons). Exports carry zero user
  data — clean content only.
- **Share with Community** opens a pre-filled GitHub issue on the
  content repo so a maintainer can review and add the lesson. A social
  contribution pathway that needs only GitHub — no cloud backend, no
  account, no auto-publish.
- **Import Lesson** accepts a `.json` lesson or `.zip` set, validates
  it against the schema (with specific error messages), previews it,
  and saves it to My Lessons. This closes the loop: one learner
  exports, another imports and plays — fully offline.

### Save adaptive lessons

- After completing an adaptive lesson, a **"Save this lesson?"** button
  snapshots it into My Lessons for replay. The snapshot is
  self-contained and stays playable even if the adaptive generator
  changes later.
