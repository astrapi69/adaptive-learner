# Adaptive Learner v2.11.0

Your learning progress is now anchored to stable identities instead of the exercise content itself. On the first start after this update a one-time local migration re-keys existing progress - nothing to do on your side. Your progress is preserved, and from now on content corrections (a fixed typo in an answer, a reordered exercise) no longer orphan your review cards.

Matching exercises look different. The useless hint is gone, help now sits in the button row, and the progress counter moved to the top. If you know the exercise, you will notice.

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads the ready-built AdaptiveLearner image from GitHub's registry (about 110-120 MB compressed, roughly 500 MB on disk - nothing is built on your machine), and opens the app in your browser. Later starts are fast and work offline.

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

**macOS blocks the binary on first open** and, depending on the macOS
version, offers only "Move to Trash" and "Done" - no Open button. The
program is not notarized by Apple (that needs a paid developer account).
Dismiss with **Done**, then open **System Settings > Privacy & Security**,
scroll down and click **Open Anyway**. Windows shows a SmartScreen notice
with a "More info" > "Run anyway" path. Full walkthrough per platform:
[installation overview](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/en/installation.md).

Verify the checksum first. When the system cannot tell you where a file
came from, a matching checksum is the check you can still make yourself.

## What's new

### Your learning progress now survives content updates

Progress and spaced-repetition scheduling are keyed to stable exercise identities instead of the exercise content (#2455). A one-time local migration runs on first start; author-retired exercises archive their progress instead of silently dropping it (#2458). The set-update guard now OFFERS to carry progress over when identities moved, instead of only announcing the loss (#2309), and knows every exercise type from one shared rule (#2305). Recovery resolves rows under both the old and the new identity (#2469).

### Matching exercises, reworked

The useless hint is gone; help lives in the instruction row and "How it works" sits in the top button row next to "Re-read theory" (#2448, #2454). The progress counter moved to the top (footer on mobile), and the mobile preamble collapses behind a disclosure (#2414). Hints scaffold the partner instead of revealing the full pair (#2394); knowledge sets no longer show the wrong term/definition subtitle (#2408).

### Discover: find your next set in a growing library

The content browser gained a staged discovery surface (EXP-048): a target-language facet with domain labels and clean empty-state exits (#2327), two entry points with a source facet and language-name search (#2332), batched rendering (#2334), typo-tolerant ranked search (#2338), a language-pair matrix as an alternative entry (#2339), and a collapsible source-grouped language-pair selection (#2360).
