# Adaptive Learner v1.70.1

Patch release — onboarding, assessment, content-browser and landing
UX fixes. No schema, API or data changes; frontend only.

## Fixed

- **Onboarding wizard step height** (#169). The optional profile
  wizard rendered each of its five steps at a different height, so the
  panel visibly jumped on every "Next" / "Back". The step area now has
  a uniform minimum height (taller on mobile, where the timeframe
  options stack into one column), so stepping through is shift-free.
- **Assessment dead-ends** (#171). The first assessment question's
  "Previous" button was disabled, leaving no way out but answering all
  twelve questions, and the browser back button dropped the learner
  onto the onboarding name/topic form (which looked like the
  just-created project was lost). The first step now offers a
  **"Continue later"** exit — the assessment is resumable, so progress
  is kept — and leaving onboarding after the project is created no
  longer leaves a stale form in the browser history.
- **Documentation link opened in the same tab** (#173). The landing
  screen's "Read the documentation" link now opens in a new tab
  (`rel="noopener noreferrer"`), so reading the docs no longer drops
  the learner out of the app.
- **Onboarding tab order** (#175). Tabbing from the **Name** field
  jumped to the Topic "?" help icon instead of the **Topic** input,
  because the icon sits between the two fields in the DOM. The help
  icon is now out of the tab order (still clickable; the same term is
  reachable via the intro tooltip), so Tab flows Name → Topic.
- **Content Browser button visibility in dark themes** (#177). The
  secondary action buttons next to the search field (Import Lesson /
  Import Chat / Learning Path) and the "Recommended books" toggle used
  the surface-less `ghost` button variant and read as nearly invisible
  on dark backgrounds. They now use the bordered `outline` variant —
  the app's established secondary-action style — which stays legible
  (WCAG AA) across all twelve themes, light and dark.

The new "Continue later" assessment string is translated in the eight
supported languages (DE, EN, ES, FR, EL, PT, TR, JA).
