# Adaptive Learner v1.74.0

Maintenance / infrastructure release on top of v1.73.0's feature-strategy work
- CI hardening, the ESLint warning debt cleared, and the TipTap dependency tree
reconciled. Frontend tooling + CI + dependencies; no schema, API, or data-model
change.

## Added

- **Dexie-smoke E2E CI workflow (#301, #302).** The Dexie-mode Playwright
  release gate (`make test-dexie-smoke`) now runs in CI on push / PR, not only
  locally - so a feature that crashes in the GitHub-Pages-shape build is caught
  before merge instead of after deploy.

## Changed

- **ESLint warning debt cleared, gate tightened to zero (#220, #292).** The 438
  pre-existing ESLint warnings are resolved and the gate is set to
  `--max-warnings 0`, so the `Frontend Tests` CI job is green again (it had been
  red since the ESLint flat-config landed in v1.72.0, forcing admin-merges all
  through the v1.73.0 cycle).
- **TipTap reconciled to a consistent v2 tree (#304) + held there (#306).** The
  whole `@tiptap/*` stack is realigned on `2.27.2` - extending v1.73.0's
  three-extension pin to `starter-kit` and every sibling Dependabot had bumped
  toward v3 - and Dependabot is configured to hold `@tiptap` major bumps so the
  v2/v3 `MISSING_EXPORT` skew cannot recur.
- **CI installs frontend deps with `--legacy-peer-deps` (#293, #294).** Matches
  the lockfile's resolution mode (a pre-existing `eslint-plugin-react` vs
  ESLint 10 peer conflict), so `npm ci` in CI stops failing on the peer graph.
- **Dependency bumps (Dependabot):** `@astrapi69/feature-strategy` 0.1.1,
  `@types/node` 25, `@vitejs/plugin-react` 6, `@eslint/js` 10, backend `ruff`
  (backend-minor-patch), and the frontend-minor-patch groups (#295-#300,
  #307-#310).

## Notes

- Visual-regression baselines regenerated against the bumped dependency set and
  verified stable across repeated runs.
