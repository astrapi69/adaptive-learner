# Adaptive Learner v1.34.0

**Released**: 2026-05-28

Phase 51 — **Content Expansion: French A1 + Spanish A1 +
GH-Pages bundling**. The first release where Adaptive Learner
ships a real learning experience out of the box: 15 A1-level
language lessons across two pairs, bundled into the GitHub
Pages build so first-time visitors see lessons immediately
without any external content repo.

## Why this release

v1.27.0 (Phase 43) shipped the content-loader infrastructure
— manifest parser, lesson schema, exercise renderers, Dexie
cache, the Set Browser page. v1.30.0–v1.32.0 added the SRS
loop + the storage abstraction. The infrastructure was
complete; the content was not. The pilot held two French A1
lessons (greetings + numbers) — enough to demonstrate the
exercise types, nowhere near enough for someone to actually
learn a language.

v1.34.0 fixes the content gap. The release ships:

- **8 new French A1 lessons** (3-10): articles, être/avoir,
  self-introduction, family, colors + clothing, restaurant,
  directions, passé composé.
- **5 new Spanish A1 lessons**: greetings, numbers + telling
  time, articles + gender, ser/estar (the central A1
  challenge), restaurant.
- **Build-time bundling** of both pilot sets into
  ``frontend/public/content/``, so the GH-Pages deployment
  is fully self-contained.
- **A bugfix** along the way: session + lesson headers
  weren't showing topic or set context — users had no
  visual indication of WHAT they were learning. Fixed.

Total content: **15 lessons**, ~3 hours of A1-level study
material, all four exercise types represented in every
lesson, pedagogically progressive (later lessons build on
earlier vocabulary + grammar in the same set).

## What changed

### Added

#### Phase 51A — French A1: 8 new lessons (3-10)

Expands ``docs/explorations/sample-content/fr-a1/`` from 2
lessons to 10. Each lesson: 3-5 theory steps + 8-12 exercises
mixing all 4 exercise types, 10-15 estimated minutes, 12-20
cards with pronunciation + grammar notes.

- **03-articles**: definite (le/la/l'/les) + indefinite
  (un/une/des) + the elision rule. 13 cards.
- **04-etre-avoir**: present tense conjugation of être +
  avoir, tu/vous formality, idioms (J'ai faim). 20 cards.
- **05-se-presenter**: four-piece introduction (name + age
  + nationality + profession), no-article rule for
  professions after être. 13 cards.
- **06-famille**: family vocabulary + mon/ma/mes
  possessives, including mon-before-feminine-vowel. 12 cards.
- **07-couleurs-vetements**: color agreement (m/f/sg/pl),
  invariable colors (rouge, jaune, orange), irregular
  blanc → blanche, clothing number traps (pantalon
  singular, chaussures plural, chapeau → chapeaux). 13 cards.
- **08-au-restaurant**: ordering, polite expressions,
  food vocabulary with look-alikes (poisson vs poison,
  vin vs vingt). 13 cards.
- **09-directions**: location prepositions, direction verbs,
  asking phrases (Excusez-moi, où est ___ ?). 14 cards.
- **10-passe-compose**: regular -er verbs in the passé
  composé, j'ai + past participle, negation pattern. 12 cards.

Manifests updated: set version 1.0.0 → 1.1.0, lesson_count
2 → 10, all 8 new filenames added to metadata.lessons.

#### Phase 51B — Spanish A1 pilot set (5 lessons)

New set at ``docs/explorations/sample-content/es-a1/``.

- **01-saludos**: greetings (Hola, Buenos días), inverted
  ¡/¿ punctuation, basic introduction. 12 cards.
- **02-numeros-hora**: numbers 1-15 + 20, days of the week
  (lowercase + masculine), telling time (Es la una / Son
  las dos). 21 cards.
- **03-articulos-genero**: el/la/los/las + un/una/unos/unas,
  the reliable -o/-a gender rule, exceptions (la mano,
  el día, el agua). 14 cards.
- **04-ser-estar**: the A1 challenge. Both conjugation
  tables, the "could-this-change" decision rule, side-by-side
  worked examples (identity vs state). 14 cards.
- **05-restaurante**: ordering (Quisiera), polite
  expressions (¡Buen provecho!), menu vocabulary, ser/estar
  callback (Está bueno vs Es bueno). 14 cards.

#### Phase 51C — Content authoring guide (EN + DE)

New developer-docs page at
``docs/help/{en,de}/developer/authoring-content.md``, wired
into the help system's ``_meta.yaml`` so it surfaces in both
the in-app help drawer and the public MkDocs site. Sections:
file layout, manifest format, lesson schema, the four
exercise types with examples, 12-item quality checklist,
local-test commands, PR workflow, common pitfalls,
references to the pilot sets. ~250 lines per language.

#### Phase 51D — Default sources + bundled pilot content

- New ``frontend/scripts/copy-bundled-content.mjs``: build
  hook that copies ``docs/explorations/sample-content/{fr,es}-a1/``
  to ``frontend/public/content/`` so the Vite build ships
  both pilot sets as static assets. Wired into ``predev`` +
  ``prebuild`` npm scripts; zero new dependencies.
- ``content-loader-dexie.ts``: new ``bundled:`` source
  prefix. ``rawUrl()`` resolves ``bundled:{key}`` to
  ``${BASE_URL}content/{key}/{path}`` (Vite static-asset
  path, respects ``VITE_BASE`` so the GH-Pages deployment
  under ``/adaptive-learner/`` works). GitHub-source URLs
  (no prefix) keep the existing ``raw.githubusercontent.com``
  behaviour.
- ``DEFAULT_SOURCES`` order: bundled sources first
  (``bundled:fr-a1``, ``bundled:es-a1``), then the canonical
  upstream (``astrapi69/adaptive-learner-content``). The
  bundled sources guarantee something to show on first
  load; the upstream picks up any newer or community-added
  sets the bundle hasn't shipped.
- Graceful fallback: each source is tried independently;
  a missing bundle (dev mode without the build step) or
  an offline upstream falls through to the next source.
- ``.gitignore``: ``frontend/public/content/`` (regenerated
  on every build, canonical source in ``docs/explorations/``).

#### New schema-validation test

``plugins/adaptive-learner-plugin-content-loader/tests/test_pilot_content.py``:
parametrized pytest that discovers every lesson JSON under
``docs/explorations/sample-content/*/sets/*/lessons/`` via
glob and validates each against the v1.0 schema. Adding
future lessons picks up automatically — no test edit needed.
+31 pytest cases (15 schema validations + 15 exercise-variety
+ 1 non-empty-tree guard).

### Fixed

#### Session + Lesson headers missing topic / set context

User-reported gap: the session header showed only
"Lernsession" / "Learning session" + provider chip + cycle
counter — no indication of WHAT was being learned.
Multi-tab learners couldn't tell at a glance which project /
which set was open in each tab.

- ``Session.tsx``: new ``project`` state populated by
  ``getStorage().projects.get(session.project_id)`` on
  mount + resume. New ``<p class="session-header-topic">``
  below the heading shows ``Topic: ${project.topic}``.
- ``Lesson.tsx``: new ``setTitle`` state populated via
  ``getStorage().contentLoader.listSets()`` filtered by
  setId. New ``<p class="lesson-header-set">`` above the
  heading shows ``Set: ${setTitle}``.
- Both lines degrade silently if the fetch fails or the
  data isn't available.
- New i18n keys ``session.topic_label`` + ``lesson.set_label``
  added to all 8 catalogs.
- New CSS classes ``.session-header-topic`` +
  ``.lesson-header-set`` (muted color, smaller font).
- New test IDs ``session-header-topic`` +
  ``lesson-header-set``.

## Architectural decisions

Phase 51 added two:

| ID | Decision | Rationale |
|----|----------|-----------|
| **D-CONTENT-BUNDLING** | Bundled pilot content as static assets in ``frontend/public/content/``, copied at build time from ``docs/explorations/``. Canonical source stays in ``docs/``; the bundle is a derived artefact and gitignored. | Option (ii) per the kickoff. Lowest code change; content stays in one canonical place; no duplication in the frontend tree. |
| **D-BUNDLED-PREFIX** | Source identifiers can carry a ``bundled:`` prefix. ``rawUrl()`` dispatches: prefix → static-asset path, no prefix → ``raw.githubusercontent.com``. | Minimal API surface change. Existing GitHub-source code paths are untouched. Adding a third source kind later (HTTP server, IPFS) follows the same dispatch pattern. |
