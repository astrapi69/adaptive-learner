# Adaptive Learner v1.53.1

Patch release - bug fixes only. No schema, data-model, or migration
changes; both storage modes (API + Dexie) unaffected.

## Fixed

- **Single two-phase button on the Adaptive Lesson and Review pages.**
  Both pages showed two buttons at once during an exercise - the
  exercise's own "Prüfen" (Check) submit AND the page's "Weiter" (Next)
  nav button - because they rendered the exercise uncontrolled. They now
  use the same controlled single button as the main lesson viewer: one
  button that grades on "Check", then flips to "Weiter". (The main
  Lesson page was already correct; the defect was only on these two
  routes.)
- **Community sharing via pull request now works for lessons of any
  size.** Realistic single lessons (whose JSON exceeded the create-file
  URL cap) fell back to GitHub's upload page pointed at a set directory
  that does not exist yet for a brand-new set - so the lesson file could
  never be placed and the PR had no file. Single lessons now always use
  the create-file flow (which creates the new nested path and auto-forks
  for non-collaborators); the content is pre-filled when it fits,
  otherwise the file is downloaded so you can paste it into the editor.
  Multi-lesson sets keep the drag-and-drop upload flow. New
  "paste" instructions localised in all 8 languages.

## Verified + regression-pinned (no behaviour change)

- **Analysis context survives session resume.** When you continue a
  session started from an imported, analysed chat ("Sitzung fortsetzen"),
  the analysis (topic, weaknesses, vocabulary, ...) is still sent to the
  AI. This was already implemented end-to-end; v1.53.1 adds a regression
  test that pins the resume path so it cannot silently break.
- **Navigation collapses to a hamburger during lessons.** On the lesson,
  review, and adaptive-lesson screens the top navigation shrinks to a
  hamburger-only bar (links move behind the drawer) at any width, so the
  lesson reclaims vertical space. Verified; covered by existing tests.
