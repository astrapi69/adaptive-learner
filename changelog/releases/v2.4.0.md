# Adaptive Learner v2.4.0

A feature release on top of the v2.3.0 polish-and-consolidation release. The
headline is a **Create-Lesson authoring upgrade**: a knowledge lesson can be
built from pasted textbook text, an author can edit an existing own lesson and
combine several own lessons into a set, and card images are uploaded instead of
hand-typed as asset paths. Alongside it, **free-text exercises accept multiple
answers and offer an AI second opinion** on a wrong answer, the **AI settings
tab links straight into key import** (with paste-content import and a reactive
refresh), and the content engine is **re-pinned to 0.13.0 (schema 1.8)** so
uploaded images feed `picture_choice` exercises. Under the hood, the **frontend
god-file burn-down is completed** (ten oversized modules split by concern behind
tightened size/complexity ratchets) and a **content-load robustness sweep**
hardens lesson loading (unicode/umlaut card ids, a friendly load-error message,
a missing-profile guard). No app-side schema/API/data-model change; the engine
schema bump 1.7 -> 1.8 is additive and backward-compatible.

## Added

- **Knowledge lesson from pasted textbook text (#1743).** The Create-Lesson
  wizard can turn pasted textbook prose into a complete knowledge lesson, so a
  learner can author study content without an external source repo (#1745).
- **Edit and combine own lessons (#1740 / #1741).** An own lesson can be edited
  after creation, and several own lessons can be combined into a single set
  (#1752).
- **Card image upload (#1763).** Cards take an uploaded image instead of a
  hand-typed asset path; the uploaded image is wired through to the exercise
  (#1764).
- **Typeable exercise count (#1760).** The Create-Lesson exercise count is a
  direct number input instead of stepper-only (#1761).
- **Free-text multiple accepted answers + AI second opinion (#1803).** The
  wizard accepts several correct answers per free-text exercise, and a wrong
  answer can request an AI second opinion instead of a flat "incorrect".
- **AI key-import shortcuts (#1765).** The AI settings tab links directly to
  key import, supports paste-content import, and refreshes reactively after a
  key changes (#1769).
- **Engine 0.13.0 / schema 1.8 (#1770).** Re-pin to `learn-content-engine`
  0.13.0; uploaded images now feed `picture_choice` exercises (#1774). Additive,
  backward-compatible.
- **i18n script-sanity lint (#1755).** A `verify-i18n-scripts` gate flags
  substitute-spelling forms in the German catalog and latin transliteration in
  the Greek/Hindi catalogs, plus a legacy de/hi catalog cleanup (#1758 / #1759).

## Changed

- **Frontend god-file burn-down completed.** Ten oversized modules split by
  concern with the suite kept green: `Session.tsx` (#1804), `ImportDetail.tsx`
  (#1799 / #1750), `Lesson.tsx` (#1790), `Content.tsx` (#1793),
  `dexie-storage.ts` (#1786), `content-loader-dexie.ts` (#1780),
  `sync-engine.ts` (#1795), `backup.ts` (#1806), `ClozeExercise` (#1782), and
  `WordTilesExercise` (#1776). Size/complexity ratchets were tightened after the
  burn-down (#1801 / #1802), with direct hook pins added for `useWordTilesDnd`
  (#1792).
- **Docker / Bun close-out (#1771 / #1492).** The broken production frontend
  image and dev compose are repaired and the docs swept, finishing the Bun
  package-manager migration (#1772).
- **Versionless help index pages (#1766).** Help index pages drop
  feature-provenance version markers, guarded by an extended `verify_docs` gate
  (#1768).
- **Visual baselines refreshed (#1779).** 15 stale theme-matrix baselines
  regenerated (#1784).
- **Dependencies.** Frontend minor/patch group (29 updates, #1749) and the
  backend minor/patch dev group (#1748).

## Fixed

- **Content loading is robust to authored content.** Unicode/umlaut card ids
  and tags are accepted (e.g. `waehrung` / `praesenz`-style ids, #1808 / #1809);
  a lesson that fails to load shows a friendly error instead of failing silently
  (#1824 / #1826); marking a lesson complete no longer dies silently when there
  is no learner profile (#1787 / #1788).
- **Content lifecycle leaves no ghosts.** The availability oracle requires a
  cached set rather than a bare index entry (#1816 / #1818), deleting a set
  cleans up its progress (opt-in) and purges the service-worker lesson cache
  (#1819 / #1825), and repo-removal opt-in delete now works in server mode
  (#1821 / #1822).
- **Settings.** Key-vault import works in server mode (#1812 / #1813), opening
  key import/export scrolls to the key-vault section (#1773 / #1775), toggle-row
  checkbox sizes are unified (#1817 / #1823), and the applied template card
  shows a pressed state (#1756 / #1757).
- **i18n.** Catalog fetch retries with a capped backoff instead of failing on a
  transient blip (#1810 / #1811); native-script book-lesson strings are restored
  in 7 catalogs (#1753 / #1754).
- **Paths.** Snap-sandbox XDG directories are ignored so the data dir resolves
  to the stable real home (#1814 / #1815).
