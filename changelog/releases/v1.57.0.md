# Adaptive Learner v1.57.0

Minor release — **community PR automation + Content Browser search**,
on top of the continuing **Tailwind/shadcn migration (Phase D)** and a
big **psychology content** expansion. CCW's in-flight work (Exercise
Renderers) lands in a later release.

## Features

### GitHub PR automation for community sharing

Sharing a lesson with the community no longer opens a pre-filled GitHub
URL and hopes the content survives (URL-length limits + browser
differences regularly left contributors with an empty PR). The app now
creates the pull request **programmatically**:

- **fork** the content repo (idempotent — reuses an existing fork) ->
  **commit** the lesson JSON at the correct tree path -> open the
  **pull request** fork -> upstream, with a best-effort manifest listing
  update.
- Works in **both storage modes**: API mode proxies through a new
  `/api/github/*` backend (the token never leaves the server); Dexie /
  GitHub-Pages mode runs the same flow browser-direct against
  `api.github.com`.
- The ShareWizard shows phased progress and a "Pull request created!"
  state with the PR link. **Graceful degradation** is preserved: no
  token, a multi-lesson set, or any GitHub failure falls back to the
  existing pre-filled-URL flow (failures surface a friendly, classified
  message + a "share manually" button).

### GitHub token in Settings > Integrations

A new **Integrations** tab stores a GitHub Personal Access Token
(`repo` scope): instant format validation (`ghp_` / `github_pat_`), a
**Test** button that verifies the token and shows the connected
username, a source line (secrets.yaml / environment / browser) and a
Remove button. The token is **Fernet-encrypted in `secrets.yaml`** in
API mode (sibling of the AI-provider keys) and held in the browser in
Dexie mode; an env-managed token is read-only in the UI.

### Content Browser search

A full-width search bar above the `/content` tree, with **instant,
debounced (300 ms)** client-side filtering over the cached library:

- searches set titles / descriptions / domain + lesson titles + card
  fronts/backs + tags
- **case-insensitive, diacritic-insensitive, German-digraph aware**
  (`francais` finds "Français", `gruesse` finds "Grüße")
- results replace the tree (non-matches hidden), matched text is
  highlighted, with a result count and an empty state; each lesson
  result opens the lesson
- **Cmd / Ctrl + K** focuses the search; a clear (X) restores the tree
- the index is built **lazily on first interaction** from the
  content-loader cache (no network, no backend, no new dependency), so
  the browse-only path stays cheap

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads AdaptiveLearner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```
