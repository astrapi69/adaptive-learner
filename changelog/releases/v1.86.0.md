# Adaptive Learner v1.86.0

A feature release on top of v1.85.0: the two largest threads are **EXP-033 —
AI Content Validation** (set-wide AI quality checks with a signed, cached,
badge-surfaced report) and **EXP-029 — Media Integration** (companion media
per lesson/domain under a reciprocity gate). Plus a cluster of review-flow and
mobile fixes, the i18n completion of the repository-management UI, and a large
documentation/governance pass. No schema or data-model change.

20 substantive commits.

## Added

- **EXP-033 — AI Content Validation.** Content authors and learners can have a
  whole set checked by an AI using their own API key (no server). Set-wide
  batched prompt + structured JSON parser (#676), a "Check with AI" action with
  a per-batch progress + findings report UI (#683), the report cached in
  IndexedDB with a Markdown export (#687), and a content-hash + signature +
  "AI-Checked" badge so a completed check is verifiable and survives re-open
  (#691). Open follow-ups: the CI action `ai_review.py`, set-wide auto-fix, and
  signature invalidation on content change.
- **EXP-029 — Media Integration with a reciprocity principle.** Lessons and
  domains can carry companion media (videos, podcasts, articles, books,
  courses, websites) via a `media.yaml` parser + loader with a reciprocity gate
  (free media always allowed; commercial courses/websites only with proven
  partnership, fail-closed), a "Vertiefe das Thema" lesson section with
  `ResourceCard`, media-availability badges on set rows, and offline-aware
  YouTube thumbnails (#688).
- **Settings "Check for updates" button.** An active update check in
  Settings → About, alongside the rebuilt PWA update banner (#669).
- **Auto-focus in text exercises.** Cloze and Free-Text inputs focus on mount,
  so the learner can type immediately (#693).

## Fixed

- **P1 — Review badge did not decrease after a session (#675).** Synthesised
  review steps now carry the source `lesson_id`, so the SRS rows reschedule and
  the review-queue badge counts down correctly (closes #673).
- **P1 — Duplicate questions in SRS review (#665).** The review queue collapses
  duplicate questions and reconciles the counts.
- **P1 — Mobile hamburger drawer would not close on iPhone (#667).** The
  navigation drawer now closes on link tap, Escape, and outside click.
- **P2 — Repository-management UI not translated (#662).** The content-repository
  management surface is translated across all 9 catalogs (52 keys).
- **P2 — Greek i18n stray placeholder (#702).** Removed the stray `{das}`
  placeholder in the Greek `content.ai_check.progress` string.
- **CI gates red on develop (#689).** `content-loader-dexie.ts` exceeded the
  1000-line file-size gate (the EXP-033 AI concern split into
  `content-loader-dexie-ai.ts`) and `Content.tsx` exceeded the complexity gate
  (baselined, behaviour-preserving) (#704).

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads AdaptiveLearner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

If your operating system warns about an unsigned binary, see the [AdaptiveLearner installation overview](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/installation.md).
