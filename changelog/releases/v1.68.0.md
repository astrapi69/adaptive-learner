# Adaptive Learner v1.68.0

Minor release — lesson-result export and theory back-links, a
matched-pair visual overhaul, and a cluster of dark-mode contrast fixes.

## Added

- **Export lesson results for AI-assisted practice** (#138). The lesson
  summary screen gains **Copy result** and **Save as file**. Both build
  a Markdown report — score, each wrong exercise with the learner's
  answer and the correct answer, and the still-unmastered weak areas —
  so a learner can paste it into an AI assistant (Claude, ChatGPT) and
  drill the weak spots. Copy uses the clipboard; save downloads
  `lesson-result-<slug>-<date>.md`. Both storage modes.
- **Re-read the relevant theory from an exercise** (#140). An exercise
  step shows a subtle "Re-read theory" link that jumps to the nearest
  preceding theory step in the same lesson; the theory step then offers
  "Back to exercise" to return exactly where you were. Runtime-derived
  from the lesson's step order — no content change required.

## Changed

- **Matched pairs are visually connected** (#145). Both tiles of a pair
  now share a distinct color (drawn from the per-theme categorical chart
  palette) **and** a matching number badge, so the pairing is
  unambiguous and conveyed redundantly — not by color alone — for
  color-blind learners.
- **Matching adapts to the lesson domain** (#149). A knowledge lesson
  (a non-language domain, or a set whose source and target are the same
  language) no longer shows translation-specific wording: it uses
  neutral Term / Definition column labels, drops the "German → German"
  language display, and a "match each term with its definition"
  instruction.
- **Read-aloud no longer changes the panel** (#147). Reading a theory
  step aloud used to replace the rendered Markdown with a plain-text
  follow-along, dropping headings, lists, bold and code. It now only
  plays audio; the formatted panel stays put.
- **Search + exercise polish** (#143). The search icon moved to the
  right of the search field, and matching / word-tile cards in a row now
  share a uniform height.
- **AI-assistance credit** in Settings → About → Credits, naming Claude
  (Anthropic) for architecture, code, content and documentation —
  transparency for users and other developers.

## Fixed

- **Dark-mode invisible text.** Button-styled link anchors
  (`<Button asChild>` + a router `<Link>`) kept their own variant text
  color instead of the global accent color, which could put accent text
  on an accent background (#146). Outline and ghost buttons — including
  the lesson "Previous" button — now set an explicit foreground color so
  they no longer fall back to black on a dark surface (#148).

All new strings are translated in the eight supported languages.
