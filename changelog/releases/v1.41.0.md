# Adaptive Learner v1.41.0

**Released**: 2026-05-29

Phase 58 — **UX/UI Audit + Multi-Theme System**. Manual testing
surfaced significant dark-mode visibility problems (many components had
only ever been built in light mode). This release audits every page,
fixes the root causes, and ships a proper **six-theme** system with an
automatic OS-following mode. Closes the F1 dark-mode token bug and folds
in an accessibility re-audit plus a critical Dexie-upgrade fix.

## What's new

### Six themes + auto

Pick a theme in **Settings > General > Appearance** from a preview card:

- **Light** (default), **Dark**, **Ocean** (deep blue, night-calm),
  **Forest** (earthy green/amber), **High Contrast** (accessibility-first
  black/white/signal colors), **Sepia** (warm paper, book-like).
- **Auto (System)** follows your OS light/dark setting and switches live.

The switch is **instant** (no reload), your choice is remembered, and the
theme is applied **before the first paint** so there's no flash of the
wrong theme on load. Every theme is authored to **WCAG 2.1 AA** contrast.

### Complete semantic color system

- A full canonical token set — backgrounds, text, borders, interactive
  surfaces, accent, status pairs, exercise feedback, charts, star, and
  shadows — is defined per theme in `frontend/src/styles/themes/theme-*.css`.
- Fixes a long-standing class of dark-mode bug: ~10 tokens (e.g.
  `--info`, `--warning-bg`, `--text`) were referenced but never defined,
  so they silently rendered **light** colors in dark mode (light-blue
  Dashboard banner, black text on a dark sync modal, etc.).
- Charts (Recharts) now recolor per theme — axis, grid, tooltip, and
  series read the active theme's tokens and update on a theme switch.
- All five exercise types, the lesson summary, celebrations, star
  ratings, and badge tiers use dedicated `--exercise-*` / `--star`
  tokens so feedback stays legible in every theme.

### Accessibility re-audit (WCAG 2.1 AA)

- Re-audited the components shipped since v1.24.0 across all themes.
- Content download status is now announced to screen readers
  (`aria-live`); a global keyboard-focus baseline guarantees a visible
  focus ring in every theme (including a high-vis ring in High Contrast).
- Full audit: `docs/audits/wcag-2026-05-29.md`.

## Fixed

- **Dexie database closed on /import for v1.40.0 users.** The schema-v21
  (badge-tier) upgrade did a dynamic `import()` inside the IndexedDB
  upgrade transaction; that finished the transaction early, so the
  upgrade aborted and every later read failed with `DatabaseClosedError`
  ("Importierte Konversationen konnten nicht geladen werden."). The badge
  catalog data was extracted to a dependency-free module and imported
  statically. The fix is self-healing — affected users re-run the
  upgrade successfully on the next load.
- Content-loader no longer spams the production console when the
  not-yet-published upstream content repo 404s (the bundled lessons load
  regardless); the diagnostic is kept for Developer Mode.

## Changed

- Dependencies refreshed to the latest **in-range** versions (backend
  resolution). Held back for a dedicated session: **mypy 2.0** (major)
  and **anthropic 0.105** (a large 0.x SDK jump). Frontend was already
  current.
