# Adaptive Learner v1.55.0

A foundation + feature release: **Tailwind CSS v4.3.0 + shadcn/ui** are
adopted as the styling framework (Phase A, additive), and the **Error
Replay** feature lets learners retry only the exercises they got wrong.

## Highlights

### CSS framework: Tailwind CSS v4.3.0 + shadcn/ui (Phase A)
- **Additive install, incremental migration.** Tailwind is installed and
  configured now; existing components are migrated **when touched**, not in
  a Big Bang rewrite. No existing component was restyled in this release.
- **The 6 themes keep working — Tailwind CONSUMES them.** Tailwind v4 is
  configured CSS-first (an `@theme` block in
  `frontend/src/styles/tailwind.css`) that maps utilities onto the existing
  CSS variables (`bg-accent` → `var(--accent)`, `text-fg-primary` →
  `var(--fg-primary)`, `rounded-app` → `var(--radius-md)`, …). Switching
  `[data-theme]` flips the variables, so every Tailwind utility recolors
  automatically across light / dark / ocean / forest / high-contrast /
  sepia.
- **Existing pages stay pixel-identical.** Preflight (Tailwind's reset) is
  intentionally not imported, and all Tailwind output is in cascade layers
  while `global.css` + the theme sheets are unlayered — so unlayered rules
  always win. Verified: the bundle ships no Tailwind reset, the JS bundle is
  unchanged, and the Dexie route-walk renders every page cleanly.
- **shadcn/ui base wired** (`components.json`, the `cn()` helper at
  `@/lib/utils`, the `@/*` path alias, and `clsx` / `tailwind-merge` /
  `class-variance-authority`). No components are installed yet —
  `npx shadcn@latest add <component>` is ready for future use; the shadcn
  semantic-token bridge lands with the first component.
- **`LessonStickyFooter`** is the proof-of-concept (first component written
  entirely in Tailwind utilities; pinned by a Vitest spec).
- **Architecture rules updated** (`.claude/rules/architecture.md` +
  `coding-standards.md` + `CLAUDE.md`) so Tailwind/shadcn is the sanctioned
  approach for new code, with the full guide at
  `docs/development/tailwind-migration.md`.

### Error Replay — "Fehler wiederholen"
- After finishing a lesson, retry **only the exercises you got wrong**
  instead of the whole lesson. New `/error-replay/:setSlug/:setId/:filename`
  route + `ErrorReplayLesson` page + `frontend/src/lib/lesson/error-replay.ts`.
- **Priority-aware next-step suggestions:** at 0–1 stars, error replay is
  surfaced as the PRIMARY next step (you fix mistakes before moving on);
  higher scores promote the usual next-lesson / review suggestions.
- Full i18n in all 8 languages.

### Other
- **TTS read-aloud** for lesson cards.
- **Stryker** frontend mutation testing wired (nightly, opt-in).
- Carries forward the content library: **10 sets / 200 lessons / 3 domains**
  (shipped in v1.54.0).
