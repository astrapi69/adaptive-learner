# Adaptive Learner v1.95.0

A learning-modes release on top of v1.94.1. The headline is a full
**lesson-mode system** — a lesson (or a whole set) can now be played as
**Practice**, **Exam**, **Timed (Auf Zeit)**, or **Zufall (interleaved
shuffle)**, plus gated **"Fehler trainieren"** entry points — built on a
pure config-object architecture so every exercise/help component reads
mode *flags* instead of branching on a mode string. Exam mode adds
delayed feedback, a dedicated end-of-exam result view, a pass/fail
verdict, and a 1.5x XP bonus; the chosen mode is persisted on the
attempt. Alongside: My-answer/Solution reveal toggles on two more
exercise types, GitHub-repo set **export** (the missing half of repo
sharing), and a substantial launcher overhaul (single persistent window,
verbose cleanup, Windows/Linux fixes).

**Schema change:** Alembic `0033` adds an additive `lesson_mode` column
to `LessonProgress` (`server_default 'practice'`, non-indexed — no Dexie
schema-version bump). Old attempts read back as `practice`; every
existing flow and test is unaffected.

## Added

- **Lesson modes — Practice & Exam (#1007 / #1008).** A lesson plays in
  one of several modes, framed from learning research. **Practice** keeps
  every aid on (low pressure); **Exam** hides the aids (the testing
  effect — retrieve under realistic conditions): hints, "Re-read theory",
  TTS / auto-read, the solution/My-answer toggles, and the celebration
  layer are all gated off via a `LessonMode` context (no deep prop
  threading). A segmented control at the top of the lesson selects the
  mode, seeded from a new default-mode setting and **locked once the run
  is under way**. Default is `practice`, so Review, Adaptive-Lesson, and
  every existing flow are unchanged.
- **Timed mode — "Auf Zeit" (#1009 / #1010).** A per-question countdown
  with immediate feedback and aids on: per-exercise-type limits (matching
  8s/pair, cloze 20s, word-tiles 30s, free-text 90s, picture-choice 15s)
  scaled by a difficulty multiplier (relaxed 2x / normal / fast 0.7x), a
  +5s correct-answer bonus, a colour-shifting `LessonCountdownBar` (green
  → yellow → red), a timeout that records the question wrong and
  auto-advances, and an end-of-run timing summary.
- **Zufall mode — interleaved set shuffle (#1014 / #1026).** Mixes the
  exercises of every lesson in a set (Fisher-Yates, never more than 3
  consecutive from the same lesson, capped at 20), recording each attempt
  through the same SRS path as Review so a correct answer levels the card
  up. New `/shuffle-lesson/:setId` player, pure deterministic builder
  (`shuffle-lesson.ts`, injectable RNG, 9 unit specs).
- **Exam delayed feedback (#1007 / #1037).** In exam mode the runner
  hides per-question correctness until the end: a single forward button
  that submits **and** advances in one click, forward-only (no Previous)
  until completion; the Enter shortcut mirrors it. Practice/Timed flows
  are unchanged.
- **Dedicated end-of-exam result view (#1007 / #1039).** A prominent
  `LessonExamResult` panel at the top of the summary in exam mode:
  passed/not-passed verdict vs the configured threshold, score
  (correct/total + %), time, and XP earned with the exam-bonus note, plus
  a "Retry exam" button that restarts as a fresh attempt carrying the
  persisted mode.
- **Persist lesson mode + mode-weighted XP (#1030 / #1033).** The mode is
  stored on the attempt (Alembic 0033) and weights the lesson-XP award
  (exam 1.5x, timed/reverse 1.25x), composed with the streak multiplier
  in a byte-identical expression across the Python and TypeScript
  calculators.
- **"Fehler trainieren" entry points per lesson + set (#1012 / #1025).** A
  reusable, gated `TrainErrorsButton` into the adaptive lesson, rendered
  only when the in-scope active error-card count is >= 1 (hide-when-empty,
  matching the sibling surfaces). A per-lesson button trains only that
  lesson's errors (`?lesson=` scope); the set-wide button replaces the
  previously ungated link that dead-ended on an empty adaptive screen.
- **My-answer / Solution reveal toggle on more exercises** — word-tiles
  (#1005 / #1006) and free-text (#1019 / #1020), matching the Matching
  exercise toggle from v1.94.0 (and gated off in exam mode).
- **Export a set to a GitHub repository (#1017 / #1018).** The missing
  EXPORT half of repo sharing: a "Share as repository" dialog serialises a
  set + its lessons into the official content-repo format (manifest.yaml,
  `lessons/NN-slug.json` verbatim, search-index.json, generated README)
  and pushes it in a single commit via the Git Data API. The exported repo
  is immediately importable as a content source. Browser-direct in Dexie
  mode; ApiStorage returns a clear "browser mode" message (server-side
  push is a tracked follow-up).
- **Launcher: single persistent window is the sole GUI entry point
  everywhere (#1045).** One never-self-closing window backs the launcher
  on every path; progress, errors, and success render in place.
- **Launcher: live install streaming + auto-rebuild + tray + verbose
  uninstall.** Install progress streams live in the window (#992 / #996);
  the image auto-rebuilds on start so a `git pull` is picked up (#999 /
  #1000); the window minimises to the system tray (#987 / #988); uninstall
  is verbose with an install manifest and a startup cleanup offer (#1041 /
  #1042 / #1043 / #1044).

## Changed

- **Config-object lesson-mode infrastructure (#1011 / #1016).** Generalises
  the mode system into pure data: `lessonModeConfig.ts` defines a
  `LessonModeConfig` per mode (7 modes defined, practice/exam/timed/shuffle
  wired); `useLessonMode()` returns the active config and consumers read
  flags (`showHints`, `immediateFeedback`, `showAnswerToggle`,
  `showTheoryRecap`, `showReadAloud`) instead of branching on the mode
  string. Mode labels + the 4 new names added to i18n in all 11 languages.
- **Reusability audit — decouple two cards from app types (#1021 / #1022).**
- **CI back to green — ratchet baselines + ruff-format drift (#1034 /
  #1035).**

## Fixed

- **Launcher startup cleanup — verbose per-step output (#1052).** The
  cleanup offer now emits a line for every step: a discovery count per
  category (containers / images / volumes / config remnants), a per-artifact
  ✓/✗ result with the freed size on images (e.g. `✓ (245 MB)`), actual
  removal of stale config dirs (previously offered but never deleted; the
  learner's data dir is never targeted), and a closing summary (artefacts
  removed + space freed + a "Lerndaten beibehalten" note).
- **Mode toggle enabled on a fresh lesson (#1027 / #1028).**
- **System tray works on Ubuntu Linux (#1003 / #1004).**
- **Content-loader list always surfaces downloaded sets from the cache
  (#1001 / #1002).**
- **PWA: `/api/` is NetworkOnly so server-mode sets don't disappear (#997 /
  #998).**
- **nginx `client_max_body_size` raised to 50M (#994 / #995).**
- **Launcher window widened so the button row never clips (#991 / #993).**

## Tests / Tooling

  `--debug` and captures timestamped logs under `launcher/logs/`
  (combined stdout/stderr + an archived per-run `launcher-debug.log`) for
  later analysis; extra flags via `ARGS`.
- Per-feature visual screenshot baselines + a subdir path fix (#1023 /
  #1024 / #1029); the per-feature screenshot rule anchored in the project
