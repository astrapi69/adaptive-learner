# Adaptive Learner v1.60.0

Minor release — **lesson-reading UX, the Learning Path Achievement Map,
the Tailwind exercise-renderer migration, a help-glossary performance
win, and the B1 content roadmap completed**. No schema or storage
changes; both storage modes (API + Dexie / GitHub-Pages) carry it.

## UX

### Auto-hide header during lessons

- While reading a lesson, scrolling **down** slides the sticky top nav
  up out of view (more reading space); scrolling **up** — or returning
  to the top — slides it back in. Scoped to the active learning surfaces
  (`/lesson`, `/review`, `/adaptive-lesson`, `/error-replay`); every
  other page is untouched.
- New `useScrollDirection()` hook tracks up/down/top within the `#root`
  scroll container with a 10 px threshold (ignores trackpad jitter). The
  nav hides via a Tailwind transform (`-translate-y-full` +
  `transition-transform duration-300 motion-reduce:transition-none`), so
  the slide is `prefers-reduced-motion`-safe (instant hide/show) and
  causes no layout shift (the nav is already `position: sticky`). It
  never hides while the menu drawer is open, and the bottom sticky
  lesson action (Prüfen / Weiter) stays visible at all times.
- `useIsLessonActive` now also covers `/error-replay/`, which also gives
  that surface the existing compact-nav treatment.

### Learning Path — Achievement Map view

- A new **Map** view groups the learner's progress by **domain**
  (`LearningPathMap`), giving a bird's-eye overview of mastery across
  the library alongside the per-set detail.
- The Learning Path now offers **three views: Persönlich / Map / Graph**,
  switchable in-page (the xyflow graph stays lazy-loaded).

### Settings — responsive buttons

- Settings secondary actions become **icon-only on mobile** (icon + text
  from `md` up), consistent with the Dashboard and Content Browser
  toolbars.

## Tailwind

- **All five exercise renderers migrated to Tailwind** — PictureChoice,
  Matching, FreeText, Cloze, WordTiles. The app is now **~85–90 % on
  Tailwind**.
- **Post-Tailwind theme audit** (`docs/audits/theme-review-post-tailwind.md`):
  43-token parity verified across all 6 themes, and the Dialog overlay
  is themed (token-driven) instead of a hard-coded scrim.
- **Dead CSS removed** after the migration (e.g. `xp-widget`,
  `api-key-last-test`; `docs/audits/shared-css-cleanup-post-exercise.md`).

## Performance

- **Help glossary lazy-loaded per language.** English stays eagerly
  bundled (the lingua-franca fallback, keeps the lookup API synchronous
  and never-null); the other seven languages are lazy per-language
  chunks loaded on demand via `loadGlossaryLanguage` + a new
  `useGlossary` hook. The main `index` chunk dropped **731.71 → 449.51 KB
  (gzip 244.87 → 138.44 KB, −106 KB gzip)**; the help content moved to 28
  on-demand chunks (~7–16 KB each), so a non-EN user fetches only their
  own language (~16 KB gzip). Closes `PERF-HELP-GLOSSARY-LAZY-01` (audit
  F-3).

## Fixed

- **Domain-content import (`IMPORT-LANG-PIPELINE-SELECT-MIGRATION-01`):**
  a chat imported as same-language material (German grammar for German
  speakers, source == target) is now auto-detected as **knowledge**
  (non-language) content. The Save flow stamps the content domain on the
  lesson (schema v1.3) and the Share Wizard inherits the same-language
  pair as intentional domain content instead of repairing it as a legacy
  `en/en` mistake — so it shares without a same-language error. The
  previously-skipped E2E `import-language-pipeline` variant 2 (de → de)
  is **un-fixme'd** and green.
- **Share Wizard async timing (Dexie mode):** the wizard mounts before
  the lessons load (the share page fetches them asynchronously), so a
  same-language domain pair lost its inherited target. A re-apply effect
  restores the pair once the knowledge-domain lesson arrives.
- **mypy:** `github_service._base_sha` returned an `Any` from a `-> str`
  function (`no-any-return`); cast to `str`.

## Content

- **B1 roadmap complete.** Three new B1 courses for German speakers —
  **de → es B1**, **de → en B1**, and **de → fr B1**, 15 lessons each
  (Subjuntivo / Condicional / Pasiva / Estilo Indirecto; Present Perfect
  / Conditionals II + III / Reported Speech; and the French B1 parallel),
  so de → en, de → es and de → fr now each ship a full **A1 → A2 → B1**
  progression.
- Content library now at **271 lessons across 13 sets** (~66 h of
  estimated study time): 9 German-source language courses (A1–B1 ×
  es/en/fr), en → es A1, en → fr A1, the 90-lesson Psychologie course,
  and Python Grundlagen.
