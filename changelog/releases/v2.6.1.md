# Adaptive Learner v2.6.1

A patch release on top of the v2.6.0 feature release. There is no new app
feature and NO app-side schema/API/data-model change against v2.6.0. The
substance is the desktop launcher: the shipped launcher engine advances two
steps (docker-app-launcher 0.14.1 -> 0.15.0 -> 0.16.0), a frozen-binary
packaging bug is fixed, and the localized launcher UI reaches the binary for
the first time. The rest is documentation (a canonical feature-overview page,
launcher/Docker guide translations, the #1918 mirror-locale port) plus one
user-facing i18n string fix and an E2E hardening.

## Changed

- **Localized launcher UI now ships in the binary (#2031 / #2032).** The
  hand-maintained PyInstaller spec never collected the docker-app-launcher
  package data, so every frozen build to date shipped WITHOUT the 11 i18n
  catalogs and fell back to raw/default strings. The spec now bundles
  `collect_data_files("docker_app_launcher")`, so the launcher UI renders in
  the user's language from the binary. Consumer half of docker-app-launcher
  #34.
- **Launcher engine: docker-app-launcher 0.15.0 then 0.16.0 (#2024 / #2025,
  #2031 / #2032).** 0.15.0 brings the Docker-permission self-repair and
  wait-for-Docker fixes: a permission-denied Docker socket now reads as a
  dedicated "can fix" branch (offering a verified `pkexec usermod` self-repair)
  instead of the generic "Docker is not started" message, and the frontends
  poll `wait_for_docker` after starting Docker Desktop. 0.16.0 adds the runtime
  app-version About line, the version-everywhere/About surface, uninstall
  confirmation + window-geometry memory, and distinct cleanup labels.

## Fixed

- **Frozen launcher binary: correct window title, branding, and config
  (#2027 / #2028).** The one-file binary showed the package-default "My App"
  window title, because in the frozen entry module `__file__` is
  `_MEIPASS/__main__.py` (no package subdirectory), so the launcher.json path
  escaped the bundle and the fail-open config loader silently used all-defaults.
  `_config_path()` now prefers `sys._MEIPASS/launcher.json` when frozen; a
  standalone frozen run chdirs to the bundle root so the config-relative window
  icon resolves (a CWD that carries the compose stack keeps priority); and the
  spec bundles the branding mark at its real config-relative path. Four
  regression tests pin the frozen layout.
- **Create-Lesson: knowledge-lesson template card mentions the file upload
  (#2018).** The "Knowledge lesson from text" template card still said "Paste a
  textbook section..." while the step it opens has offered a book-file upload
  (EPUB/DOCX/TXT/MD) with a section picker since #1927/#1953. The card
  description now reads "paste or load a book file" across all 11 backend
  catalogs (native translations) and the frontend fallback + synced catalogs.

## Docs

- **Canonical feature-overview page (#2019).** A new
  `docs/help/{en,de}/features/overview.md` lists every major user-facing
  capability in 11 theme clusters (learning core, AI tutor chat, the
  6-core/5-extension exercise types, lessons + mechanics, authoring,
  import/analysis, content management, gamification, exports/backup, platform,
  accessibility), present-tense and version-free, cross-linked to the
  per-feature detail pages; the README "What you get" clusters become pointers
  to it. Fixes the drift where the READMEs missed several v2.6.0 headlines and
  still claimed 8 UI languages (actual: 11).
- **README: the launcher drives Docker, it is not Docker-free (#2020 / #2021).**
  The Install section no longer claims "No Docker, no terminal needed"; it now
  says the launcher drives Docker for you (no manual Docker/Compose commands)
  while Docker itself must be installed and running.
- **Launcher + Docker-Desktop guides translated (#2022 / #2023).** The
  per-platform launcher and Docker-Desktop start guides are translated into
  es/fr/el/pt/tr/ja.
- **#1918 mirror-locale port (#2033).** The feature overview, the my-lessons
  edit path, and the CI section are ported into el/es/fr/ja/pt/tr.
- **Device-verification guide for the Docker-permission fix (#2026)** and a new
  Branding section for the frozen-binary check.
- **Two error classes codified in the rules (#2029 / #2030):** an engine re-pin
  needs the schema mirror regenerated in the same PR (`make sync-schema`); and
  frozen-only behaviour is proven on the real built artifact, not the
  source-tree run. Both surfaced during the v2.6.0 release run.
