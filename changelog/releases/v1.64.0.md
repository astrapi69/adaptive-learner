# Adaptive Learner v1.64.0

Minor release — **onboarding overhaul**: a two-field quick start plus an
**optional, one-question-per-screen profile wizard** that makes the
assessment opt-in instead of mandatory. Carries three conformance fixes
(a single-scrollbar viewport fix, a WCAG accent-as-text contrast pin,
and a lesson sticky-footer stability fix). No schema change; both
storage modes (API + Dexie / GitHub-Pages) carry everything.

## Added

- **Optional onboarding wizard** (#94): after the quick start, a
  "set up your learning profile in more detail?" invite leads either
  straight to the Dashboard ("Jump right in") or into a new
  one-question-per-screen wizard (`OnboardingWizard.tsx`) — goal,
  timeframe (4w / 3m / semester / flexible), daily minutes (5–60),
  current problem, then an opt-in "Start the assessment?" finish. Every
  step is pre-filled with a sensible default so "Next" always advances,
  shows a progress bar, and has a Back button. The wizard persists its
  answers via `getStorage().projects.update`, so it works in both
  storage modes.

## Changed

- **Onboarding now requires only two fields** (#92): the quick-start
  form asks for **name + topic** only; goal, timeframe, daily minutes,
  and current problem all take defaults (the wizard above is where a
  learner can refine them). This removes the previous wall of optional
  fields on first run.
- **The assessment is now optional.** Onboarding no longer forces a
  jump to `/assessment`; the profile-less Dashboard handles an
  empty-state user, and the assessment is reachable from the wizard's
  final step (Yes) when the learner wants it.

## Fixed

- **Content Browser single scrollbar** (#42): tall pages could surface a
  second vertical scrollbar. The viewport elements set only
  `overflow-x: hidden`, which forces `overflow-y` to compute as `auto` —
  turning both `html` and `body` into scroll containers on top of
  `#root`. Locking both axes on `html` / `body` (`overflow: hidden`)
  keeps `#root` (`overflow-y: auto`, `height: 100%`) the single app
  scroller, so every page shows exactly one scrollbar; the horizontal
  mobile guard is preserved. Regression pin asserts the invariant.
- **Lesson sticky footer pinned across steps** (#43): the lesson
  player's Prev / Check / Next footer (`sticky bottom-0`) floated
  mid-screen on short steps and jumped vertically when the next step's
  content height differed. The lesson page now fills the viewport
  (`flex flex-col min-h-full`) and the step grows to absorb the slack
  (`flex-auto`), so the footer stays flush with the viewport bottom on
  every step. Tailwind-only (no `global.css` change). Regression pin:
  `e2e/dexie/lesson-footer-stability.spec.ts`.
- **WCAG contrast pin for accent-as-text** (#96): the contrast suite
  (`styles/contrast.test.ts`) did not cover `--accent` used as text, and
  catppuccin-mocha's accent on `bg-elevated` measured 4.49 (a hair under
  AA). Added a contrast pin for accent-as-text (≥4.5:1 on
  bg-primary/surface, ≥3:1 on bg-elevated) and nudged catppuccin-mocha
  via `scripts/generate_preset_themes.py` so all 12 themes pass
  computationally.
