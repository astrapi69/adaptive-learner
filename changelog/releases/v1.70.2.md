# Adaptive Learner v1.70.2

Patch release — theme contrast and Matching-exercise fixes. Frontend
only; no schema, API or data changes.

## Fixed

- **Secondary buttons invisible in the soft-pop theme** (#179). A
  contrast sweep of every shadcn button-variant across all 12 themes
  found one failure: the `secondary` variant rendered white text on
  soft-pop's vivid teal `--bg-secondary` (1.86:1). soft-pop's secondary
  surface is corrected to a readable dark tone, fixing every secondary
  button and badge at once (the lesson-result CTAs included). The
  contrast test now pins **every** button-variant colour pair across all
  12 themes, so a variant that drops below AA fails the build.
- **Red removed from Matching pair colours** (#181). Matched (correct)
  pairs cycled through the shared chart palette, where several themes
  carry a red — and red universally reads as "wrong", which was
  confusing for a *correct* match. Matching pairs now draw from a
  dedicated, red-free palette (blue / green / orange / purple / teal /
  yellow / pink); the data charts keep their own palette unchanged.
- **Matching result state now distinguishes correct and wrong pairs**
  (#183). After checking, the per-pair number badges no longer vanish,
  correct pairs are clearly **green on both tiles**, wrong pairs are
  clearly **red on both tiles** and show the **correct partner** as a
  hint, and unmatched tiles stay neutral. Red here is correct error
  feedback (distinct from the now-forbidden red *pair* colour). New
  per-theme feedback tokens are WCAG-AA verified across all 12 themes.

The new Matching "Correct: …" hint string is translated in the eight
supported languages (DE, EN, ES, FR, EL, PT, TR, JA).
