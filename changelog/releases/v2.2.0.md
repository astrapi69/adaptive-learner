# Adaptive Learner v2.2.0

A feature release on top of the v2.1.0 polish release. The headline is the
**extension-exercise tier**: four new AI-authored exercise types adopted from
the content engine, plus a first-class native `multiple_choice`. Alongside it,
**the app becomes a schema consumer** of `learn-content-engine` (engine-owned
`$id`, generated schema + TypeScript types), a **federated content-repo
registry** with a register-a-repo flow, a **simpler mobile navigation** (the
bottom tab bar is gone), and the **EXP-044 CSS-cascade repair** that layers the
`global.css` component debt below Tailwind utilities. This is the first release
since v2.0.0 with schema changes — they are **additive and backward-compatible**
(1.5 -> 1.6 -> 1.7). Tooling: Playwright upgraded to 1.61.1 (Ubuntu 26.04) and
Bun adopted as the package manager. Content library grew to **499 lessons /
35 sets / 6 domains**.

## Added

- **Extension-exercise tier (#1579).** Four new exercise types, adopted from
  the content engine's extension mechanism, each with its own renderer, grader,
  and dispatcher entry: `ext:al-categorization` (#1591),
  `ext:al-error-correction` (#1593), `ext:al-reading-comprehension` (#1603),
  and `ext:al-graded-quiz` (#1616). An extension-tier load guard refuses any
  lesson that declares an unsupported extension type at load time, rather than
  rendering a broken exercise (#1566).
- **Native `multiple_choice` exercise (#1525).** A first-class
  single-correct-answer type with its own renderer, grader, and dispatcher
  wiring (schema 1.6). Authoring-guide notes cover multiple_choice coexistence
  with the existing types in all languages (#1539).
- **Federated content-repository registry (#1511).** The content hub consumes a
  federated registry of community content repositories and gains a
  register-a-repo flow, with an actionable error when the registration pull
  request is rejected (#1514).
- **Per-set share link + Share button (#1572).** Every content set can be shared
  by a direct deep link, and the App-Tutorial gains a deep link from
  Settings > About (#1574).
- **`matching` from cards (#1523).** Matching exercises can be generated from a
  lesson's cards, mirrored from the content-engine schema.

## Changed

- **The app is now a schema consumer of `learn-content-engine`.** The engine
  owns the canonical `$id` and emits the lesson JSON-Schema and TypeScript
  types; the app consumes them instead of maintaining its own
  (#1517 / #1519 Phase 0+2, #1521 / #1522 D1b). The lesson schema advanced
  1.5 -> 1.6 (native multiple_choice) -> 1.7 (extension tier); the engine pin
  moved forward across the cycle to `learn-content-engine@0.12.0`
  (#1553 / #1564 / #1605), with the generated layers regenerated on each step.
  All schema changes are additive and backward-compatible.
- **Simpler mobile navigation.** The mobile bottom tab bar is removed — the
  hamburger drawer is the single mobile navigation (#1512). The Contribute nav
  entry is dropped and its "missing lessons" surface folded into `/content`
  (#1494 / #1495), with the `/content` gap list replaced by a static About
  block (#1504 / #1505).
- **EXP-044: CSS-cascade repair (one legacy layer).** A new `@layer legacy`,
  declared before the Tailwind utilities, so utilities reliably win over legacy
  component rules (Option A of the EXP-044 plan, #1485). Ships a pre-wrap
  conflict-audit tool (`scripts/check-legacy-wrap-conflicts.py`, #1576), the
  Tranche 0+1 legacy layer + dead-selector purge + dead-classname gate (#1497),
  and Tranches 2a/2b/2c wrapping the audit-CLEAN component blocks into the layer
  (#1568 / #1578 / #1588 / #1613 / #1583 / #1585 / #1584), plus the NavGroup
  `hideLabel` component fix and the audit blind-spot closure
  (legacy-vs-unlayered-legacy precedence, #1592 / #1598). A `global.css` size
  ratchet keeps the file from regrowing (#1467).
- **Playwright upgraded to 1.61.1.** The maintainer machine runs Ubuntu 26.04,
  where the previous pin cannot install a browser; the package and the five CI
  container tags moved to `v1.61.1-noble`, and the visual baselines were
  re-rendered under it (#1594 / #1596 / #1601 / #1602 / #1604 / #1606).
- **Bun adopted as the package manager.** The frontend (Phase 1, #1496) and the
  e2e workspace (Phase 2, #1551) install and run through Bun.
- **CI: frontend-only PRs skip the backend work.** A path-detection gate lets
  the backend / plugin / lint jobs skip their steps on frontend-only changes
  (#1617); the advisory extra-smoke defaults to opt-in (#1477).
- **Content library grew to 499 lessons / 35 sets / 6 domains** (#1531 / #1534).

## Fixed

- **Grading correctness.** Word-tiles now grades the composed token sequence
  rather than tile indices, so a correct arrangement built from duplicate tiles
  is accepted (#1544 / #1545). Free-text sentence answers stop failing on
  punctuation, curly quotes, and whitespace differences (#1580 / #1581).
- **iOS input handling.** The viewport carries `maximum-scale` / `user-scalable`
  to suppress the #1569 caret/touch hit-test desync on an installed iPhone PWA,
  a deliberate revision of the #1353 stance (#1610); the `ios-zoom-guard` vitest
  guard was realigned with that documented trade-off (#1614).
- **Visual-regression flake.** The `lesson-matching@mobile` capture flake is
  closed by pinning the `.lesson-header h1` line-height plus a small residual
  tolerance (#1540 / #1618); deterministic data anchors + a settle retry landed
  earlier in the cycle (#1554 / #1541).
- **Settings and i18n.** The learning-repo load effect no longer clobbers edits
  on an identity change (#1486); the duplicate "Sprache" heading collision is
  resolved and the SRS heading moved under `settings.*` (#1461); the
  error-report textarea uses token-backed background and text colors (#1490);
  the Learning-tab profile test id is corrected (#1460); the General + AI tabs
  get the standard tabpanel spacing (#1484), and the Settings inline styles
  migrate to token-backed Tailwind utilities (#1476 / #1482).
- **Content and invites.** Invite-code fetches route through the CORS-safe host
  weiche (#1439); the content-repo extension-tier load guard refuses
  undeclared-support lessons (#1566).
- **CI hygiene.** The Playwright-container nightlies install Bun via npm (the
  noble image lacks the `unzip` that `setup-bun` needs, #1530); Dependabot no
  longer opens individual `@playwright/test` bumps for `/e2e` (#1582 / #1586).
