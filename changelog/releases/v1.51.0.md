# Adaptive Learner v1.51.0

Minor release shipping the **Visual Learning Path** (Phase 66 /
EXP-022) — an interactive map of every lesson across all your content
sets — alongside a **Dexie-mode backup overhaul** that closes a silent
data-loss bug and adds a real save-to-disk experience.

## Highlights

### Visual Learning Path (`/learning-path`)
- An interactive, zoomable graph of all lessons across every set,
  built with `@xyflow/react`.
- **Custom lesson nodes** showing mastery state (green / yellow / grey),
  star rating, and receptive / productive direction indicators.
- **Set group nodes** with per-set progress bars; collapsible to keep
  large paths readable.
- **Auto-layout** via `dagre` so the graph arranges itself.
- **Recommended next lesson**: a pulsing accent node sourced from the
  adaptive generator points you at the best thing to do next.
- **Error-cluster overlay** (toggle) surfaces your weakness patterns
  directly on the map.
- **Filter** by set / status / direction and **search** to highlight
  matching nodes.
- **Stats sidebar**: lessons, mastery, streak, XP at a glance.
- **Context menu** per node: start the lesson, start an adaptive
  lesson, or open details.
- **Keyboard navigation** and screen-reader accessible; renders in all
  6 themes.
- **Lazy-loaded** via `React.lazy` (~100 KB) so it never weighs down
  the rest of the app.

### Backup: save-to-disk for Dexie mode (BACKUP-DIR-EXPORT-01)
- **Save to disk** via the File System Access API (`showSaveFilePicker`):
  on Chromium browsers you choose exactly where the backup file lands
  through the native OS dialog; Firefox / Safari fall back to a normal
  download, and a dismissed dialog is treated as cancelled.
- **"Your backup contains"** preview: a read-only summary of record
  counts (error entries, lesson progress, badges, sessions, projects,
  chat imports) plus a total, so you know what a backup holds before
  you save it.

### Backup: data-loss fix — 10 missing Dexie tables (BACKUP-DIR-EXPORT-01)
- The Dexie-mode (GitHub Pages) backup had drifted to 20 tables while
  the backend sync surface grew to 30. A browser-mode export **silently
  dropped every gamification (XP / badges / streaks), lesson-progress,
  SRS element-error, missions, anki, and study-question row** — the file
  looked complete but lost the user's actual learning state.
- The Dexie export now covers the full 30-table sync surface, and a
  local backup → restore round-trip brings progress back.
- Filed **BACKUP-API-RESTORE-01** (P1): the backend `_RESTORE_ORDER`
  has the mirror-image gap (restores 18 of 30 exported tables); tracked
  for a follow-up.

## Notes
- New i18n strings ship in all 8 languages (DE, EN, ES, FR, EL, PT, TR,
  JA), German with real umlauts.
- No schema or migration changes; the backup file format is unchanged
  (the Dexie export simply stopped omitting tables it already knew how
  to restore).
- Restore-from-file, the last-backup indicator, the 7-day reminder, and
  auto-backup were already shipped (Phase 15C / 25) and were adapted,
  not rebuilt.
- New frontend dependencies for the Learning Path: `@xyflow/react`
  and `dagre`.
