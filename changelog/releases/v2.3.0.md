# Adaptive Learner v2.3.0

A polish-and-consolidation release on top of the v2.2.0 feature release. The
headline is the **completed EXP-044 CSS concern-split**: the monolithic
`global.css` is decomposed byte-identically into per-concern legacy files and
becomes a pure import manifest, guarded by a byte-identity gate — the
CSS-cascade repair that started in v2.2.0 is now complete. Alongside it, a
**lesson-player UX rework** (collapsible options panel, pause control in the
footer, slimmer title area), **listen-first audio exercises**, an
**adaptive-generator upgrade** (authored difficulty as cold-start prior), and a
**hardened lesson/set file import/export**. A large fix sweep covers the
Create-Lesson wizard, content-browser visibility in Dexie mode, and
accessibility. No schema/API/data-model change against v2.2.0.

## Added

- **Listen-first audio exercises (#1600).** `free_text` and `matching`
  exercises can lead with audio: the learner hears the prompt before seeing
  it, training listening comprehension ahead of reading (#1687).
- **Adaptive lessons use authored difficulty (#1599).** A lesson author's
  `card.difficulty` (1-5) now seeds the adaptive generator as a cold-start
  prior, so the first adaptive lesson is sensibly ordered before any error
  history exists (#1683).
- **Hardened lesson/set file import/export (#1672).** Importing lesson/set
  files now handles id collisions, survives partial imports, and enforces a
  size guard; the Create-Lesson wizard gains a "Save as file" export
  (#1681 / #1685).
- **Shared UI primitives (#1629 Half A).** A generic `Tile` surface component
  (#1714) and a `FormHint` component (#1720) replace the scattered `.tile` /
  `.form-hint` legacy CSS consumers.
- **Discover: always-visible source-language chip (#1699).** The
  source-language filter surfaces as a visible chip instead of hiding in a
  menu (#1701).

## Changed

- **EXP-044 concern-split complete.** `global.css` is split byte-identically
  into per-concern files under `styles/legacy/` — Peels 1-5 (head/`:root`
  tokens, base resets, buttons, landing, onboarding: #1663 / #1670 / #1675 /
  #1680 / #1682) followed by Batches A-E (assessment/dashboard/session,
  QR/rating/settings/progress, navigation/celebration/curriculum,
  diff/animations/mobile/export/editor, gamification..learning-path:
  #1684 / #1686 / #1688 / #1689 / #1690) — leaving `global.css` a pure import
  manifest. A byte-identity gate proves each step changes nothing in the
  emitted CSS (#1657), an accepted-conflicts allowlist scopes the legacy-wrap
  audit (#1630), and the last entangled zone (QR scanner + lesson-mode nav)
  is wrapped into `@layer legacy`, completing the v2.2.0 cascade repair
  (#1592 / #1695). The lesson-header/summary block was wrapped earlier in the
  cycle (#1634).
- **Lesson player UX rework.** The lesson header controls are bundled into a
  collapsible options panel (#1625 / #1628), the pause control moves from the
  header into the sticky footer (#1642 / #1644), the title area shrinks and
  the in-lesson description is dropped for more exercise space
  (#1633 / #1635), and the duplicate favorite button on the summary is
  removed (#1648 / #1649).
- **CI gates.** Backend/plugin/lint jobs already skipped on frontend-only PRs;
  the symmetric gate now also skips the frontend-tests steps on pure-backend
  PRs (#1659). Visual-critical PRs are gated on accompanying visual-baseline
  updates (#1640 / #1641), and `forceRerunTriggers` closes the `readFileSync`
  blind spot of selective Vitest (#1673).
- **`learn-content-engine` re-pinned 0.12.0 -> 0.12.3** for the browser-safe
  entry point (#1678).
- **Visual baselines.** All 51 FeatureShot screenshots regenerated with
  deterministic anchors (#1567 / #1726); lesson/content baselines refreshed
  across the cycle (#1639 / #1643 / #1654 / #1694 / #1704).

## Fixed

- **Create-Lesson wizard sweep.** Step 1 is redesigned and the outdated
  same-language block dropped (#1715 / #1721); steps 2-4 get a consistent
  layout (#1732 / #1737); the structure-check failure now names its reason and
  the inline card edit is guarded (#1722 / #1724); template cards no longer
  render raw i18n keys (#1667 / #1674); and the stale `languagePair` entry in
  `BOOLEAN_CHECK_KEYS` that disabled the Save button is removed
  (#1729 / #1730).
- **Content visibility in Dexie mode.** Deleted sets stay deleted across a
  Refresh in "Meine Inhalte" (#1709 / #1719), cached sets from unconfigured
  sources surface again (#1731 / #1734), the graded-quiz demo reference set is
  hidden from Discover + My Content (#1702 / #1706), and book recommendations
  come from the federated registry instead of the removed official
  `books.yaml` (#1712 / #1717). The remove-repo dialog names the keep-progress
  default (#1651 / #1652).
- **Adaptive generation.** Card-less exercise types no longer crash the
  adaptive pool builder (#1636 / #1637), and a context-free `"___"` cloze is
  declined in favor of a replay instead of showing a blank-only exercise
  (#1668 / #1669).
- **Accessibility.** The skip-to-content label was invisible — the
  content-link rule is demoted via `:where()` so the utility classes win
  (#1723 / #1727).
- **Exercises and i18n.** `codeMode` is passed into ClozeExercise grading, so
  code clozes grade whitespace/case-correctly (#1595 / #1700); the no-provider
  `t()` respects an explicit empty-string fallback (#1676 / #1703).
- **Deploy.** The bundled `content/` directory serves a real SPA shell, fixing
  deep links into it on the static deployment (#1713 / #1718).
