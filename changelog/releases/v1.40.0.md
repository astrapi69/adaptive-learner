# Adaptive Learner v1.40.0

**Released**: 2026-05-29

Phase 57 — **Badge Tiers + Badge Gallery** (EXP-010 follow-up,
deferred from v1.39.0). Badges stop being flat: every progression
badge now carries a **bronze / silver / gold** tier, there's a
**gallery** to browse them all, and tier-coloured icons make progress
tangible. Closes P-158, D-127, F-129, Q-122.

## What's new

### Badge tiers (bronze / silver / gold)

- All 28 shipped badge keys are **kept** — no merge, no removal, no
  data loss. Two tier shapes:
  - **Static visual tiers**: the existing sibling families render as one
    progression — `sessions_10/50/100` → bronze/silver/gold,
    `level_5/10/25`, `streak_3/7/30/100`. Each keeps its own row; the
    tier is a fixed visual attribute.
  - **Dynamic tiers**: siblingless count badges climb in place as a
    metric grows — `lessons_10` (10/50/100), `review_master`
    (50/200/500). The single row upgrades bronze → silver → gold (a
    **high-water mark** that never demotes) and awards the XP **delta**
    on each step (50 → +100 → +150), guarded against double-award.
- Identical tier evaluation in **both storage modes** (API + Dexie),
  pinned byte-for-byte by a cross-language parity golden.

### Badge gallery

- A slide-over **gallery drawer** browses every badge with its
  tier-coloured icon: category filter tabs, sort (recently earned /
  progress / category), and a click-to-expand card showing the
  description + tier-threshold breakdown.
- **Locked badges stay visible** — greyed icon + an unlock hint — so
  you always see what you're working toward (the shape carries meaning,
  not just colour).
- Opened from **Settings > Gamification** and from the **Dashboard**
  badge widget.

### Tier-coloured icons + celebrations

- New deterministic SVG generator: ~10 geometric glyphs (book, star,
  flame, target, globe, …) × bronze/silver/gold/locked palettes. No
  files, no network — works offline + Dexie + GitHub Pages.
- A tier **upgrade celebrates**, scaled by the reached tier: silver gets
  an ascending chime, gold the triumphant chord + a golden glow on the
  badge. Intensity-gated and `prefers-reduced-motion`-safe (sound +
  event still fire; no overlay/animation).

### Dashboard

- The badge card now shows the earned count, the 3 most-recent badges as
  tier-coloured mini icons, and a "next badge" pointer — each opens the
  gallery.

## Also in this release

- **Fix — Matching exercise UX**: the selected tile is now obvious (3px
  accent border, tint, scale, glow + pulse), with an instructions line,
  a first-pair flow hint, visible column headers (Term / Translation),
  and a shake on wrong pairs. Reduced-motion-safe; new strings in all 8
  catalogs.

## Under the hood

- `UserBadge` gains `tier` + `updated_at`; `Badge` gains `base_tier` +
  `tier_thresholds`. Alembic `0022` adds the columns and backfills the
  static sibling tiers (defensive no-op on fresh DBs). Dexie schema
  **v21** mirrors the backfill from a single source (BUNDLED_BADGES).
- `user_badges` sync promoted **append-only → MUTABLE** (tier is a
  monotonic high-water mark, so last-write-wins stays correct).
- New i18n: `gamification.tier.*` + `gamification.gallery.*` in all 8
  catalogs (real umlauts in German; pt/tr/ja clear the EN-passthrough
  audit).
