# Adaptive Learner v1.83.0

A maintenance + gap-hardening release on top of the v1.82.0 hint-economy /
review-queue wave. It fixes three reported defects (a P1 in the review session,
two P2 theory-rendering issues) and closes a six-item gap-hardening audit (#630)
that finishes the rough edges around cloze input, hint gating, favorites,
review suggestions, free-text feedback, and the Dashboard. No schema, API, or
data-model change.

4 substantive commits.

## Fixed

- **P1 — review session: Enter, element de-dup, live badge (#631, Refs #629).**
  The review runner now honours the Enter shortcut (check, then advance) the
  same way the main + error-replay runners do, de-duplicates elements so a word
  missed in several lessons appears once in the queue, and recomputes the
  live XP badge after a review so the header reflects the just-earned points.
- **P2 — theory tables had no visual styling (#633, Refs #632).** Markdown
  tables in theory content now render with proper borders, header emphasis, and
  padding (token-backed, all themes) instead of unstyled rows.
- **P2 — theory back-link pointed at the wrong page (#635, Refs #634).** The
  "re-read theory" link now resolves to the theory step by topic rather than the
  nearest preceding step, so it lands on the relevant page.

## Changed

Gap-hardening audit (#630) — six spec gaps closed:

- **Cloze Tab navigation (#623).** Tab moves between the blanks of a cloze
  exercise so the whole exercise is keyboard-fillable.
- **Hints honour the feature-not-available policy (#624).** With no AI key the
  hint control is visible-but-disabled with a localized reason (the
  FUNKTION-NICHT-VERFUEGBAR policy), not silently missing.
- **Dashboard favorites Top-5 cap (#625).** The favorites widget shows the top 5
  and stops growing unbounded.
- **Review "repeat in 2 days" suggestion (#626).** After a review the next-step
  surface offers a concrete spaced-repetition suggestion.
- **Free-text typo detection (#627).** A near-miss free-text answer gets a
  "Fast! Achte auf:" ("Almost! Watch out for:") hint pointing at the typo
  instead of a flat "wrong".
- **Dashboard Quick-Review button (#628).** A one-click entry point to the
  review queue from the Dashboard.

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads AdaptiveLearner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

If your operating system warns about an unsigned binary, see the [AdaptiveLearner installation overview](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/installation.md).
