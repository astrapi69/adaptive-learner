# Adaptive Learner v2.12.0

Finished a set? You can now start it over as a fresh run - a "Durchgang" - and your spaced-repetition history follows along instead of resetting. This builds on the stable-identity work from the last release: progress is keyed to each exercise's own identity, so a local edit to a lesson no longer strands your review cards.

Bringing keys from another app is easier too: Adaptive Learner can import your provider keys from a Topos `.alk` export, and it gains Perplexity as an AI provider.

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads the ready-built AdaptiveLearner image from GitHub's registry (about 110-120 MB compressed, roughly 500 MB on disk - nothing is built on your machine), and opens the app in your browser. Later starts are fast and work offline.

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

**macOS blocks the binary on first open** and, depending on the macOS
version, offers only "Move to Trash" and "Done" - no Open button. The
program is not notarized by Apple (that needs a paid developer account).
Dismiss with **Done**, then open **System Settings > Privacy & Security**,
scroll down and click **Open Anyway**. Windows shows a SmartScreen notice
with a "More info" > "Run anyway" path. Full walkthrough per platform:
[installation overview](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/en/installation.md).

Verify the checksum first. When the system cannot tell you where a file
came from, a matching checksum is the check you can still make yourself.

## What's new

### Run a completed set again - a Durchgang

A set you have finished can be reworked as a second run, and the review history is shared across runs instead of being wiped (#2580, #2125). Spaced-repetition scheduling now consumes each exercise's own stable identity, so review cards survive a local lesson edit (#2565, #2569, #2566) - the same stable-identity model the last release introduced, now carried down to the individual exercise.

### Import your keys from another app, and a new provider

Adaptive Learner can import your AI provider keys from a Topos `.alk` export, so you do not have to re-enter them (#2513). The same change adds **Perplexity** as an AI provider (backend-only).

### Editing and generating lessons

The inline create-lesson editor can convert word-tile and multiple-choice exercises into free-text ones in place (#2596). Adopted community exercise types (`ext:al-*`) now run through the full Check phase like the built-in types - graded, scored, and tracked, instead of falling into an always-passable placeholder (#2601).

### Lessons that are clearer about what you missed

The mistake-replay call-to-action is shown directly, and the correction round now comes before the next-steps block (#2571). "Why you missed these" checks your last-attempt correctness rather than long-term mastery, so it reflects the round you just did (#2548). Discover falls back to `manifest.yaml` to list a repository's sets when the search index is missing, instead of showing nothing (#2564).

### Reliability, deep links, and accessibility

- A stalled or failed lazy-loaded route no longer blanks the content area - the app keeps what was there (#2574).
- Every static route resolves to a real file, so deep links answer 200 instead of a soft 404 (#2544); the noscript landing-page links are base-absolute (#2542).
- Header badges compose their accessible name from the visible text (WCAG 2.5.3) (#2540).

### Settings and UI polish

- Recommended-repository "Add" buttons are gated per row instead of all at once (#2561); the key-vault file-picker button is styled to match (#2557).
- The settings sidebar resets native list/button chrome (#2546); auto-backup gains spacing between its label and the action row (#2550).
- The assistant's exercise-type selection sits above the textbook textarea (#2523); the method badge is consolidated onto one shared component (#2597).

### For developers

- A LAN-servable Dexie build with a secure-context HTTPS option makes iOS on-device debugging possible (#2584).
- The export path stamps `schema_version` from the schema mirror (#2555); the Docker frontend build stage copies `schema/` in (#2560).

### Changed / internal

- The project now requires Python ~3.12 (#2518); content-engine re-pinned to 0.22.0 (#2563).
- The dead-classname gate also scans package-emitted class names, closing the blind spot that removed a still-used rule last cycle (#2588).
- Transitive `nanoid` raised (#2516); routine backend and frontend dependency groups bumped.
