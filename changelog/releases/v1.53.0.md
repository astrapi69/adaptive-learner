# Adaptive Learner v1.53.0

Minor release that takes the platform **beyond languages**: a content
**schema v1.3** for technical material, the first **programming course
(Python)**, and the rendering + exercise support that makes code-based
learning work — plus the domain grouping that organises it all.

## Highlights

### Content schema v1.3 — technical / programming content
- Cards gain optional, backward-compatible fields: `code_snippet`,
  `code_language`, `expected_output`, `hint`, `difficulty` (1-5), and
  `media_type` (`text` | `code` | `formula` | `diagram`). Every field is
  optional, so all existing v1.0-v1.2 lessons load unchanged.
- `is_supported_schema_version` does a major-version match, so v1.3
  content loads on v1.x readers and a future 2.x is rejected with a
  friendly upgrade hint.

### Domain support — non-language content
- Content sets declare a `domain` (default `language`). Non-language
  domains (`programming`, `psychology`, ...) are explained in the same
  language they teach, so **source == target is allowed** (the content
  validator and the app-side validator both honour this).
- **Content Browser** now splits the library into **"Sprachen"**
  (the source → target → level language tree) and **"Wissen"**
  (knowledge domains), each domain with its own icon (code, brain,
  calculator).

### Code rendering + code-aware exercises
- **Syntax-highlighted code blocks** in the lesson viewer via
  `highlight.js` (lazy-loaded, so lessons without code never pay for
  it): language label, copy button, an "Output:" block for
  `expected_output`, and horizontal scroll on mobile.
- **Code-aware exercises**: when a card is a code/formula card, free-text
  answers use a monospace, spellcheck-off textarea and
  whitespace/quote-tolerant, case-sensitive matching
  (`print( 'x' )` == `print('x')` == `print("x")`); cloze sentences
  render monospace.

### NEW: Python Grundlagen (programming course)
- A 15-lesson German-language **Python basics** course
  (`de/python-basics`, `domain: programming`, source == target = `de`)
  with **123 code-snippet cards** exercising the new schema end to end.

### Content library: 7 sets, 100 lessons (~22 hours)
- `de/en-a1`, `de/es-a1`, `de/fr-a1`, `en/es-a1`, `en/fr-a1` (languages),
  `de/psych-intro` (psychology), `de/python-basics` (programming) —
  **100 lessons total**, all bundled into the GitHub Pages build.

### Fix
- **Analysis-to-lesson source language** now defaults to the active app
  language (Settings > Language) instead of `"en"`, so a German chat no
  longer lands at `en -> de`. (Follow-ups for content-based target
  detection / domain auto-suggest / placement language warning are filed
  as P3: `ANALYSIS-TARGET-DETECT-01`, `ANALYSIS-DOMAIN-SUGGEST-01`,
  `PLACEMENT-LANG-WARN-01`.)

## Notes

- No DB schema / migration changes; the content schema bump is additive.
- New i18n in all 8 languages (`content.tree.knowledge` / domain labels /
  code-block copy + output / code placeholder).
- Tests: backend + plugins + 2992 Vitest, the Dexie-mode release gate
