# Adaptive Learner v1.69.0

Minor release — theory example links and per-domain book
recommendations, an Enter-key shortcut in the Error-Replay runner, and
a backup-restore title fix.

## Added

- **Example links in theory steps** (#139). A lesson's theory step can
  now carry an optional `example_url` (+ `example_label`) that renders
  as a "View example" button linking to an external article, video, or
  visualization. Content schema 1.3 -> 1.4 (additive — lessons without
  it stay valid); both the client validator and the content-repo CI
  reject a non-`http(s)` URL.
- **Book recommendations per domain** (#141). A maintainer-curated
  `books.yaml` at the official content repo root maps a content domain
  to recommended books, surfaced in the Content Browser. Pulled directly
  from the raw content repo, so it works in both storage modes with no
  backend.

## Changed

- **Enter-key shortcut in the Error-Replay runner** (#154). "Fehler
  wiederholen" now honors the same Enter shortcut as the main lesson
  runner (Enter checks an answered exercise, then advances), via a
  shared `useLessonEnterKey` hook so the two runners can't drift.

## Fixed

- **Restored content sets keep their title and step progress** (#134,
  recurrence). After v1.67.1 the Dashboard still showed the raw
  `set_id` (`analysis-<uuid>`) instead of the lesson-set title, and step
  progress collapsed. Cause: the restore read the title with a regex
  that only matched a root-level `title:`, but the synthesised manifest
  stores it under `sets[].title`. Restore now parses the manifest
  properly (real YAML parser) and recovers the title plus the other set
  fields, preferring the carried metadata when present. Verified by a
  real export -> import round-trip through the actual backup functions.

All new strings are translated in the eight supported languages.
