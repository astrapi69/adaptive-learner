# Adaptive Learner v1.63.0

Minor release — **6 recommended WCAG-AA theme presets**, a **systematic
i18n audit** (subject names + 92 missing catalog keys), and the
**dashboard subject filter scoped to the user's own subjects**, plus
two theme/i18n conformance fixes. No schema change; both storage modes
(API + Dexie / GitHub-Pages) carry everything.

## Added

- **6 recommended WCAG-AA theme presets** (#86): alongside the 6 classic
  themes, the Appearance picker now leads with a **Recommended** sub-tab
  offering `catppuccin-latte`, `supabase`, `graphite` (light) and
  `catppuccin-mocha`, `soft-pop`, `amethyst-haze` (dark). Each is a full
  43-token theme generated from tweakcn presets by
  `scripts/generate_preset_themes.py`, which derives the non-shadcn
  tokens and **enforces WCAG AA computationally** (all text pairs ≥4.5:1,
  UI/exercise ≥3:1, verified by `contrast.test.ts` across all 12 themes).
  The classic 6 are unchanged; `ThemePicker` opens on the active theme's
  group so existing users keep their pick.

## Fixed — i18n (systematic audit, #80)

- **77 subject / category names rendered in English everywhere**: the
  seeded subjects (Sciences, Mathematics, Psychology, …) stored only
  their canonical English `name`. A new `subjects.*` catalog section
  (60 translatable keys × 8 languages) plus `subjectI18n.ts`
  (`translateSubjectName` / `translateSubjectPath`, fallback to
  `subject.name` for proper nouns and custom subjects) now translates
  them in the Dashboard filter and Onboarding suggestions.
- **92 `t()` keys were called in code but missing from every catalog**:
  notably the entire `editor.*` rich-text toolbar (26 keys), the
  settings danger-zone (14), dashboard metric labels, and learning-path
  aria-labels — all fell through to their inline English fallback in
  every language. Added and fully translated in all 8 catalogs
  (en/de/es/fr/el/pt/tr/ja). Pins: `subjects.*` parity + helper unit
  tests; the backend i18n parity/translation audit stays green.

## Fixed — UI / themes

- **Dashboard subject filter scoped to the user's subjects** (#72): the
  filter dropdown offered the entire global catalog; it now lists only
  subjects attached to the user's projects, and hides entirely when none
  is attached.
- **Theme contrast — `accent-foreground`** (#82): the shadcn
  `--color-accent-foreground` bridge now maps to the on-accent colour
  (`--accent-fg`) instead of `--fg-primary`, so ghost/outline hover text
  meets WCAG AA in every theme.
- **`dashboard.no_data` i18n key** (#84): the empty-state label was
  missing from every catalog; added in all 8 languages.

## Internal

- **mypy `no-any-return` in `backup_service`** (#87): annotated
  `parent_table` so the backup restore path type-checks cleanly. (`make
  release-test` does not run mypy — CI does; run it manually before
  tagging.)
