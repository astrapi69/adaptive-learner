# Adaptive Learner v1.19.0

**Released**: 2026-05-22

Phase 32 — **NotebookLM Integration Patterns.** NotebookLM has
no public API, so direct integration isn't possible. This
release adds the next-best path: AI-generated active-recall
study questions, a comprehensive AI-generated study guide, and
a NotebookLM-optimized ZIP export with structured Markdown for
NotebookLM's source upload. Closes BL-22.

## Added

### Plugin: `adaptive-learner-plugin-notebooklm`

- `NotebookLMPlugin` + path-dep wired into the backend;
  added to `app.yaml.enabled`. Eighth shipped plugin
  alongside anki / gamification / session / tracking /
  tools / assessment / 3× ai providers.

### 32B — Active-recall question generator

- `StudyQuestion` model + Alembic 0013 + Pydantic schemas
  (`Out` / `Create` / `Update`).
- Sync surface: `study_questions` MUTABLE direct scope
  (**28 synced tables**, was 27).
- `question_generator.py`:
  - JSON-emitting prompt + tolerant parser (strips
    `json`-fenced blocks, coerces unknown types/difficulties
    to safe defaults, returns `[]` on parse failure rather
    than crashing).
  - `session_transcript` + `project_transcript` helpers
    (project mode aggregates the 5 most recent completed
    sessions; oldest get truncated when over the prompt
    budget).
  - `_persist` writes one `study_questions` row per parsed
    question; the AI is called once per generation.
- Plugin routes under `/api/plugins/notebooklm/*`:
  - `GET /questions/{user_id}` — filter by `project_id`,
    `difficulty`, `topic` (case-insensitive substring)
  - `POST /questions?user_id=…` — manual insert
  - `PATCH /questions/{id}` — inline edit; touching text
    flips `edited=True` so future re-generation skips
  - `DELETE /questions/{id}`
  - `POST /questions/generate/session/{id}` — AI from one
    session
  - `POST /questions/generate/project/{id}` — AI from N
    recent sessions

### 32C — Study guide generator

- `study_guide_generator.py`:
  - **One big AI call** with content-clipping to ~30K chars
    (≈ 10K tokens). Sessions truncate oldest-first when
    over budget per spec.
  - `assemble_project_context` pulls project +
    `LearningProfile` + analyzed-conversation vocabulary +
    10 recent completed sessions into a single context dict
    the prompt builder consumes.
  - Parser strips outer ```markdown``` fence if the model
    adds it; otherwise passes through verbatim.
- Route `POST /api/plugins/notebooklm/study-guide/{project_id}`
  returns `text/markdown; charset=utf-8` directly.
- No persistence — the user re-generates anytime. The
  result would stale instantly after the next session.

### 32A — NotebookLM ZIP export (client-side)

- `frontend/src/lib/export/notebooklm-package.ts` assembles
  a ZIP from the user's existing data via the storage
  abstraction (works in both API + Dexie modes).
- ZIP contents per spec:
  - `summary.md` — topic + goal + profile + activity counts +
    pointers to other files
  - `vocabulary.md` — Markdown table of every vocabulary
    entry from analyzed conversations (Phase 30D shape)
  - `rules.md` — first AI message per recent session (typically
    states the rule/concept)
  - `errors.md` — session-rating notes
  - `flashcards.md` — Q&A pairs for every saved study question
    + every accepted Anki card
  - `sessions/{id-prefix}.md` — one file per recent session
    with key excerpts (NOT the full transcript — spec: only
    teaching moments)
- All files use short paragraphs + clear H2 sections —
  optimised for NotebookLM's source parser.
- JSZip is lazy-loaded (same chunk that already serves
  Phase 30's .apkg builder), so zero main-bundle cost.

## Migration notes

Alembic 0013 is a clean-add of the `study_questions` table
(3 indexed FKs, `ondelete=SET NULL` on the session FK so a
deleted session doesn't take its questions with it).

Existing installs run `alembic upgrade head` once. No backfill
needed. Users see an empty NotebookLM section until they
trigger their first generation.

## Browser support

The ZIP exporter requires `JSZip` (already shipped in v1.17.0
for Anki). The study-guide download is a `Blob` download — same
mechanism the Anki .apkg export uses. Works in all browsers
that support the Web Speech / Web Crypto / IndexedDB feature
stack we already depend on.
