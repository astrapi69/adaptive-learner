# Adaptive Learner v1.58.0

Minor release — **a user-centric UX overhaul** of the Content Browser
and Dashboard, reorganised around the learner's first question: *"Where
was I? What do I do next?"* No schema or storage changes; both storage
modes (API + Dexie / GitHub-Pages) carry it.

## UX

### "Weitermachen" / Continue Learning

A new shared **Continue Learning** section surfaces the learner's most
recently-touched lesson per set (newest first), each with a single
sensible action:

- **resume** an in-flight or paused lesson, with a `step n/total` hint
- **next**: the just-completed lesson's stars + a pointer to the next
  lesson in the set
- **set complete** when every lesson in the set is done

It reads `LessonProgress` (sorted by `updated_at`) + the set manifests
entirely through `getStorage()`, so the GitHub-Pages Dexie build
computes it client-side with no backend. Each read is individually
guarded — a transient miss degrades that row, never the section — and
it renders nothing while loading or when there is no identified user.
It appears on **both** the Content Browser (top 5) and the Dashboard
(top 3).

### Content Browser reordered around the learning flow

- **Search first**: the search bar moves to the top (full width), so
  finding something is the first action.
- **Compact icon toolbar**: the Import Lesson / Import Chat / Learning
  Path / Create actions are now icon-only on mobile (44 px touch
  targets), icon + label from `md` up — they no longer eat a full row
  on a phone.
- Continue Learning sits directly below the search, above the set tree;
  My Lessons + Contributions hide while a search is active so the
  results own the view.

### Dashboard reordered

Continue Learning is now at the **very top**, above any gamification.
The widget grid leads with the actionable cards (paused lessons, daily
missions, focus areas, review queue), then the motivational ones (XP /
streak / badges), then the analytical panels — so the Dashboard answers
"what do I do now?" before "how much XP do I have?".

### Responsive buttons

The secondary action buttons (Content Browser toolbar + the Dashboard
pronunciation / create-lesson / learning-path actions) follow one
pattern going forward: **icon-only on mobile** (with `aria-label` /
`title` preserving the accessible name), **icon + text from `md` up**.
Primary lesson CTAs keep their always-on labels.

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads AdaptiveLearner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```
