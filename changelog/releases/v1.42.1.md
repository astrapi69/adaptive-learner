# Adaptive Learner v1.42.1

**Released**: 2026-05-29

Patch release: fixes the Save-as-Offline-Lesson failure in API mode
(shipped in v1.42.0) and reorganizes the Settings tabs.

## Fixed

- **Save as Offline Lesson failed in API mode (HTTP 422).** The
  `saveUserSet` API call double-encoded its request body, so the
  backend rejected it with *"Input should be a valid dictionary or
  object to extract fields from"*. The body is now sent as a plain
  JSON object. Added an api-client regression test for the body
  shape. (Dexie / offline mode was unaffected.)

## Changed

- **Settings tabs reorganized (7 tabs).** Help and About are now
  separate tabs — **Help** is the glossary / article browser,
  **About** holds version, system info, credits, donations and
  license. The swipe-gesture toggle moved to the **Learning** tab,
  and the identity-file section moved to the **Data** tab (with
  Sync / Backup / Danger Zone). No settings were lost or duplicated
  (confirmed by a full settings-section audit).

## Notes

- New i18n keys `settings.tab_about` + `settings.section_interaction`
  in all 8 catalogs.
- Green through `make test` + `npm run build` + Vitest +
  `make test-dexie-smoke`.
