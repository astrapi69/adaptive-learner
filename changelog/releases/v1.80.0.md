# Adaptive Learner v1.80.0

Minor release. The headline is the **EXP-026 / EXP-025 content lane**: a learner's
own lessons now **fold into the published content tree**, author-provided
**book-companion** metadata renders in the Content Browser, and the learner gets
a **profile picture**. Plus a localized lesson-split title, two accessibility
fixes, and a maintenance batch that clears three CI-gate regressions
(import cycle, component complexity, a flaky test). No schema / API / data-model
change beyond the additive book-metadata block.

## Added

- **User profile picture (#508, PR #535).** The learner can pick or upload an
  avatar, shown in the nav, the About panel, and the Dashboard. New
  `shared/InitialsAvatar` (deterministic initials fallback) + `shared/AvatarUpload`
  (client-side resize), persisted in both storage modes (Dexie blob + API
  filesystem, like content assets); no backend account system.

- **User lessons folded into the content tree (EXP-026, #97 — UGC-01..07).**
  A user-generated lesson whose language pair + level matches a published set now
  folds into that tree node instead of only living in "My Lessons": it carries a
  **"Your lesson" / "Your edit"** badge (the shared `IconBadge` primitive), the
  node shows a **"(+N own)"** count, and folded lessons are indexed in search.
  Built on a pure `resolveTreePlacement` matcher (UGC-01) and a `buildContentTree`
  fold (UGC-02), with a content-page integration test (UGC-07). Unmatched user
  lessons stay in the "My Lessons" fallback.

- **Book companion in the Content Browser (EXP-025, #142).** An author-provided
  content repo can declare a `book` block in its root `manifest.yaml`
  (title / author / direct non-affiliate URL + optional subtitle / isbn / asin /
  cover / edition), validated by the content-repo validator (AUTH-01, PR #530).
  When present, the Content Browser shows a discreet companion card (cover /
  author / edition) linking to the book in a new tab — no auto-redirect, no
  in-app purchase (AUTH-02, PR #532). The full author/cross-repo publishing flow
  (AUTH-03+) stays deferred pending shared-backend infrastructure.

- **Localized lesson-split part titles (#512, PR #516).** When an oversized
  imported lesson is auto-split, each part's title is now localized
  ("… - Teil 2" / "… - Part 2") instead of a hardcoded English suffix; the
  language-neutral default is retained for non-UI callers and the parity goldens.

- **Selective data export (#544, PR #545).** A new "Daten-Export" section in
  Settings > Data offers a grouped, checkbox-driven export (content / master
  data / …) to a dated `adaptive-learner-export-{date}.json`, behind an
  `ALWAYS_ACTIVE` feature gate.

## Accessibility

- **Skip-to-content focus (#514, PR #516).** The skip link now moves keyboard
  focus to `main` (WCAG 2.4.1), not just scrolls.
- **Dialog focus management (#515, PR #517).** Hand-rolled modal dialogs get
  initial focus + a focus trap.

## Fixed

- **About tab horizontal overflow at 320px (#163, PR #511).**
- **Recommended-repos discovery fetch** is skipped until the catalogue is
  published, removing a spurious fetch/error on the Content Browser (70108061).
- **Flaky Content near-duplicate wizard test (#537, PR #539).** The test clicked
  the "My Lessons" share button, which EXP-026 asynchronously folds away; it now
  shares from the stable folded tree row (same wizard + duplicate scan). Flake
  (~10%) → deterministic.
- **Import cycle `content-tree.ts` ↔ `tree-placement.ts` (#540, PR #542).** The
  shared `baseLanguage` / `domainOf` helpers moved into a pure
  `lib/content/language-utils.ts`; madge back to 0 cycles.
- **`Content.tsx` complexity over the hard gate (#541, PR #542).** The EXP-026
  fold split extracted into a pure `computeUserFold`, and the book-companion +
  contributions sections into their own components; the page's worst cyclomatic
  complexity drops 22 → 19, clearing the radon/eslint Phase-2 gate.
- **Dexie release gate green again (#543, PR #548).** The EXP-026 fold moved
  saved/created user lessons out of "My Lessons" into the matching tree node, so
  three Dexie E2E specs timed out; they now accept the lesson's share button in
  either location. (`recommended-repos` discovery E2E `test.fixme`'d while its
  catalogue is unpublished — #547.)
