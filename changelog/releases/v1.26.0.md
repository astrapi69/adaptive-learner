# Adaptive Learner v1.26.0

**Released**: 2026-05-25

Phase 42 — **Git-Backed Learning Repository** (BL-30).
Implements the Article-3 "learning repository" pattern from
Asterios Raptis' *Von Theorie zur Praxis* Medium series:
per-project Markdown artefacts (README / LEARNING_STATS /
CHEATSHEET / ROADMAP) auto-emitted from existing DB state,
with optional `git init` + commit-on-render + tag-on-exit
under `~/.local/share/adaptive_learner/repos/{project_id}/`.

Sole headline item — no other phases bundled. Seven atomic
commits per the BL-30 plan (schema → scaffold → renderer →
routes → git → frontend → i18n+E2E), each green individually.

## Why this release

The in-app learning surface stays the primary tool, but
sessions live inside the app's database. Article 3 of *Von
Theorie zur Praxis* argues the case for **versioned,
on-disk** documentation of the learning process — the same
"if code deserves git, your brain deserves it too" thesis.
v1.26.0 closes that loop: the user gets browsable Markdown
artefacts (in-app + downloadable ZIP), and opt-in git
integration commits every render so the learning journey
becomes inspectable with any git client.

## What changed

### A — Data-model prerequisite (commit `ba0600f`)

New `SessionNote.kind` column (`String(32)`, default
`"note"`). Constants `SESSION_NOTE_KIND_NOTE` and
`SESSION_NOTE_KIND_META_LEARNING` document the canonical
values. The `"meta_learning"` kind is the Article-3
"Meta-Learning Insight" slot — observations about *how* the
learner learns best. Alembic 0017 adds the column with a
server_default; Dexie schema v15 back-fills existing rows
via the upgrade modify-loop.

### B — `learning-repo` plugin (commits `ddf4574`..`a99153a`)

New plugin under `plugins/adaptive-learner-plugin-learning-repo/`,
registered as `learning-repo` and mounted at
`/api/plugins/learning-repo/*`. Three endpoints:

- `GET /render/{project_id}?language=de` — returns the
  `{path: content}` map for the four root meta-files + topic
  folder stubs as JSON.
- `POST /export-zip/{project_id}?language=de` — same content
  packaged as a deterministic ZIP download
  (`{slug}-learning-repo.zip`).
- `POST /persist/{project_id}?language=de` — opt-in
  side-effecting variant: writes the tree to
  `{repos_dir}/{project_id}/`, runs `git init` once + commit
  per render with subject `Cycle N — U X/10, T Y/10`. Tags
  `cycle-{N}-mastered` when the Article-1 § 8 exit
  threshold is met (Understanding ≥ 9/10 AND Transfer ≥ 8/10
  stable over 2 consecutive cycles). Disabled by default;
  missing `git` binary surfaces as HTTP 502
  (ExternalServiceError pattern).

Renderer is sync-read + AI-free. Single source of truth for
the exit-threshold logic in
`adaptive_learner_learning_repo/thresholds.py` —
LEARNING_STATS.md's stats-pin and the git-tagger consume the
same helpers.

### C — Generic plugin-settings endpoint (commit `946ee92`)

`GET / PATCH /api/plugin-settings/{plugin_name}` reads and
writes `backend/config/plugins/{plugin_name}.yaml` and
reloads the plugin's in-memory config so the very next
request sees the change. Backstops the architecture-rule
"every non-`# INTERNAL` plugin setting MUST be editable in
the plugin UI" — until v1.26.0, every plugin's settings
YAML was hand-edited only. Plugins opt in implicitly; no
allow-list.

### D — Frontend surfaces (commit `946ee92`)

- New page at `/projects/:projectId/learning-repo` with a
  file-list sidebar (root meta-files + collapsible
  per-topic groups) and a Markdown viewer powered by
  `react-markdown` (reused from the help system — no new
  deps). Three actions: Re-render, Download ZIP, Persist
  to git.
- Dashboard `LearningRepoWidget` card linking to the page.
- Settings > Learning Repository section: `enable_git`
  toggle, `repos_dir` input, Save button.
- API client gains `api.learningRepo` and
  `api.pluginSettings` namespaces.

### E — i18n + E2E (commit `f106d70`)

- `repo.*` block added to all 8 i18n catalogs (DE, EN, ES,
  FR, EL, PT, TR, JA). DE + EN native; ES/FR/EL/PT/TR/JA
  AI-translated, pending native review.
- `labels_for(language)` in the renderer reads
  `backend/config/i18n/{lang}.yaml` under the `repo.*`
  namespace, falling back to English inline defaults for
  any missing key.
- New E2E smoke spec `e2e/smoke/learning-repo.spec.ts`
  (4 tests): widget mounts, page renders four meta-files +
  switches viewer, ZIP download triggers, persist
  400-gates without `enable_git`.
