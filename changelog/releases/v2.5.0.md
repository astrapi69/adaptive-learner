# Adaptive Learner v2.5.0

A feature release on top of the v2.4.0 authoring release. The headline is that
**Create-Lesson becomes a full exercise authoring tool**: every one of the five
core exercise types is editable in step 3, exercises can be added by hand, the
native `multiple_choice` type is authorable with a prominent single/multi mode
control, and a new **extension-authoring wizard** covers all four AI-authored
extension types (categorization, error-correction, reading-comprehension,
graded-quiz). Alongside it, **`ext:al-dictation` (audio dictation) joins as the
fifth extension type** and is offered in the core exercise-type picker.

Under the hood, two subsystems become **published npm packages consumed instead
of maintained in-tree**: the PWA update + version display now runs on
`@astrapi69/pwa-update(-react)`, and the AI key vault on
`@astrapi69/ai-key-vault(-react)`. Exercise grading, payload validation, and
authoring are consolidated under `lib/exercises/` behind a single barrel.

Two governance rules are codified: **PR-PFLICHT** (a pushed code change opens a
PR by default, not on request) and **TESTPLAN-PFLICHT** (user-visible
functionality updates the manual test plan in the same PR).

No schema/API/data-model change against v2.4.0.

## Added

- **Editable exercises in Create-Lesson step 3 (#1844).** All five core
  exercise types can be edited after generation instead of being
  generate-only (#1845).
- **Manual exercise authoring + `multiple_choice` (#1849 / #1850).** An
  exercise can be added by hand, and the native `multiple_choice` type is
  authorable (#1853), with a prominent single/multi mode control in the MC
  editor (#1888).
- **Extension-authoring wizard (#1852).** Editors for all four AI-authored
  extension types: categorization + error-correction (#1859), then
  reading-comprehension + graded-quiz (#1865).
- **`ext:al-dictation` — audio dictation (#1881).** Adopted as the fifth
  extension exercise type, added to the extension wizard (#1887), and offered
  in the core exercise-type picker with a generalized `requires_extensions`
  gate (#1895).
- **Discoverable cloze / word_tiles / picture_choice generation (#1847).**
  The three types that were effectively hidden are surfaced in the generator
  (#1848).
- **Legacy prompt migration on edit (#1860).** Opening an older own lesson in
  the editor migrates exact-default English exercise prompts to the UI
  language, with an explicit notice and persistence only on save (#1861).
- **Night-shift WebKit layout gate (#1843).** A scheduled WebKit workflow
  catches iOS/Safari CSS-engine layout bugs the Chromium gates structurally
  cannot; also runs on `release/**` pushes.

## Changed

- **PWA updates consume `@astrapi69/pwa-update(-react)` (#1873).** The update
  banner, version display, and update checker move onto the published packages
  instead of in-tree modules.
- **AI key vault consumes `@astrapi69/ai-key-vault(-react)` (#1863).** The key
  vault and AI settings panel move onto the published packages (#1868).
- **Exercise logic consolidated under `lib/exercises/` (#1862).** Grading and
  payload validators move into `{grading,payload}/` subfolders (#1867), the
  free-text grader is extracted (#1877), and the whole surface is exposed via a
  single barrel.
- **Governance: PR-PFLICHT (#1846).** Opening a pull request is the default for
  every pushed code change, not something the task has to ask for.
- **Governance: TESTPLAN-PFLICHT (#1858).** A PR that adds or changes
  user-visible functionality updates `docs/manual-tests/testplan-*.md` (DE + EN)
  in the same PR, or leaves a referenced follow-up on #1087 (Refs #1087).
- **CI.** A `--unstyled` render-unstyled gate joins `check-dead-classnames.py`
  (#1892); `release-prepare` defaults `skip_e2e` to true, aligned with
  `release.yml` (#1838).
- **Help docs.** The exercise-type catalog documents the extension tier and
  wizard availability (#1851).
- **Dependencies.** `bun audit` high advisories cleared (brace-expansion,
  js-yaml); `learn-content-engine` re-pinned to 0.13.1.

## Fixed

- **iOS / WebKit.** The lesson footer's Pause/Next no longer overlap under
  WebKit (#1834 / #1839), and the tap-offset defect is addressed by resetting
  the phantom window scroll plus a keyboard-resizes-layout viewport (#1569 /
  #1832).
- **Exercises.** The correction round resolves the cloze source card by front
  text instead of id (#1870); the AI second-opinion verdict no longer leaks raw
  JSON and shows only the fallback message when unparseable (#1883); the
  matching "Retry Errors" replay shows only the wrong pairs (#1874); Enter
  triggers the sole button on the error-replay and endless completion screens
  (#1864 / #1866).
- **Create-Lesson.** Generated exercise instruction templates localize to the
  UI language instead of defaulting to English (#1855 / #1857).
- **Content.** The batch "generate exercises for all lessons" button is
  disabled up front when every lesson already has exercises, with the reason as
  its tooltip, instead of reporting it only after the click (#1896).
- **Settings.** The AI-key warning notice points at the right link target
  (#1835) and refreshes reactively after an import (#1836 / #1842).
- **PWA.** `AppUpdateProvider` follows the async i18n catalog so its messages
  localize (#1894).
- **i18n.** `review.correct_answer` added to all 11 catalogs so the summary
  answer-diff label localizes (#1854 / #1856).
- **Adaptive pipeline.** An end-to-end guard rejects context-free `___` clozes
  (#1840 / #1841).
- **Tests.** The lesson-import-export collision spec is stabilized with
  settled-count barriers (#1878), and the AboutTab dexie test is pinned to DE so
  its storage-label assertion is order-independent (#1875).
