# Adaptive Learner v1.98.0

A ContentHub-redesign and internationalisation release on top of v1.97.1.
The content area gains a collapsible desktop sidebar, a global grid/list view
preference, and per-set status management (active / deferred / completed +
delete) in "Meine Inhalte"; Dev Mode now defaults sensibly per release strand;
and the Spanish + French catalogs get a thorough LLM-assisted quality pass
(restored accents, French informal "tu" register). The first release cut and
finished through the one-click `workflow_dispatch` pipeline (container CI +
RELEASE_PAT-driven deploy/launcher automation). No schema, API, or data-model
change.

## Added

- **Content browser — global view preference, default list (#1257 / #1261).**
  A single content-view preference (grid ⇄ list) now applies across the content
  surfaces and persists across navigation/reload; the default is the compact
  list view.
- **Discover — grid/list view toggle (#1262 / #1264).** The Discover tab gains
  its own keyboard-operable grid/list toggle, consistent with the content
  browser.
- **Desktop nav — collapsible sidebar (#1260 / #1263).** The desktop sidebar
  gains an open/close toggle with a drawer-style collapse, reclaiming
  horizontal space for the content area.
- **"Meine Inhalte" — per-set status management (#1300 / #1301).** A downloaded
  set can be marked **active**, **deferred**, or **completed**, or deleted,
  directly in "Meine Inhalte", so learners can curate their library.
- **ContentHub — inline info button + clearer header (#1272 / #1274).** A
  compact inline info button (replacing a permanent intro paragraph), a
  "Meine Inhalte" title, and the content sources named in the info text.
- **Settings — Dev Mode default per strand (#1271).** Developer Mode now
  defaults **ON** in the Latest strand and **OFF** in the Haupt strand, so
  everyday users do not see developer diagnostics while contributors do.
- **i18n — LLM translation quality-check pass + CSV review export (#1296 /
  #1297).** A tooling pass that runs an LLM quality check over the catalogs and
  exports a CSV for external four-eyes review, with a provenance cache for the
  fr + es results (#1302).

## Changed

- **ContentHub — "Weitermachen" panel removed from "Meine Inhalte" (#1269 /
  #1270).** The Continue-Learning panel no longer appears on the
  "Meine Inhalte" tab, decluttering the downloaded-content view.

## Fixed

- **Error-Replay — successes merge back into the SRS error list (#1304).**
  "Fehler trainieren" was the only interactive exercise mode that never
  persisted per-element attempts, so a retrained mistake stayed in the
  learner's focus areas / review queue even after a correct answer. Each graded
  attempt now flows through the same `elementErrors.recordBulk` path the main
  viewer / review / correction-block use (a correct answer advances mastery, a
  wrong one keeps the error); failure-tolerant and storage-agnostic (Dexie +
  API).
- **"Meine Inhalte" — Dev-Mode download-date readout (#1298 / #1299).** The
  downloaded-at timestamp now shows in the Dev-Mode readout in
  "Meine Inhalte".
- **Learning Path — Dev-Mode download-date readout + download-order guards
  (#1258 / #1259).** The downloaded-at readout is shown in Dev Mode on the
  Learning Path, with regression guards pinning the download-order behaviour.

## Internationalisation

- **Spanish — restored missing accents (#1287 / #1289).** 124 accent fixes in
  `es.yaml`, plus orthography stragglers and the `¿` opening mark (#1290).
- **French — informal "tu" register + verified accents (#1287 / #1291 /
  #1295).** The stray formal "vous" strings switched to the app's informal
  "tu" register, with verified ES/FR accents.
- **LLM-found diacritics applied via surgical reimport (#1296 / #1303).** 67
  French + 26 Spanish diacritics fixes from the quality-check pass.
- **`common.yes` / `common.no` consolidation (#1286 / #1288 / #1292 / #1293).**
  Quoted as strings, translated for hi/id/ko (+ es "Sí"), and the duplicated
  `discover.filter.yes/no` deduped into the shared `common.yes/no`.

## Docs

- **Help + README sweep for the ContentHub redesign + lesson modes (#1279 /
  #1280).** Phase 1 documentation sweep aligning the help site and README with
  the redesigned content area and the lesson-mode system.
- **`docs/` root decluttered into audits/handover/policies/reference (#1283).**
  Phase 2 reorganisation of the documentation tree.
- **Pre-v1.98.0 catalog review export (#1284 / #1285).** A DE-source i18n
  catalog export for the external four-eyes check.
- **EXP-040 directory-restructuring exploration (#1267).** Documents the
  god-folder split work and closes the EXP numbering gap (#809).

## Refactoring / Infra / CI / Tests

- **Settings controls god-folder split by concern (#1275 / #1276).**
- **Release pipeline hardening (#1265 / #1266 / #1254 / #1281).** The
  release-finish workflow publishes + pushes `main` via `RELEASE_PAT` so the
  GH-Pages deploy and launcher-binary workflows fire automatically (GitHub does
  not fire downstream workflows from `GITHUB_TOKEN` events); the extra
  Playwright smoke runs in its own job with CI timeout headroom.
- **E2E step-advance waits made explicit (#1189 / #1277).** Replaced
  `waitForTimeout` step-advance waits with explicit step-detach waits.
- **Feature-screenshot baselines refreshed (#1278)** for the desktop sidebar +
  content list view.

No schema, API, or data-model change.
