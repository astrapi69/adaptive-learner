# Adaptive Learner v1.96.0

Imported-chat sessions reach full backend/API-mode parity with the
Dexie-mode experience, the launcher moves onto the standalone
`docker-app-launcher` engine, and the lesson player gains Reverse and
Endless modes. Plus invitation-code content sharing, online-to-local data
migration, SEO, an auto-deploying preview site, and the complexity
burn-down.

## Added

- **Lesson modes — Reverse + Endless (#1013 / #1015):** Reverse mode flips
  the exercise direction (and reverses cloze: answer shown, context blanked,
  #1067); Endless mode is a continuous SRS practice stream.
- **Lesson UX:** social-media sharing of lesson results (#1073), a
  collapsible lesson-header description with "show more" (#1071), and a
  collapsible "View all answers" detail on the summary (#1007).
- **Content — invitation codes (#1094):** private content sharing for
  coaches/teachers via redeemable invitation codes (+ redeem-flow E2E #1113).
- **Backup — online-to-local migration (#1099):** a welcome dialog +
  Settings entry to migrate online data into local storage.
- **Launcher — `docker-app-launcher` engine (#1064/#1065):** replaces the
  bespoke launcher; run-in-background + branded tray icon (#1089),
  expert-configurable internal container ports (#1084), Makefile convenience
  targets (#1091). Bumped through 0.2.0 → 0.12.1.
- **SEO (#1108):** meta tags, Open Graph, Twitter Cards, structured data,
  robots + sitemap.
- **assistant-ui (#1126):** Phase-0 adapter-seam spike behind a `?ui=assistant`
  flag (#1128) + adoption evaluation / migration plan (#1127). Umbrella #1126
  (phases 1-4) stays open.
- **CI — preview deploy (#1134/#1135):** a `deploy-preview` workflow auto-
  deploys develop to the `adaptive-learner-content-test` GH-Pages preview host.

## Fixed

- **Imported-chat sessions (Dexie + backend parity):**
  - Raw transcript folded into the session context (#1078).
  - Rebuild-on-resume: context rebuilt fresh from the conversation FK instead
    of replaying a frozen prompt (#1122).
  - Lesson-progress (#797) suppressed for imported sessions so the tutor stays
    on the imported topic (the "Inception" drift) (#1137).
  - Header shows the imported chat's topic, not the project topic (#1141).
  - Imported-chat session opens clean with the topic as the intro (#1143).
  - `session.get()` returns `imported_conversation_id` so header topic + intro
    resolve (#1147).
  - **Backend/API-mode parity (#1154):** the above now also holds in
    desktop/server mode — `compose_system_prompt` (#797 suppression) +
    `build_outgoing_history` (rebuild-on-resume across `/message` + streaming)
    + the session DTO carrying the FK.
  - **Tutor-session key gate (#1158):** the "Continue session" / "Start
    session" entry on an imported chat is disabled with an explaining tooltip
    when no AI key is set (it was a dead door into a session that could only
    error-toast — a FUNKTION-NICHT-VERFUEGBAR violation), and `/session` shows
    a clean no-key empty state with a link to the AI settings tab instead of a
    dead chat, covering every route-level entry. Lessons and reviews stay
    usable without a key.
- **Word Tiles (#1160):** equivalent tile reorderings (e.g. interchangeable
  words) are accepted as correct instead of being scored wrong.
- **Dashboard "Continue Learning" (#729):** readable lesson titles +
  table-like styling, plus a UUID-resolution fix.
- **Session UX:** Enter sends the message, Shift+Enter is a newline (#1131);
  the Session entry is back in the primary navigation (#1129).
- **Settings:** a successful AI-key Test now saves + activates the key (#1133);
  no premature "API key required" notice + a link to the AI settings tab
  (#1133/#1148).
- **Deploy/CI:** `.git` excluded from bundled content so the preview GH-Pages
  build stops creating a submodule gitlink (#1140); `force_orphan` +
  `.nojekyll` to clear the stale-gitlink failure (#1139); GH-Pages deploy gets
  room when the backend is slow (#1105); nginx body-size pin targets
  `nginx.conf.template` (#1117).
- **GitHub API:** default fetch bound to `globalThis` to avoid an "Illegal
  invocation" (#1100).
- **Launcher:** dropped Bibliogon from `legacy_names` + `cleanup_configs`
  (#1109).
