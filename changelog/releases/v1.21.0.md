# Adaptive Learner v1.21.0

**Released**: 2026-05-22

Phase 35 — **Comprehensive Documentation Update**.
Documentation-only release. No code changes; no schema
changes; no plugin changes. 34 phases of feature
development had left CLAUDE.md, both READMEs, the MkDocs
site, the ROADMAP, and the project-reference partially
stale; this release brings every doc surface up to date
against the v1.20.0 baseline.

## Documentation refresh

The release was structured as 10 sub-phases per the audit
plan in [docs/audits/docs-staleness-2026-05-22.md](https://github.com/astrapi69/adaptive-learner/blob/main/docs/audits/docs-staleness-2026-05-22.md):

### 35A — Staleness audit

Single-commit audit doc identifying **137 stale version
references** across CLAUDE.md / READMEs / 8 central docs +
60 MkDocs help pages. Headline findings: CLAUDE.md was
46K (4.7× the 10K target); READMEs claimed v0.8.1
(12 minor versions behind); ROADMAP stopped at Phase 26 /
v1.13.0; project-reference still opened with
"v0.0.0-template (Skeleton aus Bibliogon v0.33.0)".

### 35B — CLAUDE.md rewrite (46K → 9.9K, –79%)

Cumulative "Current state (vX.Y.0)" narrative across 34
phases was the bloat root cause. Replaced with a single-
line state pointer plus a link to
`changelog/releases/v1.20.0.md`. Plugin count corrected
7 → 10. Model count 19 → 25. All 13 frontend routes
listed. Tech-stack versions current (React 19, Vite 8,
TS 6, Node 24, FastAPI ^0.136, SQLAlchemy ^2.0,
pluginforge ^0.10.0).

### 35C — README.md + README-de.md

Both rewritten end-to-end. Version badges + tests badges
added. Feature sections split into 9 categories
(Learning core / 3 AI providers / Dual storage / Sync +
backup / Import + analysis / Exports / Gamification /
Voice / Mobile + PWA / Rich text + i18n). Plugin table
extended 7 → 10. Tech stack updated. German prose with
real umlauts throughout.

### 35E — MkDocs developer guide
