# Adaptive Learner v2.8.2

**Security patch on top of v2.8.0 - update recommended.** v2.8.0's image
rendered a WHITE PAGE for every image-mode user: the backend shipped its
deny-everything API Content-Security-Policy on the served app (#2197), a
premise stale since the single-container consolidation and first user-
visible the day the image path shipped. v2.8.2 also hardens the bare
container: it no longer defaults to debug mode (#2198) - v2.8.0 exposed
stack traces in 5xx responses and public Swagger docs to anyone running
the image without the launcher (launcher and compose users were
unaffected: both set debug=false explicitly).

**Sicherheits-Patch auf v2.8.0 - Update empfohlen.** Das v2.8.0-Image
zeigte im Image-Modus eine WEISSE SEITE (#2197); ausserdem startete der
nackte Container im Debug-Modus (#2198, Stacktraces in Fehlerantworten -
Launcher- und Compose-Nutzer waren nicht betroffen, beide setzen
debug=false explizit).

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads the ready-built AdaptiveLearner image from GitHub's registry (about 110-120 MB compressed, roughly 500 MB on disk - nothing is built on your machine), and opens the app in your browser. Later starts are fast and work offline.

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

If your operating system warns about an unsigned binary, see the [AdaptiveLearner installation overview](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/installation.md).

**Why v2.8.2 and not v2.8.1:** v2.8.1 was never published. During its
preparation a further CSP violation (#2205) was found and fixed, the git
tag had to be re-pointed several times, and the GHCR `:2.8.1` image tag
briefly carried a defective build from a cancelled pipeline run. Rather
than overwrite a once-pullable image tag with different content, the
number was skipped - v2.8.2 is the first published release of this line.

**Warum v2.8.2 und nicht v2.8.1:** v2.8.1 wurde nie veroeffentlicht.
Waehrend der Vorbereitung wurde ein weiterer CSP-Verstoss (#2205)
gefunden und behoben, der Git-Tag musste mehrfach neu gesetzt werden,
und der GHCR-Tag `:2.8.1` trug kurzzeitig ein defektes Image aus einem
abgebrochenen Pipeline-Lauf. Statt einen einmal oeffentlich ziehbaren
Image-Tag mit anderem Inhalt zu ueberschreiben, wurde die Nummer
uebersprungen - v2.8.2 ist das erste veroeffentlichte Release dieser

## What's new in v2.8.2

### Fixed

- **White page over the image path (#2197).** The SPA is now served with
  a same-origin policy computed from the real index.html (inline blocks
  allowed by hash - never `unsafe-inline` for scripts); the API keeps its
  strict deny-everything policy. The app's own browser-side calls
  (update check via api.github.com, recommended repos / lesson media via
  raw.githubusercontent.com, static YouTube thumbnails) are explicitly
  allowed - nothing else is.
- **Bare container no longer defaults to debug (#2198).** Safe default in
  the application; wrapper overrides stay, now redundant instead of
  load-bearing.
- **Lesson validation no longer needs `unsafe-eval` (#2205).** Ajv
  compiled the lesson schema at runtime via `new Function()`, which the
  new CSP correctly refuses - "My lessons" and analysis-to-lesson broke.
  The validator is now compiled at build time (Ajv standaloneCode); the
  shipped bundles contain zero runtime code generation, and a
  pin-coupling test fails loudly if the schema is re-pinned without
  regenerating.
- **Create-lesson console noise (#2206).** The pristine empty draft no
  longer logs `console.error`; precise validator reasons stay for real
  invalid input.

### Changed

- **The publish chain now proves the page APPEARS, not merely responds.**
  A real Chromium opens the published image's page, demands a visible
  element and a clean console (the v2.8.0 white page had shipped through
  a fully green chain of status-code proxies), and pins debug=false +
  the CSP on the bare artifact. The walk now enters 24 route states
  (content tabs, dashboard tabs, all settings tabs, learning-path map
  view) and proves every shipped lazy bundle loads somewhere or carries
  a named excuse - the #2205 violation lived in a lazy chunk the old
  check would never have executed.
- **Size gates: tolerance anchored to measured noise.** +/-200000 bytes
  (~4.2x the measured 47651-byte rebuild jitter) around ceilings
  re-anchored to the v2.8.0 published per-arch values; an unexpected
  shrink now fails too instead of reading as headroom.
