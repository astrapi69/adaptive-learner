# Adaptive Learner v1.50.0

Minor release shipping the **standalone Lesson Creator** (Phase 65 /
EXP-021) — a guided, no-API-key way to build a complete, shareable
lesson from scratch.

## Highlights

### Standalone Lesson Creator (`/create-lesson`)
- A four-step wizard: **Metadata → Card Editor → Exercise Generator →
  Save / Share**.
- **Card editor** with drag-and-drop reorder (`@dnd-kit`) and **CSV
  import** for bulk card entry.
- **Auto-generate exercises** from your cards across all five exercise
  types, plus a **manual exercise editor** for fine control.
- **Lesson templates** for a quick start: Blank, Vocabulary, Grammar,
  Conversation.
- **Draft auto-save** to localStorage — you never lose work in
  progress.
- **Preview before save**: play the lesson in the real LessonViewer
  before committing.
- Entry points from the **Content Browser** and the **Dashboard**.
- **Save locally** to My Lessons and **share via Pull Request**
  (Phase 64 sharing pipeline integration — lands at the correct tree
  path, CI-validated).

## Notes
- Works in both storage modes (API + local/Dexie); no API key required
  to build or save a lesson.
- New i18n strings ship in all 8 languages (DE, EN, ES, FR, EL, PT, TR,
  JA), German with real umlauts.
- No schema or migration changes; reuses the existing content lesson
  schema and the Phase 64 share pipeline.
