# Adaptive Learner v1.91.0

A focused UX release on top of v1.90.0. The headline is **EXP-037 — a
navigation restructuring** that cuts the primary nav from 12+ entries to 7
grouped entries (Nielsen-Norman 5-7) with no function loss — every page stays
reachable — plus a PWA fix so the update banner stops nagging after the user
accepts it. No schema, API, or data-model change.

## Changed

- **Navigation restructured to 7 grouped entries (EXP-037, #850).** The
  top-level navigation drops from 12+ primary entries to 7, reorganised around
  the learning flow, with every page still reachable:
  - **Primary bar — 7 entries** (Dashboard, Lernpfad, Meine Inhalte, Entdecken,
    Fortschritt, Settings, Help) via a reusable `NavGroup` labelled-section
    component (transparent on the horizontal bar, shows section headers in the
    mobile More sheet). Session, Curriculum, Statistics, Import, and Anki are
    removed from the bar.
  - **Mobile bottom tab bar.** A new `BottomTabBar` is the mobile primary nav —
    5 tabs (Lernen, Inhalte, Entdecken, Fortschritt, Mehr) plus a "Mehr" bottom
    sheet for the secondary destinations (Lernpfad, Einstellungen, Hilfe).
    Hidden on the onboarding funnel and during lessons; 44px touch targets,
    token-backed across all themes; reserves bottom scroll space.
  - **ProgressHub (`/progress`).** Now a tabbed page — Übersicht / Statistik /
    Meine Pfade — embedding the existing Progress, LearningStatistics, and
    Curriculum pages, with only the active tab mounted (no duplicate `<main>`).
  - **DiscoverHub (`/discover`).** Gains an Import tab; Discover and Import are
    embedded in one hub.
  - **Anki** is removed from the nav and reachable via an action on Meine
    Inhalte (`/anki` is kept — a hard redirect would lose the Anki UI).
  - **Redirects keep old links alive:** `/statistics` → `/progress?tab=stats`,
    `/curriculum` → `/progress?tab=paths`, `/import` → `/discover?tab=import`
    (`/import/:id` stays separate). Session is removed from the nav but its
    route is kept (start from the Dashboard / a lesson).
  - New `nav.group.*` / `nav.tab.*` / `nav.primary` / `progress.tab.*` /
    `discover.tab.*` / `content.anki_export` i18n keys in all 11 languages.

## Fixed

- **PWA update banner no longer reappears after accepting "Aktualisieren"
  (#846).** Acceptance is now persisted (the accepted version + timestamp in
  localStorage) and the banner is gated by a `shouldShowUpdateBanner` check, so
  it stays dismissed across reloads within a 1h quiet window and for the
  already-accepted version; only a genuinely newer version re-offers it. The
  SW activation moved to a capped-backoff background driver that reloads only on
  a real `controllerchange`, instead of a safety-net reload that re-served the
  stale precache.
