# Adaptive Learner v1.67.1

Patch release — a backup-restore fix for user-generated lessons, plus an
internal architecture refactor.

## Fixed

- **Restored user-generated lessons keep their title and step progress**
  (#134). After importing a backup, a user-generated lesson (Lesson
  Creator / saved offline lesson / adaptive snapshot) showed the raw
  `set_id` (`analysis-ed08d0f5...`) instead of its real title (`Deutsche
  Grammatik...`), and its step progress (`Aufgabe 1/26`) collapsed to a
  bare `Fortsetzen`. Cause: a Dexie-origin user-generated set carries its
  title in the `contentSets` row and ships no `manifest.yaml`; the API
  restore wrote the lesson files but dropped that metadata, so the set
  landed manifest-less in the filesystem cache (which derives all
  metadata from the manifest). Restore now synthesises a one-set
  `manifest.yaml` from the backup metadata when none is present, so the
  title resolves and the lesson — and its step count — loads. (To recover
  an already-restored set, re-import the original backup with this
  build.)

## Changed

- **Backend repository pattern** (#133, EXP-024 Phase 1). All backend
  request services now go through a repository layer, decoupling the
  service logic from SQLAlchemy. Internal architecture only — no
  user-visible change.
