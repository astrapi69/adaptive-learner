# Adaptive Learner v1.88.0

A feature release on top of v1.87.0. Two user-facing additions — **QR-code app
sharing** and a clean **separation of the Content Browser from content
discovery** — plus a media-priority refinement, a Settings input fix, and the
release-time documentation sync. No schema, API, or data-model change.

5 substantive commits (plus a bundled-content-stats refresh).

## Added

- **QR-code app sharing (#775).** A new "Share the app" entry in the About tab
  shows a scannable QR code of the public app URL so others can open the app
  directly. The modal offers copy-URL, download-as-PNG, and native Web Share
  (with download as the fallback where the Web Share API is unavailable). Built
  on a reusable, app-agnostic `shared/QrCodeModal` (props: `url`, `title`,
  `onClose`, optional labels) that reuses the already-bundled `qrcode` library
  at error-correction level H, rendered on a white backing so it scans on any
  theme. Works in both storage modes (the URL is static — no backend/Dexie
  call).
- **Media priority — companion book shown first in "Vertiefe das Thema"
  (#770).** A set's companion book is now surfaced first in the lesson's
  "Vertiefe das Thema" section, with an explicit media-priority order.

## Changed

- **Content Browser shows only local content; discovery moved to `/discover`
  (#773).** The Content Browser ("Meine Inhalte") now shows only locally
  downloaded content; its local search/filter still searches the learner's own
  sets. Discovery of not-yet-downloaded sets (the index search + per-set
  download) lives solely on `/discover` ("Inhalte entdecken"). The two surfaces
  are cross-linked: the Content Browser points to `/discover` to find more, and
  `/discover` links back to the Content Browser after a download. The nav labels
  are updated accordingly (`nav.content` -> "Meine Inhalte",
  `nav.discover` -> "Inhalte entdecken") across all 11 locales. This separates
  the surfaces that DIS-07 (#742) had conflated.

## Fixed

- **Settings token/API-key inputs no longer trigger the browser password
  manager (#768).** The provider token / API-key fields in Settings no longer
  prompt the browser's password manager to offer to save them.

## Infrastructure / Docs

- **Release-time version-badge + roadmap/backlog header refresh (#771).** The
  README / README-de version badges, CLAUDE.md current state, and the
  ROADMAP/backlog "Current state" headers are bumped in the release branch (the
  lesson from v1.87.0, which had to fix them after the fact).
- Bundled-content stats in the README refreshed from the content repo.
