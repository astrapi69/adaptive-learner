# Adaptive Learner v1.56.0

Minor release — **performance + PWA hardening**, on top of the
Tailwind/shadcn migration (Phases B + C) and the backend rate-limiting /
OpenAPI work that landed since v1.55.0.

## Performance

- **~460 KB gzip saved** across two targeted, low-risk fixes:
  - **Lazy i18n catalogs (F-1):** the 8 language catalogs were eagerly
    bundled into the main chunk (~215 KB gzip on *every* page). They are
    now per-language chunks fetched on demand — the main `index` chunk
    dropped **446 KB → 233 KB gzip** (≈ −213 KB per page load).
  - **Curated highlight.js (F-2):** the lesson code-block highlighter
    pulled the full library (~190 grammars, 296 KB gzip). It now loads
    `highlight.js/lib/core` + only the ~11 grammars the content uses
    (shared with the editor): **296 KB → 21 KB gzip** on the first code
    lesson.
- **Bundle audit** documented at
  `docs/audits/performance-audit-2026-06-03.md` (Rolldown build +
  treemap; methodology + before/after).
- **Dexie + backend query layers audited and verified healthy** —
  appropriate indexes, batched `.anyOf()` / `.in_()` reads, joins,
  `selectinload`; no page-load N+1. The one inefficiency
  (badge-evaluation per-badge queries, off the hot path) was filed as
  `BADGE-EVAL-NPLUS1-01` (P3) rather than refactored.

## PWA hardening

- **Offline indicator** — a dismissable "You're offline. Saved content
  is available." banner below the nav, with a "Back online!" flash on
  reconnect; network-dependent actions (Analyze, Share-with-community,
  content Download) disable offline with a "Not available offline"
  tooltip.
- **Background sync queue** — lesson-progress upserts that fail while
  offline are queued (localStorage, capped, FIFO) and replayed on
  reconnect, so progress recorded offline is never lost.
- **Cache management UI** in Settings → Data — offline lesson-cache size
  + count, with a two-step Clear button.
- **Install prompt** — re-offers after a 7-day dismissal (was
  permanent), never shows when already installed (standalone), reframed
  around offline use.
- **API-mode lesson caching** — a service-worker StaleWhileRevalidate
  route caches `/api/.../lessons/*.json` + assets so API-mode lessons
  work offline after first view (app-shell + stale-version indicator
  verified already in place).

## Tailwind / shadcn

- **Phase B:** shadcn Button / Card / Badge, the Lesson sticky footer,
  the Dashboard grid.
- **Phase C:** all core buttons migrated; the Lesson leave dialog +
  Share wizard moved to shadcn Dialog; form inputs/selects (API key,
  import language pickers, Create-Lesson, Share-wizard step 1,
  max-lesson-size) migrated to shadcn Input / Select.
- 44px minimum touch targets baked into every shadcn component.

## Backend

- **OpenAPI documentation** — 20 tagged sections, per-endpoint summaries

  now injects the set's language pair / domain into each lesson (the

  and the per-theory "Read aloud" control renders. It had been silently
  absent for all Dexie / GitHub-Pages users. Closes
  `TTS-E2E-HEADLESS-GUARD-01` (the lesson-tts dexie specs also needed a
  read-only `speechSynthesis` override fix in their harness).

  fix carried forward.
