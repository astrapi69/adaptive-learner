# Adaptive Learner v1.99.0

A mobile-hardening and content-flow release on top of v1.98.0. The headline is
the **tappable multiple-choice renderer** — a `cloze` `select`-mode question now
renders as touch-friendly answer buttons instead of a native dropdown, fixing
the iOS tap-misfire that made multiple choice unusable on iPhone (the
driving-licence test set exercises exactly this). Alongside it ship a set of
device fixes (iOS focus-zoom, iPhone delete-menu, persisted UI language), the
Discover content-language filter, multi-select in "Meine Inhalte", opt-in
auto-advance, and inline worked examples. The lesson schema gains an additive
`examples` field (1.4 -> 1.5); no API or data-model change.

## Added

- **Tappable multiple-choice buttons (#1341 / #1342).** A `cloze` `select`-mode
  question renders as a touch-friendly radio-button group (new shared
  `ChoiceButtonGroup`) instead of a native `<select>`, fixing the iOS
  tap-misfire (a WebKit inline-native-`<select>` hit-testing quirk). Data model,
  grading, and SRS are unchanged — presentation only.
- **Opt-in auto-advance after a correct answer (#1330 / #1331).** A new
  general setting: when on, a fully-correct answer advances to the next
  exercise automatically after a brief success moment. Default OFF; a wrong
  answer never auto-advances. SRS recording is untouched.
- **Inline worked examples for theory steps + exercises (#1326 / #1327).** The
  lesson schema gains an optional `examples` list (text, or syntax-highlighted
  code) on theory steps and exercises. Additive schema bump **1.4 -> 1.5**;
  pre-1.5 content validates unchanged.
- **"Ask AI" about a theory block / exercise (#1321 / #1322).** A BYOK-gated
  button passes the current block as context for a deeper question, reusing the
  existing AI path.
- **Discover — visible source-language filter (#1343 / #1344).** A filter
  defaulting to the UI locale, persisted across navigation.
- **Discover — content-language filter follows a UI-language switch (#1347 /
  #1348).** Switching the UI language resets the Discover filter to match.
- **Discover — "New" indicator for newly-published sets (#1339 / #1340).**
- **"Meine Inhalte" — multi-select + bulk-action bar (#1351 / #1352).** Select
  several downloaded sets and act on them at once.
- **Typed imported-repo category + reusable badge (#1319 / #1320).** A typed
  `official` / `private` / `validated` / `unverified` category with a shared
  badge component.
- **QR — Latest-strand QR + QR image upload for add-repo (#1316 / #1317 /
  #1318).** A QR for the Latest strand and decoding a QR from an uploaded image
  in addition to the camera scan.
- **Soft Pop as the default theme (#1315).** New installs default to Soft Pop;
  an existing saved theme choice is preserved.

## Changed

- **Content-Engine source -> canonical boundary (EXP-042, #1311).** The
  content engine's source-adapter -> canonical-lesson boundary is made
  explicit, preparing the `learn-content-engine` extraction.

## Fixed

- **iOS Safari zoom on task inputs / step change (#1353 / #1354).** A
  `@media (pointer: coarse)` guard floors every focusable text control at 16px
  on any touch device (iPhone + iPad, all orientations), and the mount-focus
  inputs use `preventScroll` so focus no longer fights the step scroll. The
  viewport stays zoomable (no WCAG regression).
- **iPhone delete menu (#1349 / #1350).** The "Meine Inhalte" set-actions
  dropdown is portalled so its items are tappable on iPhone (delete worked
  everywhere but there).
- **Persisted UI language survives an update (#1333 / #1334).** The saved UI
  language is now read at startup (localStorage, both storage modes) instead of
  silently falling back to German after a reload / PWA update.
- **Long Continue-Learning titles kept inside the card (#1328 / #1329).** Long
  "Weitermachen" titles no longer overflow the card on narrow viewports.
- **New content sets appear (#1337 / #1338).** The content catalogue is
  force-refreshed so newly-published sets show up in Discover.
- **README title reference corrected (German -> English).**
