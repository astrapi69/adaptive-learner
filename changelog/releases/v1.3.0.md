# Adaptive Learner v1.3.0

**Released**: 2026-05-20

Phase 16 — **Learning Progress Export (PDF + Markdown).** Three
new export types — Progress Report, Session Detail, Curriculum
Overview — work in both storage modes and render to either a
Markdown file or a browser-print-dialog PDF. Markdown is the
primary format; PDF is derived from the same source. Zero
server-side dependency for PDF: the browser's native print dialog
saves the file as PDF.

## Added

### 16A — Export data aggregation service

- New ``backend/app/services/export_service.py`` builds three
  structured payloads:
  - ``build_progress_report(db, user_id, lang)`` — the learner's
    full journey: latest method profile, per-project session
    counts + method distribution + method switches, last 10
    sessions across projects, step-evaluation insights, analyzed
    imported conversations.
  - ``build_session_detail(db, session_id, lang)`` — single
    session with full transcript, ratings, step-evaluation
    timeline, parent project context.
  - ``build_curriculum_overview(db, curriculum_id, lang)`` —
    curriculum with depth-first topic tree (each node carries
    a computed ``depth`` field for indented rendering) plus
    ordered lessons.
- New ``backend/app/routers/export.py`` exposes
  ``GET /api/export/progress?user_id=&lang=``,
  ``GET /api/export/session/{id}?lang=`` and
  ``GET /api/export/curriculum/{id}?lang=``.
- New ``frontend/src/storage/export-builder.ts`` mirrors the
  service browser-side so Dexie mode produces identical payloads.
  Field-name reconciliation (``StepEvaluationRow.suggested_step``
  → ``to_step``, ``created_at`` → ``evaluated_at``) lives in this
  module so the renderers see a single shape.
- ``IStorageService`` gains an ``export`` namespace with parity
  in both modes.
- 27 new pytest cases in ``test_export_service.py`` +
  ``test_export_router.py``; 16 new Vitest specs in
  ``export-builder.test.ts``.

### 16B — Markdown renderer

- New ``frontend/src/lib/export/markdown-renderer.ts`` dispatches
  by ``payload.type`` and emits human-readable Markdown:
  - Star ratings (★★★★☆) on 1-5 scales.
  - Percentage bars (█████░░░░░ 50%) for method profile weights.
  - GFM tables for method distribution, recent sessions,
    step-evaluation insights, step-evaluation timeline.
  - Blockquoted transcript with role headers.
  - Indented topic tree by depth.
- ``frontend/src/lib/export/i18n.ts`` ships DE + EN labels for
  every export string. Other six languages fall back to EN per
  the existing app convention.
- ``exportFilename(payload, ext)`` produces a slug + date based
  filename (e.g.
  ``adaptive-learner-progress-report-2026-05-20.md``).
- 22 new Vitest specs in ``markdown-renderer.test.ts``.

### 16C — Browser-side PDF generation

- New ``frontend/src/lib/export/markdown-to-html.ts`` — a
  lightweight Markdown → HTML converter handling exactly the
  subset the renderer emits (headings, paragraphs, nested lists,
  blockquotes, fenced code, GFM tables, inline ``**bold**`` /
  ``_italic_`` / ````code````). HTML escaped at the source so
  user-supplied content cannot inject tags.
- New ``frontend/src/lib/export/pdf-generator.ts`` —
  ``markdownToPrintHtml(md, title)`` wraps the HTML in a
  print-optimised document with theme-coloured headings,
  borders, page-break rules, and ``@page`` margins.
  ``openPrintWindow(md, title)`` attaches a hidden iframe,
  writes the document, calls ``contentWindow.print()`` and
  keeps the iframe attached for two seconds so the browser's
  print dialog can capture the document. The user picks "Save
  as PDF" — no PDF library shipped with the bundle.
- 25 new Vitest specs (``markdown-to-html.test.ts`` +
  ``pdf-generator.test.ts``).

### 16D — Export UI

- New ``frontend/src/components/ExportSection.tsx`` placed in
  Settings between BackupSection and AboutTab. Three rows, each
  with a label, an optional selector (session dropdown,
  curriculum dropdown), and three buttons:
  - **Preview** — populates an inline preview pane showing the
    first ~30 Markdown lines.
  - **Markdown** — downloads the rendered file via the standard
    Blob + anchor pattern (matches BackupSection).
  - **PDF** — opens the browser print dialog so the user picks
    "Save as PDF".
- i18n keys under ``export.*`` in all 8 catalogs (DE + EN
  translated, six others EN passthrough). i18n parity test
  stays green.
- Light dedicated CSS for the section (collapsible rows,
  preview pane, action button group).
- 5 new Vitest specs in ``ExportSection.test.tsx``.

### 16E — Integration with learning extractions

- The Progress Report's "Analyzed conversations" section now
  renders the structured ``ConversationAnalysisResult`` fields
  (``topic`` / ``user_level`` / ``subtopics`` / ``strengths`` /
  ``weaknesses`` / ``error_patterns`` / ``recommended_method`` /
  ``recommended_focus`` / ``summary`` / ``suggested_curriculum``)
  as human-readable Markdown — labelled sections, bullet lists,
  blockquoted summary, linked project id. Unknown / partial
  fields fall through to a JSON appendix so future analysis
  shapes still surface.
- 2 new Vitest specs in ``markdown-renderer.test.ts``.
