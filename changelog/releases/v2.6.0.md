# Adaptive Learner v2.6.0

A feature release on top of the v2.5.0 authoring release. The headline is that
the **session chat is rebuilt on assistant-ui and cut over**: after a phased
parity migration (i18n, theming, markdown, voice, imported sessions, cycle
transitions, resume hydration), the assistant-ui thread is now the default
chat and the self-built SessionChat is removed (#1126).

The second headline extends Create-Lesson's book path into a real ingestion
tool: **book-text file upload** (EPUB/TXT/MD and DOCX) with a chapter picker,
**multi-select of detected sections with a front-/backmatter exclusion
heuristic, and batch lesson generation** per selected section. Dictation
authoring completes with an **audio-file upload** for the dictation editor,
and content sets can now be **hidden via the engine's manifest `visibility`
flag** instead of a hard-coded blocklist.

Operationally, the desktop launcher moves onto **context-aware Docker
detection** (docker-app-launcher 0.14.1), and CI hardens: the ci.yml gates
become **required checks on develop**, plus three new gates (testid-reference,
visual-baseline auto-sync, Docker build smoke for the prod compose path).

The engine is re-pinned 0.13.1 -> 0.14.0 (manifest `visibility` field; the
engine is canonical, the app a consumer). NO app-side schema/API/data-model
change against v2.5.0.

## Added

- **assistant-ui session chat, cut over (#1126).** The session chat runs on
  `@assistant-ui/react`: parity phases covered i18n + theming + markdown +
  testids (#1984), Voice/Mic + read-aloud (#1986), imported-session clean-open
  with intro topic and the AI opening turn, domain wiring (#2003),
  cycle-transition parity (#2006), and resume-history hydration (#2009); the
  cutover makes the thread the default chat and removes SessionChat (#2012).
- **Book-text file upload in Create-Lesson (#1927).** Upload an EPUB/TXT/MD
  book file - DOCX joined in (#1950) - and pick chapters into the book-text
  path; `parseEpub` is decomposed under the complexity gate.
- **Multi-select sections + exclusion heuristic + batch generation
  (#1949 / #1953).** Detected book sections are multi-selectable, likely
  front-/backmatter is pre-excluded by a heuristic, and one run generates a
  lesson per selected section; the wizard path requires a title up front
  (#1946 / #1948).
- **Dictation audio upload (#1911).** The dictation editor accepts an uploaded
  audio file instead of only a typed asset path, completing the
  `ext:al-dictation` authoring chain.
- **Set visibility via manifest flag (#1707 / #1993).** A content set is
  hidden through the engine's manifest `visibility` field; the hard-coded
  `hidden-sets.ts` blocklist is dropped (engine re-pin 0.14.0).
- **Lesson picker for multi-lesson sets (#1971 / #1979).** Editing an own
  multi-lesson set offers every lesson instead of silently opening the first.
- **Content-domain selector in the wizard (#1716 / #1983)** plus two new
  knowledge domains, dog-training and traffic-knowledge (#1938).
- **Per-exercise difficulty indicator (#1693 / #1982).** Exercises surface
  their authored difficulty in the lesson player.
- **CI gates.** The ci.yml gates become required checks on develop so red CI
  is no longer mergeable (#1969); a testid-reference gate fails a PR that
  removes a spec-referenced testid on a high-visibility surface
  (#1661 / #1981); CI-rendered visual baselines auto-sync onto the PR branch
  (#1662 / #1980, using GITHUB_TOKEN for the PR housekeeping #2014 / #2016);
  a build-only Docker smoke covers the prod compose path - the
  launcher/install.sh build path no other gate exercised (#1990 / #1995).

## Changed

- **Desktop launcher: context-aware Docker detection (#1965 / #1976).**
  docker-app-launcher is bumped 0.12.1 -> 0.13.0 (context-aware Docker
  detection) -> 0.14.1 (pluggable GUI frontends); the install docs teach
  launcher self-diagnosis instead of manual docker commands, with a
  step-by-step start guide for all three binaries and a PWA-first note
  (#1960 / #1961, #1963 / #1964).
- **End-user help is versionless (#1767 / #1975).** Feature prose describes
  current behaviour; release provenance lives in the changelog, enforced by a
  verify_docs gate. Help content is synced to the post-v2.5.0 state (#2008)
  and backfilled into el/es/fr/ja/pt/tr (#2010).
- **Em-dash sweep (#2011 / #2013).** All self-authored UI copy and help docs
  across the 11 locales drop em-dashes per the coding standard.
- **CSS.** `.form-hint` / `.tile` defaults move into the shared components and
  the legacy rules are deleted (#1629 / #1985); the unstyled-classnames
  baseline ratchets down (#1996 / #1997).
- **Dependencies / security.** pyasn1 0.6.4 clears CVE-2026-59885 +
  CVE-2026-59886 (#1931); `fast-uri` is pinned >= 3.1.3 to clear the ajv
  transitive advisory (#1919); frontend mutation testing works under
  Vite 8 / Rolldown (#1956 / #1962); `learn-content-engine` re-pinned
  0.13.1 -> 0.13.3 -> 0.14.0 (#1937, #1993); routine backend + frontend
  minor/patch groups.

## Fixed

- **iOS / WebKit.** Long read-aloud text is chunked so iOS Safari stops
  truncating it (#1928); "Share result" no longer drops the result text on
  iOS (#1939), and the summary answer-diff keeps inter-word spaces
  (#1940 / #1941).
- **Lesson player.** Enter triggers the primary next-step CTA on the lesson
  summary (#1943 / #1944); a revisited step no longer auto-advances, so
  "Back" works (#1921 / #1924); the Options button sits in the progress
  indicator's row (#1942 / #1945).
- **Create-Lesson book path.** A small book-text lesson is editable without
  the create-time minimums (#1970 / #1973); a book-text lesson opens in the
  exercise editor instead of the empty card step (#1967 / #1968); editing a
  book lesson preserves the set-level book block (#1989 / #1992); the
  "language pair is valid" quality check re-renders (#1929); stray
  `ext_payload` is stripped from core exercises on edit-mode reconstruction
  (#1919).
- **Unstyled-page sweep.** Standalone page headers (#1922), the ShareWizard
  steps (#1912), the LearningRepo page (#1900), and the "My Contributions"
  section (#1972 / #1974) get real, token-backed styling.
- **i18n.** `landing.intro` and the docs link mirror into the first-paint
  fallbacks, so a non-English locale no longer flashes raw keys (#1902).
- **Visual determinism.** `media.yaml` / `books.yaml` are pinned so content
  surfaces render deterministically (#1696 / #1978), and lesson-surface shots
  pin graded state + scroll-to-top (#1785 / #1987).
- **Release tooling.** Two false alarms from the v2.5.0 run are silenced: the
  plugin-lock pairing hook resolves the repo it is actually committing in,
  and release-finish's remote-branch delete is a guarded no-op (#1903).
- **Tests / E2E.** Dexie E2E coverage for card image upload, the MC mode
  toggle, the summary favorite, and combining lessons (#1988); the
  book-upload dexie spec is rewritten for the multi-select picker (#2005);
  the dictation asset-path locator is pinned after the audio upload (#1955);
  the benign upload-artifact "no files found" warning is silenced on green
  runs (#2001 / #2002).
