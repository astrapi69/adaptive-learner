# Adaptive Learner v1.89.0

A feature release on top of v1.88.0. User-facing additions to the Settings AI
panel, the `.alb` backup format, and the Anki integration, plus a directory
restructuring with a new CI guard and a batch of fixes. No schema, API, or
data-model change.

## Added

- **Configured AI-providers overview in Settings (#812).** A Settings panel
  lists the configured AI providers with a masked preview of each stored key,
  so it is clear at a glance which providers are wired up without exposing the
  full secret.
- **`.alb` backup now carries a localStorage snapshot (#792).** The ZIP-based
  `.alb` backup export/import additionally captures and restores the
  localStorage snapshot, so client-side preferences and in-flight state survive
  a backup round-trip.
- **Browser-direct Anki AI card extraction in Dexie mode (#808).** AI-assisted
  flashcard extraction now runs browser-direct in Dexie mode, so the Anki
  feature works on the backend-less GitHub-Pages deployment.
- **Theory-only offline lessons can be saved (#796).** Saving an offline lesson
  no longer requires exercises; a theory-only lesson is now a valid save.

## Changed

- **AI chat analysis runs in the active UI language (#806).** The chat-import
  analysis prompt now generates its output in the active UI language instead of
  defaulting to a fixed locale.
- **API-key live test uses the models-list endpoint (#800).** The Settings
  API-key "Test" action validates the key against the provider's models-list
  endpoint rather than issuing a generation call, making the test cheaper and
  more reliable.
- **Relaxed Gemini/OpenAI API-key format validation (#794, #782).** The
  client-side key-format checks no longer reject valid OpenAI and Gemini keys;
  the Gemini check in particular no longer requires an AI prefix.
- **The AI gets lesson-progress context on session start (#798).** A session
  now starts with the learner's lesson-progress context so the AI's first turn
  is informed by where the learner is.
- **Directory restructuring + god-folder CI guard (#811).** Oversized
  directories (`shared/`, `components/`, `lib/`) are grouped by concern, and a
  new CI guard caps the number of files per directory to keep the structure
  from regressing. The complexity baseline is updated for the moved paths.

## Fixed

- **Native `confirm()` replaced with an app confirmation modal (#784).**
  Confirmation prompts now use the in-app `ConfirmDialog` instead of the
  browser-native `confirm()`.
- **Button-styled links keep their labels visible (#780).** Set and
  learning-path links rendered as buttons now carry `data-slot` so the label
  text stays visible across themes.
- **Backup import no longer crashes on Dexie-mode `api_key_backups` (#788).**
  An API-mode import of a Dexie-origin backup with `api_key_backups` rows no
  longer hits the `encrypted_key` NOT NULL constraint.
- **`.alb` files accepted at every backup-import surface (#786).** The `.alb`
  file picker is now available at every import entry point, including onboarding
  restore and the backup compare flow.
- **Per-level statistics labels stack above the bar (#805).** Long per-level
  labels in the statistics view stack above the bar instead of being truncated.
- **ContentPage complexity gate restored (#790).** ContentPage is decomposed
  back under the complexity gate (cc 23 -> 21).
- **Green develop restored (#802).** Backup parity, session-flow complexity,
  and end-of-file goldens realigned to keep develop green.

## Infrastructure / Dependencies

- Dependency bumps: cryptography 48.0.1 -> 49.0.0 (#777), the backend
  minor-patch group (#776), and the frontend minor-patch group (#778).
- EXP-035 design doc: Vercel AI Elements integration exploration (#789).
