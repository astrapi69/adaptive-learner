# Adaptive Learner v1.49.0

Minor release consolidating the API-key UX overhaul, the community
sharing-via-PR redesign, the chat-analysis loading indicator, and a
friendlier voice-input error path — plus the stable secret-key fix for
API-key encryption.

## Highlights

### API keys (Settings > AI)
- **Format validation** (instant, on input): each provider's key is
  shape-checked (Anthropic `sk-ant-` ≥ 90, OpenAI `sk-` ≥ 40, Gemini
  `AI` ≥ 30) with a green/red border + checkmark and an inline hint;
  Save is gated until the format is valid. Catches typos and
  wrong-provider pastes before saving.
- **Test button**: a one-click live test fires a minimal request at the
  provider and reports a clear result — works / invalid or expired /
  rate-limited / offline. Backend `POST /api/settings/{user}/test-api-key`
  in server mode; browser-direct in local (Dexie) mode.
- **Rollback cache**: a saved key is auto-tested first. A working key is
  saved and remembered as the last-known-good; a failing key never
  overwrites silently — you get Keep old / Save anyway / Restore last
  working key. Backups are Fernet-encrypted (server) / browser-local
  (Dexie), one per provider.
- **Stable Fernet encryption**: `secret.key` is now the persistent key
  source (created on first use, seeded from the env var when present),
  so saved API keys survive restarts.
- The secrets.yaml-sourced key is now **editable** in the UI (the app
  writes that file), and the displayed path is corrected to
  `~/.config/adaptive_learner/secrets.yaml`.

### Community sharing via Pull Request
- Sharing a lesson now opens a **GitHub pull request** instead of an
  issue: the lesson JSON is committed at its correct tree path
  (`sets/{source}/{target}-{level}/lessons/{nn}-{slug}.json`), the
  content-repo CI validates it automatically, and the maintainer just
  reviews and merges. Small lessons pre-fill the create-file editor
  (title + body); larger ones download the file and open the upload
  page. No token required.

### Chat analysis
- The Analyze action on an imported conversation now shows a **loading
  indicator** with phased progress, an estimated time, a spinner, a
  **Cancel** button (real abort), a friendly inline error on failure,
  and a smooth reveal of the results.

### Voice
- Microphone dictation shows **friendly, specific error messages**
  (no microphone found / offline / permission denied) instead of the
  raw Web Speech API error code.

## Notes
- All features work in both storage modes (API + local/Dexie).
- New i18n strings ship in all 8 languages (DE, EN, ES, FR, EL, PT, TR,
  JA), German with real umlauts.
- Content schema unchanged; new backend table `api_key_backups`
  (Alembic 0025) for the rollback cache; Dexie schema v24.
