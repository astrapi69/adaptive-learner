# Adaptive Learner v1.39.0

**Released**: 2026-05-29

Phase 56 — **EXP-010 Missionen und Plaketten** (missions subset).
Adds ACTIVE motivation on top of the passive XP/badge/streak
rewards: **daily missions** give the learner a few concrete,
achievable goals each day — a reason to open the app. Badge tiers
(bronze/silver/gold) and the badge-gallery drawer are deferred to
v1.40.0 / Phase 57.

## What's new

### Daily missions

- Up to **3 missions per day** on the Dashboard, between the
  streak and the badges. Optional, **no penalty** for a missed
  day — tomorrow brings a fresh set.
- **Adaptive + deterministic**: a seeded PRNG (user + date) picks
  one mission per difficulty slot; eligibility adapts to history
  (new learner → learning/exploration; with error history →
  review/mastery); the same mission never repeats two days
  running; the same day looks the same across devices.
- **Evaluated against EXISTING data** (LessonProgress /
  ElementError / streak) — the only new table is `UserMission`.
  Completion awards the template's bonus XP exactly once.
- 22-template catalog across 5 categories, fully translated in all
  8 languages; only checks computable from current data are
  assigned (5 are reserved for a future tracking phase).
- New `missions` plugin (`GET /today`, `POST /regenerate`) for API
  mode; full client-side path in Dexie mode (GitHub Pages).

### Settings — tabbed layout

- Settings moves from a long scroll to a discoverable **six-tab**
  layout (General / AI / Learning / Plugins / Data / Help),
  mirroring Bibliogon. Deep links + every existing control are
  preserved (inactive panels stay mounted, just hidden).
- New **Daily Missions** panel (Learning): on/off, count (1-3),
  difficulty mix, reset.
- New visual-only **Solo / Multiplayer mode indicator** (General):
  Solo is active; Multiplayer shows a "Coming Soon" badge — sets
  roadmap expectations with no infrastructure behind it.

### Celebration

- Missions wire into the v1.38.0 celebration bus:
  `mission_complete` + `all_missions_complete` sounds, a new
  `mission_complete` praise category, a praise toast, and a
  confetti burst when every mission for the day is done — all
  intensity-gated and reduced-motion-safe.

## Under the hood

- `UserMission` model + Alembic `0021` + Dexie schema v20 + sync
  surface (MUTABLE, 31 tables) + a new `missions`
  `IStorageService` namespace (Dexie + Api).
- Timezone-aware local-midnight rollover + a streak-joker helper.
