# Adaptive Learner v1.71.1

Patch release — a sweep of dark-theme contrast and spacing fixes from
manual testing, plus one data-export bug fix. Frontend + one plugin/
storage fix; no schema, API or data-model changes.

## Fixed

- **Session Detail export no longer fails with "Session … not found"**
  (#209). The export dropdown is populated from the tracking summary's
  `recent_sessions`, whose `id` is the **ProgressCommit** id — a distinct
  UUID from the `LearningSession` id the export builder loads by. The
  lookup therefore always missed, breaking every Session-Detail
  Markdown/PDF export in **both** storage modes. `recent_sessions` now
  carries the originating `session_id` (Dexie tracking + the API tracking
  summary) and the export targets it. Regression-pinned on both sides.
- **Bare buttons no longer go invisible in dark themes (systematic
  root-cause)** (#211). The `.btn` base class defined layout but no text
  `color`; only its variants (`.btn-primary/-secondary/-danger`) set one,
  so a variant-less `.btn` (a bare `<button class="btn">` or an
  `<a class="btn">`) had no explicit colour and fell back to an invisible
  value on dark surfaces. The v1.71.0 `button { color: inherit }`
  base-layer reset only reached raw `<button>` elements. `.btn` now sets
  `color: var(--fg-primary)`; variants still override it. A contrast-test
  guard pins that `.btn` always declares a colour.
- **Daily Missions "Reset today's missions" button is readable in dark
  themes** (#205). It was a raw `<button class="btn">` (the class above)
  and is now the shadcn `<Button variant="destructive">` — correct
  per-theme contrast by construction, and the right variant for a reset.
- **ThemePicker inactive tab is readable in dark themes** (#207). The
  inactive theme-group tab used `text-fg-muted`, which drops below WCAG
  AA on elevated surfaces (catppuccin-latte `fg-muted` on `bg-elevated` =
  3.49:1). It now uses `text-fg-secondary` (AA on surface + elevated
  across all 12 themes), with a new contrast-test pin closing that gap.
- **Donation "preferred" badge text is readable in dark themes** (#201).
  The badge hardcoded `background: rgba(255,255,255,0.2)` inline, so its
  text disappeared on dark themes. It now routes through the `--accent-fg`
  token (the badge sits on an accent button, so it is AA by construction).
- **Chart data-table "Show data as table" trigger is readable in dark
  themes** (#218). The `<summary>` used `var(--accent)` as text, only
  pinned ≥3:1 on the elevated chart cards. It now uses `var(--fg-primary)`
  (AA on all surfaces) with accent as the hover affordance; the data table
  migrates to a new dependency-free shadcn `Table` component, token-themed
  across all 12 themes.
- **Matching: orange dropped from the matched-pair palette** (#199).
  Orange (`--matching-pair-3`) reads as a warning/error cue on a *correct*
  pairing, the same problem red had in #181. Replaced with cyan; a guard
  pins the whole `--matching-pair-*` palette free of red/orange hues.
- **Learning Repository settings layout + dev-info** (#203). The
  settings rows had no vertical spacing and sat side by side (the
  `.settings-row` classes had no CSS); they now stack with a gap (shadcn
  `Input` for the directory field), and the developer-only
  "(POST /persist endpoint)" text is dropped from the label in all eight
  languages.
- **Dashboard tags-filter spacing + Nav "Help" consistency** (#213,
  #214). The "Tags" label and its "No tags yet" empty state collapsed
  onto one line; they now stack with a gap. The "Help" nav item is a
  `<button>` that lacked a reset, so it carried UA button chrome and
  looked like a separate raised button; it now matches the anchor
  nav-links.
- **Progress › Learning materials action spacing** (#216). Roomier,
  token-driven spacing between the three action buttons and before the
  difficulty filter.

## Notes

- New dependency-free shadcn primitive: `components/ui/table.tsx`
  (token-themed Table), introduced by #218.
- No new runtime dependencies. No database migration. Both storage modes
  (API + Dexie) verified.
