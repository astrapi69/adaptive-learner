# Adaptive Learner v1.53.2

Patch release - one P0 fix. No schema, data-model, or migration changes;
both storage modes (API + Dexie) unaffected.

## Fixed

- **Share Wizard source language ALWAYS defaults to the app language**
  (permanent fix, third occurrence). The wizard kept the saved lesson
  metadata's source language whenever it was a valid code different from
  the target, so lessons saved before the original source-language fix
  (which carry `source_language: "en"`) showed "en" in Step 1 even when
  the app was set to German. The source language (what the learner
  speaks) now always defaults to the app language (`useI18n().lang`),
  never the saved metadata; the user can still override it via the
  dropdown. The target language (what they learn) keeps the saved value
  when it is valid and different, otherwise content detection. This also
  clears the follow-on "Weiter stays disabled after changing languages"
  symptom, which was the stale source leaving the target default empty.
  Regression tests pin "app language wins" and live re-validation on
  every dropdown change; the rule is recorded in
  `.claude/rules/lessons-learned.md` so it cannot regress a fourth time.
