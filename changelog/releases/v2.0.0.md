# Adaptive Learner v2.0.0 - First public release

Adaptive Learner is a free, open-source (MIT) learning app you run yourself.
It is **offline-first** and **account-free** (your data lives in your browser
or your own SQLite file, never on someone else's server), uses **spaced
repetition** to schedule what you review, lets you **bring your own AI key**
(Claude, OpenAI, or Gemini) so AI help is optional and paid for by you, and
lets you **author and share your own lesson content**. It installs as a PWA:
no app store, works offline once loaded.

This is the first version published for a general audience. It is a **launch
milestone, not a technical break** - there is no breaking change against
v1.99.0. The jump from 1.99 to 2.0 is deliberate for two non-technical
reasons: it avoids the awkward 1.100 boundary, and a first public version is a
natural place to draw the line.

## Highlights for learners

- **Seven ways to run a lesson.** Practice, Exam (delayed feedback + a
  pass/fail result + an XP bonus), Timed (Auf Zeit), Reverse, Shuffle
  (interleaved), and Endless, plus a focused **"train your errors"** mode that
  replays only what you got wrong.
- **Learning you can configure.** Choose which sections the end-of-lesson
  summary shows **and in which order**; keep the correction round on or off (and
  it always comes last); set the order of the content tabs; opt into
  auto-advance after a correct answer.
- **Multiple choice, done right.** Single-answer questions and "select all that
  apply" multi-select, rendered as touch-friendly buttons that behave on a
  phone.
- **Your own content.** "My content" lets you multi-select downloaded sets,
  filter them, import lessons from a file, and connect your own content
  repositories - including private ones shared by an invitation code.
- **Discover** new sets with a source-language filter that follows your app
  language.
- **Export** your results and lessons as Anki decks, Markdown, or PDF.
- **Optional AI help (BYOK).** One inviting card sets up your own Claude,
  OpenAI, or Gemini key; AI tutoring, chat analysis, and exercise generation
  stay entirely optional and run on your key.

## Under the hood

- **A published, standalone content engine.** The lesson format now lives in
  its own package, [`learn-content-engine`](https://github.com/astrapi69/learn-content-engine),
  which the app consumes as a runtime dependency. The format is documented and
  test-validated on its own, so your content is not locked to the app: you can
  author and validate lessons against the engine's reference and schema
  directly. The content repositories mirror the same pinned engine release.
- **iOS PWA hardening.** The installed app now self-detects a new build when you
  return to it, survives the portrait/landscape rotation transition, keeps the
  action button reachable in landscape, and pins the step navigation inside the
  safe area.
- **Content-sync robustness.** Public content repositories are read over raw
  URLs (never the shared token), and each repository syncs independently with
  error isolation and an explicit "Sync all".

## Platform

- Installable PWA - add it to your home screen or desktop; no app store needed.
- Works offline for past sessions, the Dashboard, and Progress.
- Runs locally via the Docker-based launcher (Windows / macOS / Linux binaries
  attached below), or as the static browser build.

## Before you install

Adaptive Learner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads Adaptive Learner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

If your operating system warns about an unsigned binary, see the [Adaptive Learner installation overview](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/installation.md).
