# Adaptive Learner v1.97.0

A schema-and-tooling release: the lesson JSON-Schema becomes the
App-authoritative single source of truth (EXP-039) and the structural
validator is ajv-hardened against it; the desktop nav gains a vertical
sidebar and single-set deep links; cloze grows "select all that apply"
multiselect; exam answers earn an SRS interval boost; AI keys + provider
settings get a passphrase-encrypted `.alk` export; plus an exercise-type
generation rule (EXP-041), several device-test fixes, two #809 god-folder
splits, and a documentation sweep.

## Added

- **Lesson JSON-Schema as single source of truth (EXP-039):** the lesson
  schema, quality rules, doc, and TypeScript types are generated from the
  App's Pydantic models (#1197); the TS lesson types now consume that
  generated schema directly (#1200), and the structural validator is
  ajv-hardened against the generated schema (#1205). A `make sync-schema-check`
  drift gate guards it.
- **Cloze multiselect (#1195 / #1201):** cloze blanks support a "select all
  that apply" multiselect mode; multiple-choice content is authored as
  cloze-select.
- **Exam-mode SRS boost (#1040 / #1198):** a correct answer in Exam mode
  earns an extended SRS review interval.
- **Encrypted key export `.alk` (#1165):** passphrase-encrypted export/import
  of AI keys and provider settings, surfaced on the Settings AI tab.
- **Desktop vertical sidebar (#891 / #1191):** the primary navigation can
  render as a vertical desktop sidebar.
- **Single-set deep link (#892 / #1192):** a `/content/set/:setId` route opens
  a single content set directly.
- **Native share sheet (#1219 / #1220):** "Share result" uses the native Web
  Share sheet with a desktop social-link fallback.
- **Latest strand visibility (#1172):** the Latest content strand is shareable
  (Haupt + Latest) with an About-tab strand badge.
- **iOS Add-to-Home-Screen guidance (#1167):** an installation hint plus a
  testable PWA manifest.
- **AI-generation rule (EXP-041, #1225):** the exercise-generation prompt
  couples exercise type to the learning goal (`word_tiles` only for
  unambiguous sentences; definitions as cloze).

## Changed

- **Exercise UX:** a correct answer merges the redundant answer toggle into a
  success "Continue" action (#1218 / #1221).
- **Content sorting (#1211 / #1212):** untouched downloaded sets sort by
  download date, newest first.
- **Code structure (#809):** `components/exercises` (Slice A, #1206) and
  `hooks/lesson` (Slice B, #1210) split into concern subfolders; `lib/ai`
  split into generation / validation / providers (#917 / #1190); voice
  `localStorage` keys consolidated into one block (#893 / #1188).

## Fixed

- **Encrypted key export placement (#1181 / #1182, #1183 / #1184):** the
  `.alk` export lives once on the Data tab; the AI tab links to it.
- **Cloze answer review (#1216 / #1217):** cloze exercises gain the
  My-answer / Solution toggle.
- **Share intent (#1227 / #1229):** the X share-intent carries the lesson
  text, not just the link.
- **Word Tiles instruction (#1228):** same-language content shows a
  domain-aware instruction instead of "translate", so a content-correct
  sentence is no longer mis-graded by exact match.

## Tooling / CI

- **Theme/token gate (#1169 / #1173):** a `verify-theme` token-completeness +
  WCAG-contrast gate, run as a Python step in `release-test` (#1185 / #1186).
- **Local Make targets:** `test-fast` + `test-changed` (#1174 / #1176),
  `test-e2e-smoke` for the release-gate smoke run (#1177 / #1178), local
  security + circular-deps targets mirroring the nightly scan (#1179 / #1180),
  and `dev-lan` single-origin LAN serve for on-device testing (#1170 / #1171).

## Docs

- TDD anchored as a permanent rule (#1202 / #1204); EXP-041 exercise-type
  authoring guideline (#1224); multiple-choice-via-cloze-select clarified
  (#890 / #1196); a device-check session checklist for the merged-but-
  unverified UI batch (#1213); and an MkDocs help + README sweep to the
  develop feature state (#1215).

No schema-breaking, API, or data-model change: the lesson schema work is an
additive generation pipeline over the existing Pydantic models, and the
Alembic / Dexie schema versions are unchanged.
