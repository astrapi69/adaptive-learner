# Adaptive Learner v1.54.0

A big release: the **import-time language pipeline** (a root-cause fix for
the recurring source-language bug) lands alongside a **large content
expansion** — 10 sets / 200 lessons across 3 domains.

## Highlights

### ROOT CAUSE FIX: languages set once, at import time
- The language pair is now captured at **import** time and inherited
  through the **entire pipeline** — import → analysis → save-as-lesson →
  share — instead of being guessed and patched at each downstream step.
- `ImportedConversation` gains `source_language` (the chat language the
  learner speaks) + `target_language` (what they learn): Alembic 0026 +
  Dexie schema v25, both nullable/backward-compatible.
- **Import page:** two language pickers above "Analysieren" — "Chatsprache"
  defaults to the app language, "Lernsprache" is auto-detected from the
  chat content (`detect-chat-language.ts`: signal words + scripts, a
  foreign language needs ≥2 signals to beat the prose language).
- **Analysis prompt** includes a learner-language context block
  ("a {source} speaker learning {target}") so the AI extracts the right
  language's vocabulary / error patterns — both the browser-direct and
  backend analyze paths.
- **Save-as-lesson** and the **share wizard** READ the pair from upstream
  instead of guessing; the app language is now only a fallback for old
  imports without a pair. The share wizard inherits the lesson's source
  when it is a valid code different from the target.

### Domain-aware sharing
- A language set needs source != target, but **same-language material**
  (grammar, a subject) now ships as non-language **knowledge** content —
  `source == target` is allowed for non-language domains, mirroring the
  content repo's `validate_content.py`. The share wizard no longer blocks
  it; a hint explains it.

### Content: 10 sets / 200 lessons across 3 domains
- **A2 levels** for German speakers: French A2, Spanish A2, English A2
  (15 lessons each, building on A1).
- **DE→EN A1** (English for German speakers, with false friends).
- **Python Grundlagen** (schema v1.3, verified code snippets).
- **Psychologie** expanded (65 lessons).
- Schema **v1.3**: code fields (`code_snippet` / `code_language` /
  `expected_output` / `hint` / `difficulty` / `media_type`), domain
  support, and code-aware exercises.

### Folded-in fixes (shipped as v1.53.1 / v1.53.2 patches)
- **FIX:** single two-phase button on the Adaptive Lesson and Review
  pages (they were showing both "Prüfen" and "Weiter").
- **FIX:** community-PR file attachment works for lessons of any size
  (single lessons use the create-file flow, which creates the new nested
  set directory and auto-forks; never falls back to a 404 upload page).
- **FIX:** share-wizard source-language inheritance (now pipeline-based,
  permanent).
- Editable, validated share-wizard Step 1 (title / source / target /
  level), empty-lesson + non-CEFR-level gating.
