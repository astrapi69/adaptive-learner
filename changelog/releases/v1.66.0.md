# Adaptive Learner v1.66.0

Maintenance release — a **systematic backup-restore fix** (the recurring
import P0, now solved generically), a **deploy-safe lazy-route reload**
for the GitHub-Pages build, and **subject-filter UX polish**. No schema
change; both storage modes (API + Dexie / GitHub-Pages) carry
everything.

## Fixed

- **Backup restore — comprehensive, generic fix** (#115, #117). The
  prior point-fixes (badges UNIQUE #49, datetime #57, FK-order/orphan
  #64) each patched one symptom; this replaces them with a generic
  type-coercion + matching layer so an import no longer aborts:
  - **Unique-key matching** — restore matched rows by primary key only,
    but 13 of the 30 tables carry a UNIQUE constraint other than `id`
    (the `user_settings`/`user_streaks`/`user_xp` singletons, the
    composite keys on `tags`/`lesson_progress`/`element_errors`/… ).
    Importing an older backup, or onto a clean install whose app already
    auto-seeded those singletons, hit a row with the same unique key
    under a different id and crashed with a UNIQUE violation. Restore now
    matches by any non-id UNIQUE constraint, updates in place, and
    redirects child FKs (derived from the FK graph). A unique-matched
    placeholder is reclaimed by the backup (fixing a latent data-loss
    the crash was masking).
  - **JSON-column serialization** — a JSON-in-`Text` column
    (`badges.tier_thresholds`, lesson/note content, anki tags) carried
    as a parsed object by an older/Dexie-origin backup bound a `dict` to
    a text column (`sqlite3.ProgrammingError: type 'dict' is not
    supported`). The restore coercer now serializes dict/list values for
    any String/Text column, keyed off the column type — like the
    datetime coercer.
  - **Empty tables skipped** — the export omits 0-row tables and restore
    skips them, shrinking the payload and the error surface.
  - Verified end-to-end through the real backup API (export → import,
    including the dict-`tier_thresholds` shape) plus a comprehensive
    test suite (clean-install, idempotent re-import, older-backup,
    FK-remap, JSON round-trip, empty-table omission).
- **GitHub-Pages: lazy route no longer crashes after a deploy** (#113).
  Navigating to a route after a new deploy could throw "Failed to fetch
  dynamically imported module" when a stale `index`/service-worker cache
  referenced a hashed chunk the deploy had purged. A `lazyWithReload`
  wrapper now performs one automatic reload (loop-guarded) to fetch the
  fresh index + chunks instead of crashing into the error boundary, and
  Workbox `cleanupOutdatedCaches` purges superseded precached chunks.
- **Subject filter UX** (#111). The Dashboard subject filter now hides
  when the user has only one subject (a one-option filter is not a
  filter), orders subjects most-used-first, and groups them by category
  once there are more than five.
