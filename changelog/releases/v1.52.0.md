# Adaptive Learner v1.52.0

Minor release that adds a **fifth language course — English A1 for German
speakers (DE→EN)** — and closes two backend data-integrity bugs in the
backup/restore path, plus a P0 fix for the Lesson Creator.

## Highlights

### NEW: English A1 for German speakers (DE→EN, 15 lessons)
- A complete A1 course teaching **English to German speakers** — the
  notes, theory, and card backs are written in German.
- **False-friend drills** for the classic DE/EN traps:
  `become`/`bekommen`, `gift`/`Gift`, `handy`/`Handy`, `chef`/`Chef`,
  `actual`/`aktuell`.
- **German-targeted distractors** that mirror the mistakes German
  learners actually make: dropped third-person `-s`, missing
  do-support, treating uncountable nouns as plural.
- **Progressive direction** across the set (EXP-018): early lessons are
  receptive (recognise), the middle is mixed, the later lessons are
  mostly productive (produce).

### Content library now spans 5 sets / 75 lessons
- Sets: `de/en-a1` (new), `de/es-a1`, `de/fr-a1`, `en/es-a1`,
  `en/fr-a1` — **15 lessons each, 75 total**, roughly **12.5 hours** of
  guided A1 material.
- All five are bundled into the GitHub Pages build, so first-time
  visitors get the full library offline with no API key.

### FIX: backend backup restore now covers all 30 tables (BACKUP-API-RESTORE-01)
- API-mode backup *exported* all 30 tables but the restore order only
  listed **16**, so a backup → restore in API/SQLite mode **silently
  dropped 14 tables** of data: gamification (XP / badges / streaks),
  lesson progress, SRS element errors, daily missions, anki cards,
  study questions, the subjects/tags taxonomy, and api-key backups.
- The restore order is now **derived from the same source as the
  export** (the sync surface, sorted by FK-dependency), so the two
  sides can never drift apart again.
- A **parity regression test** pins `export == restore == sync`, and a
  full 30-table seed → export → wipe → restore round-trip verifies
  every table's data comes back.
- **Per-table flush during restore** fixes a latent FK-violation: with
  a single end-of-restore commit, SQLAlchemy ordered inserts by ORM
  relationships, but the gamification / SRS / content tables are
  deliberately decoupled (FK columns, no relationships) — a child row
  could be inserted before its parent. Flushing in the explicit
  FK-safe order resolves it.

### FIX: production database guard
- A new process-wide guard refuses full-table `DELETE` / `DROP` /
  `TRUNCATE` against a production-marked data directory from any
  non-application process (ad-hoc scripts, REPLs). The running app is
  unaffected; scoped `DELETE ... WHERE ...` is never touched. This
  closes the gap the existing pytest tripwire didn't cover.

### FIX (P0): Lesson Creator — "Next" advances past Step 1 again
- A **resumed draft** whose source and target language were equal left
  Step 1 of the Lesson Creator permanently unadvanceable — the
  same-language guard never cleared, so "Next" silently did nothing.
  The draft loader now repairs an equal language pair on load, so a
  resumed draft is always advanceable. (A fresh form was never
  affected.)

## Notes
- No schema or migration changes. The backup *file format* is
  unchanged — the API-mode restore simply stopped omitting tables it
  already knew how to restore.
- Content lives in the `astrapi69/adaptive-learner-content` repo and is
  bundled at build time.
- Tests: backend + plugins + 2959 Vitest, the Dexie-mode release gate
  (51 specs), and the docs-discipline gate all green.
