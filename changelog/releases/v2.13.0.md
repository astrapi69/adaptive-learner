# Adaptive Learner v2.13.0

The lesson editor learns conversion: an exercise can now change its TYPE in place - dictation or image-description into free text, cloze and error-correction into free text, free text into multiple-choice or cloze, and graded quiz and reading comprehension into each other - with your review history carried along wherever the content survives, and an AI suggestion filling the fields a conversion leaves empty. Editing downloaded content is clearer too: "Edit as a copy" sits directly on the set, a fork records where it came from and wears an "Eigene Bearbeitung" badge, and re-importing a set no longer wipes the SRS history of unchanged exercises.

Two long-standing session annoyances are gone: the end-of-lesson correction round now actually corrects (it used to replay without recording), and read-aloud keeps the screen awake for the whole playback.

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive-learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads the ready-built AdaptiveLearner image from GitHub's registry (about 110-120 MB compressed, roughly 500 MB on disk - nothing is built on your machine), and opens the app in your browser. Later starts are fast and work offline.

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>

# Windows (PowerShell)
Get-FileHash adaptive-learner-launcher.exe -Algorithm SHA256
```

Compare the output with the matching `.sha256` file from the release assets.

## What's new

### Added

- Lesson editor: in-place exercise-type conversion (EXP-050) - dictation/image-description to free text, cloze/error-correction to free text (with a key-move announcement), free text to multiple-choice/cloze, and graded quiz and reading comprehension into each other; an AI suggestion fills the fields a conversion leaves empty.
- Content: a discoverable "Edit as a copy" action on downloaded sets; a fork records its derivation and shows an "Eigene Bearbeitung" badge; the ShareWizard hints at carried foreign credits and removes them in one click.
- The lesson "Ask AI" button is configurable in Settings.
- i18n: catalogs for the six al_* exercise types completed across all 11 languages.

### Changed

- Large UI-consolidation push (EXP-044 Option C): shared SettingsSection, Modal and DashboardCard components, the button family migrated to the shadcn Button, forms and remaining inline styles converted to token-backed utilities - visual polish across Settings, Dashboard and dialogs with their legacy CSS deleted.
- Dependency refresh: FastAPI 0.141 + Starlette 1.6 across backend and all plugins, TipTap 3.30.1 lockstep, @assistant-ui/react 0.15, Anthropic SDK 0.122 (live-call proven), Stryker 10.

### Fixed

- Re-importing/overwriting a content set carries the SRS and error history of unchanged exercises instead of discarding it.
- The end-of-lesson correction round records corrections again instead of replaying without effect.
- Read-aloud playback keeps the screen awake.
- Reading comprehension shows correct answers in green on check.
- The review session no longer restarts (back to loading) when the translation catalog resolves after first paint.
- Unstyled-UI sweep from the #1728 live-render audit: Dashboard, Content browser, lesson exercise and summary views, Backup section, Discover grid, resume-dialog spacing, learning-repo file buttons, long set titles truncate on mobile.
- Raw buttons no longer inherit the user-agent border (third preflight-off leftover).
- The eruda debug console ships dev-only - no chunk in the production image or on GitHub Pages.
- Topic tree tolerates a deleted parent (tree-kit 0.3.0).

### Internal

- Visual-regression pipeline made trustworthy end to end: the nightly gate now renders in the same pinned Playwright container that produces the baselines, the comparator caps diffs at an absolute 2,500 pixels (a full page-state swap used to fit inside the desktop ratio budget), the baseline sync detects re-rendered files after a deletion, tall pages actually paint below the fold, the motivation toast no longer races the screenshot, and all 135 baselines were re-rendered uniformly under pinned rasterization; the suite is CI-parallel (4 workers) and deterministic across consecutive runs.
- Rules: parametrized tests pinned as the value-table convention (with a reference retrofit), blank-baseline lesson recorded.
