# Adaptive Learner v1.72.0

Minor release — a **CI / quality-infrastructure build-out** (ESLint,
security scanning, coverage floors, circular-dependency detection,
Dependabot, Prettier, bundle analyzer, Stylelint, Playwright visual
regression + axe-core accessibility) alongside a sweep of **dark-theme
contrast, layout, and Import-Detail UX fixes** from manual testing.
Frontend + CI/tooling only; no schema, API, or data-model changes.

## Added — quality infrastructure

- **ESLint flat config + CI + pre-commit** (#222). ESLint v9 flat config
  for the frontend, a CI step (`--max-warnings` ratchet ceiling), and a
  pre-commit hook (errors block; the existing warning backlog does not).
- **Dependency security scanning** (#224). `npm audit --audit-level=high`
  (frontend) + `pip-audit --skip-editable` (backend) in CI; a high/critical
  advisory fails the build.
- **Coverage floors** (#225). Backend `--cov-fail-under=88`, frontend
  `lines=81` — ratchet floors 5% below current, raised as coverage climbs.
- **Circular-dependency detection** (#251). `madge` guard
  (`frontend/scripts/check-circular.mjs`) fails CI only when import cycles
  exceed the documented baseline of 3 (the pre-existing cycles are tracked
  in #252); the baseline only ratchets down.
- **Dependabot** (#253). Weekly npm (`/frontend`) + pip (`/backend`),
  monthly github-actions, minor/patch grouped per ecosystem.
- **Prettier — step 1** (#254). Config matching the actual house style
  (2-space, double quotes, semicolons — the `code-hygiene.md` example was
  stale), `.prettierignore`, a format-on-touch pre-commit hook scoped to
  `frontend/src/`, and a non-blocking CI check. No repo-wide reformat (a
  separate step-2 PR).
- **Bundle analyzer** (#255). `rollup-plugin-visualizer`, gated behind
  `ANALYZE=true npm run build:analyze` (dev tool; no CI gate).
- **Stylelint** (#257). `color-no-invalid-hex` as a hard error;
  `no-duplicate-selectors` / `no-descending-specificity` /
  `declaration-no-important` as warnings (pre-existing debt reported, not
  blocked).
- **Visual-regression testing** (#244). A Playwright `visual` project
  pixel-diffs 5 critical views × 12 themes (60 desktop shots) against the
  dexie preview build. Theme slugs verified against the registry; the
  suite is hardened against flake (frozen clock, pinned locale/timezone,
  font + animation settle, content-ready waits). Baseline PNGs are
  generated + reviewed via `make test-visual-update`.
- **axe-core accessibility checks** (#246). `@axe-core/playwright` audits
  7 critical routes (WCAG 2.0 A + AA) in the smoke project, failing on any
  violation outside a documented, shrinking allowlist.

## Fixed

- **My Lessons action buttons wrap onto their own row** instead of
  overflowing (#226).
- **Theory "Re-read theory" back-link contrast** in dark themes —
  `fg-muted` → `fg-secondary` for AA (#228).
- **Lesson-summary secondary actions** read as faint `ghost` → `outline`
  (#230).
- **Active project item** in the Dashboard filter gains a token-based
  accent highlight (the `.dashboard-project-item-active` class had no CSS)
  (#232).
- **Import-Detail heading** shows the analysis title, not the raw
  hyphenated filename (#234).
- **Theory "Back to exercise" button** `ghost` → `outline` so the primary
  way back is clearly clickable (#236).
- **Sessions metric labels no longer overflow** the 5-column tile —
  compact `Ø …` i18n labels (8 langs) + a responsive 5→3→2 grid (#238).
- **Import-Detail raw transcript** is collapsed by default behind a
  "Show raw transcript" toggle, so the analysis stays front-and-centre
  (#240).
- **Matching wrong-pair feedback** no longer overlaps the next tile on a
  narrow viewport (375px) — the tile `<li>` is a flex column and the
  button yields space to the feedback (#242).
- **ImportDetail test** scoped to the analysis-results region after the
  heading began showing the topic (#248).
