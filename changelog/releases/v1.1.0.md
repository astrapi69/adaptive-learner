# Adaptive Learner v1.1.0

**Released**: 2026-05-20

Phase 14 — **About tab in Settings.** Five-section panel
appended as the last block of the Settings page, with a new
backend system-info endpoint and a storage-mode-aware payload
so the same UI renders cleanly in both API and Dexie modes.
Also folds in the v1.0.1 hotfix for robust JSON extraction.

## Added

### 14A — GET /api/system/info

- New ``backend/app/routers/system.py`` mounted at
  ``/api/system/info``. Aggregates the About-tab payload in
  one call:
  - **app**: name, version (from canonical ``pyproject.toml``
    via ``app.__version__``), license, authors, repository_url,
    issues_url, docs_url, build_hash (``git rev-parse --short
    HEAD``, fallback ``"unknown"``), build_date (HEAD commit
    date, fallback ``now()``).
  - **runtime**: python_version, platform_system /release/
    machine.
  - **dependencies**: fastapi, sqlalchemy, pydantic,
    pluginforge — each a version string or ``null`` (stripped
    install graceful degrade).
  - **paths**: database_path, data_directory (from the
    canonical ``app.paths`` helpers).
- Defensive: subprocess timeout on git, ImportError catches
  on optional deps, malformed pyproject collapses to safe
  defaults.
- 7 router tests cover happy path, git-unavailable fallback,
  content type. Backend total 489 (was 482).

### 14B — About tab components

New ``frontend/src/components/about/`` directory with the
spec'd 6 files:

- **AboutTab.tsx**: parent, fetches ``SystemInfo`` once on
  mount via the storage layer, composes the five sections,
  handles loading + error states.
- **VersionSection.tsx**: app version, build hash (linked to
  the GitHub commit when not "unknown"), build date (locale-
  formatted).
- **SystemInfoSection.tsx**: storage mode label, data
  directory, db path (API mode only), Python version (API
  mode only), platform, FastAPI / SQLAlchemy / Pydantic /
  PluginForge versions (API mode only). Hides null rows in
  Dexie mode rather than rendering a column of "unknown".
- **CreditsSection.tsx**: author Asterios Raptis linked to
  github.com/astrapi69, canonical dependency
  acknowledgements (React, FastAPI, PluginForge, Dexie,
  Recharts, SQLAlchemy, Pydantic, Vite, TypeScript),
  tagline "Built for self-directed learners."
- **DonationSection.tsx**: three verified channels —
  Liberapay (primary, verified live via WebFetch on
  2026-05-20), GitHub Sponsors (HEAD 200 OK), Ko-fi (page
  confirmed live; 403 from headless probes is Cloudflare
  bot-blocking, not a missing-page signal). Each link is
  ``target="_blank"`` with ``rel="noopener noreferrer"``.
- **LicenseResourcesSection.tsx**: license string from
  SystemInfo + GitHub link to LICENSE text, repository, docs
  (astrapi69.github.io/adaptive-learner/docs/), issue
  tracker.

Storage-layer wiring:
- ``types/domain.ts``: new ``SystemInfo`` interface.
- ``api/client.ts``: ``api.system.info()``.
- ``storage/types.ts``: ``ISystemNamespace`` added to the
  storage contract.
- ``storage/api-storage.ts``: thin delegate.
- ``storage/dexie-storage.ts``: synthesises the same shape
  browser-side (version from Vite's ``__APP_VERSION__``
  define, nulls for backend-only fields, "Local Browser
  Storage (IndexedDB)" for the paths).
- ``pages/Settings.tsx``: ``<AboutTab />`` appended after
  ``<SyncSection />``.

14 Vitest cases cover each sub-section's render, storage-
mode-aware branching, and the AboutTab integration (load,
error, Dexie payload). Frontend total 591 (was 577).

### 14C — i18n

~30 keys under ``about.*`` mirrored across all 8 catalogs:
- DE + EN: handwritten native translations.
- ES + FR + EL: native translations (consistent with the
  v0.9.0 ``import.*`` convention).
- PT + TR + JA: EN passthrough (native translation is a
  separate polish track, matches the existing nav-block
  convention in these three).

i18n parity test stays at 36/36.

## Carried forward from v1.0.1 hotfix

- ``frontend/src/lib/extract-json.ts``: defensive balanced-
  brace JSON extractor used by conversation analysis,
  smart-merge, and the step evaluator. Fixes the "AI
  response was not parseable as structured JSON" failure
  the v0.9.0 launch surfaced with
  ``claude-3-5-haiku-latest``.
- Strengthened system prompts with explicit "MUST start
  with ``{``, MUST end with ``}``, NO preamble, NO fences,
  NO commentary" rules.
- ``DEFAULT_MODELS`` anthropic default bumped
  ``claude-3-5-haiku-latest`` →
  ``claude-haiku-4-5-20251001``.

## Notes

- The About tab's donation channels link to the maintainer's
  own funding accounts. The "preferred" badge marks
  Liberapay because it has the lowest platform overhead.
- ``build_hash`` resolves to ``"unknown"`` when the install
  has no ``.git`` (Docker image, PyInstaller frozen binary,
  sdist install). The UI hides the commit-link in that case.
- Dexie-mode browsers render the same panel; the rows that
  don't apply (Python version, backend dep versions, DB
  path) are hidden rather than rendered as "unknown".
