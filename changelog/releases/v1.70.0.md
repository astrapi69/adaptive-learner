# Adaptive Learner v1.70.0

Minor release — first-run backup restore, a comprehensive
documentation overhaul, context-sensitive in-app help, and a manual
test plan.

## Added

- **First-run backup restore** (#150). On an empty install (a fresh
  browser, a cleared database, a new device), onboarding now offers
  **"Restore from backup"** instead of forcing a from-scratch start.
  Returning users land back in their data after a device or browser
  switch; the offer disappears once data is present.
- **Context-sensitive in-app help** (#159). The navigation help
  button (`?`) now opens the glossary entry that describes the
  **current view** — Dashboard, Content Browser, Lesson, Settings —
  instead of a single fixed entry. Each help-drawer article gains a
  **"Learn more"** link to the matching page on the documentation
  site. Nine new glossary terms ship in all eight languages: content
  repository, trust level, streak, assessment, plus dedicated entries
  for the Dashboard, Content Browser, Lesson and Settings views and
  backup & restore.
- **Manual test plan** (`docs/MANUAL-TESTPLAN.md`). A formal
  pre-release QA checklist — onboarding, learning flow, content +
  repositories, settings + backup, mobile, cross-browser, and
  accessibility — plus a bug-report template, for the checks
  automation cannot make (layout, readability, touch, theme contrast).

## Changed

- **Documentation overhaul for v1.61 - v1.69** (#157). The MkDocs
  help site gains a feature-oriented branch — Content Browser,
  multiple content repositories, backup & restore, content creation
  (incl. the `books.yaml` format), design tokens, sync, and a
  changelog — in all eight languages, and the lessons /
  getting-started / onboarding / themes pages are refreshed. The
  documentation is deployed at
  <https://astrapi69.github.io/adaptive-learner/docs/>.

## Fixed

- **Lessons documentation correction**. The lessons help page claimed
  that the browser-only (Dexie) storage mode does not earn lesson XP
  or badges — false since v1.33.0, where lesson-XP parity landed for
  both storage modes. The page now states the modes are equivalent on
  lesson completion.

All new user-facing strings are translated in the eight supported
languages (DE, EN, ES, FR, EL, PT, TR, JA).
