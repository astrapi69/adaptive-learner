# Adaptive Learner v1.92.0

A Dexie-mode hardening + technical-debt release on top of v1.91.0. The headline
is a **critical fix so the installed PWA runs in Dexie mode instead of API mode**
(#907), a batch of browser-direct Dexie-mode fixes (study guide, pronunciation,
identity, server-option gating), a Dashboard restructure, and a large
**technical-debt sweep** — god-folder splits, complexity burn-down, and a
docstring pass across the data/API contract. No schema, API, or data-model
change.

## Fixed

- **CRITICAL: the installed PWA used API mode instead of Dexie (#907).** The
  GitHub-Pages / installed PWA now correctly runs Dexie-mode storage; the
  server-only option is hidden on GitHub Pages.
- Dashboard regression: profile-radar test failure (#899).
- The PWA update banner no longer reappears after acceptance — session guard (#905).
- Study guide works in Dexie mode (browser-direct) (#902).
- Pronunciation works in Dexie mode (browser-direct) (#903).
- Identity section hidden in Dexie mode (#914).
- Raw markdown is now rendered in the export preview (#914).
- Error-bars spacing and alignment (#880).
- Feature-strategy applied consistently (#911).
- Downloaded lessons shown first (#909).
- `Content.tsx` god-file split (1007 -> 439 lines) (#896).
- Storage god-folder split (41 -> 9 subdirs) (#868).

## Refactored (technical debt)

- **God-folder splits (#874-#879).** Six oversized flat directories regrouped
  by concern, each with a barrel and the parent re-exporting for backward
  compatibility, dropping every one from `.dirsize-baseline`:
  `components/` (84 files), `lib/content/` (49), `lib/` (29),
  `components/content/` (28), `components/lesson/` (19), `storage/types/` (18).
  Pure mechanical refactor (imports + `import.meta.glob` data-paths rewritten);
  full frontend suite green.
- **Complexity burn-down (#884-#887).** The grandfathered cc-> 20 offenders
  brought under the gate: `FreeTextExercise` 21 -> 18 and `WordTilesExercise`
  21 -> 18 (shared `ExercisePromptRow` extraction), `ImportDetail` 20 -> 18
  (`resolveConversationId` helper), and the stale `exercise-quality-gate`
  baseline dropped (already cc 13). The frontend complexity baseline now has
  zero TypeScript offenders.
- **Docstring sweep (Clean Code Block 8, #888).** ~387 Google-style docstrings /
  TSDoc across the contract layers: repository abstract + implementation methods,
  the Pydantic API schemas, the FastAPI route handlers (OpenAPI descriptions),
  and the frontend `src/lib` logic layer.
- **Clean Code Block 9 (#889).** A shared `safeSet` localStorage helper,
  `push_records` branch split, and inline-comment cleanup.
- A new `lib/ai` god-folder baseline entry (#917) was added to keep the
  folder-size gate green after #903 grew the directory.
