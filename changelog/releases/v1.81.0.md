# Adaptive Learner v1.81.0

The **biggest feature release of the project so far** — a learner-experience and
gamification wave on top of the v1.80.0 content lane. It adds a full **Learning
Statistics** page with an activity heatmap, an **SRS due-reviews** visualization,
a **staged auto-hint** system for exercises, **lesson favorites**, a much richer
**error/review** flow (answer diff + explanations), **Dashboard gamification**
(XP / streaks / badges with reusable rings, calendars and grids), a lesson-play
**UX layer** (animated counters, feedback pulses, mid-lesson motivation), a full
**offline experience** (offline + sync-status badges, download progress, pending
-sync count, install button), a global **keyboard-shortcuts** system with a help
overlay, **Hindi** as the 9th UI language, a **searchable LanguagePicker**, an
**event-recording / error-report** system (EXP-028), an **interactive avatar
crop** dialog, a responsive **Settings sidebar/hamburger** navigation, an
**editable display name** in Settings > Profile, a new **gamification dashboard
API**, and **20+ reusable `shared/` components**. Plus a P1 iPhone-navigation
fix, several smaller fixes, a security bump, the CI night-shift, and four design
explorations (EXP-027..030). No schema / API / data-model change beyond the
additive gamification read-endpoints.

31 commits, 193 files.

## Added

- **Learning Statistics page (#584).** A dedicated `/statistics` page: total XP +
  level, an activity **heatmap**, weak-area breakdown, and per-language-pair
  progress. Built on reusable primitives, both storage modes.
- **SRS visualization — due reviews (#592).** Surfaces the spaced-repetition
  queue: which elements are due, their mastery status, per-element detail, and a
  transparency view of the scheduler.
- **Staged auto-hint system for exercises (#595).** Exercises can reveal
  progressively stronger, auto-generated hints (no authoring required), so a
  stuck learner gets a nudge before the answer.
- **Lesson favorites / bookmarks (#598).** Mark lessons as favorites and find
  them again quickly; persisted in both storage modes.
- **Richer error / review UX (#602).** The review flow now shows an **answer
  diff**, per-error **explanations**, and a **review summary** — turning a replay
  into a teachable moment.
- **Dashboard gamification (#583).** XP, streaks and badges on the Dashboard via
  new reusable `shared/ProgressRing`, `shared/StreakCalendar` and
  `shared/BadgeGrid`, plus an activity trend.
- **Lesson UX layer (#589).** `shared/AnimatedCounter` + `shared/FeedbackPulse`,
  animated XP gain on correct answers, and mid-lesson motivation moments.
- **Offline experience (#605, Offline-UX).** `shared/OfflineBadge`,
  `shared/SyncStatusBadge`, `shared/DownloadProgress`, a pending-sync count, and
  an install (PWA) button — the app now communicates its offline/sync state
  clearly.
- **Global keyboard-shortcuts system + help overlay (#587).** A central shortcut
  registry with a discoverable help overlay (`?`).
- **Hindi (hi) as the 9th UI language (#571).** Full Hindi UI catalog +
  Devanagari font stack; the i18n catalogs now cover 9 languages.
- **Searchable LanguagePicker (#568).** The language selector scales to many
  languages with a searchable picker (I18N-04).
- **Event recording / error-report system (EXP-028, #566).** A taxonomy +
  snapshot + persistence layer for user events, a proactive report entry, and a
  JSON export — making "Report issue" actionable.
- **Interactive avatar crop dialog (#560).** A dependency-free `shared/ImageCropDialog`
  (drag/pan, pinch + wheel zoom, circular guide) feeding `AvatarUpload`; renders
  to a 256×256 blob, both storage modes.
- **Settings sidebar / hamburger navigation (#549).** The Settings tab bar became
  a responsive sidebar (desktop) + hamburger popover (mobile), one shared model.
- **Editable display name in Settings > Profile (#579).** The learner can see and
  edit their name; the `InitialsAvatar` and header `NavAvatar` update live via a
  profile-updated signal. Validation (trim, non-empty, max 50), 9 languages.
- **Gamification dashboard API (#572).** New read endpoints at
  `/api/gamification/*` (xp-history, streak, badges, summary) for the dashboard
  widgets, Router → Service → Repository in the gamification plugin.
- **recommended-repos.json live (#547).** The curated recommended-repos catalogue
  is published (content repo) and the app's `CATALOGUE_PUBLISHED` flag flipped on,
  so the discovery UI surfaces officially-recommended repos (Trust 3).
- **20+ reusable `shared/` components.** This release roughly doubles the
  `shared/` primitive set (rings, calendars, grids, badges, counters, pulses,
  offline/sync badges, download progress, the crop dialog, …), all props-driven
  and app-agnostic per the reusability policy.

> **Accompanying content-repo release:** Hindi → English A1 **starter content**
> (3 lessons) and the `recommended-repos.json` catalogue ship in
> `astrapi69/adaptive-learner-content` so the new Hindi UI is not an empty app.

## Changed

- **CI night-shift (#552, #576).** PRs now run **correctness gates only**.
  Security Scan (weekly + release), Coverage (daily), Content-stats drift
  (daily), the complexity **report** (daily) and dexie-smoke (daily) moved off the
  PR trigger; the complexity **gate** stays on PRs. Faster PRs, same protection.

## Fixed

- **P1 — iPhone Settings menu blocked header navigation (#597).** The mobile
  Settings menu no longer overlays/blocks the header nav on iPhone.
- **Crop image collapsed below the circle (#578).** A global unlayered
  `img { max-width: 100% }` was capping the crop image; fixed with an inline
  `max-width: none` so the image covers the circle again.
- **Settings content width + Data-card overflow (#556).** The Settings content
  column uses the available width and the Data-tab export controls no longer
  overflow their card.
- **develop unblockers (#591, #601).** Restored window-event methods in the
  exercise-tts test mock (#591) and unbroke the develop complexity gate
  (generateHints / Dashboard) (#601).

## Security

- **starlette → 1.3.1 (#607).** Bumps starlette to patch CVE-2026-54282 /
  CVE-2026-54283.

## Docs

- **EXP-027 internationalization strategy (reworked).** Two language axes, an RTL
  exercise audit, and the content-expansion plan (#559).
- **EXP-028 user-event recording.** The error-report-from-ring-buffer design that
  the #566 implementation realizes (#557).
- **EXP-029 media resources with the reciprocity principle (#608).** `media.yaml`

  app-agnostic reusability rules.
