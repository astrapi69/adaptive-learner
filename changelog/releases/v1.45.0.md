# Adaptive Learner v1.45.0

**Released**: 2026-05-30

Quality-sweep release (Phase 61). An audit-first pass over test
coverage, internal code health, and dependencies, followed by the
fixes — plus the tree-placement verification + duplicate detection
folded into the Phase 60 content-validation pipeline.

## Added

- **Tree-placement verification + duplicate detection** for community
  sharing. Before sharing, the Share modal previews where a lesson
  lands (`source → target → level`, `sets/{src}/{tgt-level}/`) and
  warns when a similar-titled set already exists for the same
  language pair + level (diacritic-insensitive, German `ß/ü`
  transliteration, Levenshtein < 3). The GitHub issue now carries the
  placement, a metadata table, and a validation summary.
- **Language-consistency + level warnings** (non-blocking): flags a
  card side that uses characters exclusive to a *different* language
  (e.g. Greek where French is expected), a non-CEFR level, or text
  too wordy for the declared level. Warnings never block sharing —
  only the rule-based minimums do.
- **Three interactive end-to-end journeys** (dexie gate): a full
  lesson playthrough across all five exercise types to the scored
  summary, the Content Browser source-language tree + filter, and the
  adaptive-lesson flow.
- The content-repo CI validator now also enforces the
  `sets/{source}/{target}-{level}` directory name.

## Changed

- **Security:** added the path-traversal guard to `read_lesson`
  (it already protected `read_asset`) — defense-in-depth on the
  content cache (P2).
- **Performance:** removed an N+1 in the session export (one
  `IN (...)` query for ratings instead of one-per-session);
  lazy-loaded `html5-qrcode` so it no longer bloats the Settings
  chunk (~376 KB split out, fetched only when the QR scanner opens).
- **Architecture:** the sync pairing call routes through the central
  api client (surfaces `ApiError`, not a bare `Error`); the Dexie
  release gate now walks `/import/:id`.
- **Tests:** missions plugin suite 14 → 41; ApiStorage delegation
  coverage 45% → 100%; `config_overlay` 51% → 90%. Suite totals:
  backend 1047 (+1 skipped) + plugins 1031 + Vitest 2624 = **4702**;
  Dexie gate 23 specs.
- **Dependencies (minor/patch):** frontend `@types/react` 19.2.15,
  `dexie` 4.4.3, `lucide-react` 1.17.0, `react-router-dom` 7.16.0,
  `vite` 8.0.14; backend `uvicorn` 0.48.0, `platformdirs` 4.10.0.

## Removed

- Dead code: backend `pairing.peek_token`, the frontend `DEFAULT_THEME`
  and `FEEDBACK_PREF_KEYS` constants, and the unused
  ProjectTaxonomy / SubjectBrowser / TagManager component cluster.

## Held for dedicated migration

Major bumps were deliberately NOT applied (each needs its own session):
`anthropic` 0.105, `mypy` 2.x, `@tiptap/*` 3, `@vitejs/plugin-react` 6,
`@types/node` 25, `sql.js` 1.14. Launcher dependency bumps
(`packaging`, `platformdirs`, `pyinstaller-hooks-contrib`) are deferred
to a launcher session that can run the PyInstaller build gate.
