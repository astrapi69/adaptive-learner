# Adaptive Learner v1.87.0

A feature release on top of v1.86.0. The largest thread is **EXP-034 — Content
Discovery + Search Index**: a search-index loader plus an "Inhalte entdecken"
discovery page, per-set download progress + removal, and search straight from
the Content Browser. Alongside it: a **Curriculum Builder** for custom learning
paths, **daily learning reminders**, the **EXP-031 `.alb` ZIP backup format**,
**EXP-032 deterministic content-quality checks**, two new UI languages (Korean +
Indonesian) with social sharing and an Anki `.txt` export, a configurable
review-session length, an editor right-click context menu, the new teal brand
mark (with a dark-mode variant), and the completion of the Hindi (hi) UI
translation. A late hardening pass (#759–#762) cleared two dexie-smoke release-
gate regressions and two user-reported UI bugs. No schema or data-model change.

27 substantive commits.

## Added

- **EXP-034 — Content Discovery + Search Index.** A parallel, cached,
  offline-tolerant search-index loader (#735); an "Inhalte entdecken" discovery
  page (DIS-05, #738); per-set download progress + per-set removal (DIS-06,
  #740); and full-text search of the index directly from the Content Browser
  (DIS-07, #742).
- **Curriculum Builder — custom learning paths (Option A).** Learners can
  assemble their own ordered learning paths from available lessons (#722, #737).
- **Daily learning reminders via the Notification API.** Opt-in daily reminders
  to keep a streak going, scheduled client-side through the browser Notification
  API (#723, #744).
- **EXP-031 — `.alb` ZIP backup format.** A new ZIP-based backup container
  (`.alb`) alongside the existing JSON dump (#713, #714).
- **EXP-032 — deterministic content-quality checks.** Rule-based, no-AI quality
  checks over content sets (#711, #712).
- **Korean + Indonesian UI languages, social sharing, Anki `.txt` export.** Two
  new UI locales plus a social-sharing surface and a plain-text Anki export
  (#728).
- **Configurable review-session length.** The review session length is now a
  user setting (default 10) instead of a fixed cap (#718, #724).
- **Editor right-click context menu.** A context menu mirroring the toolbar,
  built on a shared command-map so the two cannot drift (#672, #753).
- **Gamification level-detail popover.** The level-detail popover is enriched
  with XP history + milestones (#727, #734).
- **Hindi (hi) UI translation completed.** The long-tail Hindi translation is
  finished (#570, #755) and covered by the catalog-quality audit gate (#570,
  #758).
- **Re-read-theory backlink via content `theory_ref`.** The "re-read theory"
  link resolves through the content's `theory_ref` instead of the nearest
  preceding step (#709, #710).

## Changed

- **New teal brand mark.** The app icon is replaced with the new teal mark
  (#719), with a dedicated dark-mode icon variant (#725).

## Fixed

- **Mobile nav overflowed the 375px viewport (#759).** The two-line XP badge
  ("100 XP insgesamt") widened the right-hand indicator cluster enough to push
  the theme toggle past the right edge on the Dashboard; the nav gap +
  horizontal padding are tightened at mobile so the cluster fits (pinned by the
  no-horizontal-scroll gate).
- **Review "due" count did not update live (#761).** The Dashboard review-queue
  card now recomputes after each answered review question (it subscribes to the
  reviews-changed event, matching the header badge), in both storage modes.
- **Choice cards had unequal heights when labels wrapped (#762).** Multiple-
  choice tiles in a row now match the tallest tile's height (grid equal rows +
  full-height tiles) while labels still wrap naturally.
- **XP badge now actually renders two lines (#756, #757).** The two-line XP
  badge layout renders as intended.
- **Continue Learning — hash labels + two-line XP badge with level-detail
  popover (#732).**
- **a11y — the brand link in the lesson-compact nav now has an accessible name
  (#622, #708).**
- **deps — PyYAML is now an explicit backend runtime dependency (#696, #752).**
- **i18n — `{...}` placeholders are stripped before the EN-passthrough audit so
  interpolated strings are no longer flagged as untranslated (#745, #746).**

## Infrastructure

- **dexie-smoke backup-save assertion follows EXP-031 (#760).** The release-gate
  spec asserted a `.json` backup filename; updated to `.alb` after the EXP-031
  format change (the download fires correctly — only the assertion was stale).
- **Visual-regression matrix.** A critical-surfaces visual matrix (14 surfaces ×
  3 viewports) with a nightly CI run (#705, #706).
- **Hindi catalog-quality gate.** Hindi (hi) is now covered by the
  catalog-quality audit gate (#570, #758).
- **Docs / governance.** Library-First follow-up issues linked and the umbrella
  closed (#694, #751); EXP-034 content-discovery + search-index exploration
  documented (#731).
