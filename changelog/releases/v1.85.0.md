# Adaptive Learner v1.85.0

A P0 hotfix release on top of v1.84.0. The PWA "new version available" update
banner was unusable across every browser, which froze every user on an old
build — so no future fix (CORS, Markdown, etc.) could ever reach them. This
release rebuilds the banner so the update path works again. No schema, API, or
data-model change.

2 substantive commits.

## Fixed

- **P0 — PWA update banner invisible on desktop, unreachable on iPhone
  (#653).** The update banner was broken on all browsers, leaving users stuck on
  old versions:
  - **Desktop (Chrome/Brave):** the v1.84.0 accent-on-accent repaint (#649)
    still rendered text that matched the background on the live site, so the
    message was invisible.
  - **iPhone Safari:** anchored to the top, the banner sat under the address
    bar, was hidden by pull-to-refresh, and could not be tapped — neither the
    update nor the dismiss action was reachable.

  The banner is rebuilt on the proven Bibliogon shape:
  - **Bottom-anchored** (`fixed bottom-0 inset-x-0 z-[9999]`) with
    `padding-bottom: max(0.75rem, env(safe-area-inset-bottom))`, so it clears
    the iOS home indicator and is never hidden by browser chrome.
  - **Bar** painted with `--bg-surface` / `--fg-primary` + a top `--border` —
    the pairing `contrast.test.ts` pins ≥ WCAG AA across all 12 themes, a
    stronger guarantee than hardcoded fallbacks and fully token-backed.
  - **Update button** on the accent surface (`--accent` / `--accent-fg`, also
    AA-pinned) as the primary CTA; **dismiss X** on `--fg-secondary`. Both ≥ 44px
    touch targets.

  Regression pins cover bottom-anchoring, safe-area padding, the surface/text
  pair, the accent button, the 44px targets, and a non-empty message.

## Internal

- **Complexity ratchet gate unblocked (#656).** `FreeTextExercise.tsx` and
  `WordTilesExercise.tsx` reached cyclomatic complexity 21 in #647 without a
  paired `.complexity-baseline` update, leaving the gate red for every PR. Both
  are grandfathered into the baseline at 21 (the ratchet may only shrink, so
  future regressions still block); reducing their complexity is tracked
  separately.

## Before you install

AdaptiveLearner runs in Docker. You need Docker Desktop installed and running before starting the launcher.

- [Docker installation guide (English)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/install/docker-desktop.md) - includes a "Is Docker safe to install?" section
- [Docker-Installationsanleitung (Deutsch)](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/de/install/docker-desktop.md) - mit Abschnitt "Ist Docker sicher zu installieren?"

The launcher detects Docker, downloads AdaptiveLearner automatically, and opens it in your browser. The first launch takes 5-10 minutes (Docker images build, ~2 GB disk space).

## Download

| Platform | File |
|----------|------|
| Windows | `adaptive-learner-launcher.exe` |
| macOS (Apple silicon) | `adaptive-learner-launcher-macos.zip` |
| Linux | `adaptive-learner-launcher-linux` (ELF binary) |

Each platform also ships a `*.sha256` checksum next to the binary.

## Verifying downloads

```bash
# macOS / Linux
shasum -a 256 adaptive-learner-launcher-<platform>
cat adaptive-learner-launcher-<platform>.sha256
```

```powershell
# Windows
Get-FileHash -Algorithm SHA256 .\adaptive-learner-launcher.exe
Get-Content .\adaptive-learner-launcher.exe.sha256
```

The hashes must match.

If your operating system warns about an unsigned binary, see the [AdaptiveLearner installation overview](https://github.com/astrapi69/adaptive_learner/blob/main/docs/help/en/installation.md).
