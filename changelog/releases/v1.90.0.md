# Adaptive Learner v1.90.0

A feature release on top of v1.89.0. The headline is the **AI Exercise
Generation Pipeline** (EXP-036 / AIX-01 through AIX-06): theory-only lessons
can now have a full exercise set generated, quality-gated, balanced by type,
and regenerated from user feedback — individually or batched across a whole
set. Plus a desktop auto-update checker, an AI session-language directive,
the localStorage→Dexie migration Part B, a matching-resolution animation, and
a batch of UI fixes. No schema, API, or data-model change.

## Added

- **AI Exercise Generation Pipeline (EXP-036, AIX-01–AIX-06).** A complete
  generate→gate→balance→feedback pipeline for AI-authored exercises:
  - **AIX-01 (#817):** the exercise-generation prompt plus a defensive parser
    for the model's JSON output.
  - **AIX-02 (#829):** a "generate exercises" button on theory-only lessons.
  - **AIX-03 (#834):** a deterministic quality gate that screens generated
    exercises before they reach the learner.
  - **AIX-04 (#835):** exercise-type distribution and balancing across the
    generated set.
  - **AIX-05 (#836):** regenerate exercises with user feedback.
  - **AIX-06 (#838):** batch exercise generation for an entire set.
- **Animated pair resolution in the Matching exercise (#825, refs #824).** On
  solving a pair, the matched tiles resolve with a configurable animation.
- **Per-provider Test button in the configured-providers overview (#814, refs
  #813).** Each configured AI provider in Settings gets its own live-test
  action.
- **Desktop auto-update checker via the GitHub Releases API (#843).** The
  desktop build checks for newer releases against the GitHub Releases API and
  surfaces an update when one is available.
- **AI session replies in the learner's UI language (#828).** The session
  prompt carries an explicit language directive so the AI answers in the active
  UI language across all 11 supported languages.
- **localStorage snapshot in the `.alb` backup (#791, via #837).** The Dexie
  migration carries the localStorage snapshot through the `.alb` backup
  round-trip.

## Changed

- **localStorage → Dexie migration, Part B (#837, refs #791).** Contributions,
  custom learning paths, and language-redundancy state move from localStorage
  into Dexie, resolving the dual-source drift.
- **Pre-release CI hygiene (#844).** The msgpack CVE dependency bump, a refreshed
  complexity baseline, and a god-file split of `db.ts` into `db.ts` +
  `db-migrations.ts`.
- **CLAUDE.md UI-language count corrected 8 → 11.** The project file now reports
  the actual number of fully translated UI languages.

## Fixed

- **PWA update banner "Apply now" works (#819, refs #818).** The banner's apply
  action now closes the banner and reloads a fresh build instead of doing
  nothing.
- **Language dropdown transparent background (#821, refs #820).** The language
  dropdown uses the mapped background tokens instead of rendering see-through.
- **Matching columns stretch to equal-height rows (#823, refs #822).** Matching
  pair tiles no longer render at unequal heights.
