## Zyklus 1: Kommasetzung + Grammatik-Fachbegriffe

### (A) Mini-Erklärung

Bevor wir in die Kommaregeln gehen, hier die wichtigsten Bausteine. Analogie aus deinem Stack:

**Satz-Architektur = Code-Architektur**

- **Hauptsatz** (HS) = Main-Methode. Kann alleine stehen. Verb steht an Position 2.
- **Nebensatz** (NS) = Abhängige Methode. Braucht einen Hauptsatz. Verb steht am Ende.
- **Subjekt** = Wer/Was handelt (wie das Objekt, das eine Methode aufruft)
- **Prädikat** = Das Verb, die Aktion selbst
- **Objekt** = Worauf die Aktion wirkt (Akkusativ = direktes Objekt, Dativ = indirektes Objekt)

Die vier Fälle kurz mit Frage-Trick:

| Fall | Fachbegriff | Frage | Beispiel |
|------|-------------|-------|----------|
| 1. | Nominativ | Wer/Was? | **Der Test** läuft. |
| 2. | Genitiv | Wessen? | Das Ergebnis **des Tests**. |
| 3. | Dativ | Wem? | Ich gebe **dem Team** Feedback. |
| 4. | Akkusativ | Wen/Was? | Ich starte **den Container**. |

### (B) Beispiele: Komma bei Nebensätzen

**Regel:** Nebensätze werden immer durch Komma vom Hauptsatz getrennt. Erkennungsmerkmal: Einleitewort (Konjunktion/Subjunktion) + Verb am Ende.

Beispiel 1 (einfach):
*"Ich deploye das Update**,** weil der Bugfix kritisch ist."*
→ HS, NS (eingeleitet durch "weil", Verb "ist" am Ende)

Beispiel 2 (Kette, wie dein Diagnose-Fehler):
*"Ich glaube**,** dass der Test fehlschlägt**,** weil die Config fehlt**,** obwohl ich sie gestern geprüft habe."*
→ HS, NS, NS, NS. Jeder Nebensatz bekommt sein Komma, ausnahmslos.

## Partizip Perfekt (Partizip II)

### Was es ist

Eine Verbform, die aus jedem Verb gebildet werden kann. Keine Zeitform, sondern eine **Form des Verbs** neben dem Infinitiv (Partizip I wäre die andere: "machend", "schreibend").

### Bildungsregeln

**Regelmässige Verben (schwache Verben):** ge- + Stamm + -t

| Infinitiv | Partizip Perfekt |
|-----------|-----------------|
| machen | **ge**mach**t** |
| testen | **ge**test**et** |
| prüfen | **ge**prüf**t** |
| melden | **ge**meld**et** |

**Unregelmässige Verben (starke Verben):** ge- + Stamm (oft mit Vokalwechsel) + -en

| Infinitiv | Partizip Perfekt | Vokalwechsel |
|-----------|-----------------|-------------|
| schreiben | **ge**schrieb**en** | ei → ie |
| geben | **ge**geb**en** | - |
| finden | **ge**fund**en** | i → u |
| gehen | **ge**gang**en** | eh → ang |

### Drei Ausnahmen bei der ge-Bildung

**1. Trennbare Verben:** ge- rutscht zwischen Präfix und Stamm

| Infinitiv | Partizip Perfekt |
|-----------|-----------------|
| aufmachen | auf**ge**macht |
| fehlschlagen | fehl**ge**schlagen |
| herunterladen | herunter**ge**laden |

**2. Untrennbare Verben (be-, er-, ver-, ent-, zer-, miss-, ge-, emp-):** Kein ge-

| Infinitiv | Partizip Perfekt |
|-----------|-----------------|
| verstehen | verstanden (nicht: ~~geverstanden~~) |
| entscheiden | entschieden |
| berichten | berichtet |
| erklären | erklärt |

**3. Verben auf -ieren:** Kein ge-

| Infinitiv | Partizip Perfekt |
|-----------|-----------------|
| deployen | deployed |
| installieren | installiert |
| automatisieren | automatisiert |
| analysieren | analysiert |

### Verwendung in der Praxis

Das Partizip Perfekt hat vier Einsatzbereiche:

**1. Als Baustein für Tempora** (wie in der vorherigen Tabelle)

*"Er hat den Code **geschrieben**."* (Perfekt)
*"Er hatte den Code **geschrieben**."* (Plusquamperfekt)

**2. Als Adjektiv**

*"Der **getestete** Code läuft stabil."*
*"Die **automatisierten** Tests sind grün."*
*"Ein **verschlüsseltes** Passwort."*

Hier verhält sich das Partizip Perfekt wie ein normales Adjektiv, wird dekliniert (Endung passt sich an Genus, Kasus, Numerus an) und steht vor dem Nomen.

**3. Im Passiv**

*"Der Bug **wird gefixt**."* (Vorgangspassiv)
*"Der Bug **ist gefixt**."* (Zustandspassiv)

**4. Als verkürzte Aussage**

*"Abgemacht!"* (= Es ist abgemacht.)
*"Erledigt."* (= Es ist erledigt.)
*"Verstanden."* (= Ich habe verstanden.)

Das sind im Grunde verkürzte Passivsätze oder Perfektsätze.

### Analogie

Partizip Perfekt ist wie ein kompiliertes Artefakt. Der Source-Code (Infinitiv) ist "schreiben". Das kompilierte Artefakt (Partizip Perfekt) ist "geschrieben". Du kannst dieses Artefakt dann in verschiedene Projekte einbinden: als Tempus-Baustein, als Adjektiv, im Passiv.

---

**Zusammenfassung:**
