## Archived 2026-06-02

  Dexie mode. **Done** on branch ``feature/backup-dir-export``.
  Three things shipped: (1) ``saveBackupToDisk()`` prefers the File
  System Access API (``showSaveFilePicker`` native OS dialog on
  Chromium) and falls back to the blob-download path on

  the Dexie backup had drifted to 20 tables while the backend sync

  dropped ALL gamification (user_xp/badges/user_badges/streaks),
  progress (lesson_progress), SRS (element_errors), missions, anki,
  and study-question rows. Added the 10 missing tables to
  ``BACKUP_TABLES`` + ``RESTORE_ORDER`` so a Dexie export now
  mirrors the backend and a Dexie->Dexie roundtrip restores
  progress. i18n in 8 catalogs; +14 tests; full Vitest (2908) +
  backend backup suite (36) green. Spawned **BACKUP-API-RESTORE-01**
  (P1) for the backend's equivalent ``_RESTORE_ORDER`` gap. Restore-
  from-file, last-backup indicator, 7-day reminder, and auto-backup
  were already shipped (Phase 15C/25), so they were adapted, not
  rebuilt.
