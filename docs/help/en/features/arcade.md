# Arcade

**Arcade** is a small set of short, winnable mini-games reachable from
a Dashboard card once **Game mode** is on (Settings → Learning →
Game mode) and the **Arcade** switch is enabled. Visiting the page
directly with the switch off shows a friendly notice instead of a
dead page - the feature is never hidden, only disabled with a reason.
Its **Open settings** link lands on the *Motivation and routine* area
of the Learning tab, where the game mode card lives.

Arcade games award **no XP themselves** - they are a break, not
another grind. Three of the four are unlocked by spending XP you
already earned from learning.

---

## The games

| Game | Unlock | What it is |
|------|--------|------------|
| **Learn Memory** | Free | Match term/translation pairs pulled from your own lessons - the only game that carries learning content. |
| **Tic-Tac-Toe** | 100 XP | Three in a row against the app - beatable, not a wall. |
| **Snake** | 200 XP | The classic: collect food, grow, do not bite yourself. |
| **Simon** | 300 XP | Repeat a growing color sequence; the target length is configurable. |

The XP ladder is deliberate: Learn Memory is free because it still
teaches, and the three purely playful games cost more as they add
less educational value - the cheapest paid game (Tic-Tac-Toe) sits
just above free, Simon at the top.

---

## Tickets (optional)

If your Settings enable the **ticket economy**, playing arcade games
costs a ticket per round instead of being unlimited. Tickets are
earned through learning performance and streaks; the balance and the
on/off switch update live if changed in another tab or in Settings
while Arcade is open.
