# セット完了レビュー

以前は、セット内のすべてのレッスンを終えると、「N個のレッスンをす
べて完了」というトロフィーカードが表示されるだけで、それ以外は何も
ありませんでした。アプリは各エクササイズごとに、エラー数、連続正解
数、習得フラグ、そして自分の間違った回答をすでに記録していたにもか
かわらずです。**セット完了レビュー**は、その欠けていた全体像を示し
ます - たった今終えたセットのすべての間違いが、一箇所にまとまってい
ます。

セットの最後のレッスンの終わりに表示される**次のステップ**の提案
から、またはセット自体のページからアクセスできます。

---

## 表示内容

- **合計** - 直前にプレイしたレッスンだけでなく、セット全体でのエ
  ラー数と費やした時間。
- **レッスン別** - セット内のどのレッスンが最も多くの間違いを生ん
  だか。
- **エクササイズ種類別** - 特定の種類(マッチング、穴埋め、自由記
  述など)にエラーが集中しているかどうか。
- **弱点** - 繰り返し間違えている個々の項目。それぞれについて、直
  近の間違った回答と正しい回答を並べて表示するので、何かを直す必要
  があるということだけでなく、具体的に何を直せばよいかが正確にわか
  ります。

---

## 仕組み

このページは読み取り専用でストレージに依存しません: 復習セッション
がすでに書き込んでいるのと同じデータ(エラー数、習得フラグ)を読み
取り、単一の集計ステップにかけるため、数値はSRS復習や学習パスがす
でに記録している内容と正確に一致します - ずれが生じ得る別の集計は
存在しません。
