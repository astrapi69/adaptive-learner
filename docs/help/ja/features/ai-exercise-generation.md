# AI 演習生成

理論だけで構成されたレッスン（演習なし）は、AI にそのカードから
**演習を生成**させることで、練習できるレッスンに変えられます。
これは EXP-036 のパイプラインです。AI キーの設定（設定 → AI）が
必要です。キーがない場合、ボタンは表示されますが無効になり、
その理由がツールチップに示されます。

## パイプライン

生成は 1 回の AI 呼び出しではありません。
**生成 → 品質ゲート → バランス調整 → フィードバック**という
パイプラインです。

1. **生成。** 生成プロンプトがモデルに、サポートされている各タイプに
   わたる演習を求めます。防御的な JSON パーサーが、モデルによくある
   書式の癖を許容します。
2. **品質ゲート。** 決定論的なゲートが、形式の崩れた演習、自明な
   演習、既存の演習と重複する演習を、あなたの目に触れる前に
   除外します。
3. **バランス調整。** 生成された演習のセットは演習タイプ間で
   バランスが取られるので、レッスンが 1 つの形式だけになることは
   ありません。
4. **フィードバック付きで再生成。** 結果が適切でない場合は、
   フィードバックを付けて再生成し、次の試行の方向を定められます。

---

## レッスン単位とセット単位

- **単一のレッスン：** 理論だけのレッスンには「**演習を生成**」
  ボタンが表示されます。
- **セット全体：** 一括生成により、セット内の理論だけのすべての
  レッスンに、1 回の実行で演習を追加します。

---

## 品質と信頼性

品質ゲートは決定論的なので、生成された演習は作成者が書いた演習と
同じ最低基準（十分な数の演習、複数のタイプ、空のカードなし）を
満たします。生成は作成済みのコンテンツを補うものであり、既存の
演習を黙って上書きすることは決してありません。

*既存の*コンテンツの品質（作成済みまたは生成済み）を確認するには、
[AIコンテンツチェック](../user-guide/ai-validation.md)を参照してください。
