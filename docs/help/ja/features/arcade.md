# アーケード

**アーケード**は、**ゲームモード**(設定 → 学習 → ゲームモード)と
**アーケード**スイッチの両方がオンのときに、ダッシュボードのカード
からアクセスできる、短くクリア可能なミニゲームの小さな集まりです。
スイッチがオフの状態で直接ページにアクセスすると、機能が消えた空の
ページではなく、わかりやすい案内が表示されます - 機能が隠されること
は決してなく、理由付きで無効化されるだけです。

アーケードのゲーム自体は**XPを与えません** - これは休憩であり、もう
一つの学習作業ではありません。4つのうち3つは、学習で既に獲得した
XPを使って解放します。

---

## ゲーム一覧

| ゲーム | 解放条件 | 内容 |
|--------|----------|------|
| **学習メモリー** | 無料 | 自分のレッスンから用語と訳のペアを見つけて合わせる - 実際の学習内容を含む唯一のゲーム。 |
| **三目並べ** | 100 XP | アプリと対戦する三目並べ - 勝てる相手であり、壁ではない。 |
| **スネーク** | 200 XP | 定番ゲーム: 餌を集めて成長し、自分自身に噛みつかないようにする。 |
| **サイモン** | 300 XP | 増えていく色の並びを繰り返す。目標の長さは設定可能。 |

このXPの段階付けは意図的なものです: 学習メモリーは学習を続けるため
無料であり、純粋に遊びのための3つのゲームは、教育的な価値が少ない
ほど高くなります - 最も安い有料ゲーム(三目並べ)は無料のすぐ上に、
サイモンが一番上に位置します。

---

## チケット(任意)

設定で**チケット制**を有効にしている場合、アーケードのプレイは無制
限ではなく1プレイごとに1枚のチケットを消費します。チケットは学習の
成果や連続記録を通じて獲得され、アーケードを開いている間に別のタブ
や設定でチケット残高やオン/オフの切り替えを変更すると、その場で反映
されます。
