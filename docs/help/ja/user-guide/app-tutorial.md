# アプリチュートリアル（アプリの中でアプリを練習する）

Adaptive Learner を理解する最も早い方法は、**アプリ自身のレッスンの
仕組みでアプリを学ぶ**ことです。付属のレッスンセット
「**Adaptive Learner - App-Tutorial**」はまさにそのためのものです。
アプリの動き方を案内する 12 部構成のインタラクティブな初心者向け
チュートリアル（ドイツ語）で、無味乾燥なマニュアルではなく、短い理論と
演習を備えた本物のレッスンとして作られています。

これは（AI チャットではなく）**コンテンツセット**なので、**AI API キーは
不要**です。セットはオフラインでアプリに同梱されているので、すぐに
利用できます。公開オンライン版でも同様です。

## 直接開く

セットは同梱されているので、リポジトリを接続する必要はありません。
このリンクでチュートリアルを直接開けます：

[**アプリチュートリアルを開く**](https://astrapi69.github.io/adaptive-learner/content/set/adaptive-learner-app-from-de){ .md-button .md-button--primary }

リンクはチュートリアルのセットページに移動します（以前のように
ダッシュボードに移動するだけではありません）。セットがまだダウンロード
されていない場合、ページに「**ダウンロードして開始**」が表示され、
そのあとすぐにレッスン 1 から始められます。このリンクは、セットの
**共有**ボタンからもそのまま共有できます（リンクまたは QR コードを
コピー）。

## なぜアプリチュートリアルから始めるのか？

- **学びながら練習できます。** 説明を読む代わりに本物のレッスンを行い、
  最後にスター付きで結果を確認します。後であらゆるトピックであなたを
  導くのと同じループです。
- **セットアップ不要。** AI キーもアカウントも不要で、初回読み込みの
  後はインターネットも要りません。最初の数分に最適です。
- **アプリの基本をカバーします** - ナビゲーション、レッスンの進み方、
  ダッシュボード、進捗と復習を、短く扱いやすい単位で学べます。

## 始め方

いちばん早いのは、上の**直接開く**セクションにある直接リンクです。
または、コンテンツブラウザから始めることもできます：

1. `/content` にある[コンテンツブラウザ](../features/content-browser.md)
   （または `/discover` にある**発見**）を開きます。
2. 「**App-Tutorial**」または「**Adaptive Learner**」を検索します。セットの
   名前は **Adaptive Learner - App-Tutorial** です（出発言語はドイツ語、
   学習言語はドイツ語、レベルは「Einsteiger」、12 レッスン）。
3. セットをクリックしてダウンロードします。セットはローカルに
   キャッシュされます（バックエンドモードではファイルシステム、
   ブラウザのみのモードでは IndexedDB）。
4. **レッスン 1** を始めて進めます。各レッスンは短く、少し理論を読んで
   いくつかの演習を行います。
5. 各レッスンの後にスターが表示され、間違えた項目は自動的に後の
   [復習](lessons.md)の予定に組み込まれます。

!!! tip "すぐに始める"
    アプリチュートリアルを遊ぶのに、オンボーディングを終える必要は
    ありません。コンテンツブラウザを開き、セットをダウンロードして
    始めるだけです。実際に操作しながらアプリを知る、いちばん早い
    方法です。
