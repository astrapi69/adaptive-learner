# はじめに

## 前提条件

### AI プロバイダー

Adaptive Learner には AI プロバイダーの API キーが必要です（少なくとも一つ）。

| プロバイダー | 取得場所 |
|---|---|
| Anthropic (Claude) | [console.anthropic.com](https://console.anthropic.com) |
| OpenAI (GPT) | [platform.openai.com](https://platform.openai.com) |
| Google (Gemini) | [ai.google.dev](https://ai.google.dev) |

API キーをまだお持ちでない方へ：無料利用枠でも十分に始められます。
API キーの設定方法は [設定](settings.md) をご覧ください。

### PWA としてのインストール（オプション）

Adaptive Learner はプログレッシブウェブアプリ（PWA）として
インストールできます。

1. ブラウザのアドレスバーにあるインストールアイコンをクリック
2. 「インストール」を選択
3. アプリがデスクトップ/ホーム画面に追加されます

PWA としてインストールすると、ネイティブアプリのような使い心地で
オフラインでも動作します（コンテンツレッスン用）。

## 最初の 5 分間

### 1. アセスメントを受ける

最初にアクセスすると、アセスメントが表示されます。
12 の質問に答えると、学習プロフィール（レーダーチャート）が
生成されます。

正確な答えを出そうとする必要はありません。直感で答えてください。
プロフィールはいつでも再評価できます。

### 2. 最初のプロジェクトを作成する

アセスメント後、最初の学習プロジェクトを作成します。

- **トピック：** 具体的に（「スペイン語」ではなく「旅行のためのスペイン語」）
- **目標：** 達成可能なこと（「A2 レベルを 3 ヶ月で達成」）
- **期間：** 現実的に設定
- **毎日の学習時間：** 正直に設定（15〜30 分でも十分）

### 3. 最初のセッションを開始する

ダッシュボードから「セッションを開始」をクリックします。

学習プロフィールに基づいて推奨されるメソッドが提示されます。
最初は推奨に従うことをお勧めします。後から変更できます。

### 4. 最初のサイクルを体験する

AI があなたのトピックに関する最初の素材を提示します。
読んで、試みて、フィードバックを受けてください。

セッションを終了したら、三つのスライダー（理解度・ストレス・
メソッド適合度）で評価してください。
