# はじめに

Adaptive Learner は、研究に裏付けられた 6 メソッド・モデルに
基づく学習の相棒です。あなたに合うメソッドを見つける短い
テストを行い、その後 7 ステップのサイクルを通じて AI 支援の
学習セッションを進めます。アプリはあなたとともに学び、教え方を
適応させます。

## 今すぐ試す

Adaptive Learner を知る最も手早い方法は、公開オンライン版です。

[**アプリを開く**](https://astrapi69.github.io/adaptive-learner/){ .md-button .md-button--primary }

これは**ローカルモード**で動作します。あなたのデータはすべて
ブラウザ（IndexedDB）に留まり、AI の呼び出しはあなた自身の
API キーを使ってページから直接 Anthropic、OpenAI、Google
Gemini へ送られます。間にバックエンドはありません。

## プログレッシブ・ウェブアプリとしてインストールする

Adaptive Learner はインストール可能です。最新のブラウザは初回
訪問時に「インストール」または「ホーム画面に追加」の案内を
表示します。それを承諾すると、Adaptive Learner はスマートフォン
やデスクトップ上の独立したアプリになり、ブラウザのタブなしで
起動できます。

アプリはダッシュボードと過去のセッションについてはオフラインで
動作します。AI プロバイダーがブラウザの外にあるため、新しい
AI セッションにはインターネットが必要です。

## 必要なもの

- **最新のブラウザ**（Chrome 100+、Firefox 100+、Safari 17+、
  Edge 100+）。アプリは IndexedDB、Service Worker、モダンな
  JavaScript を使います。
- サポートされる 3 つのプロバイダー（Anthropic、OpenAI、Google
  Gemini）のうち少なくとも 1 つの **AI API キー**。無料の枠で
  たいてい始められます。キーの設定については
  [設定](settings.md)をご覧ください。

## 最初の 5 分

1. **アプリを開く**、そして言語を選びます。8 つの UI 言語
   すべてが完全に翻訳されています（DE、EN、ES、FR、EL、PT、
   TR、JA）。
2. **オンボーディング：名前 + テーマだけ。** クイックスタートは
   この 2 つのフィールドだけを求め、それ以外はデフォルトを
   採用します。その後、「すぐに始める」を選ぶか、オプションで
   アシスタントでプロフィールをより詳しく設定できます。
   [オンボーディング](onboarding.md)をご覧ください。
3. **最初のレッスンを始める** - AI キーなしで最も手早い方法：
   `/content` にある[コンテンツブラウザ](../features/content-browser.md)を
   開き、レッスンセットを選んでレッスンを始めます。短い理論を
   読んで演習を行い、最後にスター付きの結果を見ます。
   [レッスンと復習](lessons.md)をご覧ください。
4. **オプション：AI セッション。** 代わりに 6 メソッドの
   ガイド付き学習対話を希望する場合は、**API キー**を登録し
   （設定または `~/.config/adaptive-learner/secrets.yaml`）、
   オプションの[学習タイプ・テスト](assessment.md)を行い、
   [学習セッション](learning-session.md)を始めます。
5. **結果を保存する。** レッスンサマリーから結果を Markdown と
   してコピーするか、ファイルに保存できます。また、
   **設定 → データ**で[バックアップ](../features/backup.md)を
   作成できます。
