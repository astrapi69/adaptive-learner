# カリキュラム

## カリキュラムとは？

カリキュラムはあなたのトピックのための階層的な学習計画です。
セッションが個々の学習ユニットであるとすれば、
カリキュラムはそれらを構造に整理します。

カリキュラムはオプションです。なくてもセッションを実行できます。

---

## トピックツリー

カリキュラムはトピックの階層ツリーで構成されています。

```
スペイン語（初級）
├── 基本的なあいさつ
│   ├── 自己紹介
│   └── 日常的なフレーズ
├── 数と時間
│   ├── 1〜100 の数
│   └── 時刻の表現
└── 動詞の現在形
    ├── ser / estar
    └── 規則変化動詞
```

トピックは階層の任意のレベルに追加できます。
レッスンはトピックに関連付けられます。

---

## レッスン

各トピックにレッスンを追加できます。
レッスンはリッチテキスト（TipTap エディタ）で記述します。

レッスンはコンテンツの場所です。
- 文法説明
- 単語リスト
- 例文
- 練習問題の指示

---

## TipTap エディタ

Adaptive Learner は TipTap リッチテキストエディタを使用します。

**サポートされている形式：**
- 見出し（H1〜H6）
- 太字・斜体・下線
- リスト（箇条書き・番号付き）
- テーブル
- コードブロック
- リンク
- 画像

Markdown の入力もサポートしています（タイプ中に変換されます）。

## オートループとの統合

オートループが有効な場合、カリキュラムのトピックが
自動的にセッションの順序を決定します。

カリキュラムなしでオートループを使用すると、
AI が適切なフォローアップトピックを生成します。

---

## カリキュラムのインポート

会話分析（インポート機能）を使用して、
既存の AI チャットからカリキュラムを生成できます。

1. チャット（ChatGPT、Claude、Gemini）をインポートして分析する
2. 「カリキュラムを作成」をクリック
3. 抽出されたコンセプトが階層的なカリキュラムとして構造化される

[インポートについて詳しく](../api/core-endpoints.md)
