# 進捗

## 進捗ページ

進捗ページはあなたの学習履歴の詳細な分析を提供します。
ダッシュボードの「進捗を表示」からアクセスできます。

---

## トレンドの洞察

### 理解度のトレンド

時系列で理解度スコア（評価から）を表示します。
上昇傾向はあなたが着実に進歩していることを示します。
停滞または下降傾向はメソッド変更を示唆する場合があります。

### ストレストレンド

時系列でストレスレベルを表示します。
慢性的に高いストレスは、メソッドが合っていないか、
学習ペースが速すぎる可能性があります。

### メソッド分布

各メソッドで費やした時間の割合を表示します。

---

## ステップ評価

デュアルプロンプト評価器がどのステップで最も時間を費やしたか、
信頼度がどのように変化したかを示します。

これを使って特定のステップが繰り返し難しいパターンを特定できます。

---

## コミット履歴

完了した各セッションのコミット一覧です。
各コミットは以下を含みます。

- 日時
- 使用したメソッド
- 理解度・ストレス
- セッションの長さ（分）
- サイクル数

---

## エクスポート

進捗データを以下の形式でエクスポートできます。

- **JSON：** 全データの構造化エクスポート
- **Anki：** フラッシュカードの `.apkg` ファイル
- **NotebookLM：** 学習質問の ZIP ファイル
- **学習リポジトリ：** Markdown ファイルのセット（サーバーモードのみ）

エクスポートの設定は [設定](settings.md) から管理できます。

---

## 比較ビュー

二つの期間（例：先月と今月）を並べて比較できます。
変化をデルタ（+/-）として表示します。

---

## バックアップ

進捗データは [設定 > バックアップ](settings.md) からバックアップできます。

- **エクスポート：** タイムスタンプ付き JSON ファイルをダウンロード
- **インポート：** ファイルから復元
- **比較：** インポート前に現在のデータと比較

API キーはすべてのエクスポートから除外されます。
