# AIコンテンツチェック

Adaptive Learner では、ダウンロードしたレッスンセットを**任意で
AI にレビューさせる**ことができます（EXP-033）。AI はセットのカードに
翻訳、文法、レベルの問題がないかを調べ、見つけたものを報告します。
何かをブロックすることは決してなく、助言するだけです。これとは別に、
リポジトリにはひと目で読み取れる**信頼度**が付いています。

## リポジトリの信頼度

コンテンツブラウザでは、どのレッスンセットにも信頼度付きの
ソースバッジが表示されます。これが示すのは**出所**であって、
コンテンツの品質ではありません：

- **信頼度 0 - 未検証。** 新しく接続したリポジトリで、自動チェックに
  （まだ）合格していないもの。
- **信頼度 1 - 技術的に検証済み。** リポジトリに少なくとも 1 つの
  レッスンが含まれ、実行可能なコードが含まれていません。チェックは
  同期のたびに再実行されます。
- **信頼度 3 - 公式におすすめ。** 公式のおすすめリストに載っている、
  厳選されたリポジトリ。

コミュニティによる評価（信頼度 2）と中央インデックスは、まだ
実装されていません。

---

## AI チェックの前提条件

AI チェックは、ブラウザから直接 AI プロバイダーを呼び出します。
必要なもの：

- いずれかのプロバイダー（Anthropic、OpenAI、Gemini）の
  **保存済みの API キー**（設定 > AI）。
- **ブラウザモード**（Dexie） - チェックはブラウザから直接実行されます。
- **ダウンロード済みのセット**（チェックはローカルにキャッシュされた
  カードに対して行われます）。

キーがない場合、ボタンは表示されますが無効になっていて、通知から
設定へ移動できます。

> **費用：** チェックはあなた自身のプロバイダーアカウントのトークンを
> 消費し、そのプロバイダーの料金で請求されます。開始前に、ダイアログに
> 確認が必要な**費用の見積もり**が表示されます。

## セットをチェックする - 手順

1. **コンテンツブラウザ**を開き、ダウンロード済みのセットを選びます。
2. 「**AIで確認**」をクリックします。
3. ダイアログに**費用の見積もり**が表示されます。確認すると実行が
   始まります。
4. カードは**バッチ**ごとにチェックされます。進捗バーがその状況を示し、
   いつでも**キャンセル**できます。
5. 最後に**カードごとのレポート**が表示されます。指摘のあったカード
   だけが一覧になり、それぞれに所属するレッスンと AI のメモが
   付きます。

うっかり二重に請求されないよう、2 回の実行の間には短い
**クールダウン**（約 1 分）があります。

## 提案を適用する（自分のセット）

自分のセットは**コンテンツ > マイコンテンツ**でチェックします。そこにある
どのセットの行にも、同じ**AIで確認**ボタンがあります。自分で作成した
セットの場合、レポートには**提案を適用**ボタンがあります。これを押すと、
カードのフィールド（表面、裏面、メモ）を指定する提案ごとに 1 行の表が
開きます：レッスン、カード、フィールド、現在の値、提案された値。
どの行にもチェックが入っています。値ではなく説明になっているものは
チェックを外してください。適用できる値のない指摘は数えられるだけで、
書き込まれることはありません。確認ボタンには、変更するフィールドと
カードの数が表示されます。

書き込みはエディターと同じ経路を使います：すべてのレッスンを含むセット
全体を書き込むので、タイトル、言語、レベル、説明はそのまま残り、
カードの ID は変わらず、学習の進捗も保持されます。以前の値は保存され、
**直前の適用を元に戻す**で復元できます。適用後、保存されたレポートは
古くなるので破棄されます。新しい結果が欲しいときは、セットを
再チェックしてください。ダウンロードしたセットでは、このボタンは
無効になっていて、自分のレッスンにのみ適用されるという注記が付きます。

## レポート、キャッシュ、「AI確認済み」バッジ

- **キャッシュ。** レポートはローカル（IndexedDB）に保存され、次回は
  再び支払うことなく表示されます。コンテンツハッシュ + 署名が
  付いているので、セットが変更されると新しいチェックが提案されます。
- **エクスポート可能。** レポートを **Markdown** としてダウンロード
  できます。レッスンの改訂やイシューに貼り付けるのに便利です。
- **バッジ。** チェック済みのセットにはコンテンツブラウザで
  「**AI確認済み**」バッジが表示されるので、チェックが存在することが
  分かります。

AI は**助言的**なものです。起こりうる問題を強調表示しますが、
セットで学習したり、編集したり、共有したりするのを妨げることは
決してありません。判断するのはあなたです。
