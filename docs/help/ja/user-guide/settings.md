# 設定

設定ページは、コードや YAML を変更せずに調整できるすべての項目を
まとめています。ページは**タブ形式**になっていて、タブを選ぶとその
パネルが開くので、長い一覧を上から下へスクロールする必要はありません。
広い画面ではタブが左のサイドバーに並び、スマートフォンではパネルの上の
メニューボタンから開きます。アドレスには開いているタブが含まれる
（`/settings?tab=data`）ので、リンクや再読み込みでも同じタブに戻ります。
指定がない場合、ページは**一般**タブで開きます。

タブは 4 つのグループに分かれています：

- **一般**
    - **一般**：プロフィール（表示名、アバター、アバターフレーム）、
      外観（テーマ、コンテンツの表示、コンテンツタブの順序）、表示言語、
      インターフェース（ボタンのツールチップ、スマートフォンでのメニューの
      位置）、ストレージモード、アップデートの設定、アプリのインストール、
      モード表示。
- **学習と AI**
    - **学習**：レッスンの動作を、学習プロファイルからモチベーションと
      習慣までの 5 つのエリアにまとめています。音声の設定と
      ゲーミフィケーションもここにあります。
    - **AI**：プロバイダーとモデルの選択、ソース属性付きのプロバイダーごとの
      API キー、設定済みプロバイダーの一覧。
    - **プラグイン**：インストール済みのプラグインと学習リポジトリの設定。
- **データと連携**
    - **データ**：コンテンツのソース、同期、オフラインコンテンツ、
      バックアップとエクスポート（暗号化されたキーのエクスポートを含む）、
      整理、危険ゾーン。上部にセクションバーがあります。
    - **連携**：GitHub 連携（レッスンをプルリクエストとして共有するための
      トークン）。
- **情報**
    - **ヘルプ**：検索できるアプリ内の用語集。
    - **診断とサポート**：エラーレポート、開発者モード、タップ・ビューポート
      診断プローブ。
    - **情報**：バージョン、システム情報、クレジット、アプリの共有、寄付、
      ライセンス。

## プロフィール

*一般 > プロフィール*では、**表示名**を設定し、**アバター**を整えます：

- **画像をアップロード**を押すとトリミングのダイアログが開きます。結果は
  ナビゲーションの右上に表示されます。
- **またはキャラクターを選ぶ**：自分の写真の代わりに使える 8 つの
  プリセットキャラクター。1 回のクリックで十分です。アップロードした写真が
  有効な場合は、キャラクターに置き換える前にダイアログで確認されます。
  写真は一時保管され、**写真を元に戻す**でいつでも戻せます（新しい写真を
  アップロードするまで）。
- **アバターフレーム**：アバターを囲む装飾リング。ブロンズ、シルバー、
  ゴールドはレベルに応じて、フレイムは 3 日連続バッジで解放されます。
  スターとアクセントは XP と交換します（2 段階の確認があり、費用は
  ボタンに表示されます）。ロックされたフレームには条件が表示されます。

選択した内容と購入したフレームは保持され、[バックアップ](../features/backup.md)
にも含まれます。

## 外観

*一般 > 外観*の**テーマ**選択は、テーマを 2 つのタブに分けています：

- **おすすめ** - Catppuccin Latte、Supabase、Graphite（ライト系）、
  Catppuccin Mocha、**Soft Pop**、Amethyst Haze（ダーク系）。
  新しいユーザーは **Soft Pop** から始まり、選択はこのタブで開きます。
- **クラシック** - 元のテーマ：ライト、ダーク、オーシャン、フォレスト、
  ハイコントラスト（黒、白、太字のシグナルカラーとくっきりしたカードの縁で
  最大の可読性）、セピア（長時間の読書向けの温かい紙のトーン）。有効な
  テーマがクラシックの場合、選択はこちらのタブで開きます。

どちらのタブにも**自動（システム）**があり、OS のライト/ダーク設定に
従い、システムの切り替えに合わせて自動で切り替わります。

プレビューカードからテーマを選択します。変更は再読み込みなしで即座に適用され、
選択はアクセス間で記憶されます。どのテーマも WCAG 2.1 AA のコントラストを
満たすように設計されているので、テキスト、グラフ、バッジ、練習問題の
フィードバックはすべてのテーマで読みやすいままです。

このカードには**コンテンツの表示**もあります。コンテンツハブ全体の
*リスト / グリッド*の設定です（デフォルトは**リスト**）。*マイコンテンツ* /
*発見*のタブ内の表示切り替えと同じ設定なので、どちらで変更しても両方が
そろいます。カードのすぐ下では**コンテンツタブの順序**（発見 /
マイコンテンツ / インポート / 作成）を設定でき、よく使うタブでハブを
開けます。

## 言語

*一般 > 言語*では、次のレンダリング時に `PATCH /api/settings/{user_id}`
経由ですべての UI 文字列をライブで切り替えます。11 言語すべてが
ファーストクラスです - DE / EL / EN / ES / FR / HI / ID / JA / KO / PT / TR、
それぞれ完全に翻訳されたカタログ付き。`localStorage` で再読み込みを
またいで保持されます。

## インターフェース

*一般 > インターフェース*には 2 つの設定があります。**ボタンのツールチップを
表示**（アイコンボタンにマウスを重ねたときのツールチップ。スクリーンリーダー用の
ラベルは常に有効）と、スマートフォンでの**メニューの位置（モバイル）**（上に
メニューボタンとして表示するのがデフォルト、または下に親指の届くタブバーとして
表示）。スワイプジェスチャーはレッスンの設定で、*学習 > レッスン中 > 操作*に
あります。開発者モードは**診断とサポート**タブにあります（下記参照）。

## ストレージモード

*一般 > ストレージモード*では、**サーバー**と**ローカル（ブラウザ）**の
ストレージを切り替えます：

- **サーバー** - すべての読み書きが FastAPI バックエンドを経由します。
  実行中のバックエンドが必要です。バックエンド側同期による複数デバイスでの
  使用に最適です。
- **ローカル（ブラウザ）** - すべての読み書きがこのブラウザの IndexedDB を
  使用します。AI 呼び出しはプロバイダーに直接送られます。バックエンドは
  不要です。プライベートなデバイスローカルの構成に最適です。

切り替えると `localStorage` に保存され、「再読み込みが必要」の通知が
表示されます。モード間でデータは同期されません。

公開ウェブ版とインストールされたウェブアプリにはバックエンドがないため、
そこではこのカードは表示されず、アプリは常にローカル（ブラウザ）を使用します。

## アップデートとアプリのインストール

**一般**タブの残りは、アプリの動作に関する項目です：

- **アップデート**（サーバーモードのみ）：**自動アップデート確認**と
  **確認間隔**（毎日、毎週、毎月、またはしない）、および最後に確認した日時と
  現在のバージョン。手動の**更新を確認**ボタンは**情報**タブにあります。
- **アプリをインストール**：Adaptive Learner を独立したアプリとして
  インストールします（専用ウィンドウ、ホーム画面のアイコン、ネットワークなしで
  起動）。インストール後、ボタンは**インストール済み**と表示されます。
- **モード**：ソロモードが有効です。マルチプレイヤーモードは近日公開として
  表示されています。

## 学習

**学習**タブは、カードをレッスンの進行順に 5 つのラベル付きエリアに
まとめています。各エリアには小さな見出しと 1 行の説明があり、
中のカードはそれぞれのタイトルを保ちます。

エリアの上の**セクションバー**は、エリアをチップとして並べます。チップを
クリックするとそのエリアへ移動します。デスクトップではスクロール中もバーが
アプリのヘッダーの下に表示されたままになり、スマートフォンではページと一緒に
スクロールし、横にスワイプできます。バーはアドレスと連動しています。
`/settings?tab=learning&section=review` は*レッスン後*までスクロールした
状態でタブを開きます（ID：`basics`、`lessons`、`voice`、`review`、
`motivation`）。チップをクリックすると、履歴を増やさずにアドレスが
更新されます。別のタブに切り替えると、セクションの指定は外れます。
表示されないエリア（Web Speech のないブラウザでの音声エリア）にはチップがなく、
不明なセクションは無視されます。スクロール中は、強調表示されたチップが
画面上のエリアに追従します。

### 基本

誰が、どの言語で学ぶか。

- **学習プロファイル** - 6 つのメソッドの重み付けの元になる学習プロファイルを
  作成、続行、またはやり直します。
- **追加の出発言語** - アプリの言語に加えて、コンテンツツリーに表示する
  出発言語。

### レッスン中

回答中の練習問題の動作。

- **レッスンモード** - **既定のモード**（練習 / 試験 / タイム制）、試験の
  **合格基準**、**タイム制モードの難易度**（はやい、ふつう、ゆったり）。
  [レッスンと復習](lessons.md)を参照してください。
- **ヒント** - 各練習問題に段階的なヒントボタンを表示するかどうか、および
  **ヒント1回あたりのXPコスト**（0 なら無料）。
- **操作** - **スワイプジェスチャー**（評価、セッション、カリキュラムで
  スワイプして移動。タッチ対応デバイスではデフォルト ON）、
  **レッスンのキーボードショートカット**（Enter で回答をチェック、もう一度
  Enter で次へ）、**正解したら自動で次へ進む**、および **AIに質問**ボタンを
  表示するかどうか。
- **優先する練習の方向** - 方向のある練習問題をどちらの方向で開くか。
- **マッチング問題** - **訂正を別のビューで表示**（デフォルト ON）：
  チェック後、「自分の回答」には自分のペアと間違いだけが表示され、正しい答えは
  「訂正」に、解答は「解答を表示」にあります。オフの場合は、正しい答えが
  「自分の回答」の各間違いのすぐ下に表示されます。さらに**解答アニメーション**、
  マッチング問題を解いたときに再生される効果。

### 読み上げと音声入力

音声、速度、マイク、発音練習。このエリアには**音声**カードがあります：

- **音声ボタンを表示** - AI の返信とアセスメントの結果の横に、読み上げる
  スピーカーボタンを追加します。
- **AI応答を自動再生** - すべての AI の返信を自動的に読み上げます
  （デフォルト OFF - 突然の音声はたいてい望まれません）。
- **音声** - 読み上げに使う声。デフォルトでは、プロジェクトの言語に最も近い
  ものが選ばれます。
- **速度**と**ピッチ** - 0.5 から 2 までのスライダー。
- **マイクボタンを表示** - セッションの入力欄にマイクボタンを追加します。
  音声を取り込み、送信前に途中の書き起こしをテキストエリアに入力します。
- **音声入力言語の上書き** - BCP-47 コード（例：`en-US`）。空欄のままにすると、
  プロジェクトまたは UI の言語を使用します。
- **発音練習** - 語学プロジェクトのダッシュボードに*発音練習*ボタンを
  表示します。

読み上げの設定（最初の 5 つ）はブラウザが音声合成をサポートしている場合にのみ、
音声入力の 2 つの設定は音声認識をサポートしている場合にのみ表示されます。
ブラウザが Web Speech API のどちらの側もサポートしていない場合は、エリア全体が
見出しごと表示されず、*レッスン後*が*レッスン中*の直後に続きます。

### レッスン後

復習セッション、レッスンのまとめ、間違いのやり直し。

- **復習** - 回答後の解説（練習問題の作成者が書いた解説。チェック後に
  練習問題の下に表示されます。およびレッスン後に自動生成されるルールの
  ヒント）と、復習セッションあたりの問題数。「間違えなかった要素も復習する」
  （デフォルト OFF）は、復習に間違えた要素だけを含めるか、一度も間違えなかった
  要素も 3 日後と 7 日後に戻すかを決めます。カードの最後には読み取り専用の
  **間隔反復**ブロックがあります：間隔のスケジュール（連続正解数と次の
  復習までの日数）、項目が習得済みとみなされる時期、学習メソッドへのリンク。
- **レッスン後のまとめ** - レッスン終了時のまとめに表示するセクションと
  その順序。デフォルトでオンなのは*結果と統計*と*XP報酬*だけで、
  スマートフォンの 1 画面に収まるコンパクトな表示です。それ以外はレッスンの
  最後の*詳細な評価*ボタンで表示されるか、ここでチェックすれば常に表示されます。
  *間違えた理由*もこれらのセクションの 1 つです。そのメインスイッチは
  引き続き*復習*の*解説を表示*です。
- **間違いをやり直す** - やり直しラウンドが拾う間違いの範囲。

### モチベーションと習慣

ゲームモード、フィードバック、デイリーミッション、リマインダー。

- **ゲームモード** - 遊び心のあるレッスン。**マスコットのバリエーション**、
  レベルやバッジで解放されるか XP と交換できる Lernfunke のカラースキーム
  （ロックされたバリエーションは条件を表示し、購入は 2 段階の確認を求めます）
  を含みます。ゲームモードで何が変わるかの詳細は
  [称賛とお祝い](celebrations.md)を参照してください。
- **フィードバック** - フィードバックの強さとサウンド（音量、テストボタン）。
- **デイリーミッション** - ミッションを有効にするか、1 日あたりの数、
  難易度の組み合わせ、今日のミッションのシャッフル。
- **リマインダー** - リマインダーの時刻と適用する曜日。
- **ゲーミフィケーション** - XP・バッジのトースト、週末モード、毎日の
  セッション目標、*進捗をリセット*。最後のカードです（下記参照）。

ゲームモードのカードには、メインスイッチ、ゲームモードのサウンド、
オンになっているエクストラの数を示すステータス行が表示されます。
**ゲームモードの詳細**（ハート、カウントダウン、アーケード、スペシャルラウンド、
チケット、ボーナスレッスン、連続XP、マスコット）は折りたたまれていて、
選択を記憶します。**遊び心のあるレッスン**がオフの間、中のオプションは
グレー表示になります。

タブは**ゲーミフィケーション**で終わります（*進捗をリセット*を含むため、
区切り線の下に置かれています）。2 つの整理設定 - *ダッシュボードの
一時停止中のレッスン*と*レッスンの最大サイズ* - はデータのライフサイクルに関する設定で、
**データ**タブにあります（データの*オフラインコンテンツ*と*整理*を参照）。

**コンテンツの表示**（リスト / グリッド）と**コンテンツタブの順序**は、
**一般**タブの*外観*にあります。

### ゲーミフィケーション

XP・バッジ・レベルアップ通知の切り替え（オフにしてもシステムは状態を記録します）、
**週末モード**（ストリークヒートマップの土日ギャップをスキップ）、
毎日のセッション目標（1〜10）、および**進捗をリセット**（ダブル確認。
`user_xp`・`user_badges`・`user_streaks` 行を削除）。

## AI プロバイダー + モデル選択

**AI** タブでは、プロバイダーのドロップダウンが `active_provider` を
UserSettings に書き込みます。次の AI 呼び出しは新しいプロバイダーの
プラグイン（サーバーモード）または新しいプロバイダーの HTTP クライアント
（ローカルモード）を経由します。

**モデル選択**は検索可能なドロップダウンで、推奨 / すべてでグループ化され、
各プロバイダーのライブ `/v1/models` エンドポイント（1 時間キャッシュ）から
生成されます。各行に人間が読める名前 + 生の ID + コンテキストウィンドウの
バッジが表示されます。検出されたリストが利用できない場合（API キーなし、
ネットワークなし）、選択は静的なデフォルトにフォールバックし、
「オフラインデフォルトを使用中」のヒントを表示します。セッションヘッダーは
`<プロバイダー>: <モデル名>` と表示し、完全な ID とコンテキストウィンドウは
ツールチップにあります。

## API キー

各プロバイダーに独自の行があります。キーの入力欄、保存ボタン、削除ボタン、
アクティブプロバイダーのバッジ、そして新しい**ソース属性**のバッジ：

- **キーの出所: secrets.yaml** - キーは
  `~/.config/adaptive_learner/secrets.yaml` に Fernet 暗号化されて
  保存されています。サーバーモードはここで入力したキーをすべてこのファイルに
  保存するので、保存後の行にはこのバッジが表示されます。保存と削除は
  引き続き使え、保存すると保存済みのキーが上書きされます。行の下の情報行に
  パスが表示されます。
- **キーの出所: 設定** - キーが `secrets.yaml` に移る前からデータベースに
  残っている古いキーです。次回の起動時にそちらへ移されます。ローカルモード
  （ブラウザ）ではキーは IndexedDB にあり、このバッジも表示されます。
  自由に保存・削除できます。
- **キーの出所: 環境変数** - キーは
  `ADAPTIVE_LEARNER_<PROVIDER>_API_KEY` 環境変数で設定されています。
  保存と削除は無効で、環境変数が情報源です。
- **キーが設定されていません** - どこにも設定されていません。入力して
  保存すると始められます。

解決チェーン（優先度の高い順）：env > secrets.yaml > DB。
詳細は[設定ドキュメント](https://github.com/astrapi69/adaptive-learner/blob/main/docs/configuration.md)を参照してください。

キーの入力欄はマスクされた**シークレット入力**（表示/非表示の切り替え付き）を
使い、ブラウザのパスワードマネージャーを起動しません。

API キーは通常のバックアップ（`.alb`）から意図的に**除外**されています。
キーを別のデバイスやブラウザに持ち運ぶには、専用の**暗号化されたキーの
エクスポート（`.alk`）**を使います。この AI タブには、**データタブ**の
エクスポートへ直接移動する**参照ボタン**があります（*バックアップと
エクスポート*の*暗号化されたキーのエクスポート*を参照）。

## 設定済みプロバイダー

**設定済みのAIプロバイダー**の一覧には、設定したAIプロバイダーが
**マスクされたキーのプレビュー**付きで表示されるので、どのプロバイダーが
使えるかがひと目でわかります。各行の**テスト**ボタンはプロバイダーの
モデル一覧エンドポイントを呼び出し、OK / 無効なキー / レート制限 /
ネットワークエラーを報告します。生成トークンを消費しない安全な確認です。

## プラグイン

**プラグイン**タブには 2 つのカードがあります。**インストール済みプラグイン**は、
デスクトップアプリが読み込んだすべてのプラグインを表示します：名前、
バージョン、ソース（パッケージまたは直接登録）、有効化の時刻。読み込みエラーや
検出フィルターは行のマーカーとして表示され、有効化後の設定変更も同様です。
ブラウザモードでは、プラグインホストがあるのはデスクトップアプリだけだという
通知付きでカードが表示されたままになります。**学習リポジトリ**には
そのプラグインの設定（git での永続化、リポジトリのディレクトリ）があります。

## データ

**データ**タブは、カードを決まった順序で 6 つのエリアにまとめています：
コンテンツがどこから来るか、それで何が起きるか、何が生まれるか、どう守るか、
何を片付けられるか、そして最後に元に戻せないもの。各エリアには小さな見出しと
1 行の説明があります。

エリアの上の**セクションバー**は、エリアをチップとして並べます：*ソース*、
*同期*、*オフラインコンテンツ*、*バックアップとエクスポート*、*整理*、
*危険ゾーン*。学習タブのものと同じように動作します。クリックするとエリアへ
移動し、デスクトップではバーがアプリのヘッダーの下に表示されたままになり、
強調表示されたチップは画面上のエリアに追従し、アドレスもそれに連動します
（`/settings?tab=data&section=backup`。ID：`sources`、`sync`、`offline`、
`backup`、`cleanup`、`danger`）。

### ソース

- **コンテンツリポジトリ** - レッスンの取得元となるリポジトリ。
  [コンテンツリポジトリ](../features/content-repos.md)を参照してください。
- **リポジトリを登録** - 自分のコンテンツリポジトリを、リポジトリ横断検索で
  使われる共有ディレクトリに提案します。

### 同期

QR コードスキャナー（背面カメラ）またはペアリング URL の貼り付けを使用して、
ローカルネットワーク経由でこのデバイスを別のデバイスとペアリングします。
ペアリング後、プッシュ + プルボタンで双方向にデータを交換できます。
競合はバックエンドの AI マージリゾルバーで処理されます。

制限されたブラウザのフォールバック：他のデバイスの QR コードのスクリーンショットを
アップロードします（`Html5Qrcode.scanFile`）。

同期にはデスクトップアプリが必要です。ブラウザモードではエリアは表示された
ままですが、操作部分は「デスクトップアプリでのみ利用できます。」という通知に
置き換えられます。

### オフラインコンテンツ

- **オフラインキャッシュ** - オフラインレッスンキャッシュのサイズと
  レッスン数。消去ボタン付きです（確認があります）。
- **レッスンの最大サイズ** - 長いチャット分析をオフラインレッスンとして
  保存するとき、このステップ数を超えるレッスンは複数のパートに分割されます。
  *パートあたりのステップ数*は 5 から 20 まで。デフォルトは 10 です。

### バックアップとエクスポート

**バックアップ**には 3 つの機能があります：**バックアップを作成**（`.alb`
バックアップファイルをダウンロード）、**バックアップから復元**（ファイルから
復元）、**比較**（現在の状態との並列 diff）。API キーはすべてのエクスポートから
除外されます。

復元はマージであり、上書きではありません。新しい行は挿入され、変更可能な行は
新しい `updated_at` で更新され、履歴行（セッション・コミット・評価）は UUID で
重複排除されます。比較プレビューは「復元」をクリックする前にテーブルごとの
追加・削除・変更を表示し、差分が確定すると復元ボタンの表示は
「復元 (N 件追加、M 件更新)」になります。

ローカルモードでは、カードに**自動バックアップ**ブロックも表示されます。
別の IndexedDB DB に 3 つのスナップショットをローリングで保持し、
10 セッションごとまたは 7 日ごと（どちらか先）に実行されます。各スナップショットに
復元、削除、A/B として比較のボタンがあります。

このエリアのその他のカード：

- **ID ファイル**（サーバーモードのみ） - バックエンドが保持する復旧用ファイルの
  読み取り専用の表示。存在するかどうかと、どこにあるかを確認できます。
- **暗号化されたキーのエクスポート** - 下記を参照してください。
- **データエクスポート** - ワンクリックの完全バックアップ、または含める
  データカテゴリを選ぶ選択エクスポート。どちらも同じインポート可能な
  バックアップファイルを作成します。
- **エクスポート** - 3 つのレポート：*学習の進捗*、*セッション詳細*、
  *カリキュラム*。それぞれ Markdown または PDF（ブラウザの印刷ダイアログ経由）で
  出力できます。

#### 暗号化されたキーのエクスポート (.alk)

通常のバックアップは API キーを除外します。これは安全ですが、デバイスや
ブラウザを切り替えるとすべてのキーを手で入力し直す必要があります。
**暗号化されたキーのエクスポート**は、パスフレーズで保護された別ファイルで
この隙間を埋めます：

- 含まれるのは機密の認証情報**だけ**です - **API キー**とプロバイダーの設定
  （アクティブプロバイダー、モデルの上書き）。それ以外のアプリデータは
  含まれません（それは `.alb` バックアップに残ります）。
- **エクスポート**はパスフレーズ（と確認）を求め、専用の **`.alk`** ファイルを
  ダウンロードします。中のキーは **AES-GCM-256** で暗号化され、鍵は
  パスフレーズから **PBKDF2** で導出されます。ファイルに平文のキーが含まれる
  ことはありません。
- **インポート**は `.alk` を読み込み、パスフレーズを求め、復号して、キーと
  プロバイダーの設定を手動入力と同じ安全な保存先に書き戻します（含まれている
  プロバイダーは上書きされ、含まれていないものはそのままです）。
- **間違ったパスフレーズや改ざんされたファイル**は、1 つのメッセージで
  きれいに拒否され、**部分的なインポートは行われません** - 中途半端に
  書き込まれることはありません。
- パスフレーズの欄は入力中に**その場で**検証されます。短すぎるパスフレーズや
  一致しない確認は、クリック後のエラートーストではなく、欄のすぐそばに
  表示されます（送信ボタンは無効のままです）。API キーの入力欄と同じく、
  これらのパスフレーズ欄もブラウザのパスワードマネージャーを**起動しません**。

このエクスポートは**データタブ**の通常のバックアップの隣にあり、
**AI タブ**にはここへ移動する参照ボタンがあるだけです。**ローカル（ブラウザ）
モード**ではキーは IndexedDB にあるので、エクスポートは完全に利用できます
（主な用途です）。**サーバーモード**ではキーはサーバー側で保持され、
クライアントが平文を見ることはないため、この項目は**ヒント付きで無効**に
なります。エクスポートできるキーがまだ設定されていない場合も無効です。

### 整理

- **ダッシュボードの一時停止中のレッスン**：ダッシュボードの一時停止中の
  レッスンカードには、この期間内に一時停止したレッスンだけが表示されます
  （*次の期間より古い一時停止中のレッスンを非表示*：7、14、30、60 日、
  または*無期限*。デフォルトは 30 日です）。古いレッスンはカードから
  消えるだけで、放棄されることはなく、位置と回答はそのまま残ります。
  カードには最近一時停止した 5 件のレッスンが表示されます。
- **未接続のコンテンツ**（ブラウザモード）：コンテンツリポジトリが接続されて
  いない進捗は、ここで削除するまで非表示のままです。このカードは片付けるものが
  あるときだけ表示されます。

*レッスンの最大サイズ*と*ダッシュボードの一時停止中のレッスン*はこのブラウザに
保存され、サーバーモードとローカルモードの両方に適用されます。

### 危険ゾーン

視覚的に区切られた最後のエリア：**すべてリセット**はすべてのデータを削除します
（サーバーモードではバックエンド上、ブラウザモードではこのブラウザ内）。
先にバックアップを作成するよう提案し、次に確認を求め、最後の**完全に削除**
ボタンは `RESET` と入力した後にだけ有効になります。

## 連携

**連携**タブには **GitHub 連携**があります。アプリがレッスンを
プルリクエストとして共有できるようにする GitHub トークン（`repo` 権限付き）
です。トークンの欄は入力中に形式を確認し、**テスト**はトークンを検証して
その所有アカウントを表示し、ソースの行がトークンの保存場所（secrets.yaml、
環境変数、またはこのブラウザ）を示し、**削除**で消去できます。環境変数から
来るトークンはここでは編集できません。

## ヘルプ

**ヘルプ**タブにはアプリ内の用語集があります。検索欄はタイトルと本文で
項目を絞り込み、項目は*コア概念*、*学習方法*、*サイクルステップ*、
*アプリ機能*にグループ分けされています。項目をクリックすると、ヘルプの
ドロワーで記事全体が開きます。

## 診断とサポート

**診断とサポート**タブには、開発者があなたのデバイスで何が起きたかを
把握するのに役立つものがまとまっています：

- **サポート** - **エラーレポートを作成**は最近の操作をレポートに集めます。
  何かがブラウザの外に出る前に、内容を確認できます。
- **開発者モード** - エラートーストに完全な技術的詳細（ステータスコード、
  エンドポイント、スタックトレース）を表示し、オンの間はナビゲーションバーに
  「DEV」バッジを表示します。デフォルトはビルド系統によって異なります。
  **Latest（プレビュー）系統ではデフォルト ON**、**Main では OFF** です。
  プレビューのテスターは完全な技術的エラー詳細を確認でき、本番の
  ユーザーにはわかりやすいメッセージが表示されます。どちらにも切り替えられます。
- **タップ・ビューポート診断プローブ** - オンの間、タップ位置とビューポートの
  変化を永続的な記録に残し、再現しにくい表示の不具合を突き止めます。
  **計測バーを表示**は記録を続けたまま上部のバーを表示・非表示にし、
  **計測バーのスティッキーボタン**はバーを切り替えるフローティングボタン
  （位置を選べます）を追加します。**記録をコピー**と**記録を消去**は記録された
  イベントに作用し、カウンターがその数を示します。

## 情報

5 つの読み取り専用ブロック：**バージョン**（`pyproject.toml` の正規バージョン、
ビルドハッシュ、ビルド日）、**システム**（ストレージモード、データディレクトリ、
サーバーモードの DB パス、Python + プラットフォーム情報）、
**クレジット**（著者、依存関係への謝辞）、
**開発を支援する**（Liberapay / GitHub Sponsors / Ko-fi リンク）、
**ライセンスとリソース**（MIT リンク、リポジトリ、ドキュメント、イシュートラッカー）。

ローカルモードでは、実行中のバックエンドにのみ意味のある行が非表示になります
（Python バージョン、FastAPI / SQLAlchemy / Pydantic / PluginForge バージョン、DB パス）。

### ビルド系統：Main と Latest

Adaptive Learner は 2 つのデプロイ系統で動いていて、情報タブでどちらを
使っているかがわかります：

- **Main** - 安定した本番サイト
  （`https://astrapi69.github.io/adaptive-learner/`）。控えめなバッジで
  表示され、警告の装飾はありません。
- **Latest** - `develop` からビルドされるプレビュー/ステージングサイト
  （`https://astrapi69.github.io/adaptive-learner-content-test/`）。
  不具合を含む可能性があることがわかるよう、はっきりした**テスト版**の
  バッジで表示されます。

バッジには系統と一緒にブランチと短いコミットハッシュが表示されます。
ビルド時に埋め込まれたビルド情報に基づいており、URL による推測は明示された
フォールバックにすぎず、情報がない場合は推測せずに「不明」と表示されます。

### アプリを共有

情報タブには**アプリを共有**の項目があり、公開アプリの URL の読み取り可能な
**QR コード**を、コピー / PNG のダウンロード / ネイティブ共有の操作付きで
表示します。アプリをスマートフォンに入れるのに便利です。

**Latest** 系統にいる場合、共有ではプレビューの URL が**リンクのみ - QR コード
なし**で、不安定さの警告と一緒に提示されます。読み取ったコードが誰かを
黙って不安定なテスト版へ送ることがないようにするためです。**Main** では、
これまでどおり本番 URL の QR コードで共有できます。

### 更新を確認

バージョンブロックの**更新を確認**ボタンは、あなたのバージョンを最新の
GitHub リリースと比較します。デスクトップ版はさらに GitHub Releases API を
使った**自動アップデートチェッカー**を実行し、新しいバージョンがあると
知らせます。その間隔は**一般**タブの*アップデート*で設定します。PWA の
更新後、「新しいバージョンがあります」のバナーは一度受け入れると
閉じたままになります（再読み込みのたびに再表示されなくなりました）。
