# デイリーミッション

デイリーミッションは、毎日追求できる具体的で達成可能な目標をいくつか提供します。アプリを開く理由となり、学習習慣を優しく後押しします。ミッションは**オプション**です。ミッションなしでもアプリはまったく同じように動作し、**ペナルティもありません**。翌日には新しいセットが用意されます。

## 仕組み

- **1日最大3つのミッション**が、ダッシュボードのストリークとバッジの間に表示されます。
- ミッションは1日15〜30分アプリを使用すれば**達成可能**で、難易度は**あなたに適応します**。新しい学習者には「学習」と「探索」の穏やかな目標が提示されます。エラー履歴がたまると、「レビュー」と「習得」ミッションも加わります。
- ミッションは**決定論的**です。同じ日には複数のデバイスで同じミッションが表示され、同じミッションが2日連続で割り当てられることはありません。
- 進捗はすでに行っていること（レッスンの完了、要素のレビュー、単語の習得）から自動的に更新されます。ミッションが完了するとボーナス**XP**を獲得します。
- ローカルの深夜になると、未完了のミッションは静かに期限切れとなり、新しいミッションが割り当てられます。

## ミッションの設定

**Settings > Learning > Daily Missions**では以下を設定できます。

- デイリーミッションを**オン/オフ**にする（デフォルトはオン）。
- **1日の数**を選択する（1〜3）。
- **難易度のバランス**を選択する（Balanced（デフォルト）、Easy、またはChallenging）。
- **今日のミッションをリセット**して新しいセットを取得する。

## ストリークジョーカー

ミッションのストリークを続けて1日だけ欠かした場合、時間をかけて獲得したストリークフリーズがそのギャップを埋め、ストリークを維持できます。2日連続で欠かすとストリークは終了します。ただし、繰り返しになりますが、ペナルティは一切なく、ただ新たなスタートです。
