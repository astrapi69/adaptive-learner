# 称賛とお祝い

Adaptive Learnerはあなたの進歩を称えることで、学習を充実感のあるものにします。邪魔にはなりません。お祝いは**獲得したもの**であり、決して押し付けがましくはありません。成果が大きいほど、フィードバックが目立つようになります。

## 表示されるもの

- **正解**には素早い緑のパルス、チェックアイコン、そして時々回答の下に短い称賛フレーズが表示されます。不正解の場合は穏やかな赤いフラッシュと修正（修正すべき正確な言葉）が表示されます。批判は一切ありません。
- **レッスンの完了**時にはスコアがカウントアップされ、星のレーティングと励ましのメッセージが表示されます。パーフェクト（3星）の場合は紙吹雪のバーストが追加されます。
- **マイルストーン**（7/30/100日のストリーク、新しいレベル、50/100/500個の習得要素、または新しいバッジ）は、画面上部に短時間バナーとして表示され、自動的に消えます。

## フィードバック強度

**Settings > Interface > Feedback Intensity**でお祝いの強さを選択できます。

- **Subtle（控えめ）** - 正解/不正解の色だけ。フレーズなし、紙吹雪なし、マイルストーンバナーなし。
- **Normal（通常）**（デフォルト）- アニメーション、称賛フレーズ、パーフェクトスコア時の紙吹雪。
- **Enthusiastic（熱狂的）** - すべての要素に加え、マイルストーンバナーと正解ごとの称賛フレーズ。

デバイスが動作の軽減を要求している場合、アニメーションは自動的にオフになり、この設定に関わらず強度は控えめに保たれます。

## サウンド

サウンドはデフォルトで**オフ**です。突然の音声に驚かされることはありません。**Settings > Interface > Sounds**でオンにした後、音量スライダーと**Test**ボタンでプレビューできます。サウンドは短い合成チャイムで、常に補助的なものです。サウンドが伝えるすべてのキューは、画面上でも表示されます。
