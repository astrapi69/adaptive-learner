# コンテンツレッスンとレビュー

**コンテンツレッスン**は、公開レッスンセットからダウンロードした小さな手作りの学習ユニットです（通常5〜10分）。AIチャットセッションとは異なる専用のビューアーで実行されます。レッスン後、アプリはどの単語、ペア、またはフレーズを間違えたかを正確に記憶し、後で集中的なレビューセッションのためにスケジュールします。

レッスンはAI APIキーを必要としない**代替学習経路**です。アプリを試すのに最適で、厳選された教材が自由形式のチャットよりも優れているコンテンツにも適しています。

---

## レッスンの出所

レッスンは**コンテンツセット**内に格納されています。公開GitHubリポジトリに公開された小さなバンドルです。アプリの`/content`にある**セットブラウザー**で利用可能なすべてのセットが一覧表示されます。セットをクリックするとダウンロードできます。セットはローカルにキャッシュされます（バックエンドで実行している場合はファイルシステムに、ブラウザのみのデプロイメントではIndexedDBに）。最初のダウンロード後はオフラインで学習できます。

パイロットv1.27.0セットは**フランス語A1**（2レッスン、14カード、4つすべてのエクササイズタイプをカバーする9エクササイズ）です。各リリースでさらに追加されます。現在のカタログは[セットリポジトリ](https://github.com/astrapi69/adaptive-learner-content)を参照してください。

---

## レッスンフロー

セットを開き、レッスンを選択すると、**レッスンビューアー**が各カードとエクササイズをステップバイステップで案内します。

1. **カード**は読む素材を提示します。準備ができたら「Next」をクリックします。
2. **エクササイズ**で何を覚えているかを確認します。4つのタイプがあります:
   - **Matching** — ペアをドラッグ（単語 ↔ 翻訳）。
   - **Picture choice** — プロンプトに合う画像を選択。
   - **Free text** — 答えをタイプ入力。
   - **Word tiles** — タイルから文章を組み立てる。

上部のプログレスバーでレッスンの進捗を確認できます。いつでも離れることができます。進捗はステップごとに保存され、離れた場所から再開します。

### サマリー画面

最後のエクササイズが完了すると、**レッスンサマリー**が表示されます。

- スコアに基づく**0〜3星のレーティング**:
  - **3星** ≥ 90%正解
  - **2星** ≥ 75%
  - **1星** ≥ 50%
  - **0星** 50%未満
- **エクササイズごとの内訳**（合格したエクササイズと間違いのあったエクササイズを表示; 不正解の場合は正解が表示）。
- **次のレッスン**、**繰り返し**、**セットに戻る**ボタン（次の操作がワンクリック）。

初回の試みで3星を取ると、星が小さなお祝いアニメーションを再生します（OSの「動作軽減」設定を尊重します）。

## 要素レベルのエラートラッキング

すべてのエクササイズタイプにおけるすべての不正解は、**間違えた特定の要素**（個々の単語、ペア、またはフレーズ）にキーを持つ行を書き込みます。アプリは単に「レッスン3で6/10点」を覚えるのではなく、「特に*bonjour*と*merci*が苦手だった」を覚えています。

同じ要素を**3回連続で正解すると**、**習得済み**に変わり、レビューキューから削除されます。習得済みの要素を後で間違えると、**キューに戻ります**。忘れた習得は習得ではありません。

---

## レビューキュー

レビューが必要な要素が1つ以上ある場合、**レビューキューカード**がダッシュボードに表示されます。表示内容:

- 期日が来た要素の数
- **期限超過**の要素の数（スケジュールされたレビュー日を過ぎたもの）
- `/review/:setId`での集中ミニセッションを開く**Review now**ボタン

スケジューリングは、その要素を連続して何回正解したかに基づく3つのバンドを使用します。

| 正解の連続数 | 次のレビュー |
|---|---|
| 0 | 1日後 |
| 1 | 3日後 |
| 2 | 7日後 |
| 3（習得済み） | キューから削除 |

キュー内では、アイテムは**期限超過が最初**、次に**エラー数の多い順**、次に**最近失敗した順**で並び替えられます。最も苦手な要素が上位に浮かび上がります。

---

## レビューセッション

`/review/:setId`でのレビューセッションは、キューの上位アイテムから**オンザフライでミニレッスンを合成**します。**v1.35.0**時点での混合戦略:

- **マッチング**や**ピクチャーチョイス**エクササイズで単語を間違えた場合、そのエクササイズを再実行します（新たにシャッフルされるため、単なる筋肉記憶ではありません）。
- **フリーテキスト**や**ワードタイル**で間違えた場合、間違えた正確な単語をターゲットにした**クローズ**（穴埋め）を生成しようとします。同じ知識を別の形で確認します。柔軟性が鍛えられ、特定のエクササイズ形式の思い出しだけではありません。
- そのアイテムについてクローズ生成でクリーンな穴が作れない場合（例: ソースプロンプトに回答がインラインで含まれていない）、レビューはサイレントに元のエクササイズの再生にフォールバックします。壊れたステップや空のステップが表示されることはありません。

レビューセッションが完了すると、同じスコアリング + 星レーティング + 要素トラッキングが動作します。レビューを通じて50個の要素を習得すると、**Review Master**バッジを獲得します。

## 各レッスン終了時の訂正ラウンド

**v1.35.0**の新機能: 不正解があったレッスンが終了すると、サマリーページのスコアと「次のレッスン」ボタンの間に小さな**訂正ラウンド**が表示されます。このレッスンからの最大5つの具体的なミスを選び、間違えた正確な単語や冠詞をターゲットにした新しいクローズとして提示します。

- **いつでもスキップできます**。「次のレッスン」ボタンはずっと表示されています。訂正ラウンドはオプションの練習であり、ゲートではありません。
- **修正するものがある場合のみ表示されます**。完璧なスコアのレッスンは完全にスキップします。ミスをクリーンなクローズに変換できない（まれな）レッスンもスキップします。
- **完成した各クローズは習得に向けてカウントされます**。訂正ラウンドはメインレッスンと同じ要素トラッキング行を書き込みます。それらの特定の要素のストリークが3回正解の習得閾値に向けて進みます。

ラウンド終了時に短い「{n}個の要素が改善されました」というメッセージが表示され、追加練習の成果が確認できます。

## ビジュアルdiffフィードバック

**v1.35.0**の新機能: フリーテキストとワードタイルの不正解に、あなたが書いたものとカノニカルな回答の**トークンレベルのdiff**が表示されるようになりました。3色で、色だけに依存しません。

- **赤の取り消し線** — あなたが書いたが不要なもの（画面読み上げや色覚障害者のためのマーカー付き）。
- **緑** — カノニカルに含まれているがあなたが欠けていたもの（+マーカー付き）。
- **アンバー**と矢印 → — 少し間違えた単語（`あなたが書いたもの` → `期待される`として表示）。

同じdiffは、v1.35.0以降がユーザーの回答を保存しているフリーテキストまたはワードタイルの試みに対して、レッスンサマリーのエクササイズごとの内訳行にも表示されます。

## XPとバッジ

完了した各レッスンは星ごとの計算式でXPを獲得します。

- **30 XP**基本
- **星ごとに+10 XP**（0 → 0、1 → +10、2 → +20、3 → +30）
- 初回の試みで3星を獲得した場合（すべてのステップがattempts = 1で、再試行なし）に**+20 XP bonus**
- チャットセッションと同じ**毎日のストリーク乗数**（連続活動日ごとに+25%、7日間上限）

4つの新しいバッジがレッスンに関連して解除されます。

- **First Lesson** — 最初のコンテンツレッスンを完了。
- **10 Lessons Completed** — 10個のコンテンツレッスンを完了。
- **3-Star Streak** — 3つのレッスンで連続して3星を獲得。
- **Review Master** — 間隔反復を通じて50個の要素を習得。

レッスンの完了は**毎日のストリーク**にもカウントされるため、コンテンツレッスンで学習することでチャットセッションと同様にヒートマップが埋まります。

## ストレージモード

レッスンは**両方**のストレージモードで動作します。API（バックエンド）とDexie（ブラウザのみ / GitHub Pages）。要素レベルのエラートラッキングとSRSスケジューリングは、ブラウザのみのデプロイメントでIndexedDBに対して同一に動作するため、公開GitHub Pagesサイトを訪問するユーザーはバックエンドなしで完全なレビューループを利用できます。

ブラウザのみモードで**異なる**点: XP付与 / バッジ獲得の副作用はAPIモードでのみ発生します（バックエンドのゲーミフィケーションフックが必要）。Dexieモードでは引き続きチャットセッションパスを通じてXPとバッジを獲得できます。レッスンの完了はまだその合計に加算されません。

---

## プライバシー

レッスンの進捗、要素エラー行、レビューキューの状態、スケジューリングデータはすべて、APIモードでは**自分のデバイス**（ファイルシステム）に、ブラウザではIndexedDBに留まります。どの単語が苦手かについての情報はどこにも送信されません。
