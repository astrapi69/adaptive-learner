# 学習パス

**学習パス**ページ（`/learning-path`）は、2 つの問いにひと目で
答えます：*自分は今どこにいて、次は何か？* デフォルトでは
**パーソナル**パスが表示されます。ダウンロードしたレッスンセットを
最近の活動順に並べた、コンパクトな 2 階層のリストです。代わりの表示と
して、インタラクティブな**グラフ**ビューも引き続き利用できます。

## 学習パスを開く

- 上部のナビゲーションバーで**学習パス**をクリックします。
- ダッシュボードで、**学習パス**のクイックアクションボタンを使います。
- コンテンツブラウザ（マイレッスンのセクション）で、**学習パス**を
  クリックします。

## パーソナルビュー（デフォルト）

### レベル 1 - セットの概要

ダウンロードした各セットが **1 行**になります：

| 要素 | 意味 |
|---------|---------|
| ドメインアイコン + タイトル | コース（脳 = 心理学、旗 = 言語、コード = プログラミング） |
| ミニ進捗トラック | レッスンごとに 1 つの点 - 塗りつぶし = 完了、半分 = 進行中、中空 = 未開始 |
| パーセンテージ | セットのレッスンのうち完了した割合 |
| 最終活動 | このセットに最後に取り組んだ時期（「昨日」、「3 日前」） |
| 現在のレッスン | 次にやるべきレッスン |
| アクションボタン | **続ける** / **開始** / **次のレベルが利用可能** / **完了** |

セットは最終活動順（新しいものが先）に並びます。まだ手を付けていない
ダウンロード済みのセットは下に沈みます。そしてその中では、**最も最近
ダウンロードしたセットが先**に来るので、ダウンロードしたばかりの
セットは埋もれることなく、未開始グループのいちばん上にあります。
コースのすべてのレッスンを終え、次の CEFR レベルが存在する場合、
その行に**次のレベルが利用可能**が表示されます。

### レベル 2 - レッスンの詳細

セットの行をクリックすると、その場で展開されます（ページは切り替わり
ません）。各レッスンには、番号とタイトル、スター（0〜3、一度も挑戦
していない場合は -）、方向ごとの習得度（**受容** / **産出**）、
最後に挑戦した日付が表示されます。▶ マーカーはセットの現在の
レッスンを強調します。任意のレッスンをクリックすると、開始または
再開できます。

展開したセットのいちばん下には次のものがあります：

- **アダプティブレッスンを開始** - このセットでのあなたの間違いから
  生成されるレッスン。
- **間違いを復習（N）** - セットの未解決の間違いを復習します（間違いが
  ある場合にのみ表示）。

もう一度セットの行をクリックすると折りたたまれます。

### 自分のみ / すべてのセット

**[自分のみ] [すべてのセット]** の切り替えは、下部の
*ダウンロードされていません*セクションをどれだけ目立たせるかを
決めます。**自分のみ**（デフォルト）ではそのセクションを折りたたんだ
ままにし、**すべてのセット**では展開するので、さらにコースを閲覧して
ダウンロードできます。選択は記憶されます。

### ダウンロードされていません

下部にある折りたたみ可能なセクションに、まだダウンロードしていない
コンテンツセットが、それぞれ**ダウンロード**ボタン付きで一覧表示
されます。セットをダウンロードすると、上のアクティブなリストに
移動します。

## グラフビュー（代替）

ヘッダーの**パーソナル / グラフ**の切り替えで、ズーム可能な
インタラクティブなグラフを開きます。ダウンロードしたすべてのセットと
レッスンが、ドラッグ、絞り込み、検索、詳細表示ができるノードとして
配置されます。グラフ（とその大きめの描画ライブラリ）は切り替えた
ときにだけ読み込まれるので、デフォルトのパーソナルビューは速いままです。

### レッスンノードとセットノード

各レッスンノードには、番号とタイトル、スター、方向ごとの習得度
（**R ✓** / **P ✓**）、XP、ステータスの色、おすすめの次のレッスンに
付く脈打つアクセント、前提条件が満たされていない場合の鍵アイコンが
表示されます。セットのグループノードは、セットのレッスンを進捗バーと
習得度のまとめ付きで囲みます。そのヘッダーをクリックすると、
折りたたみまたは展開ができます。

### グラフの操作

- **ステータスフィルター** - すべて / 未開始 / 進行中 / 習得済み。
- **方向フィルター** - すべて、または受容か産出の習得が欠けている
  レッスンのみ。
- **検索** - 一致したものを強調表示します。**Enter** を押すと最初の
  一致に移動します。
- **統計** - 完了したレッスン、受容で習得、産出で習得。
- **エラークラスタを表示** - 共通の間違いのパターン（例：*冠詞の性*）
  と、ワンクリックで始められるアダプティブレッスン。
- **レイアウトをリセット** - 自動レイアウトを復元し、ドラッグした
  位置を消去します（位置はユーザーごとにブラウザのストレージに保存
  されています）。

## キーボード操作

すべての操作要素にキーボードで到達できます：**Tab** でフォーカスを
移動し、**Enter / Space** で行、レッスン、ボタンを有効にします。
タッチターゲットは少なくとも 44 px で、ページは幅 375 px まで
きれいにレイアウトし直されます。

## ヒント

- **現在のレッスン**（▶）は、常に最善の次の一歩です。レッスンの順序
  だけでなく、あなたの間違いの履歴に基づいています。
- 一時停止したレッスンは、その行またはダッシュボードの一時停止中の
  レッスンカードから再開できます。
- **受容**と**産出**の両方の習得に達すると、そのレッスンは完全に
  習得済みとみなされます。
