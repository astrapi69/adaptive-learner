# ナビゲーション

アプリのメインナビゲーションは、**グループ化された少数の項目**で
構成されています（EXP-037。Nielsen Norman の「5〜7 項目」の指針に
従っています）。それでも**機能が失われることはありません**。すべての
ページに到達でき、古いリンクはリダイレクトによって引き続き使えます。

## デスクトップ：グループ化された項目

デスクトップのナビゲーションは、再利用可能な `NavGroup`
コンポーネントによって、ラベル付きのグループに整理されています：

- **学習** - ダッシュボード、学習パス、セッション。
- **コンテンツ** - 4 つのタブを持つ**コンテンツハブ**（`/content`）：
  *発見*（カタログ）、*マイコンテンツ*（ダウンロードしたもの）、
  *インポート*、*作成*（自分の新しいレッスン）。ハブは、あなたが
  設定した順序の最初のタブで開きます。デフォルトでは発見です。
  順序は*設定 > 一般 > 外観*で変更できます。
- **進捗** - **ProgressHub**（`/progress`）。概要、統計、マイパスを
  タブとして持ちます。
- **設定**と**ヘルプ**がバーを締めくくります。

Anki は独立した項目ではなく、コンテンツページ上のアクションです。
その `/anki` ルートは引き続き機能します。

### 画面幅ごとにメインナビゲーションは 1 つ

デスクトップの幅では、横並びの上部バーが**唯一の**メイン
ナビゲーションです。ハンバーガーボタンもドロワーもありません。
狭い幅やモバイルの幅では、同じグループ化された項目が
**ハンバーガードロワー**の中に移ります。どちらの表示も共通の
行き先リスト 1 つから描画されるので、常に同じページにつながります。
アクティブな項目には `aria-current` が付き、どのターゲットも少なくとも
44px あり、すべてのテーマで機能します。（設定ページには、自身のタブ用の
独立したセクションサイドバーがあります。これはメインナビゲーションとは
関係ありません。）

## モバイル：下部タブバー（オプション）

スマートフォンでは、ナビゲーションはデフォルトで上部にメニューボタン
として表示されます。*設定 > 一般 > インターフェース*の
**メニューの位置（モバイル）**で**下（タブバー）**に切り替えると、
親指で操作しやすい 5 つのタブを持つバーになります：**学習 / コンテンツ
/ 学習パス / 進捗 / その他**。*その他*は設定とヘルプを含むボトムシートを
開きます。ハンバーガードロワーはどちらの位置でも引き続き利用できます。
ターゲットは 44px で、バーはすべてのテーマに対応し、オンボーディングの
流れとレッスン中は非表示になるので、コンテンツを覆うものはありません。

## ハブとリダイレクト

2 つのページは**タブ付きのハブ**で、アクティブなタブだけを
読み込みます：

- **ProgressHub**（`/progress`）は、進捗 + 学習統計 + カリキュラムを
  まとめています。
- **コンテンツハブ**（`/content`）は、発見 + マイコンテンツ +
  インポート + 作成をまとめています。

古い URL はリダイレクトで保たれています。例：`/statistics` →
`/progress?tab=stats`、`/curriculum` → `/progress?tab=paths`、
`/discover` → `/content?tab=discover`、`/import` →
`/content?tab=import`。
