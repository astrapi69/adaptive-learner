# よくある質問

## データの安全性

### 私のデータはどこに保存されますか？

**サーバーモードの場合：** データは FastAPI バックエンドが動作している
デバイス上の SQLite データベースに保存されます（デフォルトパス：
`~/.local/share/adaptive_learner/adaptive_learner.db`）。
保存のためにクラウドサーバーへ送信されることはありません。
オフライン中に記録されたレッスンの進捗と音声録音は、
送信されるまでこのブラウザ内で待機します。

**ブラウザモード（ローカル）の場合：** あなたのブラウザが、あなたのデータを
あなた自身のデバイス（IndexedDB と localStorage）に保存します。
保存されるものには、進捗、インポートされたチャット、API キーと GitHub
トークンを含む設定などがあります。その際、運営者のサーバーは関与しません。
これらのデータの一部を他者が受け取るのは、機能がそれを必要とする場合だけです。
たとえば、AI を使うときはあなたの AI プロバイダーが、
アプリが起動時に新しいコンテンツを自動的に問い合わせるときは GitHub が
受け取ります。ブラウザのタブを閉じても、これらのデータは削除されません。
ブラウザでサイトデータを削除すると、あなたのデバイスから消去されます。
共有のデバイスでは、このブラウザプロファイルにアクセスできる人なら誰でも、
それらを読むことができます。

### AI プロバイダーには何が送信されますか？

どのモードも、テレメトリ、アナリティクス、あなたのメッセージを第三者に
送信しません。例外は、あなたが選んだ AI プロバイダーです。学習セッションでは、
このプロバイダーが次のものを受け取ります。

- システムの指示：学習プロジェクトのテーマと目標、プロフィールのヒント
  （好みの学習方法とその重み）、完了したレッスンとその結果、取り組み中の
  レッスンとステップ、最近の間違い（それぞれあなたの回答、正解、回数）、
  AI が回答に使う言語。インポートされたチャットから始めたセッションでは、
  学習の進捗の代わりにそのチャットの分析と記録が含まれます。
- あなたのメッセージと、そのセッションでの AI のこれまでの返答。
- すべてのリクエストと同様に、ほかの情報とともに、あなたの IP アドレスと
  API キー。

XP とバッジはこれに含まれません。
ほかの AI 機能もあなたのプロバイダーにデータを送信します。たとえば、
インポートされたチャットの分析です。
[AIコンテンツチェック](ai-validation.md) は、チェックするセットのカード
（カードごとに識別子、表面、裏面、メモ）を送信します。
共有前の AI チェックが送信するのは、あなたのレッスンのうち共有するものだけで、
その中のカード、ステップのテキスト、練習問題（問題文と誤答の選択肢）などです。
どちらも、セットの出発言語、対象言語、レベルも送信します。
これらの内容に自分で書いたものも一緒に送られ、
それ自体が個人的な内容である場合があります。AI へのすべてのリクエストは
[プライバシーポリシー](../legal/privacy.md) に記載されています。

### データを削除するにはどうすればよいですか？

**サーバーモードの場合：** SQLite ファイルを削除するか、
[設定 > 学習 > ゲーミフィケーション > 進捗をリセット](settings.md) からゲーミフィケーションデータのみを
リセットできます。

**ブラウザモードの場合：** ブラウザの IndexedDB をクリアするか、
アプリ内でリセットできます。

## API キー

### API キーを持っていない場合はどうすればよいですか？

[はじめに](getting-started.md) をご覧ください。無料利用枠でも始められます。

### API キーが漏洩した場合はどうすればよいですか？

1. すぐにプロバイダーのコンソールでキーを無効にしてください
2. 新しいキーを生成してください
3. 設定で新しいキーを更新してください

**サーバーモードの場合：** キーは Fernet 暗号化されて保存されています。
ただし、万が一のために他のセキュリティ手順も実施してください。

### `ADAPTIVE_LEARNER_SECRET_KEY` とは何ですか？

これはバックエンドの暗号化キーです。
API キーの暗号化に使用されます。
自動生成されますが、本番環境では手動で設定することをお勧めします。

## オフライン使用

### インターネットなしで Adaptive Learner を使用できますか？

**ブラウザモードでコンテンツレッスンを使用する場合：** はい。
コンテンツレッスンはオフラインで動作します（以前にキャッシュされた場合）。

**AI 機能（セッション）の場合：** いいえ。AI セッションには
プロバイダーへのインターネット接続が必要です。

### PWA としてインストールするとオフラインで動作しますか？

コンテンツレッスンはオフラインで動作します。
AI セッションにはネットワークが必要です。

## メソッドと学習

### メソッドを自分で選択すべきですか、それとも AI アダプティブを使うべきですか？

Adaptive Learner が初めての場合は、最初の数セッションで
各メソッドを手動で試すことをお勧めします。
どのメソッドが最も自然に感じるかが分かったら、
AI アダプティブを使用するとより洗練された推奨が得られます。

### メソッドをセッション中に変更できますか？

直接変更することはできませんが、「セッション終了」後に
別のメソッドで新しいセッションを開始できます。

メソッド切り替え推奨が表示された場合は、そこから変更できます。

### 「自動ループ」とは何ですか？

ステップ 7 の後にセッションが自動的に新しいサイクルを開始する機能です。
[7 ステップサイクル](../concept/seven-steps.md) を参照してください。

## エクスポート

### Anki にエクスポートできますか？

はい。Anki プラグインを有効にすると、`/api/plugins/anki/cards` から
`.apkg` ファイルをエクスポートできます。[進捗](progress.md) を参照してください。

### NotebookLM にエクスポートできますか？

はい。NotebookLM プラグインを有効にすると、
学習質問と学習ガイドを ZIP でエクスポートできます。

## 音声

### 音声機能はどのように動作しますか？

[設定 > 学習 > 読み上げと音声入力](settings.md) から TTS（テキスト読み上げ）と
STT（音声認識）を設定できます。
ブラウザの Web Speech API を使用しています。

## チャットインポート

### どのチャット形式をインポートできますか？

ChatGPT（JSON）、Claude（テキスト/Markdown）、Gemini（テキスト）を
サポートしています。詳細は [Import](../api/core-endpoints.md) を参照してください。

## 同期とバックアップ

### 複数のデバイス間でデータを同期できますか？

**サーバーモードの場合：** はい。[設定 > データ > 同期](settings.md) を使用してください。

**ブラウザモードの場合：** 直接的な同期はありませんが、
[設定 > データ > バックアップとエクスポート](settings.md) からエクスポートして他のデバイスでインポートできます。

## ChatGPT との比較

### Adaptive Learner は ChatGPT とどう違いますか？

ChatGPT は汎用 AI アシスタントです。
Adaptive Learner は ChatGPT（または Claude・Gemini）の上に構築された
**学習構造**です。

| 機能 | ChatGPT | Adaptive Learner |
|---|---|---|
| 進捗追跡 | ✗ | ✓ |
| 学習メソッド | ✗ | 6 つのメソッド |
| 間隔反復 | ✗ | ✓ |
| 評価 | ✗ | ✓（デュアルプロンプト） |
| カリキュラム | ✗ | ✓ |
| オフライン | 限定的 | コンテンツレッスン |

Adaptive Learner は ChatGPT の代替ではありません。
ChatGPT での会話をより効果的な学習に変換するツールです。
