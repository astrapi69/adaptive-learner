# よくある質問

## データは安全ですか？

**ローカルモード**では、あなたのブラウザが、あなたのデータを
あなた自身のデバイス（IndexedDB と localStorage）に保存します。
保存されるものには、進捗、インポートされたチャット、API キーと GitHub
トークンを含む設定などがあります。その際、運営者のサーバーは関与しません。
これらのデータの一部を他者が受け取るのは、機能がそれを必要とする場合だけです。
たとえば、AI を使うときはあなたの AI プロバイダーが、
アプリが起動時に新しいコンテンツを自動的に問い合わせるときは GitHub が
受け取ります。ブラウザのタブを閉じても、これらのデータは削除されません。
ブラウザでサイトデータを削除すると、あなたのデバイスから消去されます。
共有のデバイスでは、このブラウザプロファイルにアクセスできる人なら誰でも、
それらを読むことができます。

**サーバーモード**では、あなたの学習データは、FastAPI バックエンドが
管理する SQLite データベースに保存されています。レッスンの進捗と
音声録音のうち、オフライン中に生じたものは、アプリが送信するまで
このブラウザ内で待機します。最大でどれだけの量が待機するか、残りが
どうなるかは、[バックアップと復元](../features/backup.md) に記載されています。
API キーは Fernet で暗号化されて `~/.config/adaptive_learner/secrets.yaml`
に保存され、プロバイダーごとに、最後に正常に動作した API キーの予備の
コピーも、同じく暗号化されてデータベースに保存されます。
暗号化キーは初回起動時に生成され、
`~/.config/adaptive_learner/secret.key` に保存されます。何も設定する
必要はありません。独自のキーを指定したい場合は、初回起動の前に
`ADAPTIVE_LEARNER_SECRET_KEY`（または `secrets.yaml` の `secret_key:`）を
設定してください。

どのモードも、テレメトリ、アナリティクス、あなたのメッセージを第三者に
送信しません。例外は、あなたが選んだ AI プロバイダーです。学習セッションでは、
このプロバイダーが次のものを受け取ります。

- システムの指示：学習プロジェクトのテーマと目標、プロフィールのヒント
  （好みの学習方法とその重み）、完了したレッスンとその結果、取り組み中の
  レッスンとステップ、最近の間違い（それぞれあなたの回答、正解、回数）、
  AI が回答に使う言語。インポートされたチャットから始めたセッションでは、
  学習の進捗の代わりにそのチャットの分析と記録が含まれます。
- あなたのメッセージと、そのセッションでの AI のこれまでの返答。
- すべてのリクエストと同様に、ほかの情報とともに、あなたの IP アドレスと
  API キー。

XP とバッジはこれに含まれません。
ほかの AI 機能もあなたのプロバイダーにデータを送信します。たとえば、
インポートされたチャットの分析です。
[AIコンテンツチェック](ai-validation.md) は、チェックするセットのカード
（カードごとに識別子、表面、裏面、メモ）を送信します。
共有前の AI チェックが送信するレッスンは、あなたのレッスンのうち共有するものだけで、
それらからはカード、ステップのテキスト、練習問題（問題文と誤答の選択肢）などを送信します。
どちらも、セットの出発言語、対象言語、レベルも送信します。
これらの内容に自分で書いたものも一緒に送られ、
それ自体が個人的な内容である場合があります。AI へのすべてのリクエストは
[プライバシーポリシー](../legal/privacy.md) に記載されています。

## API キーは必要ですか？

AI セッションには必要です。アプリは、対応するすべてのプロバイダーで
**Bring-Your-Own-Key**（自分のキーを使う方式）を採用しています。対応する
プロバイダーは Anthropic Claude、OpenAI GPT、Google Gemini で、さらに
サーバーモード（デスクトップアプリ）では Perplexity も使えます（ブラウザ版は
Perplexity を直接呼び出せません）。始めるには、たいてい無料枠で足ります。

キーを置ける場所は 3 つあります（優先度の高いものが使われます）。
環境変数 `ADAPTIVE_LEARNER_<PROVIDER>_API_KEY`、
`~/.config/adaptive_learner/secrets.yaml` の `ai.<provider>.api_key` フィールド、
または設定画面（キーを暗号化して、まさにこのファイルに保存します）です。
設定画面にはプロバイダーごとにキーの出どころが表示されるので、
キーがどこから来ているかを常に確認できます。

API キーがなくても、カリキュラムを見て回ったり、学習タイプの診断を受けたり、
ダッシュボードを見たり、チャット履歴のインポートまで実行したりできます。
キーが必要なのは、セッションページ、分析ステップ、AI による抽出機能です。

## オフラインで使えますか？

一部は使えます。PWA のサービスワーカーが静的アセット（HTML、JS、CSS、
アイコン）をキャッシュするので、アプリはインターネットなしでも起動します。
過去のセッションやダッシュボードのデータもローカルストレージから読み込まれるので、
以前の教材を読み返すことはできます。

**ライブセッションには引き続きインターネットが必要です。** AI プロバイダーは
あなたのブラウザの外にあるからです。セッションページはオフラインであることを
検出し、黙って失敗する代わりに、ページ内に分かりやすいメッセージを表示します。

## メソッドの切り替えとは何ですか？

3 回続けて、理解が停滞し、ストレスが高い状態のセッションが続くと、アプリは
「次のセッションで [別のメソッド] を試してみますか？」というバナーを表示します。
推奨されるのは、診断で 2 番目に強かったメソッドのうち、最近使っていないものです。

これは*提案*であって、指示ではありません。バナーを閉じて、今のメソッドのまま
続けることができます。停滞が続くと、バナーはまた表示されます。メソッドの切り替えは
`method_switches` テーブルに記録され、進捗ページのメソッド分布に表示されます。

## 自動ループとは何ですか？

セッションがステップ 7（統合）に達し、トピック移行の評価で、テーマが統合されていて、
かつ続ける価値があると判断されると、新しいサブテーマで新しいサイクルが自動的に
始まります。1 セッションあたり最大 5 サイクルです（無限ループの防止）。
チャット履歴には、切り替わるたびに破線の枠の「サイクル N」カードが表示されます。
`cycle_count > 1` の場合、セッション終了時の評価ダイアログが、複数サイクルに
わたる流れをまとめます。

デスクトップアプリのみ：ブラウザ版では、セッションはステップ 7 で止まり、
セッションページにその旨が表示されます。そこでセッションを終了し、
新しいセッションを始めてください。

## データをエクスポートできますか？

はい。主に次の方法があります。

- **バックアップ**：設定 > データ > バックアップとエクスポート >
  バックアップを作成。`.alb` バックアップファイルがダウンロードされます。
  バックアップはどちらのストレージモードでも作成できます。API キーは
  バックアップに含まれません。API キーを移す方法は、[設定](settings.md)
  ページの「暗号化されたキーのエクスポート (.alk)」セクションに記載されています。
  バックアップに含まれないもののほかの例は、
  [バックアップと復元](../features/backup.md) ページに記載されています。
- **進捗・セッション・カリキュラムのレポート**：
  設定 > データ > バックアップとエクスポート > エクスポート。
  Markdown と PDF（ブラウザの PDF 印刷）です。
- **Anki .apkg**：`/anki` ページで AI が抽出した単語カードを確認し、
  必要なものを承認して、エクスポートをクリックします。
  ファイルは Anki デスクトップでそのまま使えます。
- **NotebookLM ZIP**：進捗ページから、構造化された ZIP（まとめ、語彙、
  ルール、間違い、単語カード、セッション）をダウンロードします。
  NotebookLM のソースアップロード用の形式です。

## 音声機能とは何ですか？

Web Speech API を使った 3 つの機能です。

- **テキスト読み上げ**：AI の返答と診断の結果に。それぞれの横にある ▶ ボタンで、
  その言語に合った声で読み上げます。
- **音声入力**：セッションの入力欄に。🎤 ボタンで声を録音し、送信の前に
  途中の書き起こしをテキストエリアに入れます。
- **発音練習**：言語のプロジェクト向け。`/pronunciation` を開くと、AI が目標の文を
  作り、あなたが話し、判定役の AI が似ている度合いを評価して、改善点を提案します。

音声の設定は 設定 > 学習 > 読み上げと音声入力 にあります。このエリアは、
API に対応していないブラウザでは表示されません。

## チャット履歴のインポートとは何ですか？

インポートページ（`/import`）は、ChatGPT、Claude.ai（JSON の一括エクスポートと、
1 つの会話の Markdown エクスポートの両方）、Gemini、および任意の Markdown から、
貼り付けまたはアップロードしたチャットの記録を受け付けます。分析では、テーマ、
弱点、間違いのパターン、推奨メソッド、語彙（言語の会話の場合）、カリキュラムの
提案が抽出されます。ワンクリックで分析からカリキュラムを作り、目的を絞った
セッションを始められます。

Claude.ai の 1 つの会話の Markdown エクスポートは、確認済みのインポートの例です。
この形式では、パーサーが完全なタイムスタンプを抽出し、発言者の区切りを保ちます。

## デバイス間の同期は？

まだできません。アプリはまだ、あなたのデータをデバイス間で同期できません。
デバイスのペアリングは今のところできず、ペアリングしなければ同期で
データがやり取りされることはありません。設定 > データ > 同期 に
何が表示されるかは、ストレージモードによって異なります。

- ローカルモードでは、このエリアに操作部分は表示されず、代わりに
  「デスクトップアプリでのみ利用できます。」という通知が表示されます。
  ブラウザ版は、インストールされたウェブアプリとして使う場合も含めて、
  常にローカルモードを使います。デスクトップアプリでも、ローカルモードに
  設定されている間は同じ通知が表示されます（設定 > 一般 >
  ストレージモード：「ローカル (ブラウザ)」）。ただし、デスクトップアプリも
  今のところ同期はしません（次の項目を参照）。
- デスクトップアプリのサーバーモード（設定 > 一般 > ストレージモード：
  「サーバー」）では、このエリアにホストとポートの入力欄と
  「ペアリングコードを生成」ボタンが表示されます。これをクリックすると、
  ペアリングリンク、QR コード、リンクをコピーするボタンが表示されます。
  ただし、このリンクを利用できるデバイスはまだなく、QR コードを使っても
  利用できません。そのため、これで 2 台目のデバイスをペアリングすることは
  今のところできません。

同期が利用できない間は、バックアップを使ってデータを別のデバイスへ
移します。ただし、すべてのデータを移せるわけではありません。たとえば、
API キーはバックアップに含まれません。API キーを移す方法は、
[設定](settings.md) ページの「暗号化されたキーのエクスポート (.alk)」
セクションに記載されています。バックアップに含まれないもののほかの例は、
[バックアップと復元](../features/backup.md) ページに記載されています。

## ChatGPT とどう違いますか？

ChatGPT は、1 つのモデルとのチャット画面です。Adaptive Learner は、内部で AI を
使う*構造化された学習システム*で、さらに次のものを備えています。

1. **6 メソッド × 7 ステップのマトリクス**：それぞれに合わせたシステムプロンプト。
2. **ターンごとのステップ評価**：2 回目の AI 呼び出しが準備の度合いを判断し、
   あなたを先へ進めたり、前に戻したりできます。
3. **新しいサイクルへの自動ループ**：テーマが統合されたとき。
4. **プロフィール**：12 問の診断から得た、あなたの学習の好み。
5. **長期的な記録**：ProgressCommits、連続記録のヒートマップ、XP、バッジ、
   ステップごとの時間のグラフ。ChatGPT はタブを閉じると忘れます。
6. **プロバイダーを選べる自由**：Anthropic、OpenAI、Gemini、さらに
   サーバーモードでは Perplexity。
7. **ローカルファーストの選択肢**：ローカルモードでは、ブラウザが学習の進捗、
   統計、設定などを保存します。その一部を他者が受け取るのは、機能がそれを
   必要とする場合だけです。アプリがサーバーに接続するのは、機能がそれを必要と
   する場合です。たとえば、コンテンツのための GitHub（そのために、接続済みの
   リポジトリも起動時に自動で照合します）、あなたの AI プロバイダー、そして何かを
   共有するときや不具合の報告をそこで開くときの GitHub です。それがどの場合で、
   何が送信されるかは、[プライバシーポリシー](../legal/privacy.md) に記載されています。

## AI が間違えたら？

システムは、目に見える形で失敗します。

- **API キーが間違っている**：AI の呼び出しが、チャット内に分かりやすい
  エラーメッセージを返します。
- **プロバイダーが停止している**：同じく、エラー表示がプロバイダー API の
  HTTP ステータスを示します。
- **評価の JSON を解析できない**：決まった +1 の前進が適用され（ステップ 7 が上限）、
  `fallback_used: true` として記録されます。そのため、形式をうまく扱えない
  モデルを後の監査で見つけられます。
- **ストリーミングが途中で切れた**：途中までの返答は残り、次のメッセージは
  そこから続きます。
- **古い、またはおかしな AI の返答**：セッションを終了し、低く評価して、
  もう一度始めてください。同じことが続くと、メソッド切り替えの仕組みが別の
  メソッドを提案します。
