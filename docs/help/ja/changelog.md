# 新着情報（v1.61 – v1.69）

v1.61.0 以降のリリースをユーザー視点で概観します。バージョン
ごとの完全な技術的ノートは
[GitHub Releases](https://github.com/astrapi69/adaptive-learner/releases)
にあります。

---

## v1.69.0 — 例リンク + 書籍の推薦

- **理論内の例リンク：** 理論ステップにオプションの
  「例を見る」リンクを付けられます。
- コンテンツブラウザでの**ドメインごとの書籍推薦**
  ([書籍の推薦](content-creation/books.md))。
- **エラーリプレイでも Enter ショートカット**（「間違いを繰り返す」）。
- **バックアップ修正：** 復元時にセットのタイトルがマニフェストから
  正しく読み込まれるようになりました。

## v1.68.0 — 結果エクスポート + 理論への戻りリンク

- **レッスン結果をエクスポート：** 「結果をコピー」／「ファイルに
  保存」（AI アシスタント向けの Markdown レポート）。
- **理論への戻りリンク：** 演習から該当の理論へ飛んで、戻れます。
- **マッチング演習を刷新：** 色付きのペア + 番号バッジ
  （色覚多様性に配慮）。
- 複数箇所で**ダークモードのコントラスト**を修正。

## v1.67.1 — バックアップ復元 + デプロイの安定性

- 体系的な**バックアップ復元**の修正。
- 古いデプロイチャンク時の自動リロード。
- サブジェクトフィルタの磨き込み（サブジェクトが 1 つ以下の
  場合は非表示、最もよく使われた順）。

## v1.65.0 — 再開可能なアセスメント + Enter ショートカット

- **再開可能なアセスメント：** テストを中断して、後で中断した
  ところから続けられます。
- **Enter ショートカット：** Enter で回答済みの演習をチェックして
  進みます（設定 → 学習 で切り替え可能）。
- より分かりやすいマッチング演習 + デザイントークンの見直し。

## v1.64.0 — オンボーディングの刷新

- **名前 + テーマだけのクイックスタート**。残りはデフォルトを
  採用します。
- オプションの**オンボーディングアシスタント**（1 画面に 1 つの
  質問）。
- **アセスメントは現在オプション**です
  ([オンボーディング](user-guide/onboarding.md))。

## v1.63.0 — WCAG AA テーマプリセット

- **6 つの推奨テーマ**（Catppuccin Latte/Mocha、Supabase、
  Graphite、Soft Pop、Amethyst Haze）。計算的に AA 準拠
  ([テーマシステム](developer/themes.md))。
- 体系的な i18n 監査。ユーザーに紐づくダッシュボードフィルタ。

## v1.62.0 — バックアップの整合性 + ビルドの来歴

- **バックアップ復元**の堅牢化（データ型の強制変換、外部キーの
  順序）。
- About が「unknown」の代わりに実際のビルド情報を表示します。

## v1.61.0 — ボタンの統一 + レッスンの再開

- アプリ全体の shadcn ボタンの統一。
- **一時停止したレッスン**が正確なステップから再開します。
- クロスリポジトリのコンテンツ検証。

## この期間の大きな流れ

  リポジトリ、ローカルの評価

- **完全なスナップショットとしてのバックアップ**とクロス
  アイデンティティ・インポート
  ([バックアップと復元](features/backup.md))。
