# Docker Desktop をインストールする

Adaptive Learner は、あなた自身のマシン上で小さなコンテナ群として
動作します。デスクトップランチャーがこれらのコンテナの起動と停止を
代わりに行いますが、そのためにはまず **Docker** がインストールされ、
実行されている必要があります。このガイドでは Docker Desktop の
インストール手順を順を追って説明します。

## 必要なもの

- Docker Desktop 本体のダウンロードに約 800 MB。
- 初回起動時の Adaptive Learner イメージに約 2 GB のディスク容量
  （これは一度だけです。以降の起動は高速です）。
- 初回ビルドに数分（5-10 分が普通です）。

## インストール

1. 公式の Docker Desktop ダウンロードページを開きます：
   [docs.docker.com/desktop](https://docs.docker.com/desktop/)。
2. お使いのオペレーティングシステム（Windows、macOS、Linux）向けの
   インストーラーをダウンロードします。
3. インストーラーを実行し、案内に従います。変更する理由が特に
   なければ、デフォルト設定のままにします。
4. Docker Desktop を起動し、クジラのアイコンに
   「Docker Desktop is running」と表示されるまで待ちます。

## ランチャーを起動する

Docker Desktop が実行されたら、Adaptive Learner のランチャーを
もう一度起動します。ランチャーはまず Docker を確認し、続いて
イメージのダウンロード、ビルド、アプリの起動を行い、最後に
「ブラウザで開く」ボタンを表示します。

ランチャーの起動時に Docker がまだ実行されていない場合は、
「Docker を起動」ボタン付きの通知が表示されるので、ランチャーを
離れずに Docker を立ち上げることができます。

## Docker はインストールしても安全ですか？

はい。Docker Desktop は著名な企業である Docker, Inc. によって
作られており、世界中の何百万人もの開発者に利用されています。
これは、個人のコンピューター上でコンテナ化されたアプリケーションを
実行する標準的な方法です。

Adaptive Learner が Docker を使うのは、あなたのマシン上で自身の
コンテナを実行するためだけです。あなたの学習データはローカルに
留まります。Docker をインストールしても、あなたのデータに関する
情報が Docker, Inc. に送られることはありません。Docker Desktop は
他のアプリケーションと同様に、いつでもオペレーティングシステムから
アンインストールできます。

## トラブルシューティング

- **ランチャーが Docker は実行されていないと表示する。** Docker
  Desktop を起動し、「running」状態になるまで待ってから、
  「再試行」をクリックします。
- **ポートがすでに使用されている。** ランチャーがこれを検出し、
  別のポートを提案します。その提案を受け入れてください。
- **その他の問題が発生した。** `--debug` フラグを付けてランチャーを
  再実行し、生成された `launcher-debug.log` を共有してください：

  ```bash
  python3 -m adaptive_learner_launcher --debug
  ```
