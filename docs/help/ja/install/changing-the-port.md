# ポートの変更（データを失わずに）

デスクトップランチャーでは、Adaptive Learner が動作するポートを
変更できます（デフォルトは **8501**）。これは別のアプリがすでに
そのポートを使っている場合に便利ですが、変更する前に知っておくべき
影響が 1 つあります。

## ポートがデータにとって重要な理由

ウェブアプリのストレージは、ポートを含む正確なウェブアドレスに
結び付いています。ブラウザから見ると、`http://localhost:8501` と
`http://localhost:8502` は**別々の**アドレスであり、それぞれが
独自の独立したストレージを持ちます。

これが実際に何を意味するかは、Adaptive Learner の実行方法によって
異なります。

- **サーバーモード**（デスクトップランチャーのデフォルト）。セット、
  レッスン、進捗は、ブラウザではなくアプリ自身のバックエンドに
  保存されます。ポートの変更の影響は**受けません**。アプリは新しい
  アドレスで自動的にそれらを再び見つけます。
- **ブラウザストレージモード**（*設定 > 一般 > ストレージモード*で
  有効にできるオプションで、公開ウェブ版が使うモード）。セット、
  進捗、自分で作成した演習は**ブラウザ内**に、現在のアドレスに
  結び付いて保存されます。ポートを変更すると、アプリは新しい
  アドレスで空のブラウザストレージとともに開くので、まっさらな
  状態から始まったように見えます。**データは削除されていません**。
  以前のポートの下に保存されたままで、新しいポートでは見えない
  だけです。

## データを新しいポートに移す

ブラウザストレージモードを使っていて、すでにポートを変更した場合、
データは古いアドレスの下で待っています。バックアップで移しましょう。

1. **以前のポートに戻ります**（例：
   `http://localhost:8501`）。データが再び表示されます。
2. **設定 > データ > バックアップを作成**を開き、`.alb`
   ファイルを保存します。
3. **新しいポート**に切り替えます。
4. ようこそ画面で**既存のバックアップから復元**を選び、`.alb` ファイルを
   選択します。セット、進捗、演習、そして設定まで、すべてが
   復元されます。

バックアップについて詳しくは、[バックアップと復元](../features/backup.md)を
参照してください。

## 驚かないために：まずバックアップを

最も安全な習慣は、**ポートを変更する前にバックアップをエクスポートする**
ことです。そうすれば、何かが足りなくても新しいアドレスで復元できます。
定期的なバックアップは一般的にもよい保険です。学習をデバイス間で
移すこともできます。

## ポートを変更してもアプリはネットワークに公開されません

どのポートを選んでも、アプリは `127.0.0.1` でのみ待ち受けます。
このコンピューターからはアクセスできますが、ほかのデバイスからは
できません。ログイン機能がないため、スマートフォンや別のマシンから
アクセスできるようにするのは、別の意図的な手順
（`ADAPTIVE_LEARNER_BIND_ADDRESS=0.0.0.0`）であり、信頼できる
ネットワークでのみ意味があります。
[デスクトップランチャーを起動する](launcher.md)（「誰がアプリにアクセスできるか」）を
参照してください。
