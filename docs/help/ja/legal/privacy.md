## ブラウザ内での保存

お客様がアプリで作成したものはすべて、お客様のブラウザによって
IndexedDB および localStorage にローカルで保存されます。この保存は
アプリの動作に厳密に必要なものであり、ドイツ電気通信デジタルサービス
データ保護法（TDDDG）第25条第2項第2号の例外に該当するため、同意は
必要ありません。サーバーには何も送信されません。データは「設定」で
いつでもエクスポートまたは削除できるほか、ブラウザでサイトデータを
消去することもできます。

AI プロバイダーの API キーを入力した場合も、同様にローカルにのみ
保存されます。

## ご自身のキーによる AI 機能

AI 支援機能（学習セッション、演習の提案、コンテンツチェック）は、
お客様が「設定」でプロバイダー（Anthropic、OpenAI または Google）の
ご自身の API キーを入力した場合にのみ有効になります。その場合、
お客様のブラウザは入力内容と関係する学習コンテンツをそのプロバイダーに
直接送信します。Adaptive Learner の運営者はこの送信に関与せず、データを
受け取りません。契約はお客様とプロバイダーとの間に成立し、プロバイダーの
プライバシー通知が適用されます:

- [Anthropic](https://www.anthropic.com/privacy)
- [OpenAI](https://openai.com/policies/privacy-policy)
- [Google](https://policies.google.com/privacy)
