共有ボタンは、結果付きでレッスンを完了すると「ダッシュボード」の
「学習を続ける」の行に表示され、「設定」の「学習」にある
「レッスン後のまとめ」でオンになっている場合はレッスンの最後にも表示されます
（初期設定ではオフです）。デバイスに独自の共有ダイアログがある場合、
アプリはそれを開き、お客様は共有先をそこで選びます。
ない場合は、Facebook、LinkedIn、X、WhatsApp へのリンクとコピーの選択肢を
表示します。

これらのリンクのいずれかをクリックして初めて、ブラウザはそのネットワークの
ページを開きます。その際ネットワークは、お客様の IP アドレス、通常の
ブラウザデータ、そのネットワーク自身がお客様のデバイスに設定した Cookie
を受け取ります。Facebook と LinkedIn が受け取るのはアプリのアドレスだけで、
X と WhatsApp は、レッスンのタイトル、お客様の結果（パーセントと正解数）、
アプリのアドレスを含む入力済みのテキストを受け取ります。このテキストは
送信前に変更できます。アプリはこれらのネットワークのスクリプトやボタンを
埋め込みません。クリックした時点から、各ネットワークのプライバシー通知が
適用されます。法的根拠はお客様の要求です（GDPR 第6条第1項(b)）。

## 外部リンク

アプリとこれらのページには、外部サービス（GitHub、Amazon、YouTube、
AnkiWeb、寄付プラットフォームなど）へのリンクが含まれています。学習
コンテンツや AI の回答に含まれる、他のサーバーを指す動画や画像も、アプリは
リンクとして表示します。これらはお客様がクリックして初めて読み込まれます。
クリックするとアプリまたはこれらのページを離れ、それ以降はそれぞれの提供者
のプライバシー通知が適用されます。これらの提供者のスクリプト、ボタン、
埋め込みコンテンツは一切含まれていません。

## お客様のデバイスへの保存

お客様がアプリで作成したものは、お客様のブラウザによって IndexedDB および
localStorage にローカルで保存されます。対象は、プロフィール、学習
プロジェクト、進捗と統計、メモ、インポートしたチャット、ダウンロード
したレッスン、話して録音する練習の音声録音、自動バックアップ、API キーと
GitHub
トークンを含む設定、さらにキャッシュされたカタログです。アプリはこのほかに
次のものを使用します。

- タブを閉じるとブラウザが削除する sessionStorage。エラーレポート用の
  操作履歴（アプリでの最近の操作。たとえばクリックしたボタン、ページの
  移動、選択したオプション、表示されたメッセージ、エラーなど。キーボード入力は
  含みません）と、AI キーを入力した場合はプロバイダーのモデル一覧に使用
  します。モデル一覧は1時間、キーそのものではなくキーの短い
  フィンガープリントの下に保存されます。
- Cache Storage。アプリのファイルとダウンロードしたレッスンを保存し、
  オフラインでも動作するようにします。

これらのドキュメントページが localStorage に保存するのは、配色（ライト
またはダーク）だけです。公開プレビューはアプリと同じドメイン（`astrapi69.github.io`）
にあるため、両者はブラウザのストレージを共有します。

この保存は、お客様が使う機能に厳密に必要なものであり、ドイツ電気通信
デジタルサービスデータ保護法（TDDDG）第25条第2項第2号の例外に該当する
ため、同意は必要ありません。保存そのものは何も送信しません。データが
デバイスから送信されるのがいつかは、上記の各セクションで説明しています。
データは「設定」でいつでもエクスポートまたは削除できるほか、ブラウザで
サイトデータを消去することもできます。
