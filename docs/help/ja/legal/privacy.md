## お客様のデバイスへの保存

お客様がアプリで作成したものは、お客様のブラウザによって IndexedDB および
localStorage にローカルで保存されます。対象は、プロフィール、学習
プロジェクト、進捗と統計、ノート、インポートしたチャット、ダウンロード
したレッスン、スピーキング演習の録音、自動バックアップ、API キーと GitHub
トークンを含む設定、さらにキャッシュされたカタログです。アプリはこのほかに
次のものを使用します。

- タブを閉じるとブラウザが削除する sessionStorage。エラーレポート用の
  操作履歴（アプリでの最近の操作。たとえばクリックしたボタン、ページの
  移動、選択したオプション、メッセージ、エラーなど。キーボード入力は
  含みません）と、AI キーを入力した場合はプロバイダーのモデル一覧に使用
  します。モデル一覧は1時間、キーそのものではなくキーの短い
  フィンガープリントの下に保存されます。
- Cache Storage。アプリのファイルとダウンロードしたレッスンを保存し、
  オフラインでも動作するようにします。

これらのドキュメントページが localStorage に保存するのは、配色（ライト
またはダーク）だけです。公開プレビューはアプリと同じドメイン（`astrapi69.github.io`）
にあるため、両者はブラウザのストレージを共有します。

この保存は、お客様が使う機能に厳密に必要なものであり、ドイツ電気通信
デジタルサービスデータ保護法（TDDDG）第25条第2項第2号の例外に該当する
ため、同意は必要ありません。保存そのものは何も送信しません。データが
デバイスから送信されるのがいつかは、上記の各セクションで説明しています。
データは「設定」でいつでもエクスポートまたは削除できるほか、ブラウザで
サイトデータを消去することもできます。
