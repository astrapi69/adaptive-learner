# 同期アーキテクチャ

Adaptive Learner はローカルファーストです。ストレージモード「サーバー」
（内部名は API）では、デスクトップアプリのバックエンドが学習データを
保存します。その際ブラウザに残るのはわずかで、たとえば一部の設定と、
転送されるまでの間、オフラインで保存された変更です
（[設定](../user-guide/settings.md)を参照）。ストレージモード
「ローカル (ブラウザ)」（内部名は Dexie）では、学習データはアプリが
動作しているブラウザの IndexedDB にあります。**同期**は将来、
デバイスをローカルネットワーク経由で接続する予定ですが、まだ利用
できません（下の SYNC-UI-GATE のセクションを参照）。完全な
リファレンスは
[`docs/policies/SYNC-ARCHITECTURE.md`](https://github.com/astrapi69/adaptive-learner/blob/main/docs/policies/SYNC-ARCHITECTURE.md)
にあります。

---

## 3 つのデバイスの役割

同期の UI は、デバイスの役割に応じて異なる形で計画されています。

| 役割 | ストレージモード | 同期 UI |
|---|---|---|
| デスクトップ（サーバー） | API | QR を生成、ステータス、「今すぐ同期」 |
| モバイル（クライアント） | Dexie | QR をスキャン／リンクを貼り付け、ペアリング後のステータス |
| PWA のみ | Dexie | なし |

## SYNC-UI-GATE：原則と現在の状況

原則は「動作するものだけを表示する」です。LAN モード（フェーズ 1）は
まだ一部しか実装されておらず、まだ利用できません。ペアリングの画面の
うち、今のところ開けるのはペアリングリンクを生成する画面だけで、それも
デスクトップアプリのストレージモード「サーバー」でのみです。別のデバイスで
リンクを利用する画面（リンクの貼り付け、QR コードのスキャン）は、意図的に
無効にされています。ゲートはストレージモードに従います：

- デスクトップアプリにしかないストレージモード **サーバー**（内部名は API）
  では、*設定 > データ > 同期* のエリアが提供するのはペアリングリンクの
  生成だけです。ホストとポートの入力欄と「ペアリングコードを生成」ボタンが
  表示され、これをクリックすると QR コード、ペアリングリンク、コピー用の
  ボタンが表示されます。
- ストレージモード **ローカル (ブラウザ)**（内部名は Dexie）では、エリアは
  表示されたままですが、操作要素は表示されず、代わりに
  「デスクトップアプリでのみ利用できます。」という通知が表示されます。
  ブラウザ版は、インストールされたウェブアプリ（PWA）として使う場合も
  含めて、常にこのストレージモードを使います。デスクトップアプリでも
  このストレージモードを選べます。デスクトップアプリのバックエンドでのみ
  動作する機能は、#335/#336 以降、非表示にするのではなく通知付きで
  無効になります。その際、同期が無効かどうかを決めるのはストレージモードで
  あり、アプリの種類ではありません。
- リンクを利用する画面が表示されうるのはストレージモード
  「ローカル (ブラウザ)」だけですが、そこではエリアが無効になっているため、
  この画面は決して表示されません。

どのデバイスもペアリングできないため、ペアリング済みのデバイス向けの画面も
表示されず、その画面の「今すぐ同期」ボタンも表示されません。同期で
データがやり取りされることはありません。

現在このエリアは、たとえば次のような点で原則から外れています：

- エリアの説明「デバイスをペアリングしてデータを揃える。」は、ペアリングと
  データを揃えることを約束していますが、どちらもまだ存在しません。
- ストレージモード「サーバー」では、デスクトップアプリがペアリングリンクの
  生成を提供していますが、そのリンクを利用できるデバイスはまだありません。
- 通知「デスクトップアプリでのみ利用できます。」はデスクトップアプリを
  案内していますが、デスクトップアプリでもまだ同期はできません。
  デスクトップアプリ自体では、この通知はストレージモード
  「ローカル (ブラウザ)」のときに表示されます。

LAN モードが実装され次第、バイナリのゲート（API か Dexie か）は、上の表に
ある 3 値のゲートになる予定です。リンクを利用する画面は、このゲートが
できてから初めて再び有効にする予定です。バイナリのゲートが有効なうちに
この画面を有効にすると、ストレージモード「ローカル (ブラウザ)」のすべての
デバイスに表示されてしまいます。このゲートは「モバイル（クライアント）」と
「PWA のみ」の役割を区別しないからです。そこでは、この画面は機能しない
操作要素になります。LAN モードが実装されるまではそれらのすべての
デバイスで、実装後も、バイナリのゲートが有効な間は「PWA のみ」の役割の
デバイスで、そうなります。
