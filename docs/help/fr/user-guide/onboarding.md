# Parcours d'accueil

Lors de votre première utilisation d'Adaptive Learner, un parcours d'accueil
en plusieurs étapes vous guide jusqu'à votre premier projet d'apprentissage.

---

## Étapes du parcours

### 1. Bienvenue

Un bref aperçu de l'application — pas de configuration requise. Cliquez
sur **Continuer** pour avancer.

### 2. Créer un compte

Entrez votre nom (ou un pseudonyme). Sélectionnez votre langue d'interface
préférée parmi les huit langues disponibles.

Aucun mot de passe ni adresse e-mail n'est nécessaire — votre identité
est stockée localement.

### 3. Configurer une clé API (facultatif)

Si vous souhaitez utiliser les fonctionnalités IA (sessions d'apprentissage,
analyse de conversation, génération Anki), entrez votre clé API ici.

Vous pouvez ignorer cette étape et utiliser les leçons de contenu sans
clé API.

### 4. Test d'évaluation (facultatif)

Passez le test d'évaluation en 12 questions pour obtenir votre profil
d'apprentissage initial. Cette étape est facultative — vous pouvez la
faire plus tard depuis **Paramètres → Apprentissage**.

### 5. Créer votre premier projet

**Champs obligatoires :**

| Champ | Exemple |
|-------|---------|
| Sujet | « Grammaire française pour débutants » |
| Objectif | « Pouvoir tenir une conversation simple » |

**Champs optionnels :**

| Champ | Explication |
|-------|-------------|
| Calendrier | Quand souhaitez-vous atteindre votre objectif ? |
| Minutes par jour | Aide à calibrer les recommandations de répétition espacée |
| Problème actuel | Votre point de blocage actuel — alimente les invites IA |

### 6. Taxonomie et étiquettes (avancé, optionnel)

Vous pouvez associer votre projet à une taxonomie de sujets (par ex.
Langues > Français > Grammaire) et ajouter des étiquettes libres.

Ces métadonnées alimentent les recommandations d'outils et le filtre
de session, mais n'ont aucun impact sur la fonctionnalité de base.

---

## Après l'accueil

Vous arrivez sur le **tableau de bord** avec votre premier projet créé.
La prochaine étape naturelle est de démarrer votre première session en
cliquant sur la carte du projet.
