# Session d'apprentissage

Une session d'apprentissage est une séance guidée par l'IA suivant le
[cycle en sept étapes](../concept/seven-steps.md). Elle dure généralement
entre 20 et 45 minutes.

---

## Démarrer une session

Depuis la page du projet ou le tableau de bord, cliquez sur **Nouvelle session**.

Vous pouvez choisir :
- **Méthode** (ou laisser le système recommander selon votre profil)
- **Langue de la session** (héritée des paramètres du projet par défaut)

---

## Interface de session

L'interface de session comporte :

| Zone | Rôle |
|------|------|
| Fil de discussion | Messages entre vous et l'IA enseignante |
| Indicateur d'étape | Affiche l'étape actuelle du cycle (1-7) |
| Compteur de cycles | Affiche le cycle actuel et le maximum configuré |
| Bouton Terminer | Clôture la session à tout moment |
| Panneau de notation | Apparaît à la fin de chaque cycle |

---

## Le cycle en action

Vous n'avez pas besoin de gérer le cycle vous-même. La progression
se fait naturellement au fil du dialogue. Si vous vous demandez à
quelle étape vous êtes, vérifiez l'indicateur d'étape dans la barre
latérale.

**Conseils pratiques :**

- Répondez franchement - une tentative incomplète est plus précieuse
  qu'un refus
- Signalez à l'IA si quelque chose n'est pas clair : « Je ne comprends
  pas encore »
- Ne copiez pas des réponses de l'IA - l'évaluateur le détectera via
  une faible confiance lors des variations suivantes

---

## Recommandation de changement de méthode

Si les conditions de stagnation sont remplies (au moins 3 sessions,
stress moyen > 3, adéquation < 3), une **bannière de recommandation**
apparaît en haut de la session.

Vous pouvez :
- **Accepter** - une nouvelle session avec la méthode recommandée démarre
- **Refuser** - la suggestion ne réapparaît pas avant 3 sessions de plus
- **Reporter** - ignorer pour maintenant

---

## Évaluation de session

Après la clôture d'une session (manuellement ou après le dernier cycle),
vous évaluez trois dimensions :

| Dimension | Signification |
|-----------|---------------|
| Compréhension | Avez-vous compris le contenu ? (1-5) |
| Stress | Quelle était la pression ressentie ? (1-5) |
| Adéquation de méthode | La méthode convient-elle au sujet ? (1-5) |

Ces notes alimentent :
- Le système de recommandation de méthode
- L'évaluateur de stagnation
- Les statistiques du tableau de bord

**Notes de session :** un éditeur de texte enrichi optionnel vous permet
de noter vos insights, erreurs ou questions pour consultation ultérieure.

---

## Streaming

Les réponses de l'IA apparaissent en streaming mot par mot - vous ne
devez pas attendre la réponse complète. L'évaluation en arrière-plan
tourne pendant le streaming.

---

## Auto-boucle

Si l'auto-boucle est activée (dans les paramètres), une nouvelle boucle
démarre automatiquement après chaque cycle complété avec un nouveau sujet
de curriculum. Vous pouvez interrompre l'auto-boucle à tout moment.

Voir [Auto-boucle](../concept/seven-steps.md#auto-boucle) pour plus de détails.
