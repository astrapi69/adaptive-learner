# Tableau de bord

Le tableau de bord est la vue centrale d'Adaptive Learner. Il présente
votre progression, vos recommandations et l'accès rapide à tous vos projets.

---

## Widgets du tableau de bord

### Diagramme radar

Affiche votre profil d'apprentissage actuel — la surface couverte par
les six méthodes. La méthode dominante est surlignée.

Si vous n'avez pas encore passé le test d'évaluation, ce widget propose
un bouton **Passer l'évaluation**.

---

### XP, série et badges

**Barre d'XP et niveau**
Votre XP total et votre niveau actuel. La barre montre combien d'XP
restent jusqu'au prochain niveau.

**Série active**
Le nombre de jours consécutifs avec au moins une session ou une leçon
complétée. Les gels de série disponibles ce mois-ci sont affichés.

**Badges récents**
Les 3 derniers badges débloqués avec leurs niveaux (bronze/argent/or).
Le bouton **Galerie des badges** ouvre la collection complète.

---

### Chronologie de progression

Un graphique temporel de vos sessions, affiché sous forme de carte de
chaleur ou de graphique en barres selon la plage temporelle. Vous pouvez
basculer entre :
- 7 derniers jours
- 30 derniers jours
- Tout l'historique

---

### Répartition des méthodes

Un graphique en anneau montrant combien de sessions vous avez réalisées
avec chaque méthode. Utile pour repérer si vous utilisez exclusivement
une méthode et si vous devriez envisager plus de variété.

---

### Sessions récentes

Liste des 5 dernières sessions avec leur méthode, durée, note de
compréhension et nombre de cycles. Cliquez sur une session pour voir
son détail complet.

---

### Recommandations d'outils

Recommandations d'outils personnalisées basées sur votre profil d'apprentissage.
Les méthodes à pondération élevée se traduisent par des suggestions d'outils
spécifiques (Anki pour les profils déductifs, NotebookLM pour les profils
inductifs, etc.).

---

### File d'attente de révision

Si vous avez des éléments dus dans votre file d'attente SRS (suite à des
erreurs dans les leçons de contenu), ce widget affiche :
- Combien d'éléments sont dus
- Combien sont en retard
- Un bouton **Réviser maintenant**

---

### File des leçons en pause

Si vous avez des leçons de contenu en pause, une carte résume les leçons
en attente avec un bouton **Reprendre**.

---

### Zones de focus

Affiche vos principaux domaines de faiblesse identifiés à partir des erreurs
d'éléments SRS, avec une répartition réceptif/productif. Un bouton
**Démarrer une leçon adaptative** génère une session de révision ciblée.

---

### Missions quotidiennes

Si les missions sont activées, jusqu'à 3 objectifs quotidiens sont affichés
avec leur progression et leur valeur de bonus en XP.

---

## Gestion des projets

Le bas du tableau de bord liste tous vos projets d'apprentissage. Depuis
la carte de chaque projet, vous pouvez :
- Démarrer une nouvelle session
- Ouvrir le curriculum
- Voir la progression
- Archiver ou supprimer le projet
