# Missions quotidiennes

Les missions quotidiennes offrent jusqu'à 3 objectifs d'apprentissage
quotidiens adaptés à votre niveau et à votre activité récente.

---

## Comment fonctionnent les missions

Chaque jour à minuit local, le système génère un nouvel ensemble de missions
basé sur :

- Votre activité récente (sessions, leçons, révisions)
- Votre statut d'éligibilité (nouveau/actif/vétéran)
- La difficulté configurée (facile/moyen/difficile ou un mix)

Les missions utilisent les **données existantes** - aucun nouveau suivi
n'est requis au-delà du tableau `UserMission`.

---

## Types de missions

Les missions sont tirées d'un catalogue de 22 modèles dans 5 catégories :

| Catégorie | Exemples |
|-----------|---------|
| Sessions | « Compléter 1 session » |
| Leçons | « Terminer 2 leçons de contenu » |
| Révisions | « Réviser 10 éléments SRS » |
| Séries | « Maintenir votre série aujourd'hui » |
| Maîtrise | « Maîtriser 3 éléments » |

---

## Récompenses

Chaque mission accomplie accorde un bonus de XP une seule fois. Les
missions ne peuvent pas être gagnées plusieurs fois par jour.

L'accomplissement de toutes les missions quotidiennes déclenche une
célébration « toutes les missions accomplies » avec confettis et son.

---

## Configuration

Dans **Paramètres → Apprentissage → Missions**, vous pouvez :

- **Activer/désactiver** les missions
- **Nombre de missions** par jour (1-3)
- **Difficulté** : facile uniquement, moyen uniquement, difficile uniquement,
  ou mix
- **Réinitialiser** les missions du jour (les régénère avec de nouveaux
  objectifs)

---

## Expiration et joker de série

Les missions non accomplies **expirent à minuit** sans pénalité. Il n'y a
pas de pénalité pour les missions manquées - elles disparaissent simplement
le lendemain.

Si vous êtes en série et que vous manquez un jour entier d'activité,
le **joker de série** peut protéger automatiquement votre série (s'il reste
des gels disponibles ce mois-ci).

---

## Missions quotidiennes vs. progression à long terme

Les missions sont des **objectifs quotidiens**, pas des jalons à long terme.
Pour la progression à long terme, consultez la galerie des badges
(**Paramètres → Gamification → Galerie des badges**) qui affiche tous les
badges et leurs critères.
