# Bilan de fin de set

Auparavant, terminer chaque leçon d'un set se soldait par une carte
trophée - "les N leçons terminées" - et rien d'autre, alors que
l'appli enregistre déjà, par exercice, le nombre d'erreurs, la série,
l'indicateur de maîtrise et votre propre réponse erronée. Le **bilan
de fin de set** est l'image manquante : chaque erreur du set que vous
venez de terminer, au même endroit.

Accessible depuis les suggestions **Étape suivante** à la fin de la
dernière leçon d'un set, ou depuis la page du set elle-même.

---

## Ce qu'il affiche

- **Totaux** - erreurs et temps passé sur l'ensemble du set, pas
  seulement la dernière leçon jouée.
- **Par leçon** - quelles leçons du set ont produit le plus d'erreurs.
- **Par type d'exercice** - si un type précis (association, texte à
  trous, texte libre, ...) concentre les erreurs.
- **Points faibles** - les éléments individuels que vous ratez sans
  cesse, chacun affichant votre dernière réponse erronée à côté de la
  bonne, pour voir exactement quoi corriger, pas seulement qu'il faut
  corriger quelque chose.

---

## Comment ça marche

La page est en lecture seule et indépendante du stockage : elle lit
les mêmes lignes que vos sessions de révision écrivent déjà (nombre
d'erreurs, indicateurs de maîtrise) et les fait passer par une seule
étape d'agrégation, les chiffres correspondent donc exactement à ce
que la révision SRS et le parcours d'apprentissage enregistrent déjà
- pas de comptabilité séparée qui pourrait diverger.
