# Μια μαθησιακή συνεδρία

Μια συνεδρία είναι μια εστιασμένη συνομιλία με την ΤΝ μέσω του κύκλου
μάθησης επτά βημάτων. Οι συνεδρίες είναι σύντομες - 15-45 λεπτά είναι
τυπικό. Το κουμπί "Έναρξη συνεδρίας" του Ταμπλό δημιουργεί μια νέα·
η εφαρμογή επιλέγει τη μέθοδο μάθησης (η κυρίαρχή σου από την
αξιολόγηση) και το αρχικό βήμα του κύκλου (συνήθως 1 = Εισαγωγή).

## Τα επτά βήματα

| # | Βήμα | Τι συμβαίνει |
|---|---|---|
| 1 | Εισαγωγή | Η ΤΝ παρουσιάζει νέο υλικό στο στυλ της ενεργής μεθόδου |
| 2 | Απόπειρα | Εφαρμόζεις αυτά που μόλις έμαθες - η ΤΝ θέτει μια εργασία |
| 3 | Λάθος | Εμφανίζεται ένα λάθος· η ΤΝ το επισημαίνει με ακρίβεια |
| 4 | Ανατροφοδότηση | Η ΤΝ εξηγεί τη διόρθωση σε βάθος |
| 5 | Προσαρμογή | Προσαρμόζεις την προσέγγισή σου· η ΤΝ μπορεί να αναδιατυπώσει |
| 6 | Επανάληψη | Μια φρέσκια εργασία που εξασκεί την ίδια έννοια |
| 7 | Ενσωμάτωση | Η ΤΝ συνδέει το σημερινό υλικό με ευρύτερο πλαίσιο |

Ο κύκλος είναι ένα *πλαίσιο*, όχι κυλιόμενη ταινία. Τα βήματα
μπορούν να επαναληφθούν, να παραλειφθούν προς τα εμπρός ή ακόμα και
να επιστρέψουν πίσω όταν η τελευταία σου σειρά δείχνει σύγχυση. Η
ΤΝ κρίνει ανά ανταλλαγή και η μπάρα προόδου της εφαρμογής
ενημερώνεται αναλόγως.

[Ο κύκλος σε λεπτομέρεια](../concept/seven-steps.md)

## Πώς η ΤΝ σε καθοδηγεί

Κάθε μήνυμα που στέλνεις ενεργοποιεί έως τρεις κλήσεις ΤΝ:

1. **Η μαθησιακή απάντηση** - ρέει token-by-token μέσω SSE.
   Βλέπεις τον inline δρομέα (▍) ενώ ο βοηθός σκέφτεται· τα
   tokens προσγειώνονται στη φούσκα καθώς φτάνουν (χωρίς
   placeholder "Σκέφτομαι..."). Η προτροπή συστήματος συντίθεται
   από ένα πίνακα 42 κελιών (6 μέθοδοι × 7 βήματα), οπότε μια
   παραγωγική Εισαγωγή νιώθει πολύ διαφορετική από μια πλαισιακή
   Επανάληψη.
2. **Ο αξιολογητής βήματος** - μια δεύτερη κλήση ΤΝ διαβάζει
   την ανταλλαγή και αποφασίζει αν είσαι έτοιμος να προχωρήσεις.
   Εκπέμπει `advance`, `confidence`, `reason`, `suggested_step`.
   Η εφαρμογή εφαρμόζει την πρόταση όταν confidence ≥ 0.6.
3. **Ο αξιολογητής μετάβασης θέματος** (μόνο στο βήμα 7) - μια
   τρίτη κλήση ΤΝ αποφασίζει αν το θέμα έχει ενσωματωθεί. Αν ναι
   ΚΑΙ `continue_recommended`, ένας νέος κύκλος ξεκινά αυτόματα
   με φρέσκο υποθέμα (auto-loop, μέγ. 5 κύκλοι ανά συνεδρία).

Η ετυμηγορία εμφανίζεται διακριτικά πάνω από τη συνομιλία ως
ειδοποίηση "Βήμα μετακινήθηκε από X σε Y γιατί…" όταν πράγματι
ισχύει. Οι κάρτες μετάβασης κύκλου αποδίδονται ως κάρτες με
διακεκομμένα περιγράμματα "Κύκλος N" στο ιστορικό συνομιλίας.

**Φωνή ενεργό/ανενεργό** - ένα κουμπί TTS (▶) δίπλα σε κάθε
απάντηση ΤΝ τη διαβάζει δυνατά· ένα κουμπί μικροφώνου (🎤) στην
είσοδο σου επιτρέπει να υπαγορεύεις· τα ενδιάμεσα αντίγραφα
συμπληρώνουν την περιοχή κειμένου ώστε να μπορείς να ελέγξεις
πριν αποστείλεις. Και τα δύο βασίζονται στο Web Speech API·
εναλλαγή στις Ρυθμίσεις → Φωνή.

## Δείκτης προόδου κύκλου

Στην κορυφή της σελίδας Συνεδρίας βρίσκεται μια λωρίδα προόδου
7 κύκλων. Το τρέχον βήμα είναι γεμισμένο με το accent χρώμα του
έργου σου· τα περασμένα βήματα είναι γεμισμένα πιο ανοιχτά· τα
μελλοντικά βήματα είναι κενά. Όταν ο αξιολογητής σε μετακινεί
μπροστά (ή πίσω!), η λωρίδα κινείται για να κάνει ορατή τη
μετάβαση.

Σε κινητά (≤768px) η λωρίδα γίνεται μια ενιαία οριζόντια σειρά
μικρών κύκλων για εξοικονόμηση κατακόρυφου χώρου.

## Συστάσεις αλλαγής μεθόδου

Μερικές φορές η ενεργή μέθοδος απλώς δεν αποδίδει. Μετά από τρεις
συνεδρίες όπου η βαθμολογία "κατανόησης" δεν αυξάνεται και η
βαθμολογία "στρες" παραμένει υψηλή, η εφαρμογή εμφανίζει ένα
**MethodSwitchBanner**: "Θέλεις να δοκιμάσεις [άλλη μέθοδο] για
την επόμενη συνεδρία;". Αποδέξου και η επόμενη συνεδρία ξεκινά με
τη νέα μέθοδο ενεργή.

Η σύσταση διαβάζει το προφίλ σου και προτιμά τη δεύτερη ισχυρότερη
μέθοδό σου που δεν έχεις χρησιμοποιήσει πρόσφατα. Μπορείς να
απορρίψεις το banner· θα επανέλθει αν το πρότυπο στασιμότητας
συνεχιστεί.

Και οι δύο λειτουργίες αποθήκευσης (Διακομιστής + Τοπική)
υποστηρίζουν συστάσεις αλλαγής μεθόδου.

## Αξιολόγηση + τερματισμός συνεδρίας

Η σελίδα Συνεδρίας έχει κουμπί "Τερματισμός συνεδρίας". Πριν
κλείσει η συνεδρία συμπληρώνεις μια σύντομη αξιολόγηση:
κατανόηση, στρες και καταλληλότητα μεθόδου σε κλίμακα 1-5, συν
προαιρετική **σημείωση μορφοποιημένου κειμένου** (TipTap: έντονα,
πλάγια, λίστες, μπλοκ κώδικα με επισήμανση σύνταξης, συνδέσμους).
Η σημείωση είναι δική σου - η ΤΝ δεν τη διαβάζει.

Οι αξιολογήσεις + η περίληψη πολυκύκλιου ταξιδιού μετατρέπονται
σε μια σειρά `ProgressCommit` - το στιγμιότυπο τύπου Git μιας
συνεδρίας. Η ολοκλήρωση συνεδρίας απονέμει XP (βάση 50 ×
πολλαπλασιαστής σερί, συν μπόνους ανά κύκλο), ελέγχει για
πρόσφατα κερδισμένα σήματα και ενημερώνει το σερί σου. Δες
[Πρόοδος](progress.md), [Ταμπλό](dashboard.md) και την
[έννοια Παρακολούθησης](../concept/tracking.md).
