# Ημερήσιες Αποστολές

Οι ημερήσιες αποστολές σου δίνουν μερικούς συγκεκριμένους, εφικτούς
στόχους για κάθε μέρα - έναν λόγο να ανοίξεις την εφαρμογή και μια
ήπια ώθηση προς τη διαμόρφωση μαθησιακής συνήθειας. Είναι **προαιρετικές**:
η εφαρμογή λειτουργεί ακριβώς το ίδιο χωρίς αυτές, και δεν υπάρχει
**καμία ποινή** για μια χαμένη μέρα. Το επόμενο πρωί φέρνει απλώς ένα
φρέσκο σύνολο.

## Πώς λειτουργούν

- Λαμβάνεις έως **3 αποστολές** ανά ημέρα, εμφανιζόμενες στο Ταμπλό
  μεταξύ σερί και σημάτων σου.
- Οι αποστολές είναι **εφικτές** για οποιονδήποτε χρησιμοποιεί την
  εφαρμογή 15-30 λεπτά, και η δυσκολία **προσαρμόζεται** σε σένα:
  ένας νέος μαθητής λαμβάνει ήπιους στόχους "μάθησης" + "εξερεύνησης"·
  μόλις έχεις κάποιο ιστορικό σφαλμάτων, ενσωματώνονται αποστολές
  "επανάληψης" και "κατάκτησης".
- Είναι **ντετερμινιστικές**: η ίδια ημέρα δείχνει τις ίδιες αποστολές
  σε όλες τις συσκευές σου, και η ίδια αποστολή δεν δίνεται ποτέ δύο
  συνεχόμενες μέρες.
- Η πρόοδος ενημερώνεται αυτόματα από αυτά που κάνεις ήδη - ολοκλήρωση
  μαθημάτων, επανάληψη στοιχείων, κατάκτηση λέξεων. Όταν ολοκληρωθεί
  μια αποστολή κερδίζεις το μπόνους **XP** της.
- Στα τοπικά μεσάνυχτα, οι ημιτελείς αποστολές λήγουν ήσυχα και
  ορίζονται νέες.

## Ρύθμιση αποστολών

Οι **Ρυθμίσεις > Μάθηση > Ημερήσιες Αποστολές** σου επιτρέπουν να:

- ενεργοποιήσεις/απενεργοποιήσεις ημερήσιες αποστολές (ενεργό εξ
  ορισμού),
- επιλέξεις **πόσες** ανά ημέρα (1-3),
- επιλέξεις **μίγμα δυσκολίας** - Ισορροπημένο (εξ ορισμού), Εύκολο
  ή Απαιτητικό,
- **επαναφέρεις** τις αποστολές σήμερα για φρέσκο σύνολο.

## Joker σερί

Αν διατηρείς ένα σερί αποστολών και μετά χάσεις μια μέρα, μια
παύση παγώματος σερί (που κερδίζεται με τον καιρό) μπορεί να
γεφυρώσει αυτό το χάσμα ώστε το σερί σου να επιβιώσει. Μια δεύτερη
χαμένη μέρα το τερματίζει - αλλά, και πάλι, δεν υπάρχει ποτέ ποινή,
απλώς φρέσκο ξεκίνημα.
