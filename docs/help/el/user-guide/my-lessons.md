# Τα μαθήματά μου: δημιουργία, αποθήκευση, κοινή χρήση

Τα **μαθήματά μου** είναι μαθήματα που δημιουργείς *εσύ* - μετατρεπόμενα
στην ίδια offline, αναπαραγώγιμη μορφή με τα λαμβανόμενα σύνολα
περιεχομένου. Μπορείς να φτιάξεις ένα μάθημα από αναλυμένη συνομιλία,
να αποθηκεύσεις ένα καλό προσαρμοστικό μάθημα για επανάληψη, να εξάγεις
ένα μάθημα για κοινή χρήση με κάποιον άλλο, και να εισάγεις μαθήματα
που έχουν μοιραστεί άλλοι. Όλα λειτουργούν offline· τίποτα δεν ανεβαίνει
σε διακομιστή.

Θα βρεις τα μαθήματά μου στην κορυφή του **Set Browser** (`/content`),
πάνω από τα λαμβανόμενα σύνολα.

---

## Δημιούργησε μάθημα από ανάλυση συνομιλίας

1. Εισάγαγε μια συνομιλία και **Ανάλυσέ** την (δες *Εισαγωγή*).
2. Στο αποτέλεσμα ανάλυσης, κάνε κλικ **Αποθήκευση ως Offline Μάθημα**.
3. Μια προεπισκόπηση δείχνει τη δομή του μαθήματος - πόσες ασκήσεις και
   θεωρητικά βήματα, ο εκτιμώμενος χρόνος. Προσάρμοσε τον τίτλο αν
   θέλεις.
4. Κάνε κλικ **Αποθήκευση**. Το μάθημα εμφανίζεται στα **Μαθήματά μου**.

Το μάθημα χτίζεται από αυτά που βρήκε η ανάλυση:

- **Θεωρία** από το θέμα, περίληψη, υποθέματα, δυνατά σημεία και
  αδυναμίες σου, πρότυπα συνηθισμένων λαθών, και κάθε προτεινόμενο
  πρόγραμμα σπουδών.
- **Ασκήσεις** από το εξαγόμενο λεξιλόγιο - αντιστοίχιση και πληκτρολόγηση-
  μετάφρασης από κάθε λέξη, συν συμπλήρωση-κενού και ασκήσεις σειράς-
  λέξεων από τυχόν παραδείγματα προτάσεων.

Όσο πλουσιότερη η ανάλυση (ειδικά λεξιλόγιο με παραδείγματα προτάσεων),
τόσο πλουσιότερο το μάθημα. Αν δεν υπάρχουν αρκετά λεξιλογικά στοιχεία,
θα λάβεις ένα **μόνο-θεωρητικό οδηγό μελέτης** και υπόδειξη να εισαγάγεις
μεγαλύτερη συνομιλία για περισσότερο υλικό εξάσκησης.

Τα δημιουργηθέντα μαθήματα παίζουν στον κανονικό viewer μαθήματος με
πλήρη βαθμολόγηση, ακριβώς όπως ένα λαμβανόμενο μάθημα.

## Παίξε, επεξεργάσου, διέγραψε

Κάθε μάθημά μου έχει:

- **Αναπαραγωγή** - άνοιξέ το στον viewer μαθήματος.
- **Επεξεργασία** - ανοίγει τον οδηγό **Δημιουργία μαθήματος
  προσυμπληρωμένο** με τα μεταδεδομένα, τις κάρτες και τις ασκήσεις
  του μαθήματος. Αν ένα δικό σου σύνολο περιέχει **περισσότερα
  μαθήματα**, ένας **επιλογέας μαθήματος** ρωτά πρώτα ποιο θέλεις να
  επεξεργαστείς. Τα μαθήματα από κείμενο βιβλίου ανοίγουν απευθείας
  τον **επεξεργαστή ασκήσεων**· τα καταχωρημένα στοιχεία βιβλίου
  διατηρούνται. Κατά την αποθήκευση διαλέγεις: **Αποθήκευση αλλαγών**
  (αντικαθιστά το ίδιο μάθημα - η πρόοδος μάθησης διατηρείται για τις
  αμετάβλητες κάρτες, οι αλλαγμένες ξεκινούν από την αρχή) ή
  **Αποθήκευση ως αντίγραφο** (δημιουργεί νέο μάθημα, το πρωτότυπο
  μένει ανέγγιχτο). Τα μαθήματα που βασίζονται σε ανάλυση συνεχίζουν
  να ανοίγουν την υποκείμενη ανάλυση συνομιλίας. Τα ξένα (ληφθέντα)
  μαθήματα παραμένουν μόνο για ανάγνωση.
- **Διαγραφή** - αφαίρεσέ το (με επιβεβαίωση).

## Αποθήκευσε ένα προσαρμοστικό μάθημα

Όταν τελειώνεις ένα **προσαρμοστικό μάθημα**, εμφανίζεται κουμπί
**Αποθήκευση αυτού του μαθήματος;** στη σύνοψη. Η αποθήκευση κρατά
ένα στιγμιότυπο που μπορείς να επαναλάβεις αργότερα από τα μαθήματά
μου - χρήσιμο όταν μια προσαρμοστική συνεδρία αποδείχθηκε ιδιαίτερα
χρήσιμη. Το στιγμιότυπο παραμένει αναπαραγώγιμο ακόμα και αν ο
προσαρμοστικός γεννήτορας αλλάξει σε μεταγενέστερη έκδοση.

## Εξαγωγή και κοινή χρήση

Κάθε μάθημά μου μπορεί να κοινοποιηθεί. Η εξαγωγή δεν χρειάζεται
λογαριασμό· το pull request για την κοινότητα χρειάζεται λογαριασμό
GitHub. Ένα token GitHub επιταχύνει το pull request και χρειάζεται για να
κοινοποιήσεις ένα ολόκληρο σύνολο ως δικό σου αποθετήριο:

- **Εξαγωγή** - κατέβασε το μάθημα ως μεμονωμένο αρχείο `.json`.
- **Εξαγωγή ως σύνολο** - κατέβασε ένα `.zip` συνόλου περιεχομένου
  (manifest + μαθήματα).
- **Κοινοποίηση στην κοινότητα** - ανοίγει ένα **pull request** στο
  επίσημο αποθετήριο περιεχομένου. Το JSON του μαθήματος μπαίνει στη
  σωστή διαδρομή του δέντρου περιεχομένου, και ο έλεγχος του
  αποθετηρίου τρέχει αυτόματα. Το pull request είναι δημόσια ορατό στο
  GitHub από τη στιγμή που δημιουργείται. Ένας συντηρητής το ελέγχει·
  αν το αποδεχτεί, όλοι μπορούν να κατεβάσουν το μάθημα. Το pull request
  δημιουργείται με έναν από δύο τρόπους:
    - **Χωρίς token** - ένα μεμονωμένο μάθημα ανοίγει τον επεξεργαστή
      αρχείων του GitHub στη σωστή διαδρομή, με τον τίτλο και την
      περιγραφή του PR ήδη συμπληρωμένα. Σε ένα μικρό μάθημα, το
      περιεχόμενό του βρίσκεται ήδη μέσα στη διεύθυνση του GitHub που
      ανοίγει· σε ένα μεγαλύτερο, η εφαρμογή κατεβάζει πρώτα το αρχείο
      και εσύ το επικολλάς στον επεξεργαστή. Ένα σύνολο με περισσότερα
      από ένα μαθήματα κατεβάζει τα αρχεία και ανοίγει τη σελίδα
      μεταφόρτωσης του GitHub, όπου εσύ τα σύρεις. Το GitHub δημιουργεί
      το fork και το pull request μόλις εσύ επιβεβαιώσεις εκεί.
    - **Με token GitHub** (Ρυθμίσεις > Ενσωματώσεις, δες
      [Ρυθμίσεις](settings.md)) - κοινοποιείς ένα μεμονωμένο μάθημα
      χωρίς να βγεις από την εφαρμογή: η εφαρμογή κάνει fork το
      αποθετήριο, κάνει commit το μάθημα, ανοίγει το pull request και
      μετά σου δείχνει τον σύνδεσμο. Ένα σύνολο με περισσότερα από ένα
      μαθήματα ακολουθεί και πάλι τον τρόπο χωρίς token. Αν το GitHub
      απορρίψει το token, το μήνυμα σε παραπέμπει στις Ρυθμίσεις >
      Ενσωματώσεις.
- **Κοινή χρήση ως αποθετήριο** - στέλνει ολόκληρο το σύνολο, σε μορφή
  αποθετηρίου περιεχομένου, σε ένα δικό σου αποθετήριο GitHub (που
  δημιουργείται αν δεν υπάρχει ακόμα) με ένα μόνο commit. Επιλέγεις το
  αποθετήριο (`owner/name`), ιδιωτικό ή δημόσιο, και τον κλάδο
  (branch). Πρώτα τρέχει ένας έλεγχος ποιότητας: αν βρει προβλήματα που
  θα απέρριπταν οι έλεγχοι ενός αποθετηρίου περιεχομένου, τα απαριθμεί
  και το κουμπί γίνεται **Εξαγωγή ούτως ή άλλως**. Η κοινή χρήση ως
  αποθετήριο χρειάζεται token GitHub και υπάρχει μόνο στην έκδοση
  browser της εφαρμογής· αλλιώς το κουμπί μένει ορατό αλλά
  απενεργοποιημένο, με τον λόγο ως tooltip. Μετά μπορείς να συνδέσεις
  το αποθετήριο που στάλθηκε ως πηγή περιεχομένου (δες
  [Πολλαπλά Content-Repositories](../features/content-repos.md)).

Τα εξαγόμενα αρχεία περιέχουν μόνο το περιεχόμενο μαθήματος - χωρίς
πρόοδο, χωρίς ιστορικό σφαλμάτων, τίποτα προσωπικό.

## Εισαγωγή μαθήματος

Κάνε κλικ **Εισαγωγή Μαθήματος**, επέλεξε ένα μάθημα `.json` ή σύνολο
`.zip`, και η εφαρμογή το επικυρώνει και δείχνει προεπισκόπηση.
Επιβεβαίωσε για προσθήκη στα μαθήματά μου. Αν το αρχείο είναι άκυρο
θα δεις συγκεκριμένο λόγο αντί για σπασμένη εισαγωγή.

Αυτό κλείνει τον βρόχο: ένας μαθητής εξάγει μάθημα, ένας άλλος το
εισάγει και το παίζει - εντελώς offline.
