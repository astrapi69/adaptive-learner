# Το Ταμπλό

Το Ταμπλό είναι η βάση σου. Συγκεντρώνει πολλαπλές τομές δεδομένων
σε μία προβολή: ποιος είσαι ως μαθητής (προφίλ + XP + σήματα), πώς
τα πας τώρα (χάρτης θερμότητας σερί + μετρητής συνεδριών), τι έκανες
(πρόσφατες συνεδρίες + κατανομή μεθόδων), και τι να κάνεις στη
συνέχεια (εργαλεία + αραιωμένες συστάσεις).

Στην κορυφή βρίσκεται η **γραμμή φίλτρων Θεμάτων + Ετικετών** - επέλεξε
ένα θέμα (π.χ. Γλώσσες → Ισπανικά) ή μια ετικέτα για να περιορίσεις
κάθε widget παρακάτω στα έργα με αυτή την κατηγοριοποίηση. Τα φίλτρα
μοιράζονται μέσω παραμέτρων URL.

## Γράφημα ραντάρ προφίλ

Το γράφημα ραντάρ στην κορυφή δείχνει το προφίλ 6 μεθόδων σου από
την αξιολόγηση. Ίδιο σχήμα με το γράφημα μετά την αξιολόγηση στη
σελίδα Αξιολόγησης. Η κυρίαρχη μέθοδος επισημαίνεται κάτω από το
γράφημα με έγχρωμο σήμα.

Αν δεν έχεις κάνει ακόμα την αξιολόγηση, το ραντάρ δείχνει σχήμα
με μηδενικές τιμές και συνδέεται με τη σελίδα Αξιολόγησης.

## XP + Σερί + Σήματα

- **Widget XP** - τρέχον επίπεδο + συνολικό XP + μπάρα προόδου στο
  επόμενο επίπεδο. Τα επίπεδα ακολουθούν εκθετική καμπύλη
  (`threshold(n) = 50 * n * (n - 1)`)· τα επίπεδα 1-5 βρίσκονται
  στα 0 / 100 / 300 / 600 / 1000 XP. Βάση 50 XP ανά τερματισμένη
  συνεδρία, συν μπόνους ανά κύκλο + μπόνους πρώτης μεθόδου +
  πολλαπλασιαστής σερί (έως 2,75× σε σερί 7 ημερών).
- **Χάρτης θερμότητας σερί** (στυλ GitHub) - 365 ημέρες
  δραστηριότητας σε εβδομαδιαίες στήλες Δευ..Κυρ. Πέντε χρώματα
  επιπέδου μέσω `color-mix` στο `var(--accent)`. Εναλλαγή
  λειτουργίας σαββατοκύριακου στις Ρυθμίσεις για παράλειψη
  κενών Σαβ/Κυρ· αποθεματικό παγώματος (1 ανά 7 ημέρες σερί,
  μέγ. 3) λειτουργεί ως παύση-χωρίς-επαναφορά για χαμένη
  καθημερινή.
- **Βιτρίνα σημάτων** - 24 σήματα σε 5 κατηγορίες
  (getting_started 3, consistency 4, method_explorer 7, depth 7,
  polyglot 3). Τα κερδισμένα ανάβουν έγχρωμα + με ημερομηνία·
  τα κλειδωμένα παραμένουν γκρι.
- **Μετρητής συνεδριών** - πλακίδια για συνεδρίες, λεπτά, τρέχον
  σερί, μέση κατανόηση, μέσο στρες.

## Χρονοδιάγραμμα προόδου

Ένα γράφημα δύο γραμμών κάτω από το ραντάρ. Δύο μετρήσεις ανά
συνεδρία: η βαθμολογία **κατανόησης** και η βαθμολογία **στρες**,
καθεμία επανακλιμακωμένη από την είσοδο 1-5 σε άξονα 0-1.
Εμφανίζονται από προεπιλογή 5 πιο πρόσφατες συνεδρίες· ταξινομημένες
παλαιότερο-αριστερά προς νεότερο-δεξιά.

Τι να αναζητάς: μια ανοδική γραμμή κατανόησης είναι ακριβώς αυτό
που θέλεις. Μια επίπεδη γραμμή κατανόησης με αυξανόμενο στρες είναι
το ακριβές σήμα που παρακολουθεί η ευρετική αλλαγής μεθόδου· θα
σε σπρώξει να αλλάξεις μέθοδο.

## Κατανομή μεθόδων

Ένα οριζόντιο γράφημα ράβδων που δείχνει ποιες από τις 6 μεθόδους
έχεις χρησιμοποιεί. Το μήκος κάθε ράβδου είναι το ποσοστό των
συνεδριών που χρησιμοποίησαν αυτή τη μέθοδο. Οι ράβδοι ταξινομούνται
κατά φθίνουσα σειρά αριθμού· οι ισοβαθμίες διατηρούν την κανονική
σειρά μεθόδου.

Ο σκοπός αυτού του γραφήματος δεν είναι ο ανταγωνισμός με τον εαυτό
σου· είναι ένας καθρέφτης. Κάποιοι μαθητές τρέχουν 80% παραγωγικές
συνεδρίες και αυτό είναι εντάξει. Άλλοι ανακαλύπτουν ότι ποτέ δεν
χρησιμοποίησαν πραγματικά την πλαισιακή μέθοδο και θέλουν να τη
δοκιμάσουν.

## Πρόσφατες συνεδρίες

Οι 5 τελευταίες συνεδρίες ως συμπαγής λίστα: σήμα μεθόδου,
βαθμολογία κατανόησης της συνεδρίας (ως μικρή μπάρα) και η διάρκεια
σε λεπτά. Κάνοντας κλικ σε μια γραμμή μεταβαίνεις στη σελίδα
Προόδου φιλτραρισμένη σε αυτή τη συνεδρία - χρήσιμο όταν μια
συγκεκριμένη συνεδρία ένιωσε τέλεια ή τρομερή και θέλεις να δεις
τι συνέβη.

## Συστάσεις εργαλείων + αραιωμένης επανάληψης

Δύο κάρτες συστάσεων στο κάτω μέρος:

- **Εργαλεία** - κατατεταγμένα εξωτερικά εργαλεία προσαρμοσμένα στο
  προφίλ σου. Anki + NotebookLM είναι πλέον πρώτης κατηγορίας με
  αποστελλόμενες εξαγωγές (χωρίς χειροκίνητη μεταφορά). Κάθε ένα
  δείχνει μια μονή γραμμή "γιατί" στη γλώσσα UI σου.
- **Αραιωμένη επανάληψη** - σύντομες κάρτες δράσης "κάνε αυτό
  μετά" που καθοδηγούνται από ποιες μεθόδους δεν έχεις εξασκήσει
  πρόσφατα. Μια πολιτική πέντε ζωνών (πρώτη / ανανέωση / επανεξέταση
  / εξάσκηση / συντήρηση) καθοδηγεί τις προτάσεις διαστήματος.

Και οι δύο λίστες ενημερώνονται σε κάθε φόρτωση Ταμπλό - είναι
φθηνές στη υπολογιστική και αντικατοπτρίζουν την τελευταία συνεδρία.

## Έναρξη συνεδρίας

Το μεγάλο κύριο κουμπί στην κορυφή: "Έναρξη συνεδρίας". Ανοίγει
τη σελίδα Συνεδρίας με δημιουργημένη νέα σειρά συνεδρίας, την
ενεργή μέθοδο επιλεγμένη εκ των προτέρων από το προφίλ σου και τον
κύκλο στο βήμα 1.
