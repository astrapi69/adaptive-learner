# Συχνές Ερωτήσεις

## Είναι ασφαλή τα δεδομένα μου;

Στην **Τοπική λειτουργία** όλα τα δεδομένα σου βρίσκονται στο
IndexedDB της δικής σου συσκευής. Χωρίς backend, χωρίς υπηρεσία
τρίτων. Το κλείσιμο της καρτέλας browser δεν τα διαγράφει· η
εκκαθάριση δεδομένων ιστότοπου το κάνει. Αν μοιράζεσαι τη συσκευή,
όποιος έχει πρόσβαση σε αυτό το προφίλ browser μπορεί να τα διαβάσει.

Στη **Λειτουργία Διακομιστή** τα δεδομένα βρίσκονται στη βάση SQLite
που διαχειρίζεται το FastAPI backend. Τα API keys κρυπτογραφούνται
κατά την αποθήκευση με Fernet χρησιμοποιώντας ένα μυστικό που ορίζεις
μέσω της μεταβλητής περιβάλλοντος `ADAPTIVE_LEARNER_SECRET_KEY` ή μέσω
`secret_key:` στο `~/.config/adaptive-learner/secrets.yaml`.

Καμία λειτουργία δεν στέλνει τηλεμετρία, αναλυτικά ή τα μηνύματά σου
σε κανένα τρίτο μέρος εκτός από τον πάροχο ΤΝ που έχεις επιλέξει —
και αυτός βλέπει μόνο το περιεχόμενο μηνυμάτων που θα περίμενες
(προτροπή συστήματος + κείμενό σου + προηγούμενες απαντήσεις της ΤΝ
στη συνεδρία).

## Χρειάζομαι API key;

Ναι για συνεδρίες ΤΝ. Η εφαρμογή χρησιμοποιεί **δικό σου κλειδί** για
και τους τρεις υποστηριζόμενους παρόχους: Anthropic Claude, OpenAI GPT,
Google Gemini. Τα όρια δωρεάν πλάνου είναι συνήθως αρκετά για να
ξεκινήσεις.

Τρία μέρη για το κλειδί (υψηλότερη προτεραιότητα κερδίζει): μεταβλητή
περιβάλλοντος `ADAPTIVE_LEARNER_<PROVIDER>_API_KEY`, το πεδίο
`ai.<provider>.api_key` στο `~/.config/adaptive-learner/secrets.yaml`
ή το UI Ρυθμίσεων. Το UI δείχνει την πηγή ανά πάροχο ώστε να ξέρεις
πάντα από πού προήλθε το κλειδί σου.

Μπορείς να περιηγηθείς στο Πρόγραμμα Σπουδών, να κάνεις την Αξιολόγηση,
να δεις το Ταμπλό σου και ακόμα να εκτελέσεις την Εισαγωγή ιστορικού
συνομιλίας χωρίς API key. Η σελίδα Συνεδρίας + το βήμα ανάλυσης + τα
χαρακτηριστικά εξαγωγής ΤΝ είναι αυτά που χρειάζονται κλειδί.

## Μπορώ να το χρησιμοποιώ offline;

Εν μέρει. Ο service worker του PWA κρατά στη cache τα στατικά στοιχεία
(HTML, JS, CSS, εικονίδια) ώστε η εφαρμογή να εκκινεί χωρίς διαδίκτυο.
Παλαιότερες συνεδρίες και δεδομένα Ταμπλό φορτώνουν επίσης από τοπική
αποθήκευση, οπότε η ανάγνωση παλαιού υλικού λειτουργεί κανονικά.

**Οι ζωντανές συνεδρίες εξακολουθούν να χρειάζονται διαδίκτυο** επειδή
ο πάροχος ΤΝ βρίσκεται εκτός του browser σου. Η σελίδα Συνεδρίας
ανιχνεύει "offline" και εμφανίζει σαφές μήνυμα inline αντί να αποτυγχάνει
σιωπηλά.

## Τι σημαίνει η αλλαγή μεθόδου;

Όταν τρεις συνεχόμενες συνεδρίες δείχνουν στάσιμη κατανόηση ΚΑΙ υψηλό
στρες, η εφαρμογή εμφανίζει κορδέλα: "Θέλεις να δοκιμάσεις [άλλη μέθοδο]
για την επόμενη συνεδρία;". Η σύσταση προτιμά τη δεύτερη ισχυρότερη
μέθοδό σου από την αξιολόγηση που δεν έχεις χρησιμοποιήσει πρόσφατα.

Είναι *πρόταση*, όχι εντολή. Μπορείς να απορρίψεις την κορδέλα και να
συνεχίσεις με την τρέχουσα μέθοδό σου· η κορδέλα επανεμφανίζεται αν το
πρότυπο στασιμότητας συνεχιστεί. Οι αλλαγές μεθόδου καταγράφονται στον
πίνακα `method_switches` και εμφανίζονται στην κατανομή της σελίδας
Προόδου.

## Τι είναι το auto-loop;

Όταν μια συνεδρία φτάνει στο βήμα 7 (Ενσωμάτωση) και ο αξιολογητής
μετάβασης θέματος κρίνει το θέμα ενσωματωμένο ΚΑΙ συνιστά συνέχεια,
ξεκινά αυτόματα ένας νέος κύκλος με νέο υποθέμα. Μέχρι 5 κύκλοι ανά
συνεδρία (προστασία από εκτροχιασμό). Το ιστορικό συνομιλίας αποδίδει
κάρτες "Κύκλος N" με διακεκομμένα περιγράμματα σε κάθε μετάβαση.
Το παράθυρο βαθμολόγησης τέλους συνεδρίας συνοψίζει το ταξίδι
πολλαπλών κύκλων όταν `cycle_count > 1`.

## Μπορώ να εξάγω τα δεδομένα μου;

Ναι. Τρεις διαδρομές εξαγωγής:

- **Αντίγραφο ασφαλείας**: Ρυθμίσεις → Αντίγραφο ασφαλείας → Δημιουργία
  αντιγράφου. Λήψη χρονοσφραγισμένου JSON με κάθε γραμμή από τον λογαριασμό
  σου. Τα API keys αφαιρούνται. Λειτουργεί και στις δύο λειτουργίες
  αποθήκευσης.
- **Αναφορές Προόδου / Συνεδρίας / Προγράμματος**: Ρυθμίσεις → Εξαγωγή.
  Markdown + PDF (εκτύπωση-σε-PDF browser).
- **Anki .apkg**: ανασκόπησε τις ΤΝ-εξαγόμενες κάρτες flash στη σελίδα
  `/anki`, αποδέξου αυτές που σου αρέσουν, κάνε κλικ Εξαγωγή. Το αρχείο
  λειτουργεί απευθείας στο Anki desktop.
- **NotebookLM ZIP**: από τη σελίδα Προόδου, κατέβασε δομημένο ZIP
  (περίληψη + λεξιλόγιο + κανόνες + σφάλματα + κάρτες flash + συνεδρίες)
  μορφοποιημένο για ανέβασμα πηγής στο NotebookLM.

## Τι είναι η λειτουργία φωνής;

Τρεις ενσωματώσεις Web Speech API (από v1.18.0):

- **Text-to-Speech** σε απαντήσεις ΤΝ + αποτελέσματα Αξιολόγησης —
  ένα κουμπί ▶ δίπλα σε κάθε τις διαβάζει δυνατά, ταιριαστό με τη γλώσσα.
- **Speech-to-Text** στην είσοδο Συνεδρίας — ένα κουμπί 🎤 αποτυπώνει
  τη φωνή σου και συμπληρώνει την περιοχή κειμένου με ενδιάμεσα αντίγραφα
  πριν την αποστολή.
- **Εξάσκηση Προφοράς** για γλωσσικά έργα — επισκέψου το `/pronunciation`,
  η ΤΝ παράγει φράση στόχο, μιλάς, και μια κριτική ΤΝ βαθμολογεί
  ομοιότητα + προτείνει βελτιώσεις.

Οι εναλλαγές φωνής βρίσκονται στις Ρυθμίσεις → Φωνή. Η ενότητα κρύβεται
σε browsers που δεν υποστηρίζουν το API.

## Τι είναι η εισαγωγή ιστορικού συνομιλίας;

Η σελίδα Εισαγωγής (`/import`) δέχεται συνομιλίες επικολλημένες ή
ανεβασμένες από ChatGPT, Claude.ai (τόσο μαζική εξαγωγή JSON όσο και
εξαγωγή Markdown μεμονωμένης συνομιλίας), Gemini, και αυθαίρετο Markdown.
Ο αναλυτής εξάγει το θέμα, αδυναμίες, πρότυπα σφαλμάτων, προτεινόμενη
μέθοδο, λεξιλόγιο (για γλωσσικές συνομιλίες) και προτεινόμενο πρόγραμμα
σπουδών. Ένα κλικ εφοδιάζει ένα Πρόγραμμα Σπουδών + ξεκινά στοχευμένη
συνεδρία από την ανάλυση.

Η εξαγωγή Markdown ανά συνομιλία από το Claude.ai ήταν η περίπτωση
ελέγχου v1.19.0 — ο αναλυτής παραδίδεται με πλήρη εξαγωγή χρονοσφραγίδας
+ διατήρηση ορίων ρόλου για αυτή τη μορφή (BL-25 / BL-26 / BL-28 κλειστά
στην v1.19.1).

## Συγχρονισμός μεταξύ συσκευών;

Αμφίδρομος συγχρονισμός τοπικού δικτύου από v1.0.0. Ρυθμίσεις →
Συγχρονισμός → "Σύνδεση αυτής της συσκευής": σάρωσε τον QR code στην
οθόνη της άλλης συσκευής (πίσω κάμερα) ή επικόλλησε το URL σύνδεσης.
Μόλις συνδεθεί, τα κουμπιά push + pull ανταλλάσσουν δεδομένα· οι
συγκρούσεις επιλύονται μέσω αναλυτή AI-merge. 28 πίνακες στην επιφάνεια
συγχρονισμού από v1.19.0 (θέματα + ετικέτες + ερωτήσεις μελέτης
συμπεριλαμβανομένων).

## Πώς διαφέρει από το ChatGPT;

Το ChatGPT είναι διεπαφή συνομιλίας με ένα μοντέλο. Το Adaptive Learner
είναι *δομημένο σύστημα μάθησης* που χρησιμοποιεί ΤΝ "κάτω από την κουκούλα"
αλλά προσθέτει:

1. **Πίνακα 6 μεθόδων × 7 βημάτων** από εξατομικευμένες προτροπές
   συστήματος.
2. **Αξιολόγηση βήματος ανά γύρο** — μια δεύτερη κλήση ΤΝ κρίνει ετοιμότητα
   και μπορεί να σε μετακινήσει μπρος / πίσω.
3. **Auto-loop σε νέους κύκλους** όταν ενσωματωθεί το θέμα.
4. **Προφίλ** των μαθησιακών προτιμήσεών σου από την αξιολόγηση 12
   ερωτήσεων.
5. **Μακροπρόθεσμη παρακολούθηση** — ProgressCommits, χάρτης θερμότητας
   σερί, XP, σήματα, γραφήματα χρόνου-ανά-βήμα. Το ChatGPT ξεχνά όταν
   κλείσεις την καρτέλα.
6. **Ελευθερία παρόχου** — Anthropic, OpenAI ή Gemini.
7. **Επιλογή τοπικής αποθήκευσης** — όλα στο browser σου, τίποτα
   δεν αποστέλλεται σε διακομιστή (εκτός από κλήσεις ΤΝ).

## Τι γίνεται αν η ΤΝ κάνει λάθος;

Το σύστημα αποτυγχάνει ορατά:

- **Λάθος API key**: η κλήση ΤΝ επιστρέφει σαφές μήνυμα σφάλματος,
  εμφανιζόμενο inline στη συνομιλία.
- **Πάροχος εκτός λειτουργίας**: το ίδιο — το σφάλμα αποδίδει την HTTP
  κατάσταση από το API του παρόχου.
- **Αποτυχία ανάλυσης JSON από τον αξιολογητή**: ενεργοποιείται
  ντετερμινιστική πρόοδος +1 (περιορισμένη στο βήμα 7), με καταγεγραμμένο
  `fallback_used: true` ώστε ένας μελλοντικός έλεγχος να μπορεί να
  εντοπίσει μοντέλα που δυσκολεύονται με τη μορφή.
- **Ροή streaming διακοπεί στη μέση**: η μερική απάντηση αποθηκεύεται·
  το επόμενο μήνυμα συνεχίζει από εκεί.
- **Παλιά ή περίεργη απάντηση ΤΝ**: τερμάτισε τη συνεδρία, δώσε χαμηλή
  βαθμολογία, ξεκίνα ξανά. Η ευρετική αλλαγής μεθόδου θα εμφανίσει
  διαφορετική μέθοδο αν το πρότυπο συνεχιστεί.
