# Πρόοδος

Η σελίδα Προόδου είναι η λεπτομερής προβολή των δεδομένων μάθησής σου —
ό,τι συνοψίζει το Ταμπλό, με γραφήματα και πίνακες για βαθύτερη εμβάθυνση.

## Τι βλέπεις

Τέσσερις ενότητες από πάνω προς τα κάτω:

1. **Τάσεις** — μέση κατανόηση, μέσο στρες, συνολικά λεπτά, ημέρες σερί.
   Αριθμοί που το Ταμπλό δείχνει σε συμπαγή πλακίδια γίνονται εδώ
   επισημασμένες γραμμές.
2. **Κατανομή μεθόδων** — το ίδιο οριζόντιο γράφημα ράβδων με το Ταμπλό,
   με tooltips hover που δείχνουν τον ακριβή αριθμό συνεδριών ανά μέθοδο.
3. **Σύνοψη αξιολόγησης βημάτων** — μόνο δεδομένα v0.5.0+· διαβάζει από
   τις γραμμές StepEvaluation που παράγει η διαδρομή συνεδρίας.
4. **Ιστορικό commit** — κάθε γραμμή ProgressCommit σε χρονολογική σειρά,
   νεότερη πρώτη.

## Σύνοψη αξιολόγησης βημάτων

Η αρχιτεκτονική διπλής προτροπής γράφει μία γραμμή `StepEvaluation` ανά
γύρο ΤΝ με το ετυμηγορία αξιολογητή (advance, confidence, suggested_step,
fallback_used, reason). Ο αθροιστής παρακολούθησης τα διαβάζει και παράγει
τέσσερις αξιόλογους αριθμούς:

- **Συνολικές αξιολογήσεις** — κάθε γύρος ΤΝ παράγει ακριβώς μία.
  Ένα έργο μακράς διάρκειας θα έχει εκατοντάδες.
- **Μέση εμπιστοσύνη** — σε όλες τις αξιολογήσεις. Χαμηλός μέσος
  (< 0,5) σημαίνει ότι η ΤΝ σπάνια είναι σίγουρη ότι είσαι έτοιμος
  να προχωρήσεις, που συνήθως σηματοδοτεί ότι το υλικό είναι πραγματικά
  δύσκολο για σένα. Δεν είναι κακό — είναι πληροφορία.
- **Αριθμός επαναλήψεων** — πόσο συχνά ο αξιολογητής επέλεξε να σε
  κρατήσει στο ίδιο βήμα. Οι φάσεις με πολλές επαναλήψεις είναι
  φυσιολογικές όταν το υλικό είναι πυκνό.
- **Αριθμός εναλλακτικών** — πόσο συχνά η έξοδος JSON της ΤΝ δεν
  μπόρεσε να αναλυθεί και αντικαταστάθηκε με την ντετερμινιστική
  πρόοδο +1. Υψηλοί αριθμοί (> 10% των αξιολογήσεων) υποδηλώνουν
  ότι η ΤΝ δυσκολεύεται με τη μορφή εξόδου JSON· συνήθως ζήτημα
  μοντέλου, όχι δικό σου φταίξιμο.

## Χρόνος ανά βήμα

Γράφημα ράβδων που δείχνει συνολικά δευτερόλεπτα που αφιερώθηκαν σε
κάθε βήμα κύκλου στο έργο. Ο αθροιστής περιορίζει κενά πάνω από 2 ώρες
(έφυγες από την οθόνη — δεν είναι πραγματικός χρόνος μάθησης) ώστε
οι μεμονωμένες νυχτερινές συνεδρίες να μην κυριαρχούν.

Σε ποιο βήμα ξοδεύεις τον περισσότερο χρόνο σου λέει πολλά. Πολύς
χρόνος στο βήμα 3 (Λάθος) σημαίνει ότι το υλικό έχει πολλές παγίδες —
ίσως αυτό ακριβώς ζητούσες. Πολύς χρόνος στο βήμα 1 (Εισαγωγή)
σημαίνει ότι το υλικό είναι πυκνό και διαβάζεις αργά.

## Ιστορικό commit

Κάθε γραμμή είναι ένα ProgressCommit: μέθοδος, βαθμολογία κατανόησης,
βαθμολογία στρες, διάρκεια σε λεπτά, χρονοσφραγίδα committed_at, συν
η σημείωση συνεδρίας πλούσιου κειμένου αποδοσμένη ενσωματωμένα (TipTap
μόνο ανάγνωσης). Η λίστα είναι ταξινομήσιμη κατά ημερομηνία ή κατανόηση.

Οι αποδοσμένες σημειώσεις δείχνουν έντονα / πλάγια / λίστες / μπλοκ
κώδικα με επισήμανση σύνταξης / σύνδεσμους — ακριβώς αυτό που
πληκτρολογήθηκε στο παράθυρο βαθμολόγησης τέλους συνεδρίας. Παλαιές
σημειώσεις απλού κειμένου από πριν την v1.14.0 περνούν αναλλοίωτες.

## Εξαγωγές

Τρεις τύποι εξαγωγής μέσω Ρυθμίσεις → Εξαγωγή, όλοι ταυτόσημοι στη
μορφή σε λειτουργίες αποθήκευσης:

- **Αναφορά Προόδου** — ολόκληρη η σελίδα Προόδου συσκευασμένη σε
  έγγραφο Markdown ή PDF.
- **Λεπτομέρεια Συνεδρίας** — απομαγνητοφώνηση + βαθμολόγηση +
  αξιολογήσεις βημάτων μίας συνεδρίας.
- **Επισκόπηση Προγράμματος** — το δένδρο θεμάτων + περιλήψεις
  μαθημάτων για ένα πρόγραμμα σπουδών.

Το Markdown παράγεται από τον client· το PDF χρησιμοποιεί την εκτύπωση-σε-PDF
του browser (άνοιγμα κρυμμένου iframe με φύλλο στυλ βελτιστοποιημένο
για εκτύπωση, μετά `contentWindow.print()`). Χωρίς εξωτερική βιβλιοθήκη
PDF, χωρίς γύρο στο backend.

## Φιλτράρισμα

Μια απλή λωρίδα φίλτρων σου επιτρέπει να περιορίσεις κατά:

- **Μέθοδος** — μόνο commits που χρησιμοποιούν παραγωγική (ή οποιαδήποτε
  άλλη).
- **Εύρος ημερομηνιών** — τελευταίες 7 / 30 / 90 ημέρες ή όλος ο χρόνος.

Τα φίλτρα εφαρμόζονται σε όλες τις τέσσερις ενότητες (τάσεις, κατανομή,
αθροίσματα αξιολόγησης βημάτων, ιστορικό).

## Υπενθύμιση απορρήτου

Στην Τοπική λειτουργία η σελίδα Προόδου διαβάζει από το IndexedDB και
σου δείχνει αυτό που έχεις αποθηκεύσει σε αυτό τον browser. Στη Λειτουργία
Διακομιστή διαβάζει από τη βάση SQLite του FastAPI backend. Σε κάθε
περίπτωση, τίποτα εδώ δεν αποστέλλεται ποτέ σε υπηρεσία αναλυτικών
τρίτων.
