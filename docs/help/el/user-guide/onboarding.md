# Εισαγωγή στην εφαρμογή

Μετά τον επιλογέα γλώσσας στη σελίδα Εισόδου, η ροή Εισαγωγής
συλλέγει τέσσερα απαιτούμενα πεδία συν προαιρετική ταξινομία:

1. **Θέμα** — τι θέλεις να μάθεις. "Ισπανική γραμματική",
   "Βασικές αρχές μηχανικής μάθησης", "Αυτοσχεδιασμός lead
   κιθάρας". Να είσαι συγκεκριμένος· η ΤΝ θα το χρησιμοποιήσει
   για να αγκυρώσει κάθε συνεδρία.
2. **Στόχος** — πώς μοιάζει η επιτυχία. "Να περάσω τις εξετάσεις
   B2", "Να κατασκευάσω μια μηχανή συστάσεων από την αρχή ως το
   τέλος", "Solo σε 12-μπαρ blues πάνω από backing track χωρίς
   να χάσω τον χρόνο." Οι συγκεκριμένοι στόχοι παράγουν πιο
   χρήσιμη καθοδήγηση ΤΝ.
3. **Χρονοδιάγραμμα** — πότε θέλεις να φτάσεις τον στόχο.
   "6 εβδομάδες", "Τέλος καλοκαιριού", "Μέχρι τρίτο τρίμηνο".
   Χρησιμοποιείται για να ρυθμίσει τις προσδοκίες και να ορίσει
   τον στόχο παρακολούθησης σερί.
4. **Ημερήσια λεπτά** — πόσο χρόνο μπορείς ρεαλιστικά να δώσεις.
   15-45 λεπτά είναι το ιδανικό για προσαρμοστική μάθηση· η
   εφαρμογή δεν ανταμείβει μαραθώνιες συνεδρίες.

**Ταξινομία θέματος** (προαιρετικό, από v1.9.0) — ένα fuzzy
suggester αντιστοιχεί το θέμα σου στην ταξινομία 80+ κόμβων που
καλύπτει Γλώσσες / Μαθηματικά / Προγραμματισμός / Επιστήμες /
Μουσική / Ανθρωπιστικές επιστήμες / Κοινωνικές επιστήμες /
Δεξιότητες. Η επιλογή θέματος Γλωσσών ξεκλειδώνει αργότερα
Εξάσκηση Προφοράς για το έργο.

**Ετικέτες** (προαιρετικό) — ελεύθερες ετικέτες χωρισμένες με
κόμμα ("προετοιμασία-εξετάσεων", "καθημερινό", "αυτοκαθοδηγούμενο")
που εμφανίζονται αργότερα στη γραμμή φίλτρων του Ταμπλό.

Μπορείς επίσης να παρακάμψεις τελείως τη φόρμα — δημιουργείται
προεπιλεγμένος χρήστης και φτάνεις αμέσως στο Ταμπλό.

Επιλέγεις επίσης μια **γλώσσα** για το έργο. Αυτή είναι η γλώσσα
στην οποία θα απαντά η ΤΝ κατά τις συνεδρίες· μπορεί να διαφέρει
από τη γλώσσα UI (μπορεί να προτιμάς το UI στη μητρική σου γλώσσα
αλλά να μαθαίνεις Ισπανικά στα Ισπανικά).

## Προαιρετικό: τρέχον πρόβλημα

Ένα πεδίο "τρέχον πρόβλημα" σου επιτρέπει να φέρεις μια ανοιχτή
ερώτηση στο έργο αμέσως. Αν το συμπληρώσεις, η πρώτη συνεδρία
ξεκινά με αυτό το συγκεκριμένο εμπόδιο αντί για μια ανοιχτή
προτροπή "τι θέλεις να δουλέψεις;".

## Τι γίνεται στη συνέχεια

Όταν υποβάλεις τη φόρμα, τρία πράγματα συμβαίνουν σε μία
ανταλλαγή:

1. Δημιουργείται μια εγγραφή `User` (ή επαναχρησιμοποιείται —
   ο τοπικός browser σου διατηρεί τον ίδιο χρήστη κατά τις
   συνεδρίες).
2. Μια σειρά `LearningProject` λαμβάνει θέμα / στόχο /
   χρονοδιάγραμμα / ημερήσια-λεπτά / γλώσσα.
3. Η διαδρομή Αξιολόγησης ανοίγει αυτόματα. Μπορείς να την
   παρακάμψεις από εδώ, αλλά η εφαρμογή μετά προεπιλέγει τη
   μέθοδο μάθησης "παραγωγική" μέχρι να την κάνεις.

## Επεξεργασία του έργου σου

Τα στοιχεία έργου δεν είναι λαξευτά στην πέτρα. Η σελίδα
Προγράμματος Σπουδών σου επιτρέπει να προσαρμόσεις το θέμα και
τον στόχο καθώς ανακαλύπτεις τι πραγματικά θέλεις να μάθεις.
Η σελίδα Ρυθμίσεων χειρίζεται αλλαγές γλώσσας.

## Τι δεν αποθηκεύεται

- **Χωρίς email**, χωρίς κωδικό, χωρίς λογαριασμό.
- **Χωρίς αναλυτικά στοιχεία**, χωρίς trackers τρίτων.
- **Χωρίς τηλεμετρία** που αποστέλλεται εκτός της συσκευής
  σου σε Τοπική λειτουργία.

Ο πάροχος ΤΝ σου βλέπει τα μηνύματά σου (αυτός είναι ο λόγος
που ρωτάς την ΤΝ). Το Adaptive Learner αποθηκεύει μόνο αυτά που
πληκτρολογείς — τοπικά ή στο FastAPI backend, ανάλογα με τη
[λειτουργία αποθήκευσης](settings.md#storage-mode) που έχεις
επιλέξει.
