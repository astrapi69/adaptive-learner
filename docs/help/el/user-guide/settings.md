# Ρυθμίσεις

Η σελίδα Ρυθμίσεων συγκεντρώνει όλα όσα μπορείς να τροποποιήσεις
χωρίς να αγγίξεις κώδικα ή YAML. Ενότητες από πάνω προς τα κάτω:

1. **Γλώσσα** - γλώσσα UI (DE / EN / ES / FR / EL / PT /
   TR / JA, πλήρως μεταφρασμένες όλες).
2. **Πάροχος + επιλογέας μοντέλου ΤΝ** - ποιος πάροχος βλέπει τα
   μηνύματά σου και ποιο μοντέλο χρησιμοποιείται.
3. **API keys** - ανά πάροχο, με απόδοση πηγής
   (env / `secrets.yaml` / Ρυθμίσεις).
4. **Λειτουργία αποθήκευσης** - Διακομιστής (FastAPI + SQLite) ή
   Τοπική (browser IndexedDB).
5. **Συγχρονισμός** - σύνδεση αυτής της συσκευής με άλλη μέσω τοπικού
   δικτύου.
6. **Αντίγραφο ασφαλείας** - εξαγωγή / εισαγωγή / σύγκριση.
7. **Φωνή** - TTS + STT + εναλλαγές προφοράς.
8. **Εμφάνιση** - θέμα + πυκνότητα.
9. **Μάθηση** - πέντε περιοχές: Βασικά, Μέσα στο μάθημα, Εκφώνηση και
   υπαγόρευση, Μετά το μάθημα, Κίνητρο και ρουτίνα.
10. **Παιχνιδοποίηση** - ειδοποιήσεις XP / σήματος + λειτουργία
    Σαββατοκύριακου.
11. **Πληροφορίες** - έκδοση, πληροφορίες συστήματος, εκτιμήσεις,
    δωρεές, άδεια χρήσης.

## Γλώσσα

Αντικαθιστά αμέσως κάθε συμβολοσειρά UI στην επόμενη απόδοση μέσω
`PATCH /api/settings/{user_id}`. Και οι 8 γλώσσες είναι πρωτεύουσες -
DE / EN / ES / FR / EL / PT / TR / JA - η καθεμία με πλήρως
μεταφρασμένο κατάλογο. Αποθηκεύεται μεταξύ επαναφορτώσεων μέσω
`localStorage`.

## Πάροχος ΤΝ + επιλογέας μοντέλου

Το αναπτυσσόμενο μενού παρόχου γράφει `active_provider` στις
UserSettings· η επόμενη κλήση ΤΝ περνά από το plugin του νέου
παρόχου (Λειτουργία Διακομιστή) ή τον HTTP client του νέου παρόχου
(Τοπική λειτουργία).

Ο **Επιλογέας μοντέλου** είναι ένα αναπτυσσόμενο μενού
με δυνατότητα αναζήτησης, ομαδοποιημένο σε Προτεινόμενα / Όλα,
με πληθυσμό από το live endpoint `/v1/models` κάθε παρόχου (cache 1h).
Κάθε γραμμή δείχνει το αναγνώσιμο όνομα + raw id + σήμα παραθύρου
περιβάλλοντος. Όταν η λίστα δεν είναι διαθέσιμη (χωρίς API key, χωρίς
δίκτυο), ο επιλογέας επιστρέφει στις στατικές προεπιλογές και εμφανίζει
υπόδειξη "χρήση offline προεπιλογής". Η κεφαλίδα Συνεδρίας δείχνει
`<Πάροχος>: <Όνομα μοντέλου>`· το πλήρες id + παράθυρο περιβάλλοντος
βρίσκονται στο tooltip.

## API keys

Κάθε πάροχος έχει τη δική του γραμμή: πεδίο εισαγωγής κλειδιού, κουμπί
Αποθήκευση, κουμπί Αφαίρεση, σήμα ενεργού παρόχου, συν το νέο σήμα
**απόδοσης πηγής**:

- **Κλειδί από: Ρυθμίσεις** - το κλειδί αποθηκεύεται κρυπτογραφημένο με
  Fernet στη βάση δεδομένων (Λειτουργία Διακομιστή) ή ως καθαρό κείμενο
  στο IndexedDB (Τοπική λειτουργία). Μπορείς να Αποθηκεύσεις / Αφαιρέσεις
  ελεύθερα.
- **Κλειδί από: secrets.yaml** - το κλειδί ρυθμίζεται στο
  `~/.config/adaptive-learner/secrets.yaml`. Το κουμπί Αποθήκευση είναι
  απενεργοποιημένο· επεξεργάσου το αρχείο απευθείας για αλλαγή.
  Μια ενημερωτική κορδέλα κάτω από τη γραμμή σου υπενθυμίζει τη διαδρομή.
- **Κλειδί από: environment** - το κλειδί ρυθμίζεται μέσω της μεταβλητής
  περιβάλλοντος `ADAPTIVE_LEARNER_<PROVIDER>_API_KEY`. Αποθήκευση
  απενεργοποιημένη· η μεταβλητή είναι η πηγή αλήθειας.
- **Κανένα ρυθμισμένο κλειδί** - τίποτα δεν έχει οριστεί. Πληκτρολόγησε
  και πάτησε Αποθήκευση για να ξεκινήσεις.

Αλυσίδα επίλυσης (υψηλότερη προτεραιότητα κερδίζει): env > secrets.yaml
> DB. Δες [το έγγραφο Ρύθμισης](https://github.com/astrapi69/adaptive-learner/blob/main/docs/configuration.md)
για την πλήρη ανάλυση.

## Λειτουργία αποθήκευσης

Εναλλαγή μεταξύ **Διακομιστή** και **Τοπικής (Browser)** αποθήκευσης:

- **Διακομιστής** - κάθε ανάγνωση και εγγραφή χτυπά το FastAPI backend.
  Απαιτεί λειτουργούν backend. Ιδανικό για χρήση πολλαπλών συσκευών με
  συγχρονισμό μέσω backend.
- **Τοπική (Browser)** - κάθε ανάγνωση και εγγραφή χτυπά το IndexedDB
  σε αυτό τον browser. Οι κλήσεις ΤΝ εκπέμπονται απευθείας στον πάροχο.
  Δεν απαιτείται backend. Ιδανικό για ιδιωτική, τοπική σε συσκευή
  εγκατάσταση.

Η εναλλαγή λειτουργιών αποθηκεύεται στο `localStorage` και εμφανίζει
μήνυμα "απαιτείται επαναφόρτωση". Τα δεδομένα ΔΕΝ συγχρονίζονται μεταξύ
λειτουργιών.

## Συγχρονισμός

Σύνδεσε αυτή τη συσκευή με μια άλλη μέσω τοπικού δικτύου χρησιμοποιώντας
τον σαρωτή QR code (πίσω κάμερα) ή επικολλώντας το URL σύνδεσης. Μόλις
συνδεθεί, τα κουμπιά push + pull ανταλλάσσουν δεδομένα αμφίδρομα.
Οι συγκρούσεις επιλύονται μέσω ενός αναλυτή AI-merge στο backend.

Εναλλακτική για browser με περιορισμούς: ανέβασε στιγμιότυπο οθόνης του
QR code από την άλλη συσκευή σου (`Html5Qrcode.scanFile`).

## Αντίγραφο ασφαλείας

Τρία πράγματα σε μία ενότητα: **Εξαγωγή** (λήψη χρονοσφραγισμένου JSON),
**Εισαγωγή** (επαναφορά από αρχείο) και **Σύγκριση** (παράθεση πλευρά
με πλευρά έναντι της τρέχουσας κατάστασης). Τα API keys αφαιρούνται
από κάθε εξαγωγή.

Η επαναφορά είναι ΣΥΓΧΩΝΕΥΣΗ, όχι αντικατάσταση: νέες γραμμές εισάγονται,
μεταβλητές γραμμές ενημερώνονται με νεότερο `updated_at`, γραμμές ιστορικού
(συνεδρίες / commits / αξιολογήσεις) αποκλείουν διπλότυπα βάσει UUID.
Η προεπισκόπηση σύγκρισης δείχνει ανά πίνακα προσθήκες / αφαιρέσεις /
αλλαγές πριν κάνεις κλικ Επαναφορά· η ετικέτα κουμπιού Επαναφοράς
διαβάζει "Επαναφορά (N προσθήκες, M ενημερώσεις)" μόλις τελειώσει η
σύγκριση.

Στην Τοπική λειτουργία η ενότητα δείχνει επίσης τον μπλοκ **Αυτόματου
αντιγράφου ασφαλείας**: κυκλική ουρά 3 στιγμιότυπων σε ξεχωριστή βάση
IndexedDB, εκτελείται κάθε 10 συνεδρίες Ή κάθε 7 ημέρες (όποιο πυρκαγεί
πρώτο). Κάθε στιγμιότυπο έχει δικό του κουμπί Επαναφορά + Διαγραφή +
Σύγκριση-ως-A/B.

### Τακτοποίηση

Δύο ρυθμίσεις για τον κύκλο ζωής των δεδομένων βρίσκονται στην καρτέλα
Δεδομένα, ακριβώς δίπλα στον αποθηκευτικό χώρο που αφορούν:

- **Μέγιστο μέγεθος μαθήματος** (ακριβώς κάτω από την *Προσωρινή μνήμη
  εκτός σύνδεσης*): όταν μια μεγάλη ανάλυση συνομιλίας αποθηκεύεται ως
  μάθημα εκτός σύνδεσης, τα μαθήματα με περισσότερα βήματα από αυτόν τον
  αριθμό χωρίζονται σε πολλά μέρη. Τα *Βήματα ανά μέρος* δέχονται 5 έως
  20· η προεπιλογή είναι 10.
- **Διατήρηση παυσαρισμένων μαθημάτων** (ακριβώς πάνω από τον καθαρισμό
  *Αποσυνδεδεμένο περιεχόμενο*, που εμφανίζεται μόνο όταν υπάρχει κάτι να
  καθαριστεί): τα παυσαρισμένα μαθήματα που είναι παλαιότερα από αυτό
  εγκαταλείπονται αυτόματα στην επόμενη φόρτωση του Ταμπλό. Διάλεξε 7,
  14, 30 ή 60 ημέρες, ή *Ποτέ*· η προεπιλογή είναι 30 ημέρες. Έως 10
  παυσαρισμένα μαθήματα διατηρούνται ανεξάρτητα από την ηλικία τους.

Και οι δύο τιμές αποθηκεύονται σε αυτόν τον browser και ισχύουν τόσο σε
Λειτουργία Διακομιστή όσο και σε Τοπική λειτουργία.

## Φωνή

Τρεις εναλλαγές:

- **TTS ενεργό** - προσθέτει κουμπί ▶ δίπλα στις απαντήσεις ΤΝ +
  αποτελέσματα Αξιολόγησης που τα διαβάζει δυνατά. Επιλέγει τη φωνή
  που ταιριάζει με τη γλώσσα όταν είναι διαθέσιμη· ρυθμός + τόνος
  περιορίζονται στο [0.5, 2.0].
- **Αυτόματη αναπαραγωγή ΤΝ** - μιλά κάθε απάντηση ΤΝ αυτόματα
  (προεπιλογή ΑΠΕΝΕΡΓΟΠΟΙΗΜΕΝΟ - ο αναπάντεχος ήχος σπάνια είναι αυτό
  που θέλεις).
- **STT ενεργό** - προσθέτει κουμπί 🎤 στην είσοδο Συνεδρίας που
  αποτυπώνει ομιλία και συμπληρώνει την περιοχή κειμένου με ενδιάμεσα
  αντίγραφα πριν την αποστολή.
- **Εξάσκηση Προφοράς ενεργή** - εμφανίζει τη σελίδα `/pronunciation`
  από την γρήγορη εκκίνηση Ταμπλό για έργα με ετικέτα Γλώσσες.

Η ενότητα Φωνής κρύβεται όταν κανένα από τα δύο μέρη του Web Speech API
(σύνθεση ή αναγνώριση) δεν υποστηρίζεται από τον browser.

## Εμφάνιση

Ο **επιλογέας Θέματος** στις *Γενικές > Εμφάνιση* προσφέρει έξι θέματα
και μια αυτόματη λειτουργία:

- **Φωτεινό** - το προεπιλεγμένο, φωτεινό και υψηλής αντίθεσης.
- **Σκοτεινό** - μειωμένες επιφάνειες για χαμηλό φωτισμό.
- **Ωκεανός** - βαθιές μπλε αποχρώσεις, ήρεμο και ευχάριστο στα μάτια
  τη νύχτα.
- **Δάσος** - ζεστοί πράσινοι και κεχριμπαρένιοι τόνοι γης.
- **Υψηλή Αντίθεση** - προσβασιμότητα πρώτα: μαύρο, άσπρο και έντονα
  χρώματα σήματος, με καθαρά άκρα καρτών. Χρησιμοποίησέ το αν χρειάζεσαι
  μέγιστη αναγνωσιμότητα.
- **Σέπια** - ζεστοί τόνοι χαρτιού, άνετοι για παρατεταμένη ανάγνωση.
- **Αυτόματο (Σύστημα)** - ακολουθεί τη ρύθμιση φωτεινού/σκοτεινού
  του λειτουργικού σου συστήματος και αλλάζει αυτόματα μαζί του.

Επέλεξε θέμα από την κάρτα προεπισκόπησής του· η αλλαγή εφαρμόζεται
αμέσως χωρίς επαναφόρτωση, και η επιλογή σου θυμάται μεταξύ επισκέψεων.
Κάθε θέμα σχεδιάστηκε για να πληροί τον WCAG 2.1 AA, οπότε κείμενο,
γραφήματα, σήματα και ανατροφοδότηση άσκησης παραμένουν ευανάγνωστα
σε όλα.

## Διεπαφή

Δύο ρυθμίσεις: τα **tooltips κουμπιών** (ένα tooltip στην αιώρηση πάνω
από κουμπιά-εικονίδια· οι ετικέτες για αναγνώστες οθόνης μένουν πάντα
ενεργές) και η **Θέση μενού (κινητό)** (επάνω ως κουμπί μενού, η
προεπιλογή, ή κάτω ως γραμμή καρτελών σε απόσταση αντίχειρα). Οι κινήσεις
σάρωσης είναι ρύθμιση μαθήματος και βρίσκονται στο *Μάθηση > Μέσα στο
μάθημα > Αλληλεπίδραση*.

Η **Λειτουργία Προγραμματιστή** (στην καρτέλα **Διάγνωση και υποστήριξη**)
έχει προεπιλογή που εξαρτάται από τον κλάδο του build: είναι
**ΕΝΕΡΓΗ από προεπιλογή στον κλάδο Latest (προεπισκόπηση)** και
**ΑΝΕΝΕΡΓΗ στον Main**, ώστε οι δοκιμαστές της προεπισκόπησης να βλέπουν
πλήρεις τεχνικές λεπτομέρειες σφαλμάτων, ενώ οι χρήστες παραγωγής
παίρνουν φιλικά μηνύματα. Μπορείς να την αλλάξεις όποτε θέλεις.

## Μάθηση

Η καρτέλα **Μάθηση** ομαδοποιεί τις κάρτες της σε πέντε περιοχές με
ετικέτα, με τη σειρά που εξελίσσεται ένα μάθημα. Κάθε περιοχή έχει μια
μικρή επικεφαλίδα και μια περιγραφή μίας γραμμής· οι κάρτες μέσα της
κρατούν τους δικούς τους τίτλους.

### Βασικά

Ποιος μαθαίνει και σε ποιες γλώσσες.

- **Προφίλ μάθησης** - δημιούργησε, συνέχισε ή επανάλαβε το προφίλ
  μάθησης πίσω από τα βάρη των έξι μεθόδων.
- **Επιπλέον γλώσσες προέλευσης** - ποιες γλώσσες προέλευσης δείχνει το
  δέντρο περιεχομένου πέρα από τη γλώσσα της εφαρμογής σου.

### Μέσα στο μάθημα

Πώς συμπεριφέρονται οι ασκήσεις όσο απαντάτε.

- **Λειτουργία μαθήματος** - η **Προεπιλεγμένη λειτουργία** (Εξάσκηση /
  Εξέταση / Με χρόνο), το **Όριο επιτυχίας** της εξέτασης και η
  **Δυσκολία λειτουργίας με χρόνο** (Γρήγορο, Κανονικό, Χαλαρό)· δες
  [Μαθήματα και επαναλήψεις](lessons.md).
- **Υποδείξεις** - αν εμφανίζεται σε κάθε άσκηση ένα κουμπί υπόδειξης
  σε στάδια, και το **κόστος XP ανά υπόδειξη** (0 για δωρεάν υποδείξεις).
- **Αλληλεπίδραση** - **Κινήσεις σάρωσης** (σάρωση για πλοήγηση σε
  Αξιολόγηση, Συνεδρία και Πρόγραμμα Σπουδών· προεπιλογή ΕΝΕΡΓΟ σε
  συσκευές αφής), **Συντομεύσεις πληκτρολογίου στα μαθήματα** (το Enter
  ελέγχει την απάντηση, ξανά Enter προχωρά), **Αυτόματη μετάβαση μετά από
  σωστή απάντηση** και αν εμφανίζεται το κουμπί **Ρώτησε την ΤΝ**.
- **Προτιμώμενη κατεύθυνση άσκησης** - με ποια κατεύθυνση ανοίγουν οι
  ασκήσεις που έχουν κατεύθυνση.
- **Εφέ επίλυσης** - το εφέ που παίζει μια λυμένη άσκηση αντιστοίχισης.

### Εκφώνηση και υπαγόρευση

Φωνές, ταχύτητα, μικρόφωνο και εξάσκηση προφοράς.

- **Φωνή** - οι εναλλαγές που περιγράφονται παραπάνω στη *Φωνή*:
  μετατροπή κειμένου σε ομιλία, αυτόματη αναπαραγωγή, αναγνώριση ομιλίας
  και εξάσκηση προφοράς.

Αυτή η περιοχή εμφανίζεται μόνο όταν ο browser υποστηρίζει τουλάχιστον
τη μία πλευρά του Web Speech API (σύνθεση ή αναγνώριση). Αλλιώς λείπει,
μαζί με την επικεφαλίδα της, και το *Μετά το μάθημα* ακολουθεί απευθείας
το *Μέσα στο μάθημα*.

### Μετά το μάθημα

Επαναλήψεις, η σύνοψη του μαθήματος και η διόρθωση λαθών.

- **Επανάληψη** - οι αυτόματα παραγόμενες εξηγήσεις λαθών και ο αριθμός
  ερωτήσεων ανά συνεδρία επανάληψης. Η κάρτα τελειώνει με το μπλοκ μόνο
  για ανάγνωση **Διαστηματική επανάληψη**: το πρόγραμμα διαστημάτων
  (σωστές απαντήσεις στη σειρά έναντι ημερών μέχρι την επόμενη
  επανάληψη), πότε ένα στοιχείο θεωρείται εμπεδωμένο, και έναν σύνδεσμο
  προς τη μέθοδο μάθησης.
- **Σύνοψη μετά τα μαθήματα** - ποιες ενότητες δείχνει η σύνοψη στο τέλος
  του μαθήματος, και με ποια σειρά.
- **Επανάληψη λαθών** - ποια λάθη μαζεύει ο γύρος επανάληψης.

### Κίνητρο και ρουτίνα

Λειτουργία παιχνιδιού, ανατροφοδότηση, καθημερινές αποστολές και
υπενθυμίσεις.

- **Λειτουργία παιχνιδιού** - παιχνιδιάρικα μαθήματα, μαζί με την
  **Παραλλαγή μασκότ**, τους χρωματικούς συνδυασμούς του Lernfunke που
  ξεκλειδώνονται με επίπεδα και σήματα ή με αντάλλαγμα XP (οι κλειδωμένες
  παραλλαγές δείχνουν την προϋπόθεσή τους, οι αγορές ζητούν επιβεβαίωση
  σε δύο βήματα). Τι αλλάζει αναλυτικά η λειτουργία παιχνιδιού
  περιγράφεται στο [Επαίνος και γιορτασμός](celebrations.md).
- **Ανατροφοδότηση** - ένταση ανατροφοδότησης και ήχοι (ένταση ήχου,
  κουμπί δοκιμής).
- **Καθημερινές αποστολές** - αν τρέχουν αποστολές, πόσες την ημέρα, το
  μείγμα δυσκολίας και το ανακάτεμα των σημερινών αποστολών.
- **Υπενθυμίσεις** - η ώρα υπενθύμισης και οι ημέρες στις οποίες ισχύει.

Η κάρτα της λειτουργίας παιχνιδιού δείχνει τον κεντρικό διακόπτη, τους
ήχους λειτουργίας παιχνιδιού και μια γραμμή κατάστασης που μετρά πόσα από
τα έξτρα είναι ενεργά. Οι **Λεπτομέρειες λειτουργίας παιχνιδιού** (καρδιές,
αντίστροφη μέτρηση, arcade, ειδικοί γύροι, εισιτήρια, μπόνους μαθήματα,
XP σερί και μασκότ) είναι διπλωμένες και θυμούνται την επιλογή σου· όσο
τα **Παιχνιδιάρικα μαθήματα** είναι απενεργοποιημένα, οι επιλογές μέσα
τους είναι γκριζαρισμένες.

Η καρτέλα τελειώνει με τις υπενθυμίσεις. Οι δύο ρυθμίσεις τακτοποίησης -
*Διατήρηση παυσαρισμένων μαθημάτων* και *Μέγιστο μέγεθος μαθήματος* -
αφορούν τον κύκλο ζωής των δεδομένων και βρίσκονται στην καρτέλα
**Δεδομένα** (δες *Τακτοποίηση* κάτω από το Αντίγραφο ασφαλείας).

Η **Προβολή περιεχομένου** (λίστα / πλέγμα) και η **Σειρά καρτελών
Περιεχομένου** βρίσκονται στην καρτέλα **Γενικά** κάτω από την
*Εμφάνιση*.

## Παιχνιδοποίηση

Εναλλαγές για ειδοποιήσεις XP / σήματος / ανεβάσματος επιπέδου
(απενεργοποίηση σιγάζει τα toasts αλλά το σύστημα εξακολουθεί να
καταγράφει κατάσταση), **λειτουργία σαββατοκύριακου** (παράλειψη κενών
Σαβ/Κυρ στον χάρτη θερμότητας σερί), ημερήσιος στόχος συνεδριών (1..10)
και **Επαναφορά προόδου** (διπλή επιβεβαίωση· σβήνει γραμμές
`user_xp` + `user_badges` + `user_streaks`).

## Πληροφορίες

Πέντε μπλοκ μόνο για ανάγνωση: **Έκδοση** (κανονική έκδοση από
`pyproject.toml`, hash build, ημερομηνία build), **Σύστημα**
(λειτουργία αποθήκευσης, κατάλογος δεδομένων, διαδρομή βάσης δεδομένων
σε Λειτουργία Διακομιστή, Python + πληροφορίες πλατφόρμας), **Εκτιμήσεις**
(συγγραφέας, αναγνώριση εξαρτήσεων), **Υποστήριξη ανάπτυξης**
(σύνδεσμοι Liberapay / GitHub Sponsors / Ko-fi), **Άδεια χρήσης και
πόροι** (σύνδεσμος MIT, αποθετήριο, έγγραφα, εργαλείο παρακολούθησης
θεμάτων).

Στην Τοπική λειτουργία ο πίνακας κρύβει τις γραμμές που έχουν νόημα
μόνο για λειτουργούν backend (έκδοση Python, εκδόσεις FastAPI /
SQLAlchemy / Pydantic / PluginForge, διαδρομή βάσης δεδομένων).
