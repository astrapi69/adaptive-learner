# Μαθήματα και Επαναλήψεις Περιεχομένου

Ένα **μάθημα περιεχομένου** είναι μια μικρή, χειροποίητη μαθησιακή μονάδα
(συνήθως 5–10 λεπτά) που λαμβάνεται από ένα δημόσιο σύνολο μαθημάτων.
Εκτελείται σε αποκλειστικό viewer, όχι στη συνεδρία συνομιλίας ΤΝ.
Μετά το μάθημα η εφαρμογή θυμάται ακριβώς ποιες λέξεις, ζεύγη ή φράσεις
έκανες λάθος και τα προγραμματίζει για μια εστιασμένη επανάληψη αργότερα.

Τα μαθήματα είναι μια **εναλλακτική διαδρομή** μάθησης που δεν χρειάζεται
API key ΤΝ — τέλεια για δοκιμή της εφαρμογής ή για περιεχόμενο όπου
επιμελημένο υλικό υπερτερεί της ελεύθερης συνομιλίας.

---

## Από πού προέρχονται τα μαθήματα

Τα μαθήματα βρίσκονται σε **σύνολα περιεχομένου** — μικρές δέσμες
δημοσιευμένες σε δημόσια αποθετήρια GitHub. Το **Set Browser** της
εφαρμογής στο `/content` παραθέτει κάθε διαθέσιμο σύνολο· κάνε κλικ
σε ένα για λήψη. Το σύνολο αποθηκεύεται τοπικά (στο σύστημα αρχείων
αν τρέχεις με backend, στο IndexedDB στην ανάπτυξη μόνο-browser) ώστε
να μελετάς offline μετά την πρώτη λήψη.

Το πιλοτικό σύνολο v1.27.0 είναι **Γαλλικά A1** (2 μαθήματα, 14 κάρτες,
9 ασκήσεις που καλύπτουν και τους τέσσερις τύπους άσκησης). Κάθε έκδοση
προσθέτει περισσότερα — δες το
[αποθετήριο συνόλων](https://github.com/astrapi69/adaptive-learner-content)
για τον τρέχοντα κατάλογο.

---

## Η ροή μαθήματος

Άνοιξε ένα σύνολο, επέλεξε μάθημα, και ο **viewer μαθήματος** σε καθοδηγεί
σε κάθε κάρτα και άσκηση βήμα-βήμα:

1. Οι **κάρτες** παρουσιάζουν υλικό για ανάγνωση. Κάνε κλικ "Επόμενο"
   όταν είσαι έτοιμος.
2. Οι **ασκήσεις** ελέγχουν τι θυμάσαι. Τέσσερις τύποι παραδίδονται:
   - **Αντιστοίχιση** — σύρε ζεύγη (λέξη ↔ μετάφραση).
   - **Επιλογή εικόνας** — επέλεξε την εικόνα που ταιριάζει σε μια
     ερώτηση.
   - **Ελεύθερο κείμενο** — πληκτρολόγησε την απάντηση.
   - **Πλακάκια λέξεων** — συναρμολόγησε πρόταση από πλακάκια.

Μια μπάρα προόδου στην κορυφή παρακολουθεί πόσο έχεις προχωρήσει στο
μάθημα. Μπορείς να φύγεις ανά πάσα στιγμή — η πρόοδός σου αποθηκεύεται
ανά βήμα και συνεχίζεται από εκεί που έμεινες.

### Η οθόνη σύνοψης

Όταν ολοκληρωθεί η τελευταία άσκηση, εμφανίζεται η **σύνοψη μαθήματος**:

- Βαθμολογία **0–3 αστέρια** βάσει του αποτελέσματός σου:
  - **3 αστέρια** ≥ 90% σωστά
  - **2 αστέρια** ≥ 75%
  - **1 αστέρι** ≥ 50%
  - **0 αστέρια** κάτω από 50%
- Ανάλυση **ανά άσκηση** που δείχνει ποιες ασκήσεις πέρασες και ποιες
  είχαν λάθη (με αποκάλυψη της σωστής απάντησης για τα λανθασμένα).
- Κουμπιά **Επόμενο μάθημα**, **Επανάληψη** και **Πίσω στο σύνολο**
  ώστε η επόμενη ενέργεια να είναι ένα κλικ μακριά.

Πάρε 3 αστέρια στην πρώτη απόπειρα και τα αστέρια παίζουν μικρή
εορταστική κίνηση. (Αν έχεις ενεργοποιήσει τη ρύθμιση "μείωση κίνησης"
OS, η κίνηση σέβεται αυτό.)

## Παρακολούθηση σφαλμάτων σε επίπεδο στοιχείου

Κάθε λανθασμένη απάντηση σε κάθε τύπο άσκησης γράφει μια γραμμή
συνδεδεμένη με το **συγκεκριμένο στοιχείο που έχασες** — τη μεμονωμένη
λέξη, ζεύγος ή φράση. Η εφαρμογή ΔΕΝ θυμάται απλώς "έβαλες 6/10 στο
μάθημα 3"· θυμάται "δυσκολεύτηκες συγκεκριμένα με *bonjour* και *merci*".

Πάρε το ίδιο στοιχείο σωστά **3 φορές στη σειρά** και μετατρέπεται σε
**κατακτηθέν** — αφαιρείται από την ουρά επανάληψης. Πάρε λάθος ένα
κατακτηθέν στοιχείο αργότερα και **υποβαθμίζεται πίσω** στην ουρά.
Μια χαμένη κατάκτηση είναι μια ξεχασμένη κατάκτηση.

---

## Η ουρά επανάληψης

Όταν έχεις ένα ή περισσότερα στοιχεία που χρειάζονται επανάληψη, η
**κάρτα ουράς επανάληψης** εμφανίζεται στο Ταμπλό. Δείχνει:

- Πόσα στοιχεία είναι ληξιπρόθεσμα
- Πόσα είναι **καθυστερημένα** (πέρα από την προγραμματισμένη ημερομηνία
  επανάληψης)
- Κουμπί **Επανάληψη τώρα** που ανοίγει εστιασμένη μίνι-συνεδρία στο
  `/review/:setId`

Η προγραμματισμός χρησιμοποιεί τρεις ζώνες βάσει πόσες φορές έχεις
πάρει σωστά στη σειρά:

| Σερί σωστών | Επόμενη επανάληψη |
|---|---|
| 0 | 1 ημέρα αργότερα |
| 1 | 3 ημέρες αργότερα |
| 2 | 7 ημέρες αργότερα |
| 3 (κατακτηθέν) | αφαιρείται από ουρά |

Μέσα στην ουρά τα στοιχεία ταξινομούνται: **καθυστερημένα πρώτα**, μετά
κατά **φθίνοντα αριθμό σφαλμάτων**, μετά κατά **πιο πρόσφατη αποτυχία
πρώτη**. Έτσι τα στοιχεία με τα οποία δυσκολεύεσαι περισσότερο ανεβαίνουν
στην κορυφή.

## Συνεδρίες επανάληψης

Μια συνεδρία επανάληψης στο `/review/:setId` συνθέτει μια **μίνι-συνεδρία
σε πραγματικό χρόνο** από τα κορυφαία στοιχεία της ουράς σου. Μικτή
στρατηγική από **v1.35.0**:

- Αν έκανες αρχικά λάθος σε λέξη σε άσκηση **αντιστοίχισης** ή
  **επιλογής εικόνας**, θα επαναλάβεις αυτή την άσκηση (με νέα ανακάτεμα,
  ώστε να μην είναι καθαρή μνήμη μυών).
- Αν έκανες λάθος σε **ελεύθερο κείμενο** ή **πλακάκια λέξεων**, η
  επανάληψη προσπαθεί να παράγει **cloze** ("συμπλήρωσε το κενό") που
  στοχεύει ακριβώς τη λέξη που έκανες λάθος. Ίδια γνώση σε διαφορετική
  μορφή — εξασκείται η ευελιξία σου, όχι απλώς η ανάκλησή σου μιας
  συγκεκριμένης μορφής άσκησης.
- Αν η δημιουργία cloze δεν μπορεί να κατασκευάσει καθαρό κενό για
  αυτό το στοιχείο (π.χ. η ερώτηση πηγής δεν περιέχει inline την
  απάντηση), η επανάληψη σιωπηλά επιστρέφει στην επανάληψη του
  αρχικού. Δεν βλέπεις ποτέ σπασμένο ή κενό βήμα.

Όταν τελειώνεις μια συνεδρία επανάληψης, εκτελείται η ίδια μηχανή
βαθμολόγησης + αστέρια + παρακολούθηση στοιχείων. Κατακτείς 50 στοιχεία
μέσω επαναλήψεων και κερδίζεις το σήμα **Κύριος Επανάληψης**.

## Γύρος διόρθωσης στο τέλος κάθε μαθήματος

Νέο στην **v1.35.0**: όταν τελειώνεις ένα μάθημα που είχε λανθασμένες
απαντήσεις, η σελίδα σύνοψης δείχνει ένα μικρό **γύρο διόρθωσης** μεταξύ
της βαθμολογίας σου και του κουμπιού "Επόμενο μάθημα". Επιλέγει έως πέντε
από τα συγκεκριμένα λάθη σου από αυτό το μάθημα και προσφέρει το καθένα
ως φρέσκο cloze στοχευμένο στην ακριβή λέξη ή άρθρο που έκανες λάθος.

- **Μπορείς να παραλείψεις ανά πάσα στιγμή.** Το κουμπί "Επόμενο μάθημα"
  παραμένει ορατό καθ' όλη τη διάρκεια — ο γύρος διόρθωσης είναι
  προαιρετική εξάσκηση, όχι πύλη.
- **Εμφανίζεται μόνο όταν υπάρχει κάτι να διορθωθεί.** Τα μαθήματα με
  τέλεια βαθμολογία το παραλείπουν εντελώς. Τα μαθήματα με λάθη που δεν
  μπορούν να μετατραπούν σε καθαρό cloze (σπάνιο) επίσης παραλείπουν.
- **Κάθε ολοκληρωμένο cloze μετρά για κατάκτηση.** Ο γύρος διόρθωσης
  γράφει τις ίδιες γραμμές παρακολούθησης στοιχείων με το κύριο μάθημα·
  το σερί σου σε αυτά τα συγκεκριμένα στοιχεία προχωρά προς το κατώφλι
  κατάκτησης 3-σωστά.

Μια σύντομη γραμμή "{n} στοιχεία βελτιώθηκαν" εμφανίζεται στο τέλος
του γύρου, ώστε να βλέπεις τη διαφορά που έκανε η επιπλέον εξάσκησή σου.

## Οπτική ανατροφοδότηση diff

Επίσης νέο στην **v1.35.0**: οι λανθασμένες απαντήσεις ελεύθερου κειμένου
και πλακακιών λέξεων δείχνουν τώρα ένα **diff σε επίπεδο token** μεταξύ
αυτού που έγραψες και της κανονικής απάντησης. Τρία χρώματα, ποτέ μόνο
χρώμα:

- **Κόκκινο διαγραμμένο** — αυτό που έγραψες που δεν ανήκει (με × δείκτη
  για αναγνώστες οθόνης και αχρωματοψικούς χρήστες).
- **Πράσινο** — αυτό που η κανονική απάντηση περιλαμβάνει που έχασες
  (με + δείκτη).
- **Πορτοκαλί** με βέλος → — μια λέξη που έγραψες ελαφρά λάθος,
  εμφανιζόμενη ως `αυτό-που-έγραψες` → `αναμενόμενο`.

Το ίδιο diff εμφανίζεται στις γραμμές ανάλυσης ανά άσκηση της σύνοψης
μαθήματος για κάθε απόπειρα ελεύθερου κειμένου ή πλακακιών λέξεων για
την οποία η αποθήκη v1.35.0+ έχει την απάντηση-χρήστη.

## XP και σήματα

Κάθε ολοκληρωμένο μάθημα κερδίζει XP σύμφωνα με φόρμουλα ανά αστέρι:

- **30 XP** βάση
- **+10 XP ανά αστέρι** που κερδίστηκε (0 → 0, 1 → +10, 2 → +20, 3 → +30)
- **+20 XP μπόνους** αν κερδίσεις 3 αστέρια στην πρώτη απόπειρα
  (κάθε βήμα με απόπειρες = 1, χωρίς επαναλήψεις)
- Ο ίδιος **πολλαπλασιαστής ημερήσιου σερί** με τις συνεδρίες συνομιλίας
  (+25% ανά συνεχόμενη ημέρα δραστηριότητας, μέγ. 7 ημέρες)

Τέσσερα νέα σήματα ξεκλειδώνουν γύρω από μαθήματα:

- **Πρώτο Μάθημα** — ολοκλήρωσε το πρώτο σου μάθημα περιεχομένου.
- **10 Μαθήματα Ολοκληρωμένα** — ολοκλήρωσε 10 μαθήματα περιεχομένου.
- **Σερί 3 Αστεριών** — κέρδισε 3 αστέρια σε τρία μαθήματα στη σειρά.
- **Κύριος Επανάληψης** — κατακτείς 50 στοιχεία μέσω αραιωμένης επανάληψης.

Οι ολοκληρώσεις μαθημάτων μετρούν επίσης για το **ημερήσιο σερί** σου,
οπότε η μελέτη με μαθήματα περιεχομένου συμπληρώνει τον χάρτη θερμότητας
όπως και οι συνεδρίες συνομιλίας.

## Λειτουργίες αποθήκευσης

Τα μαθήματα λειτουργούν και στις **δύο** λειτουργίες αποθήκευσης — API
(backend) και Dexie (μόνο-browser / GitHub Pages). Η παρακολούθηση
σφαλμάτων σε επίπεδο στοιχείου και ο προγραμματισμός SRS εκτελούνται
ταυτόσημα έναντι IndexedDB στην ανάπτυξη μόνο-browser, οπότε οι χρήστες
που επισκέπτονται τη δημόσια τοποθεσία GitHub Pages λαμβάνουν πλήρη
βρόχο επανάληψης χωρίς backend.

Τι είναι *διαφορετικό* σε λειτουργία μόνο-browser: τα παρεπόμενα αποτελέσματα
βραβείου-XP / απόκτησης-σήματος ενεργοποιούνται μόνο σε λειτουργία API
(χρειάζονται τα hooks παιχνιδοποίησης του backend). Στη λειτουργία Dexie
εξακολουθείς να κερδίζεις XP και σήματα μέσω της διαδρομής συνεδρίας
συνομιλίας· η ολοκλήρωση μαθήματος απλώς δεν προσθέτει στο σύνολο αυτό
ακόμα.

---

## Απόρρητο

Όλη η πρόοδος μαθήματος, γραμμές στοιχειο-σφαλμάτων, κατάσταση ουράς
επανάληψης και δεδομένα προγραμματισμού παραμένουν **στη δική σου συσκευή**
σε λειτουργία API (σύστημα αρχείων) ή browser (IndexedDB). Τίποτα σχετικά
με ποιες λέξεις σε δυσκολεύουν δεν αποστέλλεται πουθενά.
