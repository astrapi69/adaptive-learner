# Ξεκινώντας

Το Adaptive Learner είναι ένας μαθησιακός συνοδός βασισμένος σε ένα
ερευνητικά υποστηριζόμενο μοντέλο έξι μεθόδων. Κάνεις μια σύντομη
αξιολόγηση για να ανακαλύψεις ποιες μέθοδοι σου ταιριάζουν καλύτερα,
και μετά τρέχεις συνεδρίες υποστηριζόμενες από ΤΝ μέσα από έναν κύκλο
επτά βημάτων. Η εφαρμογή μαθαίνει μαζί σου και προσαρμόζει τον τρόπο
που διδάσκει.

## Δοκίμασέ το τώρα

Ο πιο γρήγορος τρόπος να δοκιμάσεις το Adaptive Learner είναι η δημόσια
ανάπτυξη:

[**Άνοιξε τη live εφαρμογή**](https://astrapi69.github.io/adaptive-learner/){ .md-button .md-button--primary }

Αυτή τρέχει σε **Τοπική λειτουργία** — όλα τα δεδομένα σου παραμένουν
στον browser σου (IndexedDB), και οι κλήσεις ΤΝ πυροδοτούνται απευθείας
από τη σελίδα στο Anthropic, OpenAI ή Google Gemini χρησιμοποιώντας το
δικό σου API key. Χωρίς εμπλοκή backend.

## Εγκατάσταση ως Progressive Web App

Το Adaptive Learner είναι εγκαταστάσιμο. Σε σύγχρονους browsers θα δεις
μια προτροπή "Εγκατάσταση" ή "Προσθήκη στην αρχική οθόνη" την πρώτη
φορά που ανοίγεις τον ιστότοπο. Αποδέξου τη και το Adaptive Learner
γίνεται αυτόνομη εφαρμογή στο τηλέφωνο ή την επιφάνεια εργασίας σου,
εκκινήσιμη χωρίς καρτέλα browser.

Η εφαρμογή λειτουργεί επίσης offline για το Ταμπλό και προηγούμενες
συνεδρίες. Οι νέες συνεδρίες ΤΝ εξακολουθούν να χρειάζονται διαδίκτυο
επειδή ο πάροχος ΤΝ βρίσκεται εκτός browser.

## Τι χρειάζεσαι

- **Ένας σύγχρονος browser** (Chrome 100+, Firefox 100+, Safari 17+,
  Edge 100+). Η εφαρμογή χρησιμοποιεί IndexedDB, service workers και
  σύγχρονη JavaScript.
- **Ένα API key ΤΝ** για τουλάχιστον έναν από τους υποστηριζόμενους
  παρόχους (Anthropic, OpenAI ή Google Gemini). Τα δωρεάν πλάνα είναι
  συνήθως αρκετά για να ξεκινήσεις· δες [Ρυθμίσεις](settings.md) για
  το πώς να προσθέσεις ένα κλειδί.

## Τα πρώτα πέντε λεπτά

1. **Άνοιξε την εφαρμογή** και επέλεξε τη γλώσσα σου. Και οι 8
   γλώσσες UI είναι πλήρως μεταφρασμένες (DE, EN, ES, FR, EL, PT, TR, JA).
2. **Δημιούργησε το έργο μάθησής σου**: θέμα, στόχος, χρονοδιάγραμμα,
   λεπτά ανά ημέρα, συν προαιρετική ταξινομία θέματος και ετικέτες.
   Δες [Εισαγωγή](onboarding.md).
3. **Κάνε την αξιολόγηση 12 ερωτήσεων** ώστε η εφαρμογή να γνωρίζει σε
   ποιες μεθόδους μάθησης να βασιστεί. Σάρωσε αριστερά/δεξιά μεταξύ
   ερωτήσεων στο κινητό. Δες [Αξιολόγηση](assessment.md).
4. **Πρόσθεσε το API key ΤΝ σου** στις Ρυθμίσεις, Ή ρίξε το στο
   `~/.config/adaptive-learner/secrets.yaml` αν τρέχεις τον desktop
   launcher. Το UI Ρυθμίσεων δείχνει από ποιο επίπεδο προήλθε το κλειδί σου.
5. **Ξεκίνα την πρώτη σου συνεδρία**. Το κουμπί "Έναρξη συνεδρίας" του
   Ταμπλό σε οδηγεί σε μια μαθησιακή συνομιλία. Οι απαντήσεις ΤΝ ρέουν
   token-by-token· ο αξιολογητής διπλής προτροπής αποφασίζει κάθε βήμα
   κύκλου. Δες [Μαθησιακή συνεδρία](learning-session.md).
