# Διαδρομή μάθησης

Η σελίδα **Διαδρομή μάθησης** (`/learning-path`) απαντά με μια ματιά
σε δύο ερωτήσεις: *πού βρίσκομαι και τι ακολουθεί;* Από προεπιλογή
δείχνει την **Προσωπική** σου διαδρομή - μια συμπαγή λίστα δύο
επιπέδων με τα σύνολα μαθημάτων που έχεις κατεβάσει, ταξινομημένη
κατά την πιο πρόσφατη δραστηριότητά σου. Μια διαδραστική προβολή
**Γράφημα** παραμένει διαθέσιμη ως εναλλακτική.

## Άνοιγμα της Διαδρομής μάθησης

- Κάνε κλικ στη **Διαδρομή μάθησης** στην επάνω γραμμή πλοήγησης.
- Στον Πίνακα, χρησιμοποίησε το κουμπί γρήγορης ενέργειας **Διαδρομή
  μάθησης**.
- Στον Περιηγητή περιεχομένου (ενότητα «Τα μαθήματά μου»), κάνε κλικ
  στη **Διαδρομή μάθησης**.

## Προσωπική προβολή (προεπιλογή)

### Επίπεδο 1 - επισκόπηση συνόλων

Κάθε κατεβασμένο σύνολο είναι **μία γραμμή**:

| Στοιχείο | Σημασία |
|---------|---------|
| Εικονίδιο τομέα + τίτλος | Ο κύκλος μαθημάτων (εγκέφαλος = ψυχολογία, σημαία = γλώσσα, κώδικας = προγραμματισμός) |
| Μίνι διαδρομή προόδου | Μία κουκκίδα ανά μάθημα - γεμάτη = ολοκληρωμένο, μισή = σε εξέλιξη, κενή = δεν ξεκίνησε |
| Ποσοστό | Το μερίδιο των ολοκληρωμένων μαθημάτων του συνόλου |
| Τελευταία δραστηριότητα | Πότε δούλεψες τελευταία φορά σε αυτό το σύνολο («χθες», «πριν από 3 ημέρες») |
| Τρέχον μάθημα | Το μάθημα που πρέπει να κάνεις στη συνέχεια |
| Κουμπί ενέργειας | **Συνέχεια** / **Έναρξη** / **Διαθέσιμο επόμενο επίπεδο** / **Ολοκληρώθηκε** |

Τα σύνολα ταξινομούνται κατά τελευταία δραστηριότητα (το πιο
πρόσφατο πρώτο). Τα κατεβασμένα σύνολα που δεν έχεις αγγίξει πέφτουν
στο κάτω μέρος - και ανάμεσά τους, **το πιο πρόσφατα κατεβασμένο
σύνολο έρχεται πρώτο**, ώστε ένα σύνολο που μόλις κατέβασες να
βρίσκεται στην κορυφή της ομάδας που δεν έχει ξεκινήσει ακόμη, αντί
να χάνεται από κάτω. Όταν ολοκληρώσεις κάθε μάθημα ενός κύκλου
μαθημάτων και υπάρχει το επόμενο επίπεδο CEFR, η γραμμή προσφέρει
**Διαθέσιμο επόμενο επίπεδο**.

### Επίπεδο 2 - λεπτομέρειες μαθήματος

Κάνε κλικ σε μια γραμμή συνόλου για να την αναπτύξεις επιτόπου
(χωρίς αλλαγή σελίδας). Κάθε μάθημα δείχνει τον αριθμό και τον τίτλο
του, αστέρια (0–3, ή - αν δεν έχει δοκιμαστεί ποτέ), κατάκτηση ανά
κατεύθυνση (**αναγνώρισης** / **παραγωγής**) και την ημερομηνία της
τελευταίας σου προσπάθειας. Ο δείκτης ▶ επισημαίνει το τρέχον μάθημα
του συνόλου. Κάνε κλικ σε οποιοδήποτε μάθημα για να το ξεκινήσεις ή
να το συνεχίσεις.

Στο κάτω μέρος του αναπτυγμένου συνόλου:

- **Έναρξη προσαρμοστικού μαθήματος** - ένα μάθημα που δημιουργείται
  από τα λάθη σου σε αυτό το σύνολο.
- **Επανάληψη λαθών (N)** - επανάληψη των εκκρεμών λαθών του συνόλου
  (εμφανίζεται μόνο όταν υπάρχουν).

Κάνε ξανά κλικ στη γραμμή του συνόλου για να τη συμπτύξεις.

### Μόνο τα δικά μου / Όλα τα σετ

Ο διακόπτης **[Μόνο τα δικά μου] [Όλα τα σετ]** καθορίζει πόσο
εμφανής είναι η ενότητα *Δεν έχει ληφθεί* στο κάτω μέρος. Το **Μόνο
τα δικά μου** (προεπιλογή) την κρατά συμπτυγμένη· το **Όλα τα σετ**
την αναπτύσσει, ώστε να μπορείς να περιηγηθείς και να κατεβάσεις
περισσότερους κύκλους μαθημάτων. Η επιλογή σου απομνημονεύεται.

### Δεν έχει ληφθεί

Μια πτυσσόμενη ενότητα στο κάτω μέρος απαριθμεί τα σύνολα
περιεχομένου που δεν έχεις κατεβάσει ακόμη, το καθένα με ένα κουμπί
**Λήψη**. Η λήψη ενός συνόλου το μεταφέρει πάνω, στην ενεργή σου
λίστα.

## Προβολή γραφήματος (εναλλακτική)

Χρησιμοποίησε τον διακόπτη **Προσωπικό / Γράφημα** στην κεφαλίδα για
να ανοίξεις το διαδραστικό γράφημα με δυνατότητα μεγέθυνσης.
Παρουσιάζει κάθε κατεβασμένο σύνολο και μάθημα ως κόμβους που μπορείς
να σύρεις, να φιλτράρεις, να αναζητήσεις και να εξετάσεις. Το γράφημα
(και η μεγαλύτερη βιβλιοθήκη σχεδίασής του) φορτώνεται μόνο όταν
μεταβείς σε αυτό, ώστε η προεπιλεγμένη Προσωπική προβολή να παραμένει
γρήγορη.

### Κόμβοι μαθημάτων και συνόλων

Κάθε κόμβος μαθήματος δείχνει τον αριθμό και τον τίτλο του, αστέρια,
κατάκτηση ανά κατεύθυνση (**Α ✓** / **Π ✓**), XP, ένα χρώμα
κατάστασης, μια παλλόμενη έμφαση στο προτεινόμενο επόμενο μάθημα, και
ένα εικονίδιο κλειδαριάς όταν δεν πληρείται μια προϋπόθεση. Ένας
κόμβος ομάδας συνόλου περικλείει τα μαθήματα ενός συνόλου με μια
γραμμή προόδου και μια σύνοψη κατάκτησης· κάνε κλικ στην κεφαλίδα του
για σύμπτυξη ή ανάπτυξη.

### Στοιχεία ελέγχου γραφήματος

- **Φίλτρο κατάστασης** - όλα / δεν ξεκίνησε / σε εξέλιξη /
  κατακτημένο.
- **Φίλτρο κατεύθυνσης** - όλα, ή μόνο μαθήματα στα οποία λείπει η
  κατάκτηση αναγνώρισης ή παραγωγής.
- **Αναζήτηση** - επισημαίνει τα αποτελέσματα· πάτησε **Enter** για να
  μεταβείς στο πρώτο.
- **Στατιστικά** - ολοκληρωμένα μαθήματα, κατακτημένα δεκτικά,
  κατακτημένα παραγωγικά.
- **Εμφάνιση ομάδων σφαλμάτων** - κοινά μοτίβα λαθών (π.χ. *γένος
  άρθρου*) με ένα προσαρμοστικό μάθημα με ένα κλικ.
- **Επαναφορά διάταξης** - επαναφέρει την αυτόματη διάταξη και
  διαγράφει τις θέσεις που έσυρες (αποθηκεύονται ανά χρήστη στον
  αποθηκευτικό χώρο του browser).

## Πρόσβαση με πληκτρολόγιο

Όλα τα στοιχεία ελέγχου είναι προσβάσιμα με το πληκτρολόγιο: το
**Tab** μετακινεί την εστίαση, το **Enter / Space** ενεργοποιεί μια
γραμμή, ένα μάθημα ή ένα κουμπί. Οι στόχοι αφής έχουν τουλάχιστον
44 px και η σελίδα αναδιατάσσεται σωστά μέχρι πλάτος 375 px.

## Συμβουλές

- Το **τρέχον μάθημα** (▶) είναι πάντα το καλύτερο επόμενο βήμα σου -
  με βάση το ιστορικό των λαθών σου, όχι μόνο τη σειρά των μαθημάτων.
- Ένα μάθημα σε παύση μπορεί πάντα να συνεχιστεί από τη γραμμή του ή
  από την κάρτα παυσαρισμένων μαθημάτων στον Πίνακα.
- Μόλις επιτευχθεί τόσο η κατάκτηση **αναγνώρισης** όσο και η
  κατάκτηση **παραγωγής**, ένα μάθημα θεωρείται πλήρως κατακτημένο.
