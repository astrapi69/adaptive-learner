# Τι νέο υπάρχει (v1.61 – v1.69)

Μια επισκόπηση προσανατολισμένη στον χρήστη για τις εκδόσεις από την
v1.61.0 και μετά. Οι πλήρεις, τεχνικές σημειώσεις ανά έκδοση
βρίσκονται στα
[GitHub Releases](https://github.com/astrapi69/adaptive-learner/releases).

---

## v1.69.0 — Σύνδεσμοι παραδειγμάτων + προτάσεις βιβλίων

- **Σύνδεσμοι παραδειγμάτων στη θεωρία:** Ένα βήμα θεωρίας μπορεί να
  φέρει έναν προαιρετικό σύνδεσμο «Προβολή παραδείγματος».
- **Προτάσεις βιβλίων ανά τομέα** στον Content Browser
  ([Προτάσεις βιβλίων](content-creation/books.md)).
- **Συντόμευση Enter και στο Fehler-Replay** («Επανάληψη σφαλμάτων»).
- **Διόρθωση backup:** Ο τίτλος του set διαβάζεται σωστά κατά την
  επαναφορά από το manifest.

## v1.68.0 — Εξαγωγή αποτελέσματος + σύνδεσμοι επιστροφής σε θεωρία

- **Εξαγωγή αποτελέσματος μαθήματος:** «Αντιγραφή αποτελέσματος» /
  «Αποθήκευση ως αρχείο» (αναφορά Markdown για βοηθούς AI).
- **Σύνδεσμοι επιστροφής σε θεωρία:** Μετάβαση από μια άσκηση στην
  αντίστοιχη θεωρία και πίσω.
- **Άσκηση αντιστοίχισης ανανεωμένη:** χρωματιστά ζεύγη + badges
  αριθμών (ασφαλή για αχρωματοψία).
- **Αντίθεση Dark-Mode** διορθωμένη σε διάφορα σημεία.

## v1.67.1 — Backup-Restore + σταθερότητα deploy

- Συστηματική διόρθωση **επαναφοράς backup**.
- Αυτόματη επαναφόρτωση σε παρωχημένο chunk deploy.
- Βελτίωση φίλτρου subject (κρυμμένο σε ≤ 1 subject, το πιο
  χρησιμοποιημένο πρώτα).

## v1.65.0 — Συνεχίσιμο assessment + συντόμευση Enter

- **Συνεχίσιμο assessment:** Διακοπή του test και αργότερα συνέχιση
  από εκεί που σταμάτησες.
- **Συντόμευση Enter:** Το Enter ελέγχει μια απαντημένη άσκηση και
  προχωρά (εναλλάσσεται στις Ρυθμίσεις → Μάθηση).
- Σαφέστερες ασκήσεις αντιστοίχισης + πέρασμα Design-Token.

## v1.64.0 — Ανανέωση Onboarding

- **Γρήγορη εκκίνηση μόνο με Όνομα + Θέμα**· τα υπόλοιπα παίρνουν
  προεπιλογές.
- Προαιρετικός **οδηγός Onboarding** (μία ερώτηση ανά οθόνη).
- Το **assessment είναι πλέον προαιρετικό** ([Onboarding](user-guide/onboarding.md)).

## v1.63.0 — Presets theme WCAG-AA

- **6 προτεινόμενα themes** (Catppuccin Latte/Mocha, Supabase,
  Graphite, Soft Pop, Amethyst Haze), υπολογιστικά συμβατά με AA
  ([Σύστημα Theme](developer/themes.md)).
- Συστηματικός έλεγχος i18n· φίλτρο Dashboard προσανατολισμένο στον
  χρήστη.

## v1.62.0 — Ακεραιότητα backup + προέλευση build

- Ενίσχυση της **επαναφοράς backup** (μετατροπή τύπων δεδομένων,
  σειρά FK).
- Το About δείχνει πραγματικές πληροφορίες build αντί για «unknown».

## v1.61.0 — Συμμόρφωση κουμπιών + Lektions-Resume

- Συμμόρφωση κουμπιών shadcn σε όλη την εφαρμογή.
- Το **μάθημα σε παύση** συνεχίζει από το ακριβές βήμα.
- Επικύρωση περιεχομένου μεταξύ Repos.

## Μεγαλύτεροι άξονες της περιόδου

  Trust, προτεινόμενα repos, τοπικές αξιολογήσεις
  ([Πολλαπλά Content-Repositories](features/content-repos.md)).
- **Backup ως πλήρες snapshot** με Cross-Identity-Import
  ([Backup και επαναφορά](features/backup.md)).
