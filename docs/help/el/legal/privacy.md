## Αποθήκευση στο πρόγραμμα περιήγησής σας

Ό,τι δημιουργείτε στην εφαρμογή αποθηκεύεται τοπικά από το πρόγραμμα περιήγησής
σας σε IndexedDB και localStorage. Η αποθήκευση αυτή είναι απολύτως απαραίτητη
για τη λειτουργία της εφαρμογής και εμπίπτει στην εξαίρεση της § 25 παρ. 2 αρ. 2
του γερμανικού TDDDG· δεν απαιτείται συγκατάθεση. Τίποτα δεν διαβιβάζεται σε
διακομιστή. Μπορείτε ανά πάσα στιγμή να εξαγάγετε ή να διαγράψετε τα δεδομένα
στις Ρυθμίσεις ή να διαγράψετε τα δεδομένα ιστότοπου στο πρόγραμμα περιήγησής
σας.

Εάν καταχωρίσετε κλειδί API για έναν πάροχο AI, αποθηκεύεται επίσης μόνο
τοπικά.

## Φόρτωση μαθησιακού περιεχομένου

Τα σετ μαθημάτων φορτώνονται από αποθετήρια περιεχομένου στο GitHub
(`raw.githubusercontent.com`, `api.github.com`). Κατά τη διαδικασία αυτή το
πρόγραμμα περιήγησής σας αποστέλλει τη διεύθυνση IP σας στη GitHub. Αποδέκτης
είναι η GitHub, Inc. (βλ. ανωτέρω)· νομική βάση είναι η παροχή της λειτουργίας
που ζητήσατε (άρθρο 6 παρ. 1 στοιχ. β) και στ) ΓΚΠΔ). Εάν συνδέσετε δικό σας
αποθετήριο με διακριτικό πρόσβασης (access token) GitHub, το διακριτικό
παραμένει στο πρόγραμμα περιήγησής σας και αποστέλλεται μόνο στη GitHub.
