# Αλλαγή της θύρας (και διατήρηση των δεδομένων σου)

Ο desktop launcher σού επιτρέπει να αλλάξεις τη θύρα στην οποία τρέχει
ο Adaptive Learner (η προεπιλογή είναι **8501**). Αυτό είναι χρήσιμο
όταν μια άλλη εφαρμογή χρησιμοποιεί ήδη αυτή τη θύρα - υπάρχει όμως μία
συνέπεια που αξίζει να γνωρίζεις πριν το κάνεις.

## Γιατί η θύρα έχει σημασία για τα δεδομένα σου

Ο χώρος αποθήκευσης μιας web εφαρμογής είναι δεμένος με την ακριβή της
διεύθυνση web, συμπεριλαμβανομένης της θύρας. Οι διευθύνσεις
`http://localhost:8501` και `http://localhost:8502` είναι για το
πρόγραμμα περιήγησής σου δύο **διαφορετικές** διευθύνσεις, και καθεμία
έχει τον δικό της ξεχωριστό χώρο αποθήκευσης.

Τι σημαίνει αυτό στην πράξη εξαρτάται από τον τρόπο που τρέχεις τον
Adaptive Learner:

- **Λειτουργία διακομιστή** (η προεπιλογή για τον desktop launcher). Τα
  σύνολά σου, τα μαθήματα και η πρόοδος βρίσκονται στο δικό backend της
  εφαρμογής, όχι στο πρόγραμμα περιήγησης. **Δεν** επηρεάζονται από μια
  αλλαγή θύρας - η εφαρμογή τα βρίσκει ξανά αυτόματα στη νέα διεύθυνση.
- **Λειτουργία αποθήκευσης στο πρόγραμμα περιήγησης** (η επιλογή που
  μπορείς να ενεργοποιήσεις στις *Ρυθμίσεις > Γενικά > Λειτουργία
  αποθήκευσης*, και η λειτουργία που χρησιμοποιεί η δημόσια web
  έκδοση). Τα σύνολά σου, η πρόοδος και οι ασκήσεις που έγραψες ο ίδιος
  βρίσκονται **στο πρόγραμμα περιήγησης**, δεμένα με την τρέχουσα
  διεύθυνση. Μετά από μια αλλαγή θύρας η εφαρμογή ανοίγει στη νέα
  διεύθυνση με κενό χώρο αποθήκευσης στο πρόγραμμα περιήγησης, οπότε
  μοιάζει με νέα αρχή. **Τα δεδομένα σου δεν διαγράφονται** -
  εξακολουθούν να είναι αποθηκευμένα στην προηγούμενη θύρα, απλώς δεν
  είναι ορατά στη νέα.

## Μετάφερε τα δεδομένα σου στη νέα θύρα

Αν χρησιμοποιείς τη λειτουργία αποθήκευσης στο πρόγραμμα περιήγησης και
έχεις ήδη αλλάξει τη θύρα, τα δεδομένα σου σε περιμένουν στην παλιά
διεύθυνση. Φέρ' τα στη νέα με ένα backup:

1. Πήγαινε **πίσω στην προηγούμενη θύρα** (για παράδειγμα
   `http://localhost:8501`). Τα δεδομένα σου εμφανίζονται ξανά.
2. Άνοιξε **Ρυθμίσεις > Δεδομένα > Δημιουργία αντιγράφου ασφαλείας** και
   αποθήκευσε το αρχείο `.alb`.
3. Πήγαινε στη **νέα θύρα**.
4. Στην οθόνη καλωσορίσματος επίλεξε **Επαναφορά από υπάρχον αντίγραφο ασφαλείας** και διάλεξε το αρχείο `.alb`. Όλα - σύνολα, πρόοδος,
   ασκήσεις και οι ρυθμίσεις σου - επαναφέρονται.

Δες τη σελίδα [Backup και επαναφορά](../features/backup.md) για
περισσότερα σχετικά με τα backups.

## Απόφυγε την έκπληξη: πρώτα backup

Η πιο ασφαλής συνήθεια είναι να **εξάγεις ένα backup πριν αλλάξεις τη
θύρα**, ώστε να μπορείς να το επαναφέρεις στη νέα διεύθυνση αν λείπει
κάτι. Ένα τακτικό backup είναι γενικά καλή ασφάλεια - σου επιτρέπει
επίσης να μεταφέρεις τη μάθησή σου ανάμεσα σε συσκευές.

## Η αλλαγή της θύρας δεν ανοίγει την εφαρμογή στο δίκτυο

Όποια θύρα κι αν επιλέξεις, η εφαρμογή συνεχίζει να ακούει μόνο στο
`127.0.0.1` - είναι προσβάσιμη από αυτόν τον υπολογιστή, όχι από άλλες
συσκευές. Δεν έχει σύνδεση χρήστη, οπότε η πρόσβαση από το κινητό σου ή
από άλλο μηχάνημα είναι ένα ξεχωριστό, συνειδητό βήμα
(`ADAPTIVE_LEARNER_BIND_ADDRESS=0.0.0.0`), και έχει νόημα μόνο σε ένα
δίκτυο που εμπιστεύεσαι - δες
[Ξεκίνα τον desktop launcher](launcher.md) («Ποιος μπορεί να φτάσει
στην εφαρμογή»).
