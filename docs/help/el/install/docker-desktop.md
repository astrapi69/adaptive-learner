# Εγκατάσταση του Docker Desktop

Ο Adaptive Learner τρέχει ως μια μικρή ομάδα από containers στον
δικό σου υπολογιστή. Ο desktop launcher ξεκινά και σταματά αυτά τα
containers για σένα, αλλά χρειάζεται πρώτα να είναι εγκατεστημένο
και να τρέχει το **Docker**. Αυτός ο οδηγός σε καθοδηγεί στην
εγκατάσταση του Docker Desktop.

## Τι χρειάζεσαι

- Περίπου 800 MB λήψης για το ίδιο το Docker Desktop.
- Περίπου 2 GB χώρου στον δίσκο για το image του Adaptive Learner
  κατά την πρώτη εκτέλεση (αυτό συμβαίνει μία φορά· οι επόμενες
  εκκινήσεις είναι γρήγορες).
- Λίγα λεπτά για το πρώτο build (5-10 λεπτά είναι φυσιολογικά).

## Εγκατάσταση

1. Άνοιξε την επίσημη σελίδα λήψης του Docker Desktop:
   [docs.docker.com/desktop](https://docs.docker.com/desktop/).
2. Κατέβασε το πρόγραμμα εγκατάστασης για το λειτουργικό σου
   σύστημα (Windows, macOS ή Linux).
3. Εκτέλεσε το πρόγραμμα εγκατάστασης και ακολούθησε τις οδηγίες.
   Αποδέξου τις προεπιλογές, εκτός αν έχεις λόγο να τις αλλάξεις.
4. Ξεκίνα το Docker Desktop και περίμενε μέχρι το εικονίδιο της
   φάλαινας να δείξει "Docker Desktop is running".

## Ξεκίνα τον launcher

Μόλις τρέχει το Docker Desktop, ξεκίνα ξανά τον launcher του
Adaptive Learner. Ελέγχει πρώτα το Docker, μετά κατεβάζει, κάνει
build και ξεκινά την εφαρμογή, και τέλος προσφέρει ένα κουμπί
"Άνοιγμα στο πρόγραμμα περιήγησης".

Αν το Docker δεν τρέχει ακόμη όταν ξεκινάς τον launcher, εμφανίζει
μια ειδοποίηση με ένα κουμπί "Έναρξη Docker", ώστε να το εκκινήσεις
χωρίς να φύγεις από τον launcher.

Η εφαρμογή που τρέχει είναι από προεπιλογή προσβάσιμη μόνο από αυτόν
τον υπολογιστή (`127.0.0.1`). Δεν έχει σύνδεση χρήστη· το να τη
διαθέσεις σε άλλες συσκευές είναι συνειδητό βήμα - δες
[Ξεκίνα τον desktop launcher](launcher.md).

## Είναι ασφαλές να εγκαταστήσω το Docker;

Ναι. Το Docker Desktop φτιάχνεται από τη Docker, Inc., μια γνωστή
εταιρεία, και χρησιμοποιείται από εκατομμύρια προγραμματιστές
παγκοσμίως. Είναι ο συνηθισμένος τρόπος για να τρέχεις
containerized εφαρμογές σε έναν προσωπικό υπολογιστή.

Ο Adaptive Learner χρησιμοποιεί το Docker μόνο για να τρέχει τα
δικά του containers στον υπολογιστή σου. Τα δεδομένα μάθησής σου
παραμένουν τοπικά· με την εγκατάσταση του Docker δεν αποστέλλεται
τίποτα από τα δεδομένα σου στη Docker, Inc. Μπορείς να
απεγκαταστήσεις το Docker Desktop οποιαδήποτε στιγμή μέσα από το
λειτουργικό σου σύστημα, όπως κάθε άλλη εφαρμογή.

## Αντιμετώπιση προβλημάτων

- **Ο launcher λέει ότι το Docker δεν τρέχει.** Ξεκίνα το Docker
  Desktop, περίμενε την κατάσταση "running" και μετά κάνε κλικ στο
  "Δοκίμασε ξανά".
- **Η θύρα χρησιμοποιείται ήδη.** Ο launcher το εντοπίζει και
  προτείνει μια εναλλακτική θύρα· αποδέξου την πρόταση.
- **Κάτι άλλο πήγε στραβά.** Ξεκίνα ξανά τον launcher με το flag
  `--debug` και μοιράσου το αρχείο `launcher-debug.log` που
  δημιουργείται:

  ```bash
  python3 -m adaptive_learner_launcher --debug
  ```
