# Content-Repos - δημοσίευση του δικού σου repository

Ο Adaptive Learner διαθέτει μια επίσημη βιβλιοθήκη περιεχομένου, αλλά το
σύστημα περιεχομένου είναι ανοιχτό: μπορείς να διατηρείς το **δικό σου
Content-Repository** στο GitHub, να το συνδέσεις στην εφαρμογή και να
το κάνεις διαθέσιμο σε άλλους μαθητές. Αυτή η σελίδα δίνει την
επισκόπηση· οι πλήρεις οδηγίες βήμα προς βήμα βρίσκονται στον
**[Οδηγό Content-Repo](https://github.com/astrapi69/adaptive-learner/blob/main/docs/reference/CONTENT-REPO-GUIDE.md)**.

---

## Τι είναι ένα Content-Repo;

Ένα Content-Repo είναι ένα GitHub repository που περιέχει **σύνολα
περιεχομένου** στη μορφή του Adaptive Learner. Ένα σύνολο είναι μια
συλλογή μαθημάτων για ένα ζεύγος γλωσσών και ένα επίπεδο (για
παράδειγμα «Ισπανικά A1 για γερμανόφωνους») ή για έναν τομέα γνώσης
(για παράδειγμα «Βασικά στοιχεία Python»).

Η επίσημη βιβλιοθήκη και όλα τα repos χρηστών χρησιμοποιούν την **ίδια
μορφή** - δεν υπάρχει ξεχωριστό «επίσημο» σχήμα. Από τη στιγμή που το
repo σου περνά την επικύρωση, είναι πλήρως ισότιμη πηγή περιεχομένου.
Δεν χρειάζεσαι ποτέ δικό σου διακομιστή: ένα Content-Repo είναι απλώς
αρχεία σε ένα Git repository.

---

## Προϋποθέσεις

- Ένα **GitHub repository** (δημόσιο· γίνεται και ιδιωτικό, μέσω ενός
  token ανά repo).
- Ένα **`manifest.yaml`** στη ρίζα, που παραθέτει τα σύνολά σου.
- Μαθήματα στη **μορφή μαθήματος**.
- Python 3 με PyYAML, για τοπική επικύρωση πριν τη δημοσίευση.

Οι έγκυρες αναφορές για τη μορφή βρίσκονται στο επίσημο Content-Repo:

- [`docs/GETTING-STARTED.md`](https://github.com/astrapi69/adaptive-learner-content/blob/main/docs/GETTING-STARTED.md)
- [`docs/LESSON-FORMAT.md`](https://github.com/astrapi69/adaptive-learner-content/blob/main/docs/LESSON-FORMAT.md)

---

## Δομή καταλόγων

Ένα Content-Repo ακολουθεί ένα σταθερό δέντρο. Η γλώσσα προέλευσης (η
γλώσσα στην οποία είναι γραμμένες οι εξηγήσεις) είναι ο ανώτατος
φάκελος· η γλώσσα στόχος και το επίπεδο σχηματίζουν τον επόμενο:

```
my-content-repo/
  manifest.yaml                  # root manifest: lists every set
  sets/
    de/                          # source language (German speakers)
      es-a1/                     # target language + level (Spanish A1)
        manifest.yaml            # set manifest: lists the lessons
        lessons/
          01-greetings.json      # one JSON file per lesson (NN-slug.json)
        assets/                  # optional: images / audio
  scripts/validate_content.py    # the validator (from the starter kit)
```

---

## Τοπική επικύρωση

```bash
pip install pyyaml
python3 scripts/validate_content.py
```

Κωδικός εξόδου 0 όταν κάθε σύνολο περνά, διαφορετικά 1 με αναφορά ανά
αρχείο. Ελέγχει το σχήμα, τη δομή καταλόγων και τα ελάχιστα ποιότητας
(τουλάχιστον 5 ασκήσεις, 2 τύποι ασκήσεων, 1 βήμα θεωρίας ανά μάθημα,
μη κενά πεδία καρτών κ.ο.κ.).

---

## Πώς εμφανίζεται στην εφαρμογή;

Μόλις το repo σου επικυρωθεί, ένας μαθητής το συνδέει στις
**Ρυθμίσεις > Δεδομένα > Αποθετήρια περιεχομένου**: επικολλά το URL, η
εφαρμογή φέρνει το manifest της ρίζας, κάνει τεχνική επικύρωση,
συγχρονίζει και αποθηκεύει τα σύνολα στην cache. Αυτά εμφανίζονται
έπειτα στον **Περιηγητή περιεχομένου** με ένα badge προέλευσης. Τα
repos μπορούν επίσης να κοινοποιηθούν μέσω ενός συνδέσμου `/add-repo`
μαζί με έναν QR-Code.

Ένα repo φτάνει στην ενότητα **Προτεινόμενα αποθετήρια** της εφαρμογής
μόνο μέσω του επιμελημένου `recommended-repos.json` της ομάδας του
έργου - το κανάλι επίσημης σύστασης (Trust 3).

## Επίπεδα Trust

Το επίπεδο Trust δείχνει στον μαθητή πόσο ελεγμένο είναι το
περιεχόμενο. Αφορά την προέλευση και τον έλεγχο, όχι μια ετυμηγορία για
την ποιότητα.

| Επίπεδο | Όνομα | Σημασία |
|-------|------|---------|
| **1** | Επικυρωμένο | Σωστό σχήμα, τα ελάχιστα ποιότητας πληρούνται - αυτόματα κατά τον συγχρονισμό. Το περιεχόμενο δεν έχει ελεγχθεί μεμονωμένα. |
| **2** | Επαληθευμένο | Συνεισφορά της κοινότητας, ελεγμένο από έναν συντηρητή ως προς την ορθότητα του περιεχομένου. |
| **3** | Επίσημο | Επιμελημένο και ποιοτικά ελεγμένο από την ομάδα του έργου. |

Το Trust 2+ προϋποθέτει περισσότερα από τα τεχνικά ελάχιστα: ακριβείς
μεταφράσεις, σωστά άρθρα/γένη, πλήρεις τόνους, λογική πρόοδο, εύλογες
παραπλανητικές επιλογές και πολιτισμική ακρίβεια. Ένας προαιρετικός
**έλεγχος με AI** μέσα στην εφαρμογή βοηθά τους συντάκτες να εντοπίσουν
τέτοια προβλήματα πριν την κοινοποίηση (δες EXP-033)· είναι
συμβουλευτικός και δεν μπλοκάρει ποτέ την κοινοποίηση.

## Αμοιβαιότητα για σεμινάρια και ιστοσελίδες (EXP-029)

Τα μαθήματα και οι τομείς μπορούν να φέρουν **συνοδευτικά μέσα**
(βίντεο, podcasts, άρθρα, βιβλία, σεμινάρια, ιστοσελίδες). Το φίλτρο
για τα εμπορικά μέσα είναι η **αμοιβαιότητα, όχι η τιμή**: τα δωρεάν
μέσα επιτρέπονται πάντα· τα εμπορικά σεμινάρια/ιστοσελίδες μόνο όταν ο
πάροχος παραπέμπει πίσω με σύνδεσμο, διατηρεί δικό του Content-Repo ή
έχει μια τεκμηριωμένη συνεργασία. Έτσι οι συντάκτες περιεχομένου
γίνονται συνεργάτες του οικοσυστήματος αντί για διαφημιστές.
Λεπτομέρειες στο `docs/explorations/EXP-029-media-reciprocity.md`.

## Το Starter-Kit ως πρότυπο

Η ταχύτερη αρχή είναι το έτοιμο Starter-Repo
**[`astrapi69/adaptive-learner-content-test`](https://github.com/astrapi69/adaptive-learner-content-test)**:
περιέχει `docs/`, πρότυπα ανά τομέα, ένα πλήρες παράδειγμα μαθήματος
(το φαινόμενο Inception), ένα εκτελέσιμο παράδειγμα συνόλου, το
`books.yaml` και τον validator. Κάνε fork, αντικατάστησε το παράδειγμα
μαθήματος με το δικό σου, καταχώρισέ το στο `manifest.yaml` της ρίζας,
κάνε επικύρωση και σύνδεσε το repo στην εφαρμογή.
