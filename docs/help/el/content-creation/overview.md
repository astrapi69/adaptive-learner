# Δημιουργία μαθημάτων - Επισκόπηση

Ο Adaptive Learner ζει από το περιεχόμενο. Μπορείς να φτιάξεις δικά
σου μαθήματα - απευθείας στην εφαρμογή ή ως αρχείο σε μορφή
Content-Repo - και να τα μοιραστείς με την κοινότητα. Αυτή η σελίδα
δίνει την επισκόπηση· οι αναλυτικές λεπτομέρειες μορφής βρίσκονται
στις συνδεδεμένες πηγές.

---

## Δύο τρόποι δημιουργίας μαθημάτων

### 1. Στην εφαρμογή: ο Lektions-Creator

Ο **Lektions-Creator** στο `/create-lesson` είναι ένας οδηγός 4
βημάτων (Μεταδεδομένα → Επεξεργαστής καρτών → Επεξεργαστής ασκήσεων →
Αποθήκευση/Κοινοποίηση) και δεν χρειάζεται **κλειδί AI**:

- Διάταξη καρτών με Drag-and-drop ή **εισαγωγή από CSV**· οι κάρτες
  μπορούν να φέρουν μια **ανεβασμένη εικόνα**.
- Στο βήμα των μεταδεδομένων επιλέγεις τον **τομέα γνώσης** (π.χ.
  γλώσσα, προγραμματισμός, ψυχολογία, εκπαίδευση σκύλων,
  κυκλοφοριακή αγωγή).
- **Αυτόματη δημιουργία** ασκήσεων από τις κάρτες ή **πλήρης
  επεξεργασία με το χέρι** στο βήμα 3: κάθε βασικός τύπος άσκησης
  μπορεί να δημιουργηθεί, να αλλάξει και να προστεθεί χειροκίνητα -
  συμπεριλαμβανομένης της εγγενούς **πολλαπλής επιλογής** με έναν
  εμφανή διακόπτη **μονής/πολλαπλής επιλογής**.
- Η **υπαγόρευση** (ηχητική υπαγόρευση) είναι διαθέσιμη απευθείας
  στον επιλογέα τύπων άσκησης· το ηχητικό κλιπ το ανεβάζεις ως
  αρχείο (ενσωματώνεται στο μάθημα) ή δίνεις μια διαδρομή asset. Το
  μάθημα μαρκάρεται αυτόματα ως εξαρτώμενο από επέκταση.
- Ο **οδηγός δημιουργίας επεκτάσεων** φτιάχνει με υποστήριξη AI και
  τους πέντε τύπους ασκήσεων επέκτασης (κατηγοριοποίηση, διόρθωση
  σφαλμάτων, κατανόηση κειμένου, βαθμολογημένο κουίζ, υπαγόρευση).
- **Πρότυπα** (Κενό / Λεξιλόγιο / Γραμματική / Συνομιλία) και
  **αυτόματη αποθήκευση προσχεδίου**.
- **Προεπισκόπηση** στον πραγματικό προβολέα μαθημάτων πριν την
  αποθήκευση.
- **Τοπική αποθήκευση** ή **κοινοποίηση μέσω Pull Request**.

Σημεία εισόδου υπάρχουν στον Content Browser και στο Dashboard.

#### Μάθημα γνώσης από κείμενο (λειτουργία βιβλίου)

Η πέμπτη κάρτα προτύπου, **«Μάθημα γνώσης από κείμενο»**, ξεκινά μια
δική της ροή 3 βημάτων (Μεταδεδομένα → Κείμενο βιβλίου → Έλεγχος):
επικόλλησε μια ενότητα (π.χ. ένα κεφάλαιο) του εγχειριδίου σου - η
τεχνητή νοημοσύνη τη διατυπώνει **με δικά της λόγια** ως βήματα
θεωρίας (ποτέ ως αντίγραφο) και δημιουργεί κατάλληλες ασκήσεις που
παραπέμπουν στο βήμα θεωρίας τους. Προαιρετικά μπορείς να καταχωρίσεις
τα στοιχεία του βιβλίου (τίτλος, συγγραφέας, URL, ISBN/ASIN)· αυτά
διατηρούνται όταν επεξεργαστείς αργότερα το μάθημα.

Αντί να επικολλήσεις κείμενο, μπορείς επίσης να **ανεβάσεις ένα αρχείο
βιβλίου** (EPUB, DOCX, TXT ή Markdown, έως 20 MiB). Το αρχείο
αναλύεται εξ ολοκλήρου **στο πρόγραμμα περιήγησης** - τίποτα δεν
αποστέλλεται σε διακομιστή - και τα κεφάλαια που εντοπίζονται
εμφανίζονται ως **λίστα με πλαίσια επιλογής**. Ενότητες που μοιάζουν
με εισαγωγικό ή τελικό υλικό (πρόλογος, γλωσσάρι, ευρετήριο, …) είναι
**αποεπιλεγμένες από προεπιλογή** μέσω ευρετικής, αλλά παραμένουν
ορατές και επιλέξιμες:

- **Μία ενότητα επιλεγμένη** - εισάγεται στο πεδίο κειμένου (με
  προεπισκόπηση· ένα ήδη γεμάτο πεδίο ζητά πρώτα επιβεβαίωση).
- **Περισσότερες ενότητες επιλεγμένες** - η **μαζική δημιουργία**
  παράγει **ένα μάθημα ανά ενότητα** και τα αποθηκεύει μαζί ως σύνολο
  πολλών μαθημάτων.

Κατά την **επεξεργασία** ενός συνόλου πολλών μαθημάτων, ένας
**επιλογέας μαθήματος** ρωτά πρώτα ποιο μάθημα θέλεις να ανοίξεις· τα
μαθήματα από κείμενο βιβλίου ανοίγουν απευθείας τον επεξεργαστή
ασκήσεων.

Σε αντίθεση με τη διαδρομή των καρτών, αυτή η λειτουργία χρειάζεται
ένα **ρυθμισμένο κλειδί τεχνητής νοημοσύνης**. Επικόλλησε μόνο κείμενα
για τα οποία έχεις τα δικαιώματα ή που προορίζονται για προσωπική
χρήση.

### 2. Ως αρχείο: η μορφή Content-Repo

Ένα μάθημα είναι ένα αρχείο JSON μέσα σε ένα **Content-Set**. Τα
sets βρίσκονται σε δημόσια GitHub-Repos και ακολουθούν ένα σταθερό
δέντρο καταλόγων (`sets/{Quellsprache}/{Zielsprache-Niveau}/`). Οι
έγκυροι οδηγοί βρίσκονται στο repository περιεχομένου:

- **Πρώτα βήματα:**
  [`docs/GETTING-STARTED.md`](https://github.com/astrapi69/adaptive-learner-content/blob/main/docs/GETTING-STARTED.md)
- **Μορφή μαθήματος:**
  [`docs/LESSON-FORMAT.md`](https://github.com/astrapi69/adaptive-learner-content/blob/main/docs/LESSON-FORMAT.md)

Ένα έτοιμο **Starter-Kit** για παρατήρηση και αντιγραφή είναι το
[`astrapi69/adaptive-learner-content-test`](https://github.com/astrapi69/adaptive-learner-content-test).

## Κοινοποίηση μέσω Pull Request

Η κοινοποίηση μαθήματος δημιουργεί ένα πραγματικό **Pull Request**
(Fork → Commit → PR). Η εφαρμογή προτείνει αυτόματα τη σωστή
διαδρομή και ένα αριθμημένο όνομα αρχείου και αναγνωρίζει
διπλότυπα/παραλλαγές. Η **pipeline επικύρωσης** του repo
περιεχομένου ελέγχει κάθε υποβληθέν μάθημα σε κάθε PR (σχήμα, ζεύγος
γλωσσών, ελάχιστα ποιότητας), ώστε μόνο καθαρό περιεχόμενο να φτάνει
στον κατάλογο. Προαιρετικά υπάρχει έλεγχος περιεχομένου
υποβοηθούμενος από AI· δεν μπλοκάρει ποτέ την κοινοποίηση.
