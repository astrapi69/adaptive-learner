# Επισκόπηση ολοκλήρωσης σετ

Παλιότερα, η ολοκλήρωση κάθε μαθήματος ενός σετ κατέληγε σε μια
κάρτα τροπαίου - "όλα τα N μαθήματα ολοκληρώθηκαν" - και τίποτα άλλο,
παρόλο που η εφαρμογή καταγράφει ήδη, ανά άσκηση, τον αριθμό
σφαλμάτων, τη σειρά επιτυχιών, τη σημαία κατάκτησης και τη δική σας
λανθασμένη απάντηση. Η **επισκόπηση ολοκλήρωσης σετ** είναι η
εικόνα που έλειπε: κάθε λάθος του σετ που μόλις ολοκληρώσατε, σε ένα
μέρος.

Προσβάσιμη από τις προτάσεις **Επόμενο βήμα** στο τέλος του
τελευταίου μαθήματος ενός σετ, ή από τη σελίδα του ίδιου του σετ.

---

## Τι δείχνει

- **Σύνολα** - σφάλματα και χρόνος σε όλο το σετ, όχι μόνο στο
  τελευταίο μάθημα που παίξατε.
- **Ανά μάθημα** - ποια μαθήματα του σετ παρήγαγαν τα περισσότερα
  λάθη.
- **Ανά τύπο άσκησης** - αν ένας συγκεκριμένος τύπος (ταίριασμα,
  συμπλήρωση κενών, ελεύθερο κείμενο, ...) συγκεντρώνει τα σφάλματα.
- **Αδύναμα σημεία** - τα μεμονωμένα στοιχεία που συνεχίζετε να
  κάνετε λάθος, το καθένα με την τελευταία λανθασμένη απάντησή σας
  δίπλα στη σωστή, ώστε να βλέπετε ακριβώς τι να διορθώσετε, όχι μόνο
  ότι κάτι χρειάζεται διόρθωση.

---

## Πώς λειτουργεί

Η σελίδα είναι μόνο για ανάγνωση και ανεξάρτητη αποθήκευσης: διαβάζει
τις ίδιες γραμμές που ήδη γράφουν οι συνεδρίες επανάληψής σας
(αριθμοί σφαλμάτων, σημαίες κατάκτησης) και τις περνά από ένα ενιαίο
βήμα συγκέντρωσης, οπότε οι αριθμοί ταιριάζουν ακριβώς με ό,τι ήδη
καταγράφουν η επανάληψη SRS και η μαθησιακή διαδρομή - χωρίς χωριστή
λογιστική που θα μπορούσε να αποσυγχρονιστεί.
