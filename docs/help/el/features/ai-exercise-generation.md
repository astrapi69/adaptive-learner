# Δημιουργία ασκήσεων με AI

Ένα μάθημα που αποτελείται μόνο από θεωρία (χωρίς ασκήσεις) μπορεί να
γίνει μάθημα για εξάσκηση, αν αφήσεις την AI να **δημιουργήσει
ασκήσεις** από τις κάρτες του. Αυτή είναι η pipeline EXP-036.
Χρειάζεται ένα ρυθμισμένο κλειδί AI (Ρυθμίσεις → ΤΝ)· χωρίς αυτό το
κουμπί είναι ορατό αλλά απενεργοποιημένο, με την αιτία στο tooltip του.

## Η pipeline

Η δημιουργία δεν είναι μία μόνο κλήση AI - είναι μια pipeline
**δημιουργία → πύλη ποιότητας → εξισορρόπηση → ανατροφοδότηση**:

1. **Δημιουργία.** Ένα prompt δημιουργίας ζητά από το μοντέλο ασκήσεις
   σε όλους τους υποστηριζόμενους τύπους· ένας αμυντικός αναλυτής JSON
   ανέχεται τις συνηθισμένες ιδιοτροπίες μορφοποίησης των μοντέλων.
2. **Πύλη ποιότητας.** Μια ντετερμινιστική πύλη απορρίπτει ασκήσεις
   που είναι κακοσχηματισμένες, τετριμμένες ή διπλότυπα υπαρχουσών -
   πριν καν τις δεις.
3. **Εξισορρόπηση.** Το σύνολο των παραγόμενων ασκήσεων εξισορροπείται
   ανάμεσα στους τύπους ασκήσεων, ώστε ένα μάθημα να μην έχει μόνο μία
   μορφή.
4. **Επαναδημιουργία με ανατροφοδότηση.** Αν το αποτέλεσμα δεν είναι
   σωστό, μπορείς να το δημιουργήσεις ξανά με ανατροφοδότηση, ώστε να
   κατευθύνεις την επόμενη προσπάθεια.

---

## Ανά μάθημα και ανά σύνολο

- **Μεμονωμένο μάθημα:** ένα κουμπί **«Δημιουργία ασκήσεων»** εμφανίζεται
  στα μαθήματα που έχουν μόνο θεωρία.
- **Ολόκληρο σύνολο:** η μαζική δημιουργία συμπληρώνει με μία εκτέλεση
  ασκήσεις σε κάθε μάθημα ενός συνόλου που έχει μόνο θεωρία.

---

## Ποιότητα και εμπιστοσύνη

Επειδή η πύλη ποιότητας είναι ντετερμινιστική, οι παραγόμενες ασκήσεις
πληρούν το ίδιο ελάχιστο επίπεδο με αυτές που γράφει ένας συντάκτης
(αρκετές ασκήσεις, περισσότεροι από ένας τύποι, καμία κενή κάρτα). Η
δημιουργία συμπληρώνει το περιεχόμενο των συντακτών - δεν αντικαθιστά
ποτέ σιωπηλά τις υπάρχουσες ασκήσεις σου.

Για τον έλεγχο της ποιότητας *υπάρχοντος* περιεχομένου (γραμμένου από
συντάκτη ή παραγόμενου), δες τη σελίδα
[Έλεγχος περιεχομένου με ΤΝ](../user-guide/ai-validation.md).
