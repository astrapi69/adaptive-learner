# Backup και επαναφορά

Ο Adaptive Learner μπορεί να αποθηκεύσει ολόκληρη τη μαθησιακή σου
κατάσταση σε ένα μοναδικό αρχείο και να την επαναφέρει σε άλλη
συσκευή, σε μια νέα εγκατάσταση ή μετά από αλλαγή προγράμματος
περιήγησης. Τα βρίσκεις όλα στις **Ρυθμίσεις → Δεδομένα**.

## Τι περιέχει το backup

Ένα backup είναι ένα **πλήρες snapshot**: όλοι οι πίνακες
δεδομένων (μαθησιακά έργα, sessions, πρόοδος μαθημάτων, σφάλματα
ανά στοιχείο, gamification με XP/Streak/Badges, αποστολές, κάρτες
Anki, σημειώσεις και άλλα) **συν τα κατεβασμένα Content-Sets σου**.

**Περιλαμβάνονται επίσης:** τα συνδεδεμένα content repositories, οι
εξαργυρωμένες προσκλήσεις και αν το Learning Repository είναι ενεργό.
Στη λειτουργία προγράμματος περιήγησης περιλαμβάνονται και τα
αποτελέσματα των ελέγχων περιεχομένου με ΤΝ, οπότε η ένδειξη
«Ελεγμένο με ΤΝ» διατηρείται.
**Δεν περιλαμβάνονται**, για παράδειγμα, το διακριτικό πρόσβασης
ενός ιδιωτικού repository (εισήγαγέ το ξανά μετά την επαναφορά), ο
φάκελος του Learning Repository, που ανήκει στη συσκευή, και ό,τι
αφορά μόνο αυτή τη συσκευή, όπως πρόοδος μαθημάτων και ηχογραφήσεις
φωνής που έγιναν offline σε λειτουργία διακομιστή και δεν έχουν φτάσει
ακόμα στον διακομιστή, αποθηκευμένα ευρετήρια αναζήτησης και λίστες
πολυμέσων, η καταμέτρηση του αυτόματου backup και η θέση του
συγχρονισμού LAN. Το αν το αυτόματο backup είναι ενεργό περιλαμβάνεται.
Γι' αυτό, σε λειτουργία διακομιστή, φτιάξε backup όταν η εφαρμογή είναι
ξανά online.

Πριν την εξαγωγή, η εφαρμογή εμφανίζει μια προεπισκόπηση **«Το
backup σου περιέχει …»** με αριθμό εγγραφών ανά περιοχή, ώστε να
βλέπεις πριν την αποθήκευση τι θα διασωθεί.

## Δημιουργία backup

1. Άνοιξε τις **Ρυθμίσεις → Δεδομένα**.
2. Πάτησε **Δημιουργία αντιγράφου ασφαλείας**.
3. Στον αμιγή τρόπο Browser μπορείς μέσω του File-System-Access-API
   να επιλέξεις απευθείας μια τοποθεσία αποθήκευσης («Αποθήκευση σε
   αποθηκευτικό μέσο»)· αν το πρόγραμμα περιήγησης δεν το
   υποστηρίζει, η εφαρμογή κατεβάζει αντ' αυτού το αρχείο.

**Auto-Backup:** Προαιρετικά η εφαρμογή διατηρεί ένα κυλιόμενο
δαχτυλίδι από τα τελευταία snapshots, ώστε να μην μένεις ποτέ
εντελώς χωρίς αντίγραφο ασφαλείας.

---

## Επαναφορά

1. **Ρυθμίσεις → Δεδομένα → Επαναφορά**.
2. Επίλεξε το αρχείο backup.
3. Η εφαρμογή εισάγει κάθε πίνακα και κάνει κύλιση προς τα πάνω σε
   μια **σύνοψη ανά πίνακα** (προστέθηκαν / ενημερώθηκαν /
   παραλείφθηκαν), ώστε να βλέπεις ακριβώς τι εισήχθη.

Αν κάτι πάει στραβά κατά την εισαγωγή, εμφανίζεται μια **μόνιμη
ένδειξη σφάλματος** (toast), που δεν εξαφανίζεται από μόνη της -
έτσι δεν προσπερνάς κανένα σφάλμα. Στον τρόπο προγραμματιστή
(Ρυθμίσεις > Διάγνωση και υποστήριξη) το μήνυμα περιέχει τις τεχνικές λεπτομέρειες
για ένα GitHub-Issue.

## Cross-Identity-Import

Δεν χρειάζεται **να** είσαι ο ίδιος χρήστης στην ίδια συσκευή.

- **Σε μια άδεια συσκευή**, καλύτερα να εισάγεις το backup αμέσως στην
  αρχή (δες "Backup κατά την πρώτη σύνδεση"). Η εφαρμογή τότε υιοθετεί το
  προφίλ του backup.
- **Σε μια συσκευή όπου έχεις ήδη δημιουργήσει προφίλ**, μπορείς να
  εισάγεις το backup από τις Ρυθμίσεις > Δεδομένα. Αν ανήκει σε άλλο
  προφίλ, ο διάλογος επιβεβαίωσης σού το λέει πριν από την εισαγωγή. Η
  πρόοδος του backup αντιστοιχίζεται τότε στο **ενεργό σου προφίλ** και
  συγχωνεύεται με τη δική σου: η πρόοδος των μαθημάτων, τα λάθη, οι γύροι,
  οι ηχογραφήσεις, τα έργα και το ιστορικό προστίθενται, και η δική σου
  πρόοδος διατηρείται. Τα XP, το Streak και οι ρυθμίσεις λαμβάνονται από
  το backup. Το ενεργό σου προφίλ παραμένει ενεργό· δεν δημιουργείται
  δεύτερο προφίλ.

---

## Backup κατά την πρώτη σύνδεση

Αν ξεκινήσεις την εφαρμογή εκ νέου (ή για πρώτη φορά σε μια
συσκευή), ο Adaptive Learner σου προτείνει ενεργά να εισάγεις ένα
υπάρχον backup, αντί να ξεκινήσεις με κενή κατάσταση. Έτσι, μετά
από αλλαγή συσκευής ή προγράμματος περιήγησης επιστρέφεις αμέσως
στη ροή μάθησής σου.

---

## Και οι δύο τρόποι αποθήκευσης

Το backup και η επαναφορά λειτουργούν και στους **δύο** τρόπους
αποθήκευσης - Server (API) και αμιγή Browser (Dexie/IndexedDB). Το
backup είναι ένα **αρχείο `.alb`** - ένα αρχείο ZIP που περιέχει τους
πίνακες δεδομένων, το στιγμιότυπο του localStorage και τα σετ
περιεχομένου. Τα αρχεία `.alb` γίνονται δεκτά σε κάθε σημείο εισαγωγής
backup (Ρυθμίσεις > Δεδομένα και η Επικίνδυνη ζώνη). Παλαιότερα backup
σε μορφή ενός αρχείου JSON εισάγονται επίσης κανονικά.

!!! note "Προστασία δεδομένων"
    Το backup παραμένει εξ ολοκλήρου στα χέρια σου. Αποθηκεύεται
    μόνο εκεί όπου το βάζεις - τίποτα δεν αποστέλλεται σε κάποιον
    server.
