# Backup και επαναφορά

Ο Adaptive Learner μπορεί να αποθηκεύσει ολόκληρη τη μαθησιακή σου
κατάσταση σε ένα μοναδικό αρχείο και να την επαναφέρει σε άλλη
συσκευή, σε μια νέα εγκατάσταση ή μετά από αλλαγή προγράμματος
περιήγησης. Τα βρίσκεις όλα στις **Ρυθμίσεις → Δεδομένα**.

## Τι περιέχει το backup

Ένα backup είναι ένα **πλήρες snapshot**: και οι 30 πίνακες
δεδομένων (μαθησιακά έργα, sessions, πρόοδος μαθημάτων, σφάλματα
ανά στοιχείο, gamification με XP/Streak/Badges, αποστολές, κάρτες
Anki, σημειώσεις και άλλα) **συν τα κατεβασμένα Content-Sets σου**.
Τίποτα σημαντικό δεν μένει πίσω.

Πριν την εξαγωγή, η εφαρμογή εμφανίζει μια προεπισκόπηση **«Το
backup σου περιέχει …»** με αριθμό εγγραφών ανά περιοχή, ώστε να
βλέπεις πριν την αποθήκευση τι θα διασωθεί.

---

## Δημιουργία backup

1. Άνοιξε τις **Ρυθμίσεις → Δεδομένα**.
2. Πάτησε **Δημιουργία backup**.
3. Στον αμιγή τρόπο Browser μπορείς μέσω του File-System-Access-API
   να επιλέξεις απευθείας μια τοποθεσία αποθήκευσης («Αποθήκευση σε
   αποθηκευτικό μέσο»)· αν το πρόγραμμα περιήγησης δεν το
   υποστηρίζει, η εφαρμογή κατεβάζει αντ' αυτού το αρχείο.

**Auto-Backup:** Προαιρετικά η εφαρμογή διατηρεί ένα κυλιόμενο
δαχτυλίδι από τα τελευταία snapshots, ώστε να μην μένεις ποτέ
εντελώς χωρίς αντίγραφο ασφαλείας.

---

## Επαναφορά

1. **Ρυθμίσεις → Δεδομένα → Επαναφορά**.
2. Επίλεξε το αρχείο backup.
3. Η εφαρμογή εισάγει κάθε πίνακα και κάνει κύλιση προς τα πάνω σε
   μια **σύνοψη ανά πίνακα** (προστέθηκαν / ενημερώθηκαν /
   παραλείφθηκαν), ώστε να βλέπεις ακριβώς τι εισήχθη.

Αν κάτι πάει στραβά κατά την εισαγωγή, εμφανίζεται μια **μόνιμη
ένδειξη σφάλματος** (toast), που δεν εξαφανίζεται από μόνη της —
έτσι δεν προσπερνάς κανένα σφάλμα. Στον τρόπο προγραμματιστή
(Ρυθμίσεις → Διεπαφή) το μήνυμα περιέχει τις τεχνικές λεπτομέρειες
για ένα GitHub-Issue.

---

## Cross-Identity-Import

Δεν χρειάζεται **να** είσαι ο ίδιος χρήστης στην ίδια συσκευή. Ένα
backup μπορεί να εισαχθεί σε μια **νέα εγκατάσταση** ή κάτω από ένα
**άλλο προφίλ χρήστη**. Η επαναφορά αντιστοιχίζει τα δεδομένα στο
ενεργό προφίλ και επιλύει εκ νέου καθαρά τις εσωτερικές αναφορές
(ξένα κλειδιά), ώστε η πρόοδός σου να παραμένει συνεκτική — μαζί με
την πρόοδο βημάτων μαθήματος, το Streak και τα Badges.

---

## Backup κατά την πρώτη σύνδεση

Αν ξεκινήσεις την εφαρμογή εκ νέου (ή για πρώτη φορά σε μια
συσκευή), ο Adaptive Learner σου προτείνει ενεργά να εισάγεις ένα
υπάρχον backup, αντί να ξεκινήσεις με κενή κατάσταση. Έτσι, μετά
από αλλαγή συσκευής ή προγράμματος περιήγησης επιστρέφεις αμέσως
στη ροή μάθησής σου.

---

## Και οι δύο τρόποι αποθήκευσης

Το backup και η επαναφορά λειτουργούν και στους **δύο** τρόπους
αποθήκευσης — Server (API) και αμιγή Browser (Dexie/IndexedDB). Η
μορφή είναι ένα μοναδικό αρχείο JSON· δεν υπάρχει ιδιόκτητη μορφή
αρχείου.

!!! note "Προστασία δεδομένων"
    Το backup παραμένει εξ ολοκλήρου στα χέρια σου. Αποθηκεύεται
    μόνο εκεί όπου το βάζεις — τίποτα δεν αποστέλλεται σε κάποιον
    server.
