# Adaptive Learner

**Μάθε με τον τρόπο που πραγματικά μαθαίνεις.**

Το Adaptive Learner είναι ένας ανοιχτού κώδικα μαθησιακός
συνοδός βασισμένος σε ένα ερευνητικά υποστηριζόμενο μοντέλο
έξι μεθόδων. Απαντάς σε 12 ερωτήσεις αξιολόγησης, η εφαρμογή
ανακαλύπτει ποιες μέθοδοι σου ταιριάζουν, και μετά συνεδρίες
υποστηριζόμενες από ΤΝ σε καθοδηγούν μέσα από έναν κύκλο
μάθησης επτά βημάτων. Η εφαρμογή προσαρμόζει τον τρόπο
διδασκαλίας βάσει του τρόπου που πραγματικά μαθαίνεις.
**v1.20.0**, 34 αναπτυξιακές φάσεις αποσταλμένες.

## Τι το κάνει διαφορετικό

### Έξι μέθοδοι, όχι μία

Οι περισσότερες εφαρμογές μάθησης επιλέγουν μια προσέγγιση —
κάρτες, βίντεο, gamified σερί — και υποθέτουν ότι όλοι μαθαίνουν
το ίδιο. Το Adaptive Learner παρέχει έξι μεθόδους (παραγωγική,
επαγωγική, βασισμένη στο λάθος, διαλογική, πλαισιακή,
ΤΝ-προσαρμοστική) και σε βοηθά να εναλλάσσεις μεταξύ τους
καθώς εξελίσσεσαι.

[Οι έξι μέθοδοι →](concept/six-methods.md)

### Κύκλος μάθησης επτά βημάτων

Κάθε συνεδρία προχωρά μέσα από Εισαγωγή → Απόπειρα → Λάθος →
Ανατροφοδότηση → Προσαρμογή → Επανάληψη → Ενσωμάτωση. Μια ΤΝ
διπλής προτροπής αξιολογεί ανά σειρά αν είσαι έτοιμος να
προχωρήσεις, να παραμείνεις ή να επιστρέψεις. Χωρίς κυλιόμενη
ταινία — πραγματικός γνωστικός ρυθμός.

[Ο κύκλος επτά βημάτων →](concept/seven-steps.md)

### Τοπικό-πρώτο, τροφοδοτούμενο από ΤΝ

Εναλλάσσεις μεταξύ **Τοπικής λειτουργίας** (τα πάντα στον
browser, κλήσεις ΤΝ απευθείας στο Anthropic / OpenAI / Gemini)
και **Λειτουργίας διακομιστή** (FastAPI backend). Φέρε το δικό
σου κλειδί ΤΝ. Εγκατάσταση ως PWA — λειτουργεί offline για
προηγούμενες συνεδρίες και το Ταμπλό.

[Ξεκινώντας →](user-guide/getting-started.md)

### Git για μάθηση

Οι συνεδρίες είναι commits. Τάσεις αναδύονται κατά διαστήματα
εβδομάδων. Τα σερί έχουν σημασία αλλά δεν είναι ο στόχος. Ο
στόχος είναι τα πρότυπα: ποια μέθοδος λειτουργεί για ποιο θέμα,
πού αφιερώνεις γνωστικό χρόνο, ποια αλλαγή μεθόδου ξεκλείδωσε
πρόοδο.

[Παρακολούθηση →](concept/tracking.md)

## Γρήγορη εκκίνηση

1. **Άνοιξε τη live εφαρμογή** στο
   [astrapi69.github.io/adaptive-learner](https://astrapi69.github.io/adaptive-learner/).
2. **Επέλεξε τη γλώσσα σου** + **δημιούργησε το έργο μάθησής σου**
   (θέμα, στόχος, χρονοδιάγραμμα).
3. **Κάνε την αξιολόγηση 12 ερωτήσεων** (~2 λεπτά).
4. **Πρόσθεσε το API key ΤΝ σου** (Anthropic, OpenAI ή Gemini —
   τα δωρεάν πλάνα λειτουργούν).
5. **Ξεκίνα την πρώτη σου συνεδρία** από το Ταμπλό.

[Πλήρης οδηγός εκκίνησης →](user-guide/getting-started.md)

με ρύθμιση κλειδιού βάσει αρχείου `secrets.yaml` για τη
