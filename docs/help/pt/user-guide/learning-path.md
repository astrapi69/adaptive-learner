# Percurso de aprendizagem

A página **Percurso de aprendizagem** (`/learning-path`) responde a duas
perguntas num relance: *onde estou e o que vem a seguir?* Por
predefinição mostra o percurso **Pessoal** - uma lista compacta de dois
níveis com os conjuntos de lições descarregados, ordenada pela
atividade mais recente. Como alternativa, continua disponível uma vista
interativa de **Gráfico**.

## Abrir o Percurso de aprendizagem

- Clicar em **Percurso de aprendizagem** na barra de navegação superior.
- No Painel, usar o botão de ação rápida **Percurso de aprendizagem**.
- No Navegador de conteúdo (secção Minhas lições), clicar em
  **Percurso de aprendizagem**.

## Vista pessoal (predefinição)

### Nível 1 - visão geral dos conjuntos

Cada conjunto descarregado é **uma linha**:

| Elemento | Significado |
|---------|---------|
| Ícone do domínio + título | O curso (cérebro = psicologia, bandeira = idioma, código = programação) |
| Mini trilho de progresso | Um ponto por lição - cheio = concluída, meio = em curso, vazio = não iniciada |
| Percentagem | Parte das lições do conjunto já concluídas |
| Última atividade | Quando se trabalhou pela última vez neste conjunto ("ontem", "há 3 dias") |
| Lição atual | A lição a fazer a seguir |
| Botão de ação | **Continuar** / **Começar** / **Próximo nível disponível** / **Concluído** |

Os conjuntos são ordenados pela última atividade (a mais recente
primeiro). Os conjuntos descarregados ainda não tocados descem para o
fim - e, entre esses, **o conjunto descarregado mais recentemente vem
primeiro**, de modo que um conjunto acabado de descarregar fica logo no
topo do grupo ainda não iniciado, em vez de ficar enterrado. Quando
todas as lições de um curso estão concluídas e existe o nível CEFR
seguinte, a linha oferece **Próximo nível disponível**.

### Nível 2 - detalhe das lições

Um clique numa linha de conjunto expande-a no próprio lugar (sem mudar
de página). Cada lição mostra o número e o título, as estrelas (0–3,
ou - se nunca foi tentada), o domínio por direção (**receptivo** /
**produtivo**) e a data da última tentativa. O marcador ▶ destaca a
lição atual do conjunto. Um clique em qualquer lição inicia-a ou
retoma-a.

No fundo do conjunto expandido:

- **Iniciar lição adaptativa** - uma lição gerada a partir dos erros
  cometidos neste conjunto.
- **Repetir erros (N)** - rever os erros pendentes do conjunto (só
  aparece quando os há).

Um novo clique na linha do conjunto recolhe-a.

### Apenas os meus / Todos os conjuntos

O alternador **[Apenas os meus] [Todos os conjuntos]** controla o
destaque da secção *Não baixado* no fundo. **Apenas os meus**
(predefinição) mantém-na recolhida; **Todos os conjuntos** expande-a
para que seja possível explorar e descarregar mais cursos. A escolha
fica memorizada.

### Não baixado

Uma secção recolhível no fundo lista os conjuntos de conteúdo ainda não
descarregados, cada um com um botão **Baixar**. Descarregar um conjunto
faz com que suba para a lista ativa.

## Vista de gráfico (alternativa)

Usar o seletor **Pessoal / Gráfico** no cabeçalho para abrir o gráfico
interativo com zoom. Este apresenta cada conjunto e cada lição
descarregados como nós que se podem arrastar, filtrar, pesquisar e
inspecionar. O gráfico (e a sua biblioteca de desenho, maior) só é
carregado ao mudar para ele, por isso a vista Pessoal predefinida
continua rápida.

### Nós de lição e de conjunto

Cada nó de lição mostra o número e o título, as estrelas, o domínio por
direção (**R ✓** / **P ✓**), XP, uma cor de estado, um destaque
pulsante na lição seguinte recomendada e um ícone de cadeado quando um
pré-requisito não está cumprido. Um nó de grupo de conjunto envolve as
lições de um conjunto com uma barra de progresso e um resumo do
domínio; um clique no cabeçalho recolhe-o ou expande-o.

### Controlos do gráfico

- **Filtro de estado** - todos / não iniciado / em curso / dominado.
- **Filtro de direção** - todos, ou apenas as lições sem domínio
  receptivo ou produtivo.
- **Pesquisar** - realça as correspondências; premir **Enter** salta
  para a primeira.
- **Estatísticas** - lições concluídas, receptivo dominado, produtivo
  dominado.
- **Mostrar grupos de erros** - padrões de erro partilhados (p. ex.
  *género do artigo*) com uma lição adaptativa a um clique.
- **Repor disposição** - restaura a disposição automática e apaga as
  posições arrastadas (guardadas por utilizador no armazenamento do
  navegador).

## Acesso por teclado

Todos os controlos são acessíveis por teclado: **Tab** move o foco,
**Enter / Espaço** ativa uma linha, uma lição ou um botão. As áreas de
toque têm pelo menos 44 px e a página reorganiza-se corretamente até
375 px de largura.

## Dicas

- A **lição atual** (▶) é sempre o melhor passo seguinte - com base no
  histórico de erros, não apenas na ordem das lições.
- Uma lição em pausa continua retomável a partir da sua linha ou do
  cartão de lições em pausa do Painel.
- Assim que se alcança o domínio **receptivo** e o **produtivo**, uma
  lição conta como totalmente dominada.
