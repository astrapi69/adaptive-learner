# Resumen de finalización de set

Antes, terminar cada lección de un set acababa en una tarjeta de
trofeo - "las N lecciones completadas" - y nada más, aunque la app ya
registra, por ejercicio, el número de errores, la racha, el
indicador de dominio y tu propia respuesta incorrecta. El **resumen
de finalización de set** es la imagen que faltaba: cada error del
set que acabas de terminar, en un solo lugar.

Accede desde las sugerencias de **Siguiente paso** al final de la
última lección de un set, o desde la propia página del set.

---

## Qué muestra

- **Totales** - errores y tiempo dedicado en todo el set, no solo en
  la última lección jugada.
- **Por lección** - qué lecciones del set produjeron más errores.
- **Por tipo de ejercicio** - si un tipo específico (emparejar,
  completar huecos, texto libre, ...) concentra los errores.
- **Puntos débiles** - los elementos individuales que sigues fallando,
  cada uno mostrando tu última respuesta incorrecta junto a la
  correcta, para que veas exactamente qué corregir, no solo que algo
  necesita corregirse.

---

## Cómo funciona

La página es de solo lectura e independiente del almacenamiento: lee
las mismas filas que tus sesiones de repaso ya escriben (recuentos de
errores, indicadores de dominio) y las procesa en un único paso de
agregación, así que los números coinciden exactamente con lo que ya
registran el repaso SRS y la ruta de aprendizaje - sin una
contabilidad separada que pueda desincronizarse.
