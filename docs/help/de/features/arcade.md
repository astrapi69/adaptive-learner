# Arcade

**Arcade** ist eine kleine Sammlung kurzer, gewinnbarer Minispiele,
erreichbar über eine Dashboard-Karte, sobald der **Spielmodus**
aktiv ist (Einstellungen → Lernen → Spielmodus) und der
**Arcade**-Schalter eingeschaltet ist. Ruft man die Seite direkt auf,
während der Schalter aus ist, erscheint ein freundlicher Hinweis
statt einer toten Seite - das Feature wird nie versteckt, nur mit
Begründung deaktiviert.

Arcade-Spiele geben **selbst keine XP** - sie sind eine Pause, kein
weiterer Grind. Drei der vier werden mit bereits verdienten XP
freigeschaltet.

---

## Die Spiele

| Spiel | Freischaltung | Was es ist |
|-------|---------------|------------|
| **Lern-Memory** | Kostenlos | Finde passende Begriff-/Übersetzungspaare aus deinen eigenen Lektionen - das einzige Spiel mit echtem Lerninhalt. |
| **Tic-Tac-Toe** | 100 XP | Drei in einer Reihe gegen die App - schlagbar, keine Mauer. |
| **Snake** | 200 XP | Der Klassiker: Futter sammeln, wachsen, sich nicht selbst beißen. |
| **Simon** | 300 XP | Eine wachsende Farbfolge wiederholen; die Ziellänge ist konfigurierbar. |

Die XP-Leiter ist bewusst gestaffelt: Lern-Memory ist kostenlos, weil
es weiterhin lehrt, die drei rein spielerischen Spiele kosten mehr,
je weniger Lernwert sie beitragen - das günstigste bezahlte Spiel
(Tic-Tac-Toe) liegt knapp über kostenlos, Simon ganz oben.

---

## Tickets (optional)

Wenn deine Einstellungen die **Ticket-Ökonomie** aktivieren, kostet
jede Arcade-Runde ein Ticket statt unbegrenzt zu sein. Tickets werden
über Lernleistung und Serien verdient; Guthaben und Ein/Aus-Schalter
aktualisieren sich live, wenn sie in einem anderen Tab oder in den
Einstellungen geändert werden, während Arcade offen ist.
